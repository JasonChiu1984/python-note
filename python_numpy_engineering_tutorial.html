NumPy 簡介

先把 ndarray 想清楚

NumPy 的核心不是「很多函式」，而是 homogeneous N-dimensional array：固定 dtype、固定 shape、連續或有 stride 的資料區塊，再用 C-level loop 做向量化運算。

指令說明

安裝、檢查、環境與診斷

NumPy 沒有像 Cython 那樣的主要 CLI，但工程上會反覆用 pip/conda/uv、`python -c`、`np.show_config()`、pytest 與 build 指令來驗證環境與交付。

指令 / 參數用途適用時機常見錯誤
python -m pip install numpy安裝 NumPy 到目前 Python 環境一般 venv / CI用了錯的 Python 或裝到 base 環境
conda install numpy由 conda 管理 Python 與 native library科學運算、需要 MKL/OpenBLAS/CUDA 相關依賴混用 pip/conda 造成 ABI 或依賴混亂
python -c "import numpy as np; print(np.__version__)"驗證 import 與版本安裝後 smoke test只看 pip success 沒真的 import
np.show_config()檢查 BLAS/LAPACK 與 build 設定效能或部署差異排查不同平台線性代數效能差異未記錄
python -m build打包依賴 NumPy 的專案wheel / sdist release漏寫 dependencies 或 build-system
pyinstaller --onedir app.py把使用 NumPy 的工具打成執行檔內部桌面工具、CLI 交付漏掉 shared libraries 或 hidden imports
核心語法

每個語法都搭配工程範例

這章把初學常混淆的 shape、axis、broadcasting、view/copy、ufunc 與 I/O 拆開。資深專案最常見的 bug，往往不是公式錯，而是資料形狀或 copy 誤判。

詳細應用

從資料清洗到影像與金融特徵

NumPy 適合 CPU 上大量 homogeneous 資料。若資料很小、規則很複雜、I/O 才是瓶頸，就不該盲目向量化。
