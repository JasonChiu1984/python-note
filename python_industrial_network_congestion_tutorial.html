01 / ARCHITECTURE

一路上的每個節點，都有自己的速度和佇列

先分三件事：線速是每秒傳送位元數（例如 100 Mb/s 與 1 Gb/s）；吞吐量是實際每秒完成的交易／位元；延遲是單筆等多久。每次 20 位元組的輪詢仍可能等 300 ms 的從站逾時。高峰時同一出口的微突發可能塞滿緩衝，即使一分鐘平均利用率不高。

02 / CAUSE MATRIX

症狀與佐證：不要看到 timeout 就換交換器

瓶頸位置常見原因先核對的被動證據改善後要驗證
來源、PLC scan／採集輪詢間隔比設備更新還快、同一點被多系統查、CPU 通訊任務忙或排程重入scan 負載、來源時間／序號、應用 enqueue→send 等待、同點讀取頻率調整採樣與採集節奏；合併相鄰且允許的讀取範圍，別跨不支援或不同更新週期位址。
交換器出口多埠突發匯入窄 uplink、線路降到 100M、同一 QoS 佇列爭用雙端協商速度/雙工、各方向 bytes、出口佇列或 discard 增量；看時間相關，不只總累計對照備援／故障切換後可用容量；調整聚合、分流或容量時不破壞既有控制優先權。
交換器實體層線材、端子或光模組問題、雙工不符，亦可能有環路兩端介面 error、FCS/CRC、flap；分開記錄 discard；風暴時看每 VLAN 廣播／多播和拓撲事件在核可維護窗口找原因；不是每個丟棄都表示線材壞，也不是每個 FCS 都是塞車。
VLAN 與噪音大型廣播域、異常廣播／多播、未知單播泛洪或環路；trunk 仍共同占容量依 VLAN／時窗看正常基線與封包種類計數、上行負荷、環路事件按網段治理流量；VLAN 不增加實體頻寬，不會自動阻止同 VLAN 的廣播。變更須保留必要發現流量。
TCP Client 與 Server連線池排隊、反覆建連線、接收窗收縮、套接字資源、重傳、應用過早重試連線/請求耗時、已存在的 TCP retransmission／接收窗指標、服務端 pending/CPU；區分傳輸重傳與應用重送限制同時請求與期限，退避加抖動；重試不是提高容量，寫指令逾時尤其不可無條件重送。
Modbus TCP→RTU 單埠單從站慢或無回覆造成隊首阻塞；跨 TCP Client 也共用同一個 bus；短應用逾時未必取消已發送的 RTU 交易每站成功率／回覆時間、gateway queue、RTU timeout/CRC 及其他站的尾延遲按站隔離錯誤、限制重試、對連續故障設冷卻期（仍需健康檢查）；經驗證後按服務水位分 port/bus。

單鏈路全雙工應分開看雙方向利用率，兩方向比率直接加總可能誤導。設備若支援 QoS，需同時看 uplink、佇列、同 VLAN／跨 VLAN 流量與交換晶片指標，不能只看全埠平均。

04 / PASSIVE EVIDENCE

用差值與分段時間，比 CPU 體感更可靠

  • 埠速／差值：同埠同方向記錄前後 ifHCInOctets／ifHCOutOctets、間隔、協商速度；bps = Δoctets × 8 ÷ elapsed_seconds，比例再除以單方向線速。對累計器重置與回捲檢查 ifCounterDiscontinuityTime、設備 uptime 或採集世代；若無確定資料，不用負差硬展成巨量。以 SNMP 指標認定整體精確線速使用率也要考慮廠牌對 frame overhead 的計數口徑。
  • 錯誤 ≠ 丟棄：ifInErrors/ifOutErrors 是錯誤類；ifInDiscards/ifOutDiscards 可包含無錯但被丟棄的封包，並非直接證明出口佇列滿。用網管提供的 per-queue drop 或 FCS/CRC 加強判讀。
  • 應用分段：記 t_enqueue、t_dispatch、t_reply、t_commit，同一主機用單調時鐘求差；跨主機只用已同步時間分析，否則用帶相關 ID 的本機各段耗時。reply-dispatch 包含對端和路徑等候，不是純網路延遲。來源點位時間另存作 freshness，定值點應有心跳或品質判斷。
  • 尾延遲：p95/p99 要附樣本數、時窗、篩選條件和算法。下方用 nearest-rank（排序後取第 ceil(p×n) 筆），樣本少時 p99 接近最大值、容易受單筆影響；成功樣本的 p99 不包含逾時，另報丟棄／失敗率，不能將二者用一條線替代。

規範：IETF RFC 2863：介面計數器 · IETF RFC 9293：TCP／接收窗 · IETF RFC 6298：重傳定時 · Modbus.org Serial Line V1.02：單筆交易 · OPC Foundation：Sampling Interval。

05 / OFFLINE SIMULATION

一個慢站，就能拖長其他 19 站的 p95

模型每 500 ms 有一輪 20 站、輪內每 5 ms 提交一筆；一個 FIFO 單埠、最多 24 筆未完成（含執行中），正常站服務費時 20 ms，故障站服務占住 300 ms 一次，第三種情境原地再等一次 300 ms。樣本在相同虛擬時刻提交，共 12 輪、240 筆；模擬最後允許已接受項完成，不是固定觀察時間的吞吐量實測。

離線估算可先看服務預算：全健康一輪 20 × 20 = 400 ms 空間有限；一站慢 19 × 20 + 300 = 680 ms 已超過 500 ms。當限流使少部分 poll 進不了佇列，p95 仍只代表成功樣本；一定要並列 rejected 和 timeout。

"""Offline discrete-event lab. No network, device, background timing or I/O."""
import argparse
from collections import deque
from dataclasses import dataclass
import json
import math
import unittest


@dataclass(frozen=True)
class Poll:
    arrival_ms: int
    station: int


def nearest_rank(values, fraction):
    """Return the nearest-rank percentile (no interpolation)."""
    if not values or not 0 < fraction <= 1:
        raise ValueError("need samples and a quantile in (0, 1]")
    ordered = sorted(values)
    return ordered[math.ceil(fraction * len(ordered)) - 1]


def simulate(slow=False, retry=0, limit=24, rounds=12):
    """One FIFO RTU port; limit includes the in-flight request."""
    if retry not in (0, 1) or limit < 1 or rounds < 1:
        raise ValueError("invalid offline scenario")
    outstanding_finishes = deque()
    next_free = 0
    traces = []
    dropped = 0
    for cycle in range(rounds):
        for station in range(1, 21):
            # Identical offered timestamps in every scenario. Integer ms is model time.
            poll = Poll(cycle * 500 + (station - 1) * 5, station)
            while outstanding_finishes and outstanding_finishes[0] <= poll.arrival_ms:
                outstanding_finishes.popleft()
            if len(outstanding_finishes) >= limit:
                dropped += 1
                continue
            start = max(next_free, poll.arrival_ms)
            timed_out = slow and poll.station == 1
            service = 300 * (1 + retry) if timed_out else 20
            finish = start + service
            next_free = finish
            outstanding_finishes.append(finish)
            traces.append({
                "station": poll.station,
                "arrive_ms": poll.arrival_ms,
                "queue_ms": start - poll.arrival_ms,
                "service_ms": service,
                "delay_ms": finish - poll.arrival_ms,
                "timeout": timed_out,
            })
    successful = [row for row in traces if not row["timeout"]]
    latency = [row["delay_ms"] for row in successful]
    return {
        "offered": 20 * rounds,
        "completed_ok": len(successful),
        "timeout": sum(row["timeout"] for row in traces),
        "queue_rejected": dropped,
        "p95_success_ms": nearest_rank(latency, .95) if latency else None,
        "p99_success_ms": nearest_rank(latency, .99) if latency else None,
        "max_healthy_queue_ms": max((x["queue_ms"] for x in successful), default=None),
    }


class LabTests(unittest.TestCase):
    def test_nearest_rank(self):
        self.assertEqual(nearest_rank([30, 10, 20], .95), 30)
        self.assertEqual(nearest_rank([30, 10, 20], .50), 20)
        with self.assertRaises(ValueError):
            nearest_rank([], .99)

    def test_station_failure_hurts_other_stations(self):
        baseline = simulate()
        slow = simulate(slow=True)
        self.assertEqual(baseline["completed_ok"], 240)
        self.assertEqual(baseline["queue_rejected"], 0)
        self.assertEqual(baseline["timeout"], 0)
        self.assertGreater(slow["p95_success_ms"], baseline["p95_success_ms"])
        self.assertGreater(slow["timeout"], 0)

    def test_more_service_cost(self):
        self.assertGreater(simulate(slow=True, retry=1)["max_healthy_queue_ms"],
                           simulate(slow=True)["max_healthy_queue_ms"])

    def test_balanced_accounting(self):
        for slow, retry in [(False, 0), (True, 0), (True, 1)]:
            x = simulate(slow=slow, retry=retry)
            self.assertEqual(x["offered"], x["completed_ok"] + x["timeout"] + x["queue_rejected"])

    def test_bound(self):
        self.assertGreater(simulate(slow=True, limit=1)["queue_rejected"], 0)


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--self-test", action="store_true")
    args = parser.parse_args()
    if args.self_test:
        unittest.main(argv=["lab"], verbosity=2)
    else:
        print(json.dumps({
            "healthy": simulate(),
            "slow_station": simulate(slow=True),
            "slow_station_retry": simulate(slow=True, retry=1),
        }, indent=2))


if __name__ == "__main__":
    main()
