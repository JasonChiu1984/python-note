Exception groups and except*

Concurrent work can fail for several reasons at once. ExceptionGroup preserves the error structure. Each except* clause receives a matching subgroup; unmatched exceptions propagate. Do not mix except and except* in the same try or swallow all suberrors to report success.

try:
    raise ExceptionGroup("batch", [ValueError("bad input"), OSError("offline")])
except* ValueError as group:
    print("input:", len(group.exceptions))
except* OSError as group:
    print("io:", len(group.exceptions))

Structured concurrency and time budgets

TaskGroup scopes child tasks to the async with block. A non-cancellation failure normally cancels siblings, waits for cleanup, and reports errors. asyncio.timeout() converts its own cancellation into TimeoutError; catch it outside the context. Preserve cancellation when cleaning up; do not silently consume CancelledError.

import asyncio

async def job(name):
    await asyncio.sleep(0)
    return name

async def main():
    async with asyncio.timeout(1):
        async with asyncio.TaskGroup() as tasks:
            a = tasks.create_task(job("A"))
            b = tasks.create_task(job("B"))
        print(a.result(), b.result())

asyncio.run(main())

Load configuration with tomllib

tomllib parses TOML; it neither validates application fields nor writes TOML. Open files in binary mode for load(), or use loads() for strings. Boolean values are a subclass of int in Python, so validate explicitly where true is not an acceptable integer.

import tomllib

data = tomllib.loads("workers = 4")
workers = data.get("workers")
if type(workers) is not int or not 1 <= workers <= 32:
    raise ValueError("workers must be 1..32")
print(workers)
# File input: with open("config.toml", "rb") as f: data = tomllib.load(f)

Traceback spans and exception notes

Python 3.11 tracebacks can highlight the failing subexpression on a line. Use add_note() for operational context, not tokens or full requests. Consider -X no_debug_ranges when fine-grained range metadata is unwanted; that option does not suppress errors.

try:
    {"worker": None}["worker"]["name"]
except TypeError as exc:
    exc.add_note("Validate the worker record at the input boundary.")
    raise

Typing: Self and TypedDict

Self preserves the current class type in fluent methods. Required and NotRequired express whether individual TypedDict keys must exist. These hints do not validate external inputs at runtime. See PEP 646 for TypeVarTuple.

from typing import NotRequired, Self, TypedDict

class Config(TypedDict):
    workers: int
    label: NotRequired[str]

class Queue:
    def add(self, item: str) -> Self:
        print(item)
        return self

Performance and migration checks

CPython specializes some bytecode operations adaptively. What’s New reports around 1.25× average speedup on its benchmark suite, not a guarantee for your app. Measure warmed-up latency, throughput, and memory on representative inputs. Python 3.10 cannot parse except*, even behind a version guard in the same file. Use a separate module or raise the minimum Python version, and test native wheels and deployment platforms independently.
