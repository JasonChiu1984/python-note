Part 1 | Core syntax and the standard library

C01｜Blocks and names

A colon starts a compound statement; indentation defines its suite. Bind a name before reading it; if does not create a scope.

ready = True
if ready:
    state = "online"
assert state == "online"

Mixing tabs and spaces can trigger TabError; do not depend on names bound only on one branch. Expected state: online.

C02｜Numbers, text, f-strings and bytes

Text and bytes are distinct: encode and decode explicitly at I/O boundaries. A format spec changes display, not the float itself; 3.11 still has pre-PEP 701 f-string rules.

temperature = 24.5
line = f"temperature={temperature:.1f}"
wire = line.encode("utf-8")
assert wire.decode("utf-8") == "temperature=24.5"

Do not concatenate bytes and str; explicit UTF-8 avoids platform defaults. Expected decoded value: temperature=24.5.

C03｜Binding, mutability and copies

Assignment does not copy. A shallow copy copies only the outer container; explicitly rebuild or deep-copy nested data when isolation is required.

from copy import deepcopy
original = {"points": [1]}
alias, shallow, deep = original, original.copy(), deepcopy(original)
alias["points"].append(2)
assert shallow["points"] == [1, 2] and deep["points"] == [1]

Copying the outer dict does not isolate the inner list. Both original aliases see [1, 2]; the deep copy retains [1].

C04｜Operators and precedence

Parenthesize policy expressions; is tests identity, == equality. Chained comparisons evaluate intermediate operands once; and/or short-circuit and may return an operand.

value = 24
enabled = True
assert enabled and (18 <= value < 30)
assert (2 + 3 * 4, (2 + 3) * 4, -7 // 3) == (14, 20, -3)
assert (None is None) and (0 or "default") == "default"

Negative floor division rounds down, not toward zero: -7 // 3 is -3. Do not use is for string contents.

C05｜Containers, slicing, unpacking and comprehensions

A list preserves order, a set deduplicates, and a dict maps keys to values. Unpacking splits a sequence. In 3.11 flatten with two for clauses, not 3.15 starred comprehensions.

batches = [[1, 2], [2, 3]]
flat = [value for batch in batches for value in batch]
first, *middle, last = flat
assert (first, middle, last) == (1, [2, 2], 3)
assert flat[::2] == [1, 2] and set(flat) == {1, 2, 3}
assert {str(i): i*i for i in range(3)}["2"] == 4

A set does not promise presentation order; the list carries ordering. Expected flattened list [1, 2, 2, 3], slice [1, 2].

C06｜if, match, loops and loop else

match uses the first matching pattern with no fall-through; a bare name may capture. A for loop’s else runs only when no break occurs.

def classify(message):
    match message:
        case {"kind": "alarm", "value": n} if n > 30:
            return "alarm"
        case _:
            return "normal"
for value in [20, 24]:
    if value > 30:
        break
else:
    assert classify({"kind": "alarm", "value": 35}) == "alarm"

Do not read loop else as part of each iteration. No break occurs; else checks alarm classification.

C07｜Function parameters and interfaces

Parameters before / are positional-only; named parameters after * or *args are keyword-only. Defaults are evaluated at definition time; avoid shared mutable defaults.

def metric(name, /, *samples, unit="C", **tags):
    return name, sum(samples), unit, tags
assert metric("T10", 20, 4, unit="C", zone="A") == (
    "T10", 24, "C", {"zone": "A"}
)

metric(name="T10") does not satisfy this interface. Do not let arbitrary extra tags hide standard fields. Expected result is ('T10', 24, 'C', {'zone': 'A'}).

C08｜LEGB, closures and decorators

Python searches local, enclosing, global, and builtin scopes. Closures retain enclosing bindings; functools.wraps preserves wrapped function metadata.

from functools import wraps
def with_offset(offset):
    def decorate(fn):
        @wraps(fn)
        def measured(value):
            return fn(value) + offset
        return measured
    return decorate
@with_offset(2)
def read(value):
    return value
assert read(20) == 22 and read.__name__ == "read"

Closures created in loops may late-bind the outer variable; use a factory or a default argument for a snapshot. Expected read(20)=22 and original name read.

C09｜Classes, dataclasses and object protocols

dataclass generates boilerplate such as initialization and comparison; frozen does not recursively freeze nested objects. Dunder methods implement protocols such as len.

from dataclasses import dataclass
@dataclass(frozen=True, slots=True)
class Series:
    values: tuple[float, ...]
    def __len__(self):
        return len(self.values)
assert len(Series((20.0, 21.0))) == 2

Do not mistake frozen for a security boundary. Here tuple storage gives length 2; a list inside it would remain mutable.

C10｜Iterators, yield and yield from

iter obtains an iterator and next consumes an item. Generators produce lazily and do not rewind; yield from delegates to another iterable.

def points():
    yield "T10"
    yield from ["T11", "T12"]
it = iter(points())
assert next(it) == "T10"
assert list(it) == ["T11", "T12"] and list(it) == []

Do not share a single generator when you need repeated iteration. Here next returns T10, then T11/T12 remain, and then it is empty.

C11｜Exceptions, causes and ExceptionGroup

raise ... from ... preserves the cause. except* matches typed subgroups; unmatched errors propagate. Do not mix it with ordinary except in the same try.

try:
    try:
        int("bad")
    except ValueError as cause:
        raise RuntimeError("invalid reading") from cause
except RuntimeError as error:
    assert isinstance(error.__cause__, ValueError)
handled = []
try:
    raise ExceptionGroup("batch", [ValueError("input"), OSError("I/O")])
except* ValueError as group:
    handled.append(len(group.exceptions))
except* OSError as group:
    handled.append(len(group.exceptions))
assert handled == [1, 1]

except* is 3.11 syntax and cannot be parsed by 3.10. Each handler processes one error, so expect [1, 1].

C12｜with and contextmanager

with makes resource lifetime explicit. A contextmanager prepares before yield and cleans up in finally, including when the body raises.

from contextlib import contextmanager
events = []
@contextmanager
def reading_session():
    events.append("open")
    try:
        yield "T10"
    finally:
        events.append("close")
try:
    with reading_session() as sensor:
        assert sensor == "T10"
        raise ValueError("demo")
except ValueError:
    pass
assert events == ["open", "close"]

Do not swallow the original failure during cleanup. The intended ValueError still yields the event order open, close.

C13｜Typing and data contracts

TypedDict describes keys; NotRequired marks a key as optional, not nullable. Self describes fluent methods returning the current class; hints do not validate at runtime.

from typing import NotRequired, Self, TypedDict
class Point(TypedDict):
    name: str
    quality: NotRequired[str]
class Recorder:
    def add(self, point: Point) -> Self:
        self.last = point
        return self
assert Recorder().add({"name": "T10"}).last["name"] == "T10"

To permit a null value, write str | None as well. Omitting quality still stores T10; run mypy or Pyright separately for static checks.

C14｜Modules, imports, entry points and environments

Import executes module top-level statements; guard CLI execution. Isolate dependencies with venv and invoke -m pip through the same interpreter.

import importlib
import sys
def main():
    return importlib.import_module("math").sqrt(81)
if __name__ == "__main__":
    assert main() == 9
    assert sys.version_info >= (3, 11)

Do not insert untrusted paths into sys.path; control module sources at deployment. Expect 9 inside the guard, and no CLI run when imported.

C15｜Files, JSON and the standard library

Use Path for paths and UTF-8 explicitly for text. JSON with allow_nan=False rejects nonstandard floats; externally loaded data still needs validation.

import json
from pathlib import Path
from tempfile import TemporaryDirectory
with TemporaryDirectory() as tmp:
    path = Path(tmp) / "report.json"
    path.write_text(json.dumps({"value": 24.5}, allow_nan=False), encoding="utf-8")
    assert json.loads(path.read_text(encoding="utf-8")) == {"value": 24.5}

Do not rely on the system encoding for an artifact; version its schema. Expected round-trip value: {'value': 24.5}.

C16｜async and TaskGroup

await lets the loop serve other work while waiting. TaskGroup waits for children; a non-cancellation child error cancels unfinished siblings.

import asyncio
async def read(name):
    await asyncio.sleep(0)
    return name
async def batch():
    async with asyncio.TaskGroup() as group:
        tasks = [group.create_task(read(name)) for name in ("T10", "T11")]
    return [task.result() for task in tasks]
assert asyncio.run(batch()) == ["T10", "T11"]

Avoid time.sleep in async functions; it blocks the loop. Expect results in creation order, T10/T11, not completion order.

Ten additional boundary checks

Run each example independently. The assertions are the expected outcomes; exceptions are intentional. Download ten checks。

C01 / C03 | Names and identity

Names reference objects. A mutable default persists across calls; use a None default and create a fresh container when required.

def add(value, items=None):
    if items is None:
        items = []
    items.append(value)
    return items
assert add(2) == [2] and add(3) == [3]
C02 | Character count and byte count

Protocol and file sizes are often in bytes; a Chinese character is not one UTF-8 byte. Choose encoding at the input boundary.

text = '冰水'
wire = text.encode('utf-8')
assert (len(text), len(wire), wire.decode('utf-8')) == (2, 6, text)
C04 | Short circuit and meaningful zero

Do not use or to mean missing. A zero flow reading is valid and must not be replaced by a default.

def configured(value, fallback):
    return fallback if value is None else value
assert configured(0, 100) == 0
assert configured(None, 100) == 100
C05 | Slices and nested aliases

A list slice copies the outer list, not nested referents. Decide explicitly which levels a retained snapshot will copy.

points = [['T01', 24], ['T02', 26]]
copy = points[:]
copy[0][1] = 25
assert copy is not points and points[0][1] == 25
C06 | for…else and search exhaustion

A loop else belongs to the loop, not its last if. It runs on normal exhaustion but not after break.

def find_alarm(points):
    for name, value in points:
        if value >= 30:
            break
    else:
        return None
    return name
assert find_alarm([('T01', 20)]) is None
assert find_alarm([('T02', 31)]) == 'T02'
C07 / C13 | Annotation is not validation

Validate JSON/API data at runtime even with annotations. bool subclasses int; exclude booleans from strict sensor fields.

def samples(n: int) -> int:
    if type(n) is not int or n < 0:
        raise ValueError('invalid sample count')
    return n
assert samples(0) == 0
try:
    samples(True)
except ValueError:
    pass
else:
    raise AssertionError('accepted boolean')
C08 | Late binding in closures

A lambda looks up free variables later. Capture the current value through a default argument or a factory to avoid every callback reading the final item.

broken = [lambda: n for n in range(3)]
fixed = [lambda n=n: n for n in range(3)]
assert [f() for f in broken] == [2, 2, 2]
assert [f() for f in fixed] == [0, 1, 2]
C09 | Dataclass default factory

Mutable fields need a per-instance factory. frozen limits field reassignment; it is not deep immutability.

from dataclasses import dataclass, field
@dataclass
class Batch:
    values: list[int] = field(default_factory=list)
a, b = Batch(), Batch()
a.values.append(2)
assert b.values == []
C10 | Consuming an iterator twice

After sum exhausts an iterator, list will see nothing. Rebuild the source or materialize it if the size is acceptable.

rows = iter([10, 20])
assert sum(rows) == 30
assert list(rows) == []
C11 / C12 | Cleanup on failure

Put cleanup in finally, and propagate the error. Suppressing it can make callers report success.

from contextlib import contextmanager
state = []
@contextmanager
def resource():
    try:
        yield
    finally:
        state.append('closed')
try:
    with resource():
        raise OSError('simulated')
except OSError:
    assert state == ['closed']

Part 2 | Python 3.11 changes and migration

3.11.0 was released on 2022-10-24. It is in source-only security maintenance, scheduled through October 2027 by PEP 664. Verify distributor packages separately.

PEP 664 · What’s New 3.11

Exception groups and except*

Concurrent work can fail for several reasons at once. ExceptionGroup preserves the error structure. Each except* clause receives a matching subgroup; unmatched exceptions propagate. Do not mix except and except* in the same try or swallow all suberrors to report success.

try:
    raise ExceptionGroup("batch", [ValueError("bad input"), OSError("offline")])
except* ValueError as group:
    print("input:", len(group.exceptions))
except* OSError as group:
    print("io:", len(group.exceptions))

PEP 654

Structured concurrency and time budgets

TaskGroup scopes child tasks to the async with block. A non-cancellation failure normally cancels siblings, waits for cleanup, and reports errors. asyncio.timeout() converts its own cancellation into TimeoutError; catch it outside the context. Preserve cancellation when cleaning up; do not silently consume CancelledError.

import asyncio

async def job(name):
    await asyncio.sleep(0)
    return name

async def main():
    async with asyncio.timeout(1):
        async with asyncio.TaskGroup() as tasks:
            a = tasks.create_task(job("A"))
            b = tasks.create_task(job("B"))
        print(a.result(), b.result())

asyncio.run(main())

Load configuration with tomllib

tomllib parses TOML; it neither validates application fields nor writes TOML. Open files in binary mode for load(), or use loads() for strings. Boolean values are a subclass of int in Python, so validate explicitly where true is not an acceptable integer.

import tomllib

data = tomllib.loads("workers = 4")
workers = data.get("workers")
if type(workers) is not int or not 1 <= workers <= 32:
    raise ValueError("workers must be 1..32")
print(workers)
# File input: with open("config.toml", "rb") as f: data = tomllib.load(f)

Traceback spans and exception notes

Python 3.11 tracebacks can highlight the failing subexpression on a line. Use add_note() for operational context, not tokens or full requests. Consider -X no_debug_ranges when fine-grained range metadata is unwanted; that option does not suppress errors.

try:
    {"worker": None}["worker"]["name"]
except TypeError as exc:
    exc.add_note("Validate the worker record at the input boundary.")
    raise

PEP 657

Typing: Self and TypedDict

Self preserves the current class type in fluent methods. Required and NotRequired express whether individual TypedDict keys must exist. These hints do not validate external inputs at runtime. See PEP 646 for TypeVarTuple.

from typing import NotRequired, Self, TypedDict

class Config(TypedDict):
    workers: int
    label: NotRequired[str]

class Queue:
    def add(self, item: str) -> Self:
        print(item)
        return self

Part 3 | Async, parallelism and runtimes

Standard CPython 3.11 has a GIL, no free-threaded build and no public InterpreterPoolExecutor. Races remain possible: the GIL is not a lock for a multi-step update.

ModelUse and limits
asyncioGood for async I/O; CPU loops block the event loop.
threadsGood for blocking I/O; synchronize shared objects. GIL limits pure Python CPU work.
processesCPU work can span cores; account for startup, serialization and copies.
free-threaded / interpretersA 3.15 comparison only; not a public 3.11 route, and subinterpreters are not a security sandbox.

queue.Queue uses locks and suits threads. asyncio.Queue is not thread-safe. Measure queue time, serialization and compute separately.

from concurrent.futures import ThreadPoolExecutor
with ThreadPoolExecutor(max_workers=2) as pool:
    assert list(pool.map(abs, [-2, -3])) == [2, 3]

The offline lab also checks sibling cancellation, deadlines, and thread/process pools. With spawn, keep worker functions at module scope and use a __main__ guard.

Further practice: runnable example, field case and self-check

The 3.11 features engineering projects use most are asyncio.TaskGroup, except* and tomllib. This section combines them in one polling scenario: read a device list from TOML, poll concurrently, and handle failures by exception type.

Runnable example：TaskGroup, except* and tomllib

M01 is healthy, M02 times out and M03 refuses the connection at once. Note the output: as soon as M03 fails, TaskGroup cancels the other tasks, so M01 returns nothing even though it needs only 0.01 s, and M02 never reaches its timeout. That is TaskGroup's one-fails-all-cancel semantics.

Download example extension-example-en.py

"""Python 3.11: poll concurrently with TaskGroup, handle errors by type with except*, read config with tomllib (needs 3.11+)."""
import asyncio
import tomllib

CONFIG = tomllib.loads("""
[poll]
timeout_s = 0.05
[[device]]
name = "M01"
delay = 0.01
[[device]]
name = "M02"
delay = 0.2
[[device]]
name = "M03"
delay = -1
""")


async def read(dev):
    if dev["delay"] < 0:
        raise ConnectionRefusedError(f"{dev['name']} refused the connection")
    async with asyncio.timeout(CONFIG["poll"]["timeout_s"]):
        await asyncio.sleep(dev["delay"])
    return dev["name"], 22.5


async def main():
    results = {}
    try:
        async with asyncio.TaskGroup() as tg:
            tasks = [tg.create_task(read(d)) for d in CONFIG["device"]]
    except* TimeoutError as eg:
        print(f"{len(eg.exceptions)} device(s) timed out")
    except* ConnectionError as eg:
        print("Connection errors:", [str(e) for e in eg.exceptions])
    for t in tasks:
        if t.done() and not t.cancelled() and t.exception() is None:
            results.update([t.result()])
    print("Succeeded:", results)


if __name__ == "__main__":
    print("Config:", [d["name"] for d in CONFIG["device"]], "timeout", CONFIG["poll"]["timeout_s"], "s")
    asyncio.run(main())

Field case：One device goes offline and the whole batch loses its data

A project replaced asyncio.gather with TaskGroup and found that one device refusing a connection wiped out the readings of every other device in the batch. This is by design: TaskGroup suits work that only makes sense when every part succeeds, such as the steps of one transaction.

Device polling usually wants independent results. Catch expected exceptions inside read() and return a reading with bad quality, so TaskGroup only sees real programming errors; or give each device its own TaskGroup.

  1. Decide whether a batch is all-or-nothing or independent.
  2. For independent work, handle expected exceptions (timeouts, refused connections) inside the coroutine.
  3. Use except* to handle every exception in an ExceptionGroup, not just the first.
  4. Read configuration with tomllib; no third-party toml package is needed.

Exercises and self-check

  1. What is the simplest change that keeps M01's result?

    Show answer

    Catch ConnectionError and TimeoutError inside read() and return something like (name, None) instead of raising. TaskGroup then has no reason to cancel the other tasks.

  2. If M03's delay becomes 0.03 (no refusal), what is printed?

    Show answer

    M01 and M03 succeed and M02 times out at 0.05 s. When TaskGroup receives the TimeoutError the other two have already finished, so their results are kept: "1 device(s) timed out" plus two successful readings.

  3. How does except* TimeoutError differ from except TimeoutError?

    Show answer

    except* matches exceptions inside an ExceptionGroup and several except* clauses can run for one group. A plain except matches a single exception and does not catch the ExceptionGroup raised by TaskGroup.

  4. Can tomllib write TOML?

    Show answer

    No, it only reads. Use a third-party package such as tomli-w to write.
