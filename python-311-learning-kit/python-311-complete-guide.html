第一部｜核心語法與標準函式庫

C01｜區塊與名稱

冒號開始複合陳述式，縮排界定區塊。先指派再讀取；if 不建立新作用域。

ready = True
if ready:
    state = "online"
assert state == "online"

混用 Tab 與空格可能觸發 TabError；不要依賴某分支才會建立的名稱。預期 state 為 online。

C02｜數值、字串、f-string 與 bytes

文字與位元組不等同：在 I/O 邊界以明確編碼轉換。格式規格控制顯示，不改變原始浮點數；3.11 仍有舊 f-string 解析限制。

temperature = 24.5
line = f"temperature={temperature:.1f}"
wire = line.encode("utf-8")
assert wire.decode("utf-8") == "temperature=24.5"

不要把 bytes 直接拼到 str；指定 UTF-8 有助跨平台。預期解碼值為 temperature=24.5。

C03｜名稱繫結、可變性與複製

賦值不複製。淺拷貝只複製外層容器；若巢狀資料必須隔離，明確重建或深拷貝。

from copy import deepcopy
original = {"points": [1]}
alias, shallow, deep = original, original.copy(), deepcopy(original)
alias["points"].append(2)
assert shallow["points"] == [1, 2] and deep["points"] == [1]

複製外層 dict 不能隔離內層 list。預期兩份讀到 [1, 2]，深拷貝仍是 [1]。

C04｜運算子與優先序

用括號表達政策；is 比身分，== 比值。比較鏈不等於在兩側各自重算；and/or 短路且可回傳運算元。

value = 24
enabled = True
assert enabled and (18 <= value < 30)
assert (2 + 3 * 4, (2 + 3) * 4, -7 // 3) == (14, 20, -3)
assert (None is None) and (0 or "default") == "default"

負數的整除向下取整，不是向零截斷；所以 -7 // 3 得 -3。不要用 is 比字串內容。

C05｜容器、切片、解包與推導式

list 保存順序、set 用於去重、dict 映射鍵值。解包能分出首尾；3.11 用雙層推導式攤平，不用 3.15 的星號推導形式。

batches = [[1, 2], [2, 3]]
flat = [value for batch in batches for value in batch]
first, *middle, last = flat
assert (first, middle, last) == (1, [2, 2], 3)
assert flat[::2] == [1, 2] and set(flat) == {1, 2, 3}
assert {str(i): i*i for i in range(3)}["2"] == 4

set 不保證顯示排序；結果的順序來自 list。預期攤平 [1, 2, 2, 3]，切片 [1, 2]。

C06｜if、match、迴圈與 else

match 套用第一個相符模式，不會向下貫穿；裸名稱可能是繫結模式。for 的 else 在未遇 break 時執行。

def classify(message):
    match message:
        case {"kind": "alarm", "value": n} if n > 30:
            return "alarm"
        case _:
            return "normal"
for value in [20, 24]:
    if value > 30:
        break
else:
    assert classify({"kind": "alarm", "value": 35}) == "alarm"

不要把 loop else 讀成每次迴圈都跑一次。此例不會 break；else 驗證告警分類。

C07｜函式參數與介面

/ 之前只能用位置傳入；* 之後只能用關鍵字。預設值在定義時求值，別把可變容器當成共用預設。

def metric(name, /, *samples, unit="C", **tags):
    return name, sum(samples), unit, tags
assert metric("T10", 20, 4, unit="C", zone="A") == (
    "T10", 24, "C", {"zone": "A"}
)

metric(name="T10") 不符合本契約；關鍵字額外資料不應掩蓋標準欄位。預期回傳 ('T10', 24, 'C', {'zone': 'A'})。

C08｜LEGB、閉包與裝飾器

Python 按區域、外層、全域、內建查找名稱。閉包保留外層繫結；用 functools.wraps 保留原函式中繼資料。

from functools import wraps
def with_offset(offset):
    def decorate(fn):
        @wraps(fn)
        def measured(value):
            return fn(value) + offset
        return measured
    return decorate
@with_offset(2)
def read(value):
    return value
assert read(20) == 22 and read.__name__ == "read"

迴圈中建立閉包時，外層變數可能晚繫結；需要快照時用工廠函式或預設參數。預期 read(20)=22，名稱仍是 read。

C09｜class、dataclass 與物件協定

dataclass 產生初始化及比較等樣板；frozen 不遞迴凍結巢狀物件。物件協定以 dunder 方法定義可使用的操作，例如 len。

from dataclasses import dataclass
@dataclass(frozen=True, slots=True)
class Series:
    values: tuple[float, ...]
    def __len__(self):
        return len(self.values)
assert len(Series((20.0, 21.0))) == 2

不要將 frozen 誤認為資料安全邊界。本例用 tuple 儲存，len 取 2；若 tuple 含 list，內層仍可變。

C10｜迭代器、yield 與 yield from

iter 取得迭代器；next 消耗下一筆。生成器延遲產值，走完不會自動重頭；yield from 可委派子迭代。

def points():
    yield "T10"
    yield from ["T11", "T12"]
it = iter(points())
assert next(it) == "T10"
assert list(it) == ["T11", "T12"] and list(it) == []

不要在需要重複讀取時共用單一 generator；此例先取 T10，再剩 T11、T12，最後為空。

C11｜例外、原因鏈與 ExceptionGroup

raise ... from ... 保存原因。except* 依型別匹配例外群組的子群，未處理者向外傳播；不和普通 except 共用同一個 try。

try:
    try:
        int("bad")
    except ValueError as cause:
        raise RuntimeError("invalid reading") from cause
except RuntimeError as error:
    assert isinstance(error.__cause__, ValueError)
handled = []
try:
    raise ExceptionGroup("batch", [ValueError("input"), OSError("I/O")])
except* ValueError as group:
    handled.append(len(group.exceptions))
except* OSError as group:
    handled.append(len(group.exceptions))
assert handled == [1, 1]

except* 是 3.11 語法，3.10 不能解析。同一次兩個 handler 各處理一筆，預期 [1, 1]。

C12｜with 與 contextmanager

with 用語法表達生命週期。contextmanager 在 yield 前準備、在 finally 清理，確保區塊內拋錯也會回收。

from contextlib import contextmanager
events = []
@contextmanager
def reading_session():
    events.append("open")
    try:
        yield "T10"
    finally:
        events.append("close")
try:
    with reading_session() as sensor:
        assert sensor == "T10"
        raise ValueError("demo")
except ValueError:
    pass
assert events == ["open", "close"]

不要在清理時吞掉原錯誤。此例故意拋出 ValueError，離開後事件順序仍是 open、close。

C13｜typing 資料契約

TypedDict 描述鍵，NotRequired 表示鍵可缺省，不等於可填 None。Self 描述回傳目前類別的鏈式方法；提示不會做執行期驗證。

from typing import NotRequired, Self, TypedDict
class Point(TypedDict):
    name: str
    quality: NotRequired[str]
class Recorder:
    def add(self, point: Point) -> Self:
        self.last = point
        return self
assert Recorder().add({"name": "T10"}).last["name"] == "T10"

若欄位接受空值，也要寫 str | None。預期省略 quality 仍能保存 T10；型別驗收另跑 mypy 或 Pyright。

C14｜模組、import、入口與環境

匯入會執行模組頂層；用入口守衛避免匯入時執行 CLI。用 venv 隔離依賴，並以同一個直譯器呼叫 -m pip。

import importlib
import sys
def main():
    return importlib.import_module("math").sqrt(81)
if __name__ == "__main__":
    assert main() == 9
    assert sys.version_info >= (3, 11)

不要自己把未知路徑放入 sys.path；匯入來源由部署控制。預期守衛內得到 9，匯入時不執行 CLI。

C15｜檔案、JSON 與標準庫

Path 處理路徑；文字顯式指定 UTF-8。JSON 以 allow_nan=False 拒絕非標準浮點，從外部載入的資料仍需驗證。

import json
from pathlib import Path
from tempfile import TemporaryDirectory
with TemporaryDirectory() as tmp:
    path = Path(tmp) / "report.json"
    path.write_text(json.dumps({"value": 24.5}, allow_nan=False), encoding="utf-8")
    assert json.loads(path.read_text(encoding="utf-8")) == {"value": 24.5}

不要以預設系統編碼寫交付檔；儲存格式應記錄 schema。預期回讀 {'value': 24.5}。

C16｜async 與 TaskGroup

await 讓事件迴圈在等待期間處理別的工作。TaskGroup 等子任務收尾；子任務非取消錯誤會取消尚未完成的同伴。

import asyncio
async def read(name):
    await asyncio.sleep(0)
    return name
async def batch():
    async with asyncio.TaskGroup() as group:
        tasks = [group.create_task(read(name)) for name in ("T10", "T11")]
    return [task.result() for task in tasks]
assert asyncio.run(batch()) == ["T10", "T11"]

不要在 async 函式裡用 time.sleep；它會阻塞整個迴圈。預期結果依建立順序 T10、T11，不是完成順序。

十個容易誤判的語法邊界

每段可獨立執行；assert 寫出預期結果，例外皆為刻意測試。 下載十項邊界實驗。

C01 / C03｜名稱與同一物件

名稱指向物件；用可變預設引數會跨呼叫累積。若每次都應該是新資料，使用 None 佔位再建容器。

def add(value, items=None):
    if items is None:
        items = []
    items.append(value)
    return items
assert add(2) == [2] and add(3) == [3]
C02｜字元與位元組長度

網路長度與儲存格式往往以 bytes 計；中文不是每字一 byte。錯誤編碼應在輸入邊界被發現。

text = '冰水'
wire = text.encode('utf-8')
assert (len(text), len(wire), wire.decode('utf-8')) == (2, 6, text)
C04｜短路與有意義的 0

不能以 or 代替『缺值』判斷。零流量是有效量測，不應被預設流量覆蓋。

def configured(value, fallback):
    return fallback if value is None else value
assert configured(0, 100) == 0
assert configured(None, 100) == 100
C05｜切片與深層別名

列表切片建立新外層但保留內層參考。若要保存可稽核快照，明確決定是否複製內層。

points = [['T01', 24], ['T02', 26]]
copy = points[:]
copy[0][1] = 25
assert copy is not points and points[0][1] == 25
C06｜for…else 尋找失敗

迴圈的 else 不是最後一次 if 的 else。正常走完才執行，遇到 break 則跳過。

def find_alarm(points):
    for name, value in points:
        if value >= 30:
            break
    else:
        return None
    return name
assert find_alarm([('T01', 20)]) is None
assert find_alarm([('T02', 31)]) == 'T02'
C07 / C13｜驗證不是型別註記

從 JSON/API 進來的資料仍要做 runtime 驗證。Python 的 bool 是 int 子類，嚴格點表欄位應把它排除。

def samples(n: int) -> int:
    if type(n) is not int or n < 0:
        raise ValueError('invalid sample count')
    return n
assert samples(0) == 0
try:
    samples(True)
except ValueError:
    pass
else:
    raise AssertionError('accepted boolean')
C08｜閉包的晚期查找

lambda 讀取的是之後查到的名稱。讓目前值成為預設引數，或寫工廠函式，以免每筆回呼都指向最後一項。

broken = [lambda: n for n in range(3)]
fixed = [lambda n=n: n for n in range(3)]
assert [f() for f in broken] == [2, 2, 2]
assert [f() for f in fixed] == [0, 1, 2]
C09｜dataclass 預設工廠

可變的欄位要由每個實例各自建立。frozen 限制欄位重新指派，不是深層不可變。

from dataclasses import dataclass, field
@dataclass
class Batch:
    values: list[int] = field(default_factory=list)
a, b = Batch(), Batch()
a.values.append(2)
assert b.values == []
C10｜迭代器重複消費

先做 sum 再轉 list，第二次會是空。若需要重讀，重新建立來源或在資料量可接受時物化。

rows = iter([10, 20])
assert sum(rows) == 30
assert list(rows) == []
C11 / C12｜失敗也要釋放資源

釋放設在 finally，例外仍應上傳給呼叫端。若吞下例外，後續服務會誤判成功。

from contextlib import contextmanager
state = []
@contextmanager
def resource():
    try:
        yield
    finally:
        state.append('closed')
try:
    with resource():
        raise OSError('simulated')
except OSError:
    assert state == ['closed']

第二部｜Python 3.11 新增與升級變更

3.11.0 正式版 2022-10-24 發布，目前僅安全修正；依 PEP 664，原始碼安全發行規劃至 2027 年 10 月。各平台發行商套件狀態另查。

PEP 664 · What’s New 3.11

例外群組與 except*

一批平行作業可能同時產生多種錯誤。ExceptionGroup 保留錯誤結構；except* 把相符的子群分派給對應處理器，未處理的部分仍向外傳播。同一個 try 不可混用 except 與 except*。不要為了顯示成功而吞掉全部子錯誤。

try:
    raise ExceptionGroup("batch", [ValueError("bad input"), OSError("offline")])
except* ValueError as group:
    print("input:", len(group.exceptions))
except* OSError as group:
    print("io:", len(group.exceptions))

PEP 654

結構化並行與時間預算

TaskGroup 把子任務的生命週期限制在 async with；一個子任務非取消失敗時，通常取消其他仍在執行的任務，等待收尾，再回報錯誤。asyncio.timeout() 把它自己的取消轉成 TimeoutError，請在區塊外捕捉。執行清理時保留取消語意，不要默默吞掉 CancelledError。

import asyncio

async def job(name):
    await asyncio.sleep(0)
    return name

async def main():
    async with asyncio.timeout(1):
        async with asyncio.TaskGroup() as tasks:
            a = tasks.create_task(job("A"))
            b = tasks.create_task(job("B"))
        print(a.result(), b.result())

asyncio.run(main())

用 tomllib 載入設定

tomllib 只負責解析，不會驗證業務欄位，也不支援寫入。讀檔用二進位 rb 給 load()；已有字串則用 loads()。布林值在 Python 可被視為整數子類，若組態不接受 true，請做明確的型別驗證。

import tomllib

data = tomllib.loads("workers = 4")
workers = data.get("workers")
if type(workers) is not int or not 1 <= workers <= 32:
    raise ValueError("workers must be 1..32")
print(workers)
# File input: with open("config.toml", "rb") as f: data = tomllib.load(f)

錯誤位置與附註

3.11 的 traceback 可指出一行中的失敗子運算式。用 add_note() 補操作情境，別把憑證或完整請求放入例外。若不希望儲存精細範圍資訊，可評估 -X no_debug_ranges；它不會消除例外。

try:
    {"worker": None}["worker"]["name"]
except TypeError as exc:
    exc.add_note("Validate the worker record at the input boundary.")
    raise

PEP 657

型別：Self 與 TypedDict

Self 適合鏈式方法回傳目前類別型別；Required、NotRequired 可逐欄控制 TypedDict 鍵是否必有。這些型別提示不會替你在執行期驗證外部資料。更進一步可讀 PEP 646 的 TypeVarTuple。

from typing import NotRequired, Self, TypedDict

class Config(TypedDict):
    workers: int
    label: NotRequired[str]

class Queue:
    def add(self, item: str) -> Self:
        print(item)
        return self

typing

效能與升級驗收

CPython 的自適應直譯器會專門化部分位元組碼。官方 What’s New 報告標準基準平均約 1.25 倍；不是每個程式的保證。用真實資料測暖機後延遲、吞吐與記憶體。新增 3.11 專用的 except* 會讓 3.10 無法解析該檔，不能只用 if sys.version_info 包住。用獨立檔案或提高最低版本；要發行時另外驗證原生擴充 wheel、CI 與實際部署平台。

python3.11 -m venv .venv
python3.11 python-311-lab.py
python3.11 -m compileall -q python-311-lab.py

PEP 659

3.11 → 3.15 遷移矩陣

以 3.15 筆記的相同領域追蹤，但不把更新語法倒灌進 3.11。可先在現行 3.11 跑測試，再在目標版本執行獨立的 CI。

3.15 參照領域3.11 可用做法與代價
lazy import無此宣告；可在函式內 import，仍要評估錯誤時機與依賴。
星號推導式 / starred comprehensions[x for batch in batches for x in batch]，或 itertools.chain.from_iterable。
frozendict以 MappingProxyType(dict(config)) 取得頂層唯讀檢視；不等價，也不深度凍結。
sentinelMISSING = object() 並用 is；跨程序或序列化需另外定義穩定契約。
UTF-8 預設 / default所有資產讀寫明寫 encoding="utf-8"；檢查外部編碼。
TypedDict closed / extra_items; TypeForm只用支援的 3.11 typing API；若用第三方回移植，另外鎖版並驗工具。
Tachyon / profiling用 cProfile、timeit 與實際負載；不把工具差異當成效能結論。
math.integer / immutable JSON / bytearray.take_bytes使用 math.isqrt 等既有 math API；解析後手動轉不可變資料；bytes(buffer) 是複製，不是取走。
.start / .pth3.11 無 .start；盤點 .pth 所做的啟動動作，遷移成明確應用入口。
free-threading / InterpreterPoolExecutor3.11 一般 CPython 有 GIL，無公開 interpreter pool；純 Python CPU 任務可改用程序池並量測。
3.12 PEP 695 / 701使用 TypeVar／Generic；避免需 3.12 才能解析的型別參數與 f-string。

升級前的相容性檢核

3.11 的 -P 避免把潛在不安全的目錄放到 sys.path 最前方，但不會清除所有環境路徑。高位數十進位整數轉換受直譯器設定限制；不要全域取消保護，應限制輸入大小。盤點原生擴充的 cp311 wheel 與部署架構，而不是沿用舊版 venv。

python3.11 -P -c "import sys; assert sys.flags.safe_path"

第三部｜非同步、平行與執行環境

延伸學習：實作、現場案例與自我檢查

3.11 最常被工程專案用到的是 asyncio.TaskGroup、except* 與 tomllib。本節把三者放在同一個輪詢情境：從 TOML 讀取設備清單，同時輪詢，並依例外類型分別處理。

可實跑範例：TaskGroup、except* 與 tomllib

M01 正常、M02 會逾時、M03 立即拒絕連線。注意輸出：M03 一失敗，TaskGroup 就取消其他任務，所以 M01 雖然只要 0.01 秒也沒有結果，M02 也來不及逾時。這是 TaskGroup「一個失敗、全部取消」的語意。

下載範例 extension-example.py

"""Python 3.11：TaskGroup 同時輪詢、except* 依例外類型分組處理、tomllib 讀設定（需 Python 3.11+）。"""
import asyncio
import tomllib

CONFIG = tomllib.loads("""
[poll]
timeout_s = 0.05
[[device]]
name = "M01"
delay = 0.01
[[device]]
name = "M02"
delay = 0.2
[[device]]
name = "M03"
delay = -1
""")


async def read(dev):
    if dev["delay"] < 0:
        raise ConnectionRefusedError(f"{dev['name']} 拒絕連線")
    async with asyncio.timeout(CONFIG["poll"]["timeout_s"]):
        await asyncio.sleep(dev["delay"])
    return dev["name"], 22.5


async def main():
    results = {}
    try:
        async with asyncio.TaskGroup() as tg:
            tasks = [tg.create_task(read(d)) for d in CONFIG["device"]]
    except* TimeoutError as eg:
        print(f"逾時 {len(eg.exceptions)} 台")
    except* ConnectionError as eg:
        print("連線錯誤：", [str(e) for e in eg.exceptions])
    for t in tasks:
        if t.done() and not t.cancelled() and t.exception() is None:
            results.update([t.result()])
    print("成功：", results)


if __name__ == "__main__":
    print("設定：", [d["name"] for d in CONFIG["device"]], "逾時", CONFIG["poll"]["timeout_s"], "s")
    asyncio.run(main())

工程現場案例：一台設備離線，整批輪詢都沒有資料

某專案把 asyncio.gather 改成 TaskGroup 後，發現只要一台設備拒絕連線，同一批其他設備的讀值全部消失。這不是錯誤，而是 TaskGroup 的設計：適合「全部成功才有意義」的工作，例如同一筆交易的多個步驟。

設備輪詢通常希望各自獨立：在 read() 內部捕捉例外並回傳品質為 bad 的結果，讓 TaskGroup 只處理真正的程式錯誤；或者每台設備各自一個 TaskGroup。

  1. 決定一批工作是「全有全無」還是「各自獨立」。
  2. 各自獨立的工作在協程內部處理預期內的例外（逾時、拒絕連線）。
  3. 用 except* 依類型處理 ExceptionGroup，避免只看第一個例外。
  4. 設定檔改用 tomllib 讀取，不再需要第三方 toml 套件。

練習題與自我檢查

  1. 要讓 M01 的結果保留下來，最簡單的改法是什麼？

    看解答

    在 read() 內用 try/except 捕捉 ConnectionError 與 TimeoutError，回傳 (name, None) 之類的結果而不是丟出例外。TaskGroup 就不會取消其他任務。

  2. 如果把 M03 的 delay 改成 0.03（不再拒絕連線），輸出會變成什麼？

    看解答

    M01 與 M03 成功，M02 在 0.05 秒逾時。TaskGroup 收到 TimeoutError 後取消其他任務，但此時 M01、M03 已經完成，結果仍會保留；輸出「逾時 1 台」與兩台的成功結果。

  3. except* TimeoutError 與 except TimeoutError 有何不同？

    看解答

    except* 用來匹配 ExceptionGroup 內的例外，可以同時進入多個 except* 區塊；一般 except 只匹配單一例外，對 TaskGroup 丟出的 ExceptionGroup 不會生效。

  4. tomllib 可以寫入 TOML 嗎？

    看解答

    不行，tomllib 只能讀取。需要寫入時使用第三方套件，例如 tomli-w。
