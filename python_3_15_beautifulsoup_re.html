              PEP 810
              
⚡ 顯式延遲匯入 (lazy import)

            

            縮短啟動時間
          

          

            

              

                
舊寫法 (≤ 3.14)

from bs4 import BeautifulSoup
# 啟動即載入全部重型模組

              

              

                
新寫法 (Python 3.15)

                
lazy import re
lazy from bs4 import BeautifulSoup
# 首次呼叫函式才真正載入

              PEP 798
              
📦 推導式內解包 (Unpacking)

            

            一行攤平巢狀資料
          

          

            

              

                
舊寫法 (≤ 3.14)

                
flat = [x for r in rows for x in r]
merged = {k: v for d in ds for k, v in d.items()}

              

              

                
新寫法 (Python 3.15)

                
flat = [*r for r in rows]
merged = {**d for d in ds}
