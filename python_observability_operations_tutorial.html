01 / OBSERVE

先設計要驗證的使用者結果，再選監控點

以「機房歷史資料 API」為例，使用者真正需要的不是 HTTP 200，而是取得可用且新鮮的資料。範例定義合格請求：受支援的查詢流程；良好事件：回應成功、資料通過契約、來源年齡不超過 60 秒。這個秒數是教學假設，不是設備規格。預期的使用者輸入錯誤要依事先約定分類；服務端過載、錯誤降級、逾時不能無聲排除。另設延遲 SLI，不讓平均值掩蓋 p95／p99。

訊號看什麼常見誤判與控制
Metrics合格與壞事件數、延遲直方圖、在途量／佇列深度、exporter 失敗。維度用服務、路由模板、結果與版本的可控集合；不要將 request ID、原始 URL、點位 ID 放進高基數標籤。合併直方圖以相容桶為前提，不直接平均每台的 p95。
結構化 Logs事件、時間、level、服務、版本、範圍、結果、trace_id 或關聯鍵。區分設備來源時間及採集時間，對時或標示不可信；祕密與個資不進標籤或日誌。限制存取、保留期、輸出大小與記錄頻率。
Traces沿 API → DB／佇列／閘道找等待與錯誤；在同信任邊界傳遞必要 context。抽樣 trace 不做準確錯誤分母；故障常見時評估尾端抽樣的容量與遺失。Span 缺失可能是未插樁、抽樣或傳送中斷，不表示呼叫沒發生。
主動探測由外側發起合成讀取，驗證身分、契約與資料新鮮度。獨立監測採集、規則、轉送及通知的端到端心跳。探測失聯或無資料要標「未知」，不是 0 錯誤；可另走第二條告警通道。

訊號不能拖垮主服務：SDK 或 Collector 使用有界佇列、匯出重試與逾時；監控丟棄量及最舊未匯出年齡。重要紀錄若有不可遺失要求，另建耐久路徑，不用一般 Best-effort 遙測承諾稽核保存。

探針分工：startup 判斷服務何時結束啟動階段；readiness 判斷目前是否可由平台導入流量；liveness 只判斷重啟是有效補救的本身卡死。共用下游故障時，不要以 liveness 使所有服務重啟；readiness 也不能對每個可選依賴一律拒絕，須依服務模式驗證降級能力。OT 場景只觀察 PLC／DDC 的停機與連鎖，不從告警平台越權操作設備。

02 / ALERT

告警門檻要能換算成錯誤預算與行動

算例：目標 SLO 為 30 天 99.9%，容許壞事件比例 0.001。若過去 1 小時有 100,000 筆合格請求、1,500 筆壞事件，錯誤率 1.5%，燃燒速率 0.015 ÷ 0.001 = 15×。在流量大致均勻的簡化下，若維持 1 小時，約消耗 15 × 1 ÷ 720 = 2.08% 的 30 天預算；實際期間占比須算壞事件數 ÷ 全期間允許壞事件數，不能假定流量恆定。

目的示例條件預期動作
快速呼叫值班同時 1 h 和 5 min 超過 14.4×；或已有獨立可確認的服務中斷。依既定選路通知責任人，附客戶影響、圖表、變更紀錄、runbook。
持續惡化同時 6 h 和 30 min 超過 6×；或慢速長窗持續消耗預算。依業務時限分流值班或工單，避免所有預警都叫人。
未知／低流量分母太小、零流量，或沒有新樣本。不可除以零或填 0。使用足量門檻、獨立合成探測或適合低流量服務的 SLI。

同一組雙窗口用 AND，不同嚴重度分支視規則組合；14.4× 與 6× 是教學範例，並非通用政策。Alertmanager 分組、路由與抑制是通知層，不會讓底層錯誤消失。維護靜音要有期限、負責人及稽核；恢復由資料驗證，不由按下靜音判定。

一則能執行的告警：「歷史趨勢 API 新鮮度 SLO，1 h／5 min 燃燒速率均超過 14.4×；影響趨勢查詢，不代表現場控制已失效。檢查來源年齡、佇列和最新版本時間；依 runbook 分流，回復前重跑外側合成探測。」

03 / RECOVER

先縮小影響，再做回復；不要把重啟當成驗收

  1. 建立事故：確認影響範圍、時間窗口與現場安全，指派事故指揮、執行人、紀錄與通報人；凍結非必要變更，保存版本、可重現現象與原始時間線。
  2. 確認影響位置：用外側探測和 SLI 找出症狀，再以 log／trace 定位。從資料來源、閘道、持久化、API 依序查最後成功時間及各段延遲；同時比對近期發布、設定、配額或設備變更。相關不等於因果。
  3. 選可逆止血：先試依規則限流、關閉非必要功能、隔離壞副本、停止推出新版本；已得到授權才能依 runbook 切換。標記 stale 或 unavailable，不用快照冒充新資料。對疑似資安事件先照資安程序保全證據及隔離，不任意清理。
  4. 回復與對帳：確認前版可讀現有 schema、資料未被不可逆轉換，再切回；不相容就走經演練的向前修補或依組織核准程序還原。復原後驗證寫入、佇列積壓、資料缺口及重放去重；安全與原地保護機制不因 IT 回復而解除。
  5. 分段回流：用少量流量或合成探測確認質量，觀察至少跨過依賴與告警判定窗口再擴大。檢查 SLI、延遲、資料來源年齡、待處理佇列及對帳誤差。任一未達門檻就停止擴量、回到止血，不能僅看 HTTP 200 或容器起得來就結案。

如何算恢復：範例 RTO 30 分鐘、RPO 5 分鐘均是設計目標。若故障 10:00、關鍵服務驗收 10:18，事件到驗收耗 18 分鐘；若最後已驗證可復原狀態為 09:57，復原點距故障 3 分鐘。兩者皆在範例目標內，但仍要核對完整性、重複重放及實際資料缺口；目標不等於承諾。公開「MTTR」前先定義起點與「恢復」判定，並附分布而不只平均。

復盤輸出：影響、起訖時間、實際處置、看到的訊號、有效與失效的防線、未證實的假設；改進項要有負責人、期限、驗收測試及回查紀錄。

04 / VERIFY

演練矩陣：把可診斷、可告警、可回復寫成驗收條件

隔離環境演練何時算通過保留證據
資料凍結但 API 仍回 200新鮮度 SLI 變壞；消費端明確顯示舊資料；不誤觸發安全設備動作。來源／採集／讀取時間、同一查詢及告警時間線。
Collector 或通知通道中斷失聯可由獨立心跳發現；遙測不得造成主流量堵塞；恢復後可量測丟棄與積壓。主服務 p95、遙測掉量、獨立通知送達及回復紀錄。
發行後依賴超時或錯誤率上升短窗／長窗路由正確；runbook 能查出責任層，止血不擴大影響。版本對比、測試注入時間、告警接收回執、停損證據。
還原／重放在演練目標內回復；補播、重複事件及資料缺口以獨立查詢核對。備份識別、實際還原起訖、保留的復原點、對帳筆數與差額。

相關規格：OpenTelemetry 訊號 · Collector 韌性 · Kubernetes 探針 · Google SRE：SLO 告警 · Prometheus：Alertmanager · Google SRE：事故應對 · NIST：資安事故回應（另類場景）。

Logging

先讓每個事件可搜尋、可串聯、可保護敏感資訊

好的 log 不是多，而是能回答誰、何時、哪個 request、哪個版本、哪個 dependency 壞掉。

Metrics

Metrics 要支援告警與 SLO，不只是 dashboard

request count、error rate、latency 與 dependency timeout 是最小可用訊號。

Tracing

Trace 把單一 request 的跨邊界行為串起來

當 API、DB、cache、queue 都在不同層，trace id 是事件定位的主線。

Health

健康檢查要區分活著、可接流量與依賴降級

process alive 不代表服務可用；dependency failure 也不一定代表要重啟程序。

SLO

SLO 把維運討論從感覺改成門檻與證據

告警應該連到使用者影響、錯誤預算與可執行 runbook。

Incident

事故處理要留下時間線、決策與回復證據

好的 incident record 能讓團隊下次更快定位，而不是只留下聊天截圖。

from __future__ import annotations

import json
import os
import pathlib
import subprocess
import sys


ROOT = pathlib.Path(__file__).resolve().parents[1]
SRC = ROOT / "src"
TESTS = ROOT / "tests"


def run(command: list[str]) -> None:
    subprocess.run(command, cwd=ROOT, check=True)


def main() -> int:
    env = dict(os.environ)
    env["PYTHONPATH"] = str(SRC)
    py_files = [str(path) for path in SRC.rglob("*.py")]
    py_files += [str(path) for path in TESTS.rglob("*.py")]
    py_files.append(str(pathlib.Path(__file__).resolve()))
    run([sys.executable, "-m", "py_compile", *py_files])
    subprocess.run([sys.executable, "-m", "unittest", "discover", "-s", str(TESTS), "-v"], cwd=ROOT, env=env, check=True)
    output = subprocess.check_output(
        [sys.executable, "-m", "observability_operations.demo"],
        cwd=ROOT,
        env=env,
        text=True,
    )
    payload = json.loads(output)
    assert payload["metrics"]["requests_total"] == 2
    assert payload["health"]["live"] == "ok"
    assert "slo" in payload
    print("observability smoke passed: logs + metrics + health + SLO")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

from __future__ import annotations

import json

from .service import ObservedService
from .telemetry import TelemetryCollector


def main() -> int:
    collector = TelemetryCollector()
    service = ObservedService(collector)
    service.handle_request("/orders", trace_id="demo-trace-1", dependency_latency_ms=42)
    service.handle_request("/orders", trace_id="demo-trace-2", dependency_latency_ms=135)
    health = service.health_report(dependency_latency_ms=135, dependency_ok=True)
    result = {
        "logs": collector.logs,
        "spans": collector.spans,
        "metrics": collector.metrics_snapshot(),
        "health": health,
        "slo": collector.evaluate_slo(max_error_rate=0.6, max_average_latency_ms=200),
    }
    print(json.dumps(result, ensure_ascii=False, indent=2, sort_keys=True))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

from __future__ import annotations

from dataclasses import dataclass


@dataclass(frozen=True)
class DependencyState:
    name: str
    ok: bool
    latency_ms: float
    timeout_ms: float = 100.0

    @property
    def timed_out(self) -> bool:
        return self.latency_ms > self.timeout_ms


def build_health_report(dependencies: list[DependencyState]) -> dict[str, object]:
    failed = [item for item in dependencies if not item.ok or item.timed_out]
    degraded = [item for item in dependencies if item.ok and item.latency_ms > item.timeout_ms * 0.75]
    return {
        "live": "ok",
        "ready": "fail" if failed else "ok",
        "status": "degraded" if failed or degraded else "ok",
        "dependencies": [
            {
                "name": item.name,
                "ok": item.ok,
                "latency_ms": item.latency_ms,
                "timed_out": item.timed_out,
            }
            for item in dependencies
        ],
    }

from __future__ import annotations

from dataclasses import dataclass
from time import perf_counter
from typing import Any

from .health import DependencyState, build_health_report
from .telemetry import TelemetryCollector, new_trace_id


@dataclass
class ObservedService:
    telemetry: TelemetryCollector
    version: str = "v2.1.0"

    def handle_request(
        self,
        route: str,
        *,
        trace_id: str | None = None,
        dependency_latency_ms: float = 35.0,
        fail_dependency: bool = False,
    ) -> dict[str, Any]:
        trace_id = trace_id or new_trace_id()
        started = perf_counter()
        span = self.telemetry.start_span("service.handle_request", trace_id)
        self.telemetry.log("info", "request.started", trace_id, route=route, version=self.version)

        dependency_timeout = dependency_latency_ms > 100.0 or fail_dependency
        status = "ok"
        error_type = None
        response: dict[str, Any] = {"ok": True, "route": route, "trace_id": trace_id}

        if dependency_timeout:
            status = "error"
            error_type = "DependencyTimeout"
            response = {"ok": False, "route": route, "trace_id": trace_id, "error": error_type}
            self.telemetry.log(
                "error",
                "dependency.timeout",
                trace_id,
                route=route,
                dependency="orders-db",
                duration_ms=dependency_latency_ms,
                token="should-not-leak",
            )

        duration_ms = (perf_counter() - started) * 1000 + dependency_latency_ms
        self.telemetry.finish_span(span, status=status, error_type=error_type)
        self.telemetry.record_request(duration_ms, ok=not dependency_timeout, dependency_timeout=dependency_timeout)
        self.telemetry.log(
            "info",
            "request.completed",
            trace_id,
            route=route,
            duration_ms=round(duration_ms, 3),
            ok=not dependency_timeout,
        )
        return response

    def health_report(self, dependency_latency_ms: float = 35.0, dependency_ok: bool = True) -> dict[str, object]:
        dependency = DependencyState(name="orders-db", ok=dependency_ok, latency_ms=dependency_latency_ms)
        return build_health_report([dependency])

from __future__ import annotations

from dataclasses import dataclass, field
from statistics import mean
from time import perf_counter
from typing import Any
from uuid import uuid4


def new_trace_id() -> str:
    return uuid4().hex


@dataclass
class Span:
    name: str
    trace_id: str
    start_ms: float = field(default_factory=lambda: perf_counter() * 1000)
    end_ms: float | None = None
    status: str = "ok"
    error_type: str | None = None

    def finish(self, status: str = "ok", error_type: str | None = None) -> dict[str, Any]:
        self.end_ms = perf_counter() * 1000
        self.status = status
        self.error_type = error_type
        return {
            "event": "span.finished",
            "trace_id": self.trace_id,
            "span": self.name,
            "status": self.status,
            "duration_ms": round(self.end_ms - self.start_ms, 3),
            "error_type": self.error_type,
        }


@dataclass
class TelemetryCollector:
    logs: list[dict[str, Any]] = field(default_factory=list)
    spans: list[dict[str, Any]] = field(default_factory=list)
    request_latencies_ms: list[float] = field(default_factory=list)
    requests_total: int = 0
    errors_total: int = 0
    dependency_timeouts_total: int = 0

    def log(self, level: str, event: str, trace_id: str, **fields: Any) -> dict[str, Any]:
        record = {"level": level, "event": event, "trace_id": trace_id, **self._redact(fields)}
        self.logs.append(record)
        return record

    def start_span(self, name: str, trace_id: str) -> Span:
        return Span(name=name, trace_id=trace_id)

    def finish_span(self, span: Span, status: str = "ok", error_type: str | None = None) -> dict[str, Any]:
        event = span.finish(status=status, error_type=error_type)
        self.spans.append(event)
        return event

    def record_request(self, duration_ms: float, ok: bool, dependency_timeout: bool = False) -> None:
        self.requests_total += 1
        self.request_latencies_ms.append(duration_ms)
        if not ok:
            self.errors_total += 1
        if dependency_timeout:
            self.dependency_timeouts_total += 1

    def _raw_slo_values(self) -> tuple[float | None, float | None]:
        error_rate = self.errors_total / self.requests_total if self.requests_total else None
        average_latency = mean(self.request_latencies_ms) if self.request_latencies_ms else None
        return error_rate, average_latency

    def metrics_snapshot(self) -> dict[str, float | int]:
        error_rate, average_latency = self._raw_slo_values()
        return {
            "requests_total": self.requests_total,
            "errors_total": self.errors_total,
            "dependency_timeouts_total": self.dependency_timeouts_total,
            "average_latency_ms": round(average_latency, 3) if average_latency is not None else 0.0,
            "error_rate": round(error_rate, 4) if error_rate is not None else 0.0,
        }

    def evaluate_slo(self, max_error_rate: float = 0.05, max_average_latency_ms: float = 250.0) -> dict[str, Any]:
        error_rate, average_latency = self._raw_slo_values()
        if error_rate is None or average_latency is None:
            status = "no_data"
        elif error_rate <= max_error_rate and average_latency <= max_average_latency_ms:
            status = "pass"
        else:
            status = "fail"
        return {
            "slo": "request-quality",
            "status": status,
            "passed": status == "pass",
            "max_error_rate": max_error_rate,
            "max_average_latency_ms": max_average_latency_ms,
            "evaluated": {"error_rate": error_rate, "average_latency_ms": average_latency},
            "metrics": self.metrics_snapshot(),
        }

    def _redact(self, fields: dict[str, Any]) -> dict[str, Any]:
        redacted = dict(fields)
        for key in ("token", "password", "secret"):
            if key in redacted:
                redacted[key] = "***"
        return redacted

from __future__ import annotations

import unittest

from observability_operations.health import DependencyState, build_health_report
from observability_operations.service import ObservedService
from observability_operations.telemetry import TelemetryCollector


class ObservabilityOperationsTests(unittest.TestCase):
    def test_successful_request_records_log_metric_and_span(self) -> None:
        collector = TelemetryCollector()
        service = ObservedService(collector)

        response = service.handle_request("/orders", trace_id="trace-ok", dependency_latency_ms=40)

        self.assertTrue(response["ok"])
        self.assertEqual(collector.metrics_snapshot()["requests_total"], 1)
        self.assertEqual(collector.metrics_snapshot()["errors_total"], 0)
        self.assertEqual(collector.spans[0]["status"], "ok")
        self.assertEqual(collector.logs[0]["trace_id"], "trace-ok")

    def test_dependency_timeout_records_error_and_redacts_secret(self) -> None:
        collector = TelemetryCollector()
        service = ObservedService(collector)

        response = service.handle_request("/orders", trace_id="trace-timeout", dependency_latency_ms=150)

        self.assertFalse(response["ok"])
        metrics = collector.metrics_snapshot()
        self.assertEqual(metrics["errors_total"], 1)
        self.assertEqual(metrics["dependency_timeouts_total"], 1)
        error_logs = [item for item in collector.logs if item["event"] == "dependency.timeout"]
        self.assertEqual(error_logs[0]["token"], "***")

    def test_health_report_distinguishes_liveness_and_readiness(self) -> None:
        report = build_health_report([DependencyState(name="orders-db", ok=True, latency_ms=130)])

        self.assertEqual(report["live"], "ok")
        self.assertEqual(report["ready"], "fail")
        self.assertEqual(report["status"], "degraded")

    def test_slo_evaluation_fails_when_error_rate_is_too_high(self) -> None:
        collector = TelemetryCollector()
        service = ObservedService(collector)
        service.handle_request("/orders", trace_id="trace-ok", dependency_latency_ms=40)
        service.handle_request("/orders", trace_id="trace-timeout", dependency_latency_ms=180)

        slo = collector.evaluate_slo(max_error_rate=0.1, max_average_latency_ms=250)

        self.assertFalse(slo["passed"])
        self.assertGreater(slo["metrics"]["error_rate"], 0.1)


    def test_slo_with_no_samples_reports_no_data_not_pass(self) -> None:
        slo = TelemetryCollector().evaluate_slo()

        self.assertEqual(slo["status"], "no_data")
        self.assertFalse(slo["passed"])
        self.assertIsNone(slo["evaluated"]["error_rate"])
        self.assertIsNone(slo["evaluated"]["average_latency_ms"])

    def test_slo_uses_error_rate_before_display_rounding(self) -> None:
        collector = TelemetryCollector()
        for i in range(10010):
            collector.record_request(20.0, ok=i >= 501)

        slo = collector.evaluate_slo()
        self.assertEqual(slo["metrics"]["error_rate"], 0.05)
        self.assertGreater(slo["evaluated"]["error_rate"], 0.05)
        self.assertEqual(slo["status"], "fail")
        self.assertFalse(slo["passed"])

    def test_slo_uses_latency_before_display_rounding(self) -> None:
        collector = TelemetryCollector()
        collector.record_request(250.0004, ok=True)

        slo = collector.evaluate_slo()
        self.assertEqual(slo["metrics"]["average_latency_ms"], 250.0)
        self.assertGreater(slo["evaluated"]["average_latency_ms"], 250.0)
        self.assertEqual(slo["status"], "fail")
        self.assertFalse(slo["passed"])

    def test_slo_exact_limits_are_inclusive(self) -> None:
        collector = TelemetryCollector()
        for i in range(20):
            collector.record_request(250.0, ok=i != 0)

        slo = collector.evaluate_slo()
        self.assertEqual(slo["evaluated"], {"error_rate": 0.05, "average_latency_ms": 250.0})
        self.assertEqual(slo["status"], "pass")
        self.assertTrue(slo["passed"])


if __name__ == "__main__":
