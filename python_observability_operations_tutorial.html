Logging

先讓每個事件可搜尋、可串聯、可保護敏感資訊

好的 log 不是多，而是能回答誰、何時、哪個 request、哪個版本、哪個 dependency 壞掉。

Metrics

Metrics 要支援告警與 SLO，不只是 dashboard

request count、error rate、latency 與 dependency timeout 是最小可用訊號。

Tracing

Trace 把單一 request 的跨邊界行為串起來

當 API、DB、cache、queue 都在不同層，trace id 是事件定位的主線。

Health

健康檢查要區分活著、可接流量與依賴降級

process alive 不代表服務可用；dependency failure 也不一定代表要重啟程序。

SLO

SLO 把維運討論從感覺改成門檻與證據

告警應該連到使用者影響、錯誤預算與可執行 runbook。

Incident

事故處理要留下時間線、決策與回復證據

好的 incident record 能讓團隊下次更快定位，而不是只留下聊天截圖。
