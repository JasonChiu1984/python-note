## 7. Troubleshooting

| 問題 | 處理方式 |
|---|---|
| POST retry 失敗 | 加入 idempotency key 或停止 retry |
| circuit open | 檢查連續 5xx、timeout、上游維護狀態與 runbook |
| schema validation 失敗 | 確認 response 包含 `status` 與 `payload` |
| rate limit exceeded | 降低 polling interval 或調整 call budget |

## 8. Best Practices

- 外部整合要先定義 timeout 與總等待預算。
- retry 必須和 idempotency、backoff、rate limit 一起設計。
- circuit breaker 開啟時應產生 metrics、告警與 degraded 行為。
- 工業 gateway 整合要把 fail-safe 與維護流程納入交付文件。
