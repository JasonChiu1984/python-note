## 6. Troubleshooting

| 風險 | 處理方式 |
|---|---|
| beta preview lane 失敗 | 教材標示為 non-blocking readiness signal |
| workflow 範例誤放 secret | 本次範例不含 deploy token 或 production credential |
| 本機與 CI 指令不一致 | 範例以 `scripts/run_ci_gate.py` 作為共用入口 |
| coverage 被誤解為全部品質 | 教材明確說明 coverage 是風險訊號，不取代 contract test |

## 7. Best Practices

- 每個 gate 都要有風險目的、命令、阻擋規則與輸出證據。
- stable runtime lane 應阻擋 release；beta preview lane 應做相容性預警。
- release note 應引用 gate evidence，而不是只寫「CI passed」。
- 工業部署情境需把 deployment smoke、fail-safe 與 rollback note 串入 release gate。
