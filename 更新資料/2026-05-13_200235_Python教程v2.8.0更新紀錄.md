## 7. Troubleshooting

| 問題 | 處理方式 |
|---|---|
| TypedDict 未阻擋 runtime payload | 使用 `validate_payload` 做 runtime validation |
| Protocol 難以理解 | 用 `InMemoryAlarmPublisher` 示範測試替身 |
| fail-safe 沒觸發 | 檢查 `timestamp`、`status` 與 `stale_timeout_seconds` |
| type checker 導入太硬 | 先將核心 contract smoke 設為 blocking，全專案 strictness 漸進導入 |

## 8. Best Practices

- 外部 payload 與 domain model 分層處理。
- `TypedDict`、`dataclass`、`Protocol` 分別用於 payload shape、domain state、dependency boundary。
- runtime validation 保護現場輸入；static analysis 保護重構與協作。
- 工業資料契約需記錄 unit、range、timestamp、status、alarm 與 fail-safe。
