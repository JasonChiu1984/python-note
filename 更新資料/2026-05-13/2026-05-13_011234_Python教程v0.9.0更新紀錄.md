## 四、後續建議

- 若要執行範例專案 pytest，請在各範例專案資料夾執行：

```bash
python3 -m pip install -e ".[test]"
pytest -q
```

- 若要做可交付打包驗收，建議再補一輪 wheel install smoke test 與 PyInstaller onedir smoke test。
