## 1. Overview

本輪依資深工程審查結果新增「安全工程」作為第十二條 Python 教材路線。v2.1.0 已補上可觀測性與維運工程，因此 v2.2.0 聚焦 production service 的 threat model、authn/authz、input validation、secret handling、supply-chain evidence、runtime controls、audit log 與 security incident evidence。

## 6. Risk Notes

- 本輪使用標準庫建立零依賴 security baseline；尚未引入 OAuth2/OIDC、JWT rotation、pip-audit、SBOM、Sigstore、KMS 或 SIEM。
- 本輪不宣稱已把所有教材範例改成 production security stack，只新增安全工程的可執行主線。
