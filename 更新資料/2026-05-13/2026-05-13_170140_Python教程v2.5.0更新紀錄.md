## 4. 教材新增重點

- Gateway architecture、signal flow、IO mapping
- Modbus：`40001 Holding Register`、`FC03`、`FC16`、16-bit to 32-bit float conversion、word order
- OPC UA：`opc.tcp://192.168.10.20:4840`、Security=None、`ns=2;s=Boiler.SupplyTemperature`、subscription/publish、keepalive、reconnect
- BACnet/IP：object type、object instance、BBMD、foreign device、routing
- MQTT：topic naming、QoS、payload schema、store-and-forward
- Operations：timeout、retry、stale data、alarm、fail-safe、VLAN、firewall、VPN routing、SCADA isolation、maintenance handover
