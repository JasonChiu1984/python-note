## 1. Overview

本輪依資深工程審查結果新增「測試工程」作為第十條 Python 教材路線。v1.9.0 已完成高階 100 案例語意校閱，因此 v2.0.0 不再增加高階案例數，而是補上可執行、可驗收、可交付的測試品質迴路。
