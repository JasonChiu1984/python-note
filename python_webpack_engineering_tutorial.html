01 / SYSTEM BOUNDARY

webpack 是建置器，不是 Python API 伺服器

建置端

Node.js 執行 webpack，把入口及可解析的依賴轉成瀏覽器資產。建置完交付的是 HTML、JS、CSS、SVG，不是 Node.js 服務。

部署端

靜態服務送出頁面及資產；Python 處理 JSON API、身分驗證、資料品質與設備隔離。瀏覽器不可直接接工控設備。本例只送合成點位。

最容易混淆的三條路徑：output.path 是建置機上的目錄；output.publicPath 是瀏覽器抓產物的 URL 前綴；fetch('/api/reading') 則以目前網站的 origin 為準，從網站根路徑請求，跟前者沒有連動。

只做小型教材、無 npm 依賴時，先用原生 ES Modules。除非需要資產雜湊、轉譯、切包或驗收預算，否則不必為單一靜態頁引入建置鏈。

02 / COMPILATION

從 Entry 到 Emit：兩張圖，不是一個壓縮步驟

  • resolve：模組名稱、相對路徑、套件匯出條件與別名決定最後讀哪份檔。同一套件走不同入口或被安裝多份，可能拉出兩套模組；先用 stats/套件樹確認，不先調切包門檻。
  • loader 與 plugin：一般 loader normal chain 由右向左。本例 css-loader 解釋 CSS 依賴，抽取器把 CSS 寫為獨立檔；插件在 compiler/compilation hook 處理資產、最佳化與 HTML。規則 asset/resource 會產生檔案並輸出 URL；asset/inline 把內容嵌進載入它的資產；asset/source 把資產當資料；asset 依條件選擇 resource 或 inline。
  • tree shaking ≠ code splitting：前者移除可證明未使用的程式，通常仰賴靜態 ESM、正確的 sideEffects 以及正式壓縮。import './style.css' 等有副作用的匯入不可被一概標成可刪。後者讓程式切成不同載入時機，模組仍可能存在於輸出。
  • Chunk 與檔案不一定一對一：同一 chunk 可對應 JS 與 CSS；import() 通常形成非同步載入邊界，若該模組已在入口載入，就不應假定一定增加新請求。splitChunks 須達到策略門檻才會抽取共用模組，開啟不等於一定有 vendors 檔。
  • 快取分兩層：編譯的 filesystem cache 減少可重用的建置工作；瀏覽器快取依 URL 和 HTTP 標頭重用輸出。runtimeChunk: 'single' 把載入映射移出業務程式；chunk 檔名變動可影響 runtime，不能保證其他所有檔不變。

03 / DELIVERY FLOW

同一網站下，HTML、靜態檔與 API 分開處理

兩種按鈕可以獨立點擊；不要求先成功讀 API 才能開啟合成趨勢。開發時可用本例的 webpack --watch＋Python 同源服務；若另起 webpack-dev-server，可只把 /api 代理給 Python，別把開發代理當正式反向代理或安全邊界。GitHub Pages 可放靜態產物，但不會執行 serve.py。

路徑本例標頭為什麼
/field/no-cache可儲存但不可免驗證地重用；本例沒有 ETag，通常重新取得完整 HTML。正式環境可加條件請求，讓入口指向目前 release。
帶雜湊的資產public, max-age=31536000, immutable同 URL 不覆寫內容。先部署新檔再切 HTML，保留舊 chunk 供已開啟頁面。
/api/readingno-store此課的即時合成點位不應由 HTTP 快取重用。正式 API 視資料敏感度與新鮮度另訂。

const path = require('node:path');
const HtmlWebpackPlugin = require('html-webpack-plugin');
const MiniCssExtractPlugin = require('mini-css-extract-plugin');

module.exports = (env = {}, argv = {}) => {
  const production = argv.mode === 'production';
  return {
    mode: production ? 'production' : 'development',
    context: __dirname,
    entry: {dashboard: env.eager === '1' ? './src/eager.js' : './src/index.js'},
    output: {
      path: path.join(__dirname, 'dist'),
      filename: 'assets/[name].[contenthash:16].js',
      chunkFilename: 'assets/[name].[contenthash:16].js',
      assetModuleFilename: 'assets/[name].[contenthash:16][ext]',
      publicPath: '/field/',
      clean: true, // 本機獨立的 dist；不要指向部署中的共享目錄
    },
    module: {
      rules: [
        {test: /[.]css$/i, use: [MiniCssExtractPlugin.loader, 'css-loader']},
        {test: /[.]svg$/i, type: 'asset/resource'},
      ],
    },
    plugins: [
      new HtmlWebpackPlugin({template: './src/index.html'}),
      new MiniCssExtractPlugin({filename: 'assets/[name].[contenthash:16].css'}),
    ],
    optimization: {
      moduleIds: 'deterministic',
      chunkIds: 'deterministic',
      runtimeChunk: 'single',
      splitChunks: {chunks: 'all'},
    },
    devtool: production ? false : 'source-map',
  };
};

// src/ui.js
import './style.css';
import icon from './droplet.svg';

export function mount(loadReport) {
  document.querySelector('#icon').src = icon;
  const read = document.querySelector('#read');
  const report = document.querySelector('#report');
  const result = document.querySelector('#result');
  const detail = document.querySelector('#detail');
  let lastValue;
  read.addEventListener('click', async () => {
    read.disabled = true;
    try {
      const response = await fetch('/api/reading', {
        headers: {Accept: 'application/json'},
        signal: AbortSignal.timeout(3500),
      });
      if (!response.ok) throw new Error('HTTP ' + response.status);
      const data = await response.json();
      if (data.quality !== 'good' || !Number.isFinite(data.temperature_c)) {
        throw new Error('回傳資料品質或溫度格式無效');
      }
      lastValue = data.temperature_c;
      result.textContent = '合成點位：' + lastValue.toFixed(1) + ' °C';
    } catch (error) {
      result.textContent = '讀取失敗，保留最後一筆有效值：' +
        (lastValue === undefined ? '無' : lastValue.toFixed(1) + ' °C') +
        '（' + error.message + '）';
    } finally {
      read.disabled = false;
    }
  });
  report.addEventListener('click', async () => {
    report.disabled = true;
    detail.textContent = '載入摘要中';
    try {
      const {summarize} = await loadReport();
      detail.textContent = summarize([6.8, 7.1, 7.4]);
    } catch {
      detail.textContent = '摘要載入失敗，請更新頁面後再試。點位讀取不受影響。';
    } finally {
      report.disabled = false;
    }
  });
}
讀完整 Python localhost 伺服器
"""只供課堂驗證的 localhost HTTP 伺服器，不連工廠或第三方設備。"""
import argparse
import mimetypes
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path
from urllib.parse import unquote, urlsplit

DIST = Path(__file__).resolve().parent / "dist"


class Handler(BaseHTTPRequestHandler):
    def reply(self, status, body, content_type, cache):
        self.send_response(status)
        self.send_header("Content-Type", content_type)
        self.send_header("Content-Length", str(len(body)))
        self.send_header("Cache-Control", cache)
        self.send_header("X-Content-Type-Options", "nosniff")
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self):
        path = unquote(urlsplit(self.path).path)
        if path == "/api/reading":
            self.reply(200, b'{"temperature_c":7.1,"quality":"good"}',
                       "application/json", "no-store")
            return
        if path == "/field/":
            file = DIST / "index.html"
            cache = "no-cache"
        elif path.startswith("/field/assets/"):
            cached_assets = (DIST / "assets").resolve()
            file = (cached_assets / path.removeprefix("/field/assets/")).resolve()
            if file.parent != cached_assets or file.suffix == ".map":
                self.send_error(404)
                return
            cache = "public, max-age=31536000, immutable"
        else:
            self.send_error(404)
            return
        if not file.is_file():
            self.send_error(404)
            return
        kind = mimetypes.guess_type(file)[0] or "application/octet-stream"
        self.reply(200, file.read_bytes(), kind, cache)


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--port", type=int, default=8787)
    args = parser.parse_args()
    with ThreadingHTTPServer(("127.0.0.1", args.port), Handler) as server:
        server.serve_forever()

05 / MEASURE

按需載入不必然讓首頁更小

唯一變因是趨勢模組的載入方式；兩組都使用正式模式、同一套配置與合成內容。入口 JS 以 stats 的 entrypoint 資產為準；按需 JS 用其餘輸出 JS。gzip 採每檔獨立壓縮後加總，不含 CSS、SVG、標頭、實際網路延遲，也不能由此推估 LCP / INP。

配置入口 JS 原始大小入口 JS gzip延後 JS gzip
同步匯入（eager）2 檔，2,610 B1,501 B0 檔，0 B
按需載入（lazy）2 檔，3,825 B2,113 B1 檔，409 B

這個小面板不值得為趨勢切包。按需把趨勢移出初始集合，但為了定位、載入及註冊 chunk，增加 runtime 成本；這次反而多了 612 B 首批 JS。不能外推到大型圖表套件。兩次按需正式建置的完整輸出 SHA-256 一致；不代表跨 OS 與工具版本也必然一致。第二組測試只改趨勢標題：產物比對確認 HTML、runtime 和趨勢 JS 改變；入口業務 JS、CSS 與 SVG 內容不變。此結果只代表本次特定改動。

延伸實驗：① 放大趨勢模組的實際工作量，用同一工具鏈重測；② 只修改趨勢文字，對比入口、runtime、趨勢檔名以及內容 SHA-256，檢查是否因載入映射更新牽動 runtime；③ 在瀏覽器同時量冷快取與暖快取，記錄 request waterfall、傳輸量、評估時間與互動延遲；看 median 與 p95，先訂固定裝置、網路及重複次數。不要拿不同功能的網站比較 bundler 快慢。

06 / DIAGNOSIS

從症狀找證據，不先重裝套件


Chunk 404／點進才壞

Network 核對完整 chunk URL；若少 /field/，查 publicPath。若路徑正確但只在跨版本舊分頁出錯，查資產保留與 HTML/runtime 版本差；也排除 CSP、MIME、CDN 回源。不要只做無上限 reload。

API 200 卻不是 JSON

查 Response 的 Content-Type 和前幾行。反向代理若把 /api 落進 SPA fallback，可能回 HTML 200，JSON 解析才失敗。明確分開 API 路由與前端 fallback。

CSS 建置後不見

先看 stats 及 dist 有無 CSS，再查 HTML 連結與 HTTP 狀態；若根本沒產出，查 import、loader 規則及錯把 CSS 宣告無副作用。暫關壓縮只用於縮小診斷範圍，不作永久修正。

首頁 bundle 變重

先拆清楚入口與按需，再比 stats 內 module/chunk 的重複依賴及 gzip 變化。正式部署前守 entry budget；操作路徑也要守完整下載次數、主執行緒成本與錯誤率。

07 / RELEASE ENGINEERING

可追溯建置、相容發布與可回退

  1. 鎖定：固定 Node/npm 與 npm 鎖定檔；記錄 clean build 的 Git 提交、版本、檔案摘要與 stats。依賴安裝不任意執行生命週期腳本，但建置仍會執行 loader/plugin：依賴與 config 本身就是程式碼。
  2. 隔離：CI 建置用最小權限與短期憑證，禁止把 token 或私鑰傳給前端。DefinePlugin 定義值和前端任何環境設定只要進 bundle，就能被瀏覽器取得。正式 source map 若要留給錯誤追蹤，請走私有上傳與存取控管，不當作保密邊界。
  3. 先驗資產再切入口：把新檔送到獨立 release 位置並做 smoke test；檢查 HTML、JS/CSS MIME、CSP、子路徑與懶載入；之後切換。保留前版資產與相容 API，避免前後端任一方回退後打破契約。檔名雜湊是快取策略，不能替代完整性驗證；SRI 需明確覆蓋相應資產，動態 chunk 不會因 HTML 的 entry script 有 SRI 就自動受到保護。
  4. 出錯回退：先看 404、ChunkLoadError、讀點失敗比率和版本對應；將入口切回前一版。若安全事件涉及前版檔，不能盲目回退；先隔離並依事件流程撤換。

08 / TRADE-OFFS

選型：複雜度要能換到可量的成果

方案適合代價與驗證
原生 ESM靜態教學或少量同源模組，無專門轉譯需求不需要 Node 建置；瀏覽器相容性、import 路徑、快取更新仍要驗。
webpack維護已有 loader/plugin、複雜多入口、要控制 chunks 或特定資產流程設定與診斷成本較高；用同一輸入比較建置冷暖時間、輸出、瀏覽器指標。
Vite新建現代框架前端、注重開發迭代速度開發與正式建置行為必須分開驗；先以選定版本的官方設定查插件、瀏覽器目標與 base path。
