01｜資料架構與計算流程

下載可編輯的 Draw.io 架構圖與流程圖

三個常見落點：自家控制的備用發電機燃料是直接排放；向電網購入的電力是能源間接排放；外包物流、原料等價值鏈排放要另外做範疇三判定，本例不含。若有自發自用，不能把同一筆電量既算外購又算燃料；先按組織盤查邊界核對。

02｜公式與同一組月資料

排放量 kgCO₂e＝活動量 × 相容的排放係數；換成 tCO₂e 再 ÷ 1,000。若係數是各氣體的質量而非已折算的 CO₂e，要先分別計算 CO₂、CH₄、N₂O，再乘適用的 GWP100 求和。已是 CO₂e 的係數不要再乘 GWP。

排放來源公式與代入（係數皆為教學假設）結果
範疇一｜柴油800 L × 2.70 kgCO₂e/L2,160 kgCO₂e
範疇一｜冷媒逸散2.5 kg 實際逸散量 × 1,000 kgCO₂e/kg2,500 kgCO₂e
範疇二｜所在地法120,000 kWh × 0.45 kgCO₂e/kWh54,000 kgCO₂e
範疇二｜市場法40,000 kWh × 0.05 ＋ 80,000 kWh × 0.55（契約與未覆蓋電量，各自乘對應係數）46,000 kgCO₂e
合計｜選一種方法範疇一 4,660 kgCO₂e 加上其中一個範疇二值所在地法：58.66 tCO₂e；市場法：50.66 tCO₂e

活動量須能回到原始證據

  • 燃料：採用實際消耗量，採購、退料與庫存需對帳。若係數以 kg/GJ 為分母，先用適用的低位熱值把燃料換成 GJ，再逐氣體計算；不要直接乘公升。
  • 冷媒：使用按適用方法確認的逸散量，不把設備額定充填量或每張補充紀錄一律當成泄漏。台帳應區分新裝、回收、報廢與維修，辨識冷媒或混合物及對應 GWP 版本。
  • 外購電：所在地依法使用適用地理電網的平均資料；市場法按合格契約工具的證據配置，未覆蓋部分依所採指引的係數階層處理。核對時空適用、環境屬性權益和不得重複宣稱等條件。尚未確認可用係數或屬性證據時，先標待核，不自動填零。
  • 合計：兩種範疇二方法是對同一批電力的平行呈現，不是兩筆要相加的排放。市場法與所在地法的差額也不等於現場用電減少。

台灣係數示例（非本頁計算參數）：經濟部能源署 114 年度公告把公用售電業電力排碳係數列為 0.467 kgCO₂e/kWh，並區分全國電力排放係數口徑。不可依「數字最新」就套用；須確認盤查年度、適用口徑及申報制度。所在地法或法定申報應使用適合該邊界的規則。

04｜Python 實作與 API 邊界

此教材只有合成資料，不抓真實電表、不呼叫外部服務。用 Python 3.9+ 標準函式庫即可執行。下載完整 Python 程式

python python_carbon_emissions_calculation_lab.py --self-test
python python_carbon_emissions_calculation_lab.py --demo
python python_carbon_emissions_calculation_lab.py --diesel-l 800 --leaked-kg 2.5 --electricity-kwh 120000 --contracted-kwh 40000

程式內呼叫：先檢核，再由 Decimal 計算

from python_carbon_emissions_calculation_lab import calculate, as_json

report = calculate(diesel_l="800", leaked_kg="2.5",
                   electricity_kwh="120000", contracted_kwh="40000")
print(as_json(report))
# contracted_kwh=None 時，market 欄位為 null，合計也不估填。

05｜覆核清單與原始資料

  1. 每筆保留場址、期間、排放源、來源憑證、活動量與單位，活動資料變更要有原因。
  2. 每筆係數保留來源、版本、適用地區、活動量分母、涵蓋氣體、係數年度、GWP 報告版本及使用的方法；不要因為網站出新版就覆蓋歷史成果。基線重算要有已核准規則。
  3. 核對 1 MWh＝1,000 kWh、1 t＝1,000 kg，空值不得轉為 0。用對帳差異檢查多表重複或漏表；完整性不足時不要出聲稱完成的合計。
  4. 對同月份現場查兩種範疇二的用電分配，合格契約 kWh ＋ 未覆蓋 kWh 必須等於同站同期間的外購 kWh；先檢查重複憑證，再看排放差異。

此頁是組織營運排放的工程教學，不是碳足跡查證、法規適用認定或申報憑證。範疇三、抵換額度、產品生命週期與申報對象均不在算例內。
