01｜資料架構與計算流程

下載可編輯的 Draw.io 架構圖與流程圖

三個常見落點：自家控制的備用發電機燃料是直接排放；向電網購入的電力是能源間接排放；外包物流、原料等價值鏈排放要另外做範疇三判定，本例不含。若有自發自用，不能把同一筆電量既算外購又算燃料；先按組織盤查邊界核對。

02｜公式與同一組月資料

排放量 kgCO₂e＝活動量 × 相容的排放係數；換成 tCO₂e 再 ÷ 1,000。若係數是各氣體的質量而非已折算的 CO₂e，要先分別計算 CO₂、CH₄、N₂O，再乘適用的 GWP100 求和。已是 CO₂e 的係數不要再乘 GWP。

排放來源公式與代入（係數皆為教學假設）結果
範疇一｜柴油800 L × 2.70 kgCO₂e/L2,160 kgCO₂e
範疇一｜冷媒逸散2.5 kg 實際逸散量 × 1,000 kgCO₂e/kg2,500 kgCO₂e
範疇二｜所在地法120,000 kWh × 0.45 kgCO₂e/kWh54,000 kgCO₂e
範疇二｜市場法40,000 kWh × 0.05 ＋ 80,000 kWh × 0.55（契約與未覆蓋電量，各自乘對應係數）46,000 kgCO₂e
合計｜選一種方法範疇一 4,660 kgCO₂e 加上其中一個範疇二值所在地法：58.66 tCO₂e；市場法：50.66 tCO₂e

活動量須能回到原始證據

  • 燃料：採用實際消耗量，採購、退料與庫存需對帳。若係數以 kg/GJ 為分母，先用適用的低位熱值把燃料換成 GJ，再逐氣體計算；不要直接乘公升。
  • 冷媒：使用按適用方法確認的逸散量，不把設備額定充填量或每張補充紀錄一律當成泄漏。台帳應區分新裝、回收、報廢與維修，辨識冷媒或混合物及對應 GWP 版本。
  • 外購電：所在地依法使用適用地理電網的平均資料；市場法按合格契約工具的證據配置，未覆蓋部分依所採指引的係數階層處理。核對時空適用、環境屬性權益和不得重複宣稱等條件。尚未確認可用係數或屬性證據時，先標待核，不自動填零。
  • 合計：兩種範疇二方法是對同一批電力的平行呈現，不是兩筆要相加的排放。市場法與所在地法的差額也不等於現場用電減少。

台灣係數示例（非本頁計算參數）：經濟部能源署 114 年度公告把公用售電業電力排碳係數列為 0.467 kgCO₂e/kWh，並另外公布供企業排放盤查與揭露使用的「產業電力排碳係數」0.466 kgCO₂e/kWh、適用表燈非營業住宅的「民生住宅電力排碳係數」0.471 kgCO₂e/kWh，以及納入民間綠電直、轉供的全國電力排放係數口徑。企業範疇二盤查通常應先確認是否採用產業係數。不可依「數字最新」就套用；須確認盤查年度、適用口徑及申報制度。所在地法或法定申報應使用適合該邊界的規則。

05｜覆核清單與原始資料

  1. 每筆保留場址、期間、排放源、來源憑證、活動量與單位，活動資料變更要有原因。
  2. 每筆係數保留來源、版本、適用地區、活動量分母、涵蓋氣體、係數年度、GWP 報告版本及使用的方法；不要因為網站出新版就覆蓋歷史成果。基線重算要有已核准規則。
  3. 核對 1 MWh＝1,000 kWh、1 t＝1,000 kg，空值不得轉為 0。用對帳差異檢查多表重複或漏表；完整性不足時不要出聲稱完成的合計。
  4. 對同月份現場查兩種範疇二的用電分配，合格契約 kWh ＋ 未覆蓋 kWh 必須等於同站同期間的外購 kWh；先檢查重複憑證，再看排放差異。

此頁是組織營運排放的工程教學，不是碳足跡查證、法規適用認定或申報憑證。範疇三、抵換額度、產品生命週期與申報對象均不在算例內。

延伸學習：實作、現場案例與自我檢查

前面各節示範單月計算。本節把 12 個月資料彙總成年度範疇一、二，並接上 2026 年起實際開徵的碳費。

可實跑範例：年度彙總、地區／市場基礎與碳費試算

電力係數採 114 年度產業電力排碳係數 0.466；天然氣與柴油係數是教學假設值，正式盤查必須換成環境部排放係數管理表的對應版本。程式同時算地區基礎與扣除再生能源憑證後的市場基礎，兩者要分開揭露，不能互相取代。

下載範例 example.py

"""年度範疇一、二彙總與碳費試算（教學模型）。

- 範疇二採 114 年度「產業電力排碳係數」0.466 kgCO2e/kWh（經濟部能源署公告）。
- 燃料排放係數為教學假設值，正式盤查請改用環境部「溫室氣體排放係數管理表」對應年度版本。
- 碳費以一般費率每公噸 300 元、年排放量扣除 25,000 公噸後計費（碳費收費辦法）。
"""
from decimal import Decimal as D, ROUND_HALF_UP

ELECTRICITY_FACTOR = D("0.466")            # kgCO2e/kWh，114 年度產業係數
FUEL_FACTORS = {                           # kgCO2e/單位，教學假設值
    "natural_gas_m3": D("2.09"),
    "diesel_l": D("2.61"),
}

# 某廠 12 個月的活動量：電力 kWh、天然氣 m3、柴油 L（緊急發電機）
MONTHLY = [
    # (月, 電力 kWh, 天然氣 m3, 柴油 L)
    (1, 3_850_000, 182_000, 900), (2, 3_420_000, 171_000, 0),
    (3, 3_910_000, 176_500, 1_200), (4, 4_020_000, 160_200, 0),
    (5, 4_480_000, 151_000, 0), (6, 4_960_000, 140_800, 2_400),
    (7, 5_210_000, 138_400, 0), (8, 5_260_000, 139_900, 0),
    (9, 4_870_000, 145_700, 1_100), (10, 4_390_000, 156_300, 0),
    (11, 4_010_000, 168_800, 0), (12, 3_930_000, 179_600, 800),
]
GREEN_POWER_KWH = 6_000_000                # 當年度取得並註銷的再生能源憑證對應電量


def t(kg: D) -> D:
    return (kg / 1000).quantize(D("0.01"), ROUND_HALF_UP)


def annual_totals():
    kwh = sum(D(m[1]) for m in MONTHLY)
    gas = sum(D(m[2]) for m in MONTHLY)
    diesel = sum(D(m[3]) for m in MONTHLY)
    scope1 = gas * FUEL_FACTORS["natural_gas_m3"] + diesel * FUEL_FACTORS["diesel_l"]
    scope2_location = kwh * ELECTRICITY_FACTOR
    scope2_market = (kwh - GREEN_POWER_KWH) * ELECTRICITY_FACTOR
    return kwh, gas, diesel, t(scope1), t(scope2_location), t(scope2_market)


def carbon_fee(total_t: D, rate=D(300), threshold=D(25_000)):
    chargeable = max(D(0), total_t - threshold)
    return chargeable, (chargeable * rate).quantize(D("1"), ROUND_HALF_UP)


if __name__ == "__main__":
    kwh, gas, diesel, s1, s2_loc, s2_mkt = annual_totals()
    print(f"年用電 {kwh:,} kWh、天然氣 {gas:,} m3、柴油 {diesel:,} L")
    print(f"範疇一：{s1:,} tCO2e")
    print(f"範疇二（地區基礎，0.466）：{s2_loc:,} tCO2e")
    print(f"範疇二（市場基礎，扣除 {GREEN_POWER_KWH:,} kWh 憑證）：{s2_mkt:,} tCO2e")
    total = s1 + s2_loc
    print(f"範疇一＋二（地區基礎）：{total:,} tCO2e")
    chargeable, fee = carbon_fee(total)
    print(f"若適用碳費一般費率：計費排放量 {chargeable:,} t，碳費 NT$ {fee:,}")
    peak = max(MONTHLY, key=lambda m: m[1])
    print(f"用電最高月份：{peak[0]} 月，{peak[1]:,} kWh，"
          f"占全年 {(D(peak[1]) / kwh * 100).quantize(D('0.1'))}%")

工程現場案例：接近碳費門檻的工廠

範例工廠範疇一加範疇二約 2.84 萬公噸，超過 2.5 萬公噸的碳費門檻。依一般費率試算，扣除 2.5 萬公噸後的 3,385 公噸要繳約 101 萬元。電力占總排放的 86%，因此最有效的減量手段通常在空調、空壓與製程用電，而不是燃料。

以冰水系統為例：若把冰水主機的年平均 kW/RT 從 0.75 降到 0.65，在相同冷凍噸時數下，冰水主機用電約可減少 13%。這類改善要先建立量測基準（冰機電力、冰水流量與進出水溫），否則改善前後的節電量無法查證，也無法放進自主減量計畫。

  1. 從電費單與 BAS 電力監控各取一份年度用電，兩者差異超過 2% 時先查明原因（電表倍率、換表、漏抄）。
  2. 燃料用量以採購發票與庫存盤點交叉核對，緊急發電機柴油另外記錄測試運轉時數。
  3. 地區基礎與市場基礎分別計算；再生能源憑證要有註銷證明，且電量年度與盤查年度一致。
  4. 把每月排放畫成趨勢圖，標出改善措施上線日期，作為減量成效的證據。

練習題與自我檢查

  1. 把 GREEN_POWER_KWH 改成 10,000,000，市場基礎的範疇二會變成多少？為什麼地區基礎的數字不變？

    看解答

    (52,310,000 − 10,000,000) × 0.466 ÷ 1000 = 19,716.46 tCO2e。地區基礎反映實際所在電網的平均排放強度，不因購買憑證改變；憑證只影響市場基礎。兩者都要揭露。

  2. 年排放量 10 萬公噸、適用一般費率的工廠，碳費是多少？

    看解答

    (100,000 − 25,000) × 300 = 22,500,000 元。可以把範例的 carbon_fee(D(100000)) 印出來驗證。

  3. 盤查時發現 3 月電表因換表，抄表值從 998,500 跳回 1,200。程式應該怎麼處理？

    看解答

    不能直接相減（會得到負值）。要以換表紀錄分段計算：舊表最後讀值減上期讀值，加上新表讀值減新表起始值，並乘上各自的倍率。在程式中應偵測負差值並要求輸入換表紀錄，而不是自動取絕對值。

  4. 為什麼範例把係數集中放在 ELECTRICITY_FACTOR 與 FUEL_FACTORS 常數，而不是寫在計算式裡？

    看解答

    係數每年公告一次，且要能追溯版本。集中管理才能在報表上標示採用的年度與來源，係數更新時也只改一處；更好的做法是把係數和年度、來源網址一起存成資料檔。
