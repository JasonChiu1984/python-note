Python Architecture Governance

把大型 Python 專案的結構做成可治理資產

很多 Python 專案早期能快速交付，後期卻在重構時持續失控：模組責任模糊、import 邊界破裂、舊 API 沒有淘汰時程、設計決策只留在口頭。這條路線把 ADR、package ownership、import rule、deprecation 與 refactor gate 收斂成可驗證流程。
