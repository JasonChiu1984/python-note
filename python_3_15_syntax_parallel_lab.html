            Python 3.15 結構化並發與 3.15t 強化
            
asyncio.TaskGroup.cancel() 與 3.15t 關鍵更新

          

          
import asyncio

async def fetch_mirror(name: str, delay: float, winner: list[str], tg: asyncio.TaskGroup):
    await asyncio.sleep(delay)
    winner.append(f"{name} ({delay}s)")
    tg.cancel()  # Python 3.15：優雅取消其餘未完成任務，正常離開 async with

async def main():
    winner: list[str] = []
    async with asyncio.TaskGroup() as tg:
        tg.create_task(fetch_mirror("Mirror-TW", 0.12, winner, tg))
        tg.create_task(fetch_mirror("Mirror-JP", 0.35, winner, tg))
        tg.create_task(fetch_mirror("Mirror-US", 0.60, winner, tg))
    print("最快回應：", winner[0])

macOS 預設安裝 & mimalloc

              
macOS 官方安裝檔預設附帶自由執行緒建置；mimalloc 成為原始記憶體配置預設值以提升多緒效能。

            

            

              
匯入鎖父優先 (3.15.2 修正)

              
多執行緒同時匯入 pkg.sub 與 pkg.sub.mod 採階層順序鎖定，避免跨緒死結。

            

            

              
ContextDecorator 修正
