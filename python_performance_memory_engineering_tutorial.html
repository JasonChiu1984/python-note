Overview

效能問題先變成可回答的工程問題

不要先猜優化點；先定義 workload、baseline 與成功標準。

Architecture

把測量、剖析、預算與證據分層

效能工程不是單次測速，而是可重複的交付流程。

Setup

用標準庫建立最小可驗收範例

`time`、`cProfile`、`pstats`、`tracemalloc`、`unittest` 足以建立基礎 gate。

Configuration

效能參數要能進 release note

資料量、iterations、threshold、profile top N 與 memory budget 都要可追蹤。

Example

Performance Memory 範例專案

範例用可重現 sensor readings 示範 slow path、optimized path、profile、memory 與 budget report。

cd 範例程式碼/performance_memory_engineering
python3 -m py_compile src/performance_memory_engineering/*.py scripts/run_performance_smoke.py
PYTHONPATH=src python3 -m unittest discover -s tests -v
python3 scripts/run_performance_smoke.py
Verification

驗收要同時證明正確性與效能風險

效能優化不能只看速度，也要證明輸出一致、memory peak 可控、threshold 合理。

Troubleshooting

效能診斷先排除測量錯誤

資料量、測量區間、cache 狀態、I/O 與 CI 環境都會影響結論。

Best Practices

效能證據要支援交付決策

把 benchmark、profile、memory 與 budget decision 寫進 release evidence。
