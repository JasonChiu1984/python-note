Threat Model

先定義資產、入口與失敗模式

安全設計要從資料、使用者、外部依賴與濫用路徑開始，不是等弱掃報告才補洞。

從圖上的資料流寫出可測的安全需求

用一個工廠報表 API 貫穿全章。瀏覽器送出報表請求，API 用公司 IdP 的權杖建立身分；API 從資料庫取報表，中繼產物寫入隔離儲存區，稽核事件進獨立紀錄管道。請把每一條跨邊界的資料流備註為「誰能發送、要驗證什麼、可拒絕什麼、失敗要留下哪種證據」，不要只列技術名詞。先盤點資料分級與保存期限、信任邊界與管理介面，以及元件故障時是封鎖、唯讀、降級或停止服務；把決策、理由與責任寫進 ADR。

  1. 呼叫端／不可信請求參數、帳號、報表識別碼
  2. 入口／信任邊界TLS、身分、大小上限與請求預算
  3. 應用／授權決策組織＋物件權限；查核後才存取
  4. 資料與審計／分權資料庫、匯出檔、結構化安全事件

用 STRIDE 作為提問框架：冒用、竄改、抵賴、資訊揭露、阻斷服務、權限提升；不等於每格都必填。以暴露度、受影響資料與可復原性判優先順序。影響人身、設備安全或大量資料的風險，不宜只靠「機率低」接受；每筆接受紀錄須有風險負責人、補償控制、到期與重審條件。

Identity

身分驗證與授權要明確分層

登入只回答你是誰，授權才回答你能不能執行某個動作。

把登入、授權與資料隔離拆開

  • 身分：對外優先採已維護的 IdP；API 驗證簽章、允許的演算法、簽發者、受眾、期限及適用的其他聲明，僅在驗證後使用主體。短時憑證、服務獨立身分、高風險操作的強式 MFA／再驗證。
  • 授權：預設拒絕，先確定 subject＋action＋resource＋tenant＋context 再查／改資料。物件明細、列表、匯出、批次及背景工作都要施作同一組隔離原則。從已驗證身分和受控授權資料取得組織，不信任表單提供的組織旗標。
  • 持久層：查詢帶組織條件、最小資料庫權限，必要時加資料庫列級隔離；快取鍵及工作佇列也要包含組織，不可只靠 UI 隱藏功能。
  • 可撤銷：角色變更、帳號停用、金鑰輪替要有可預期的期限。設計 break-glass 的雙重覆核、短時授權、事件通報與後續檢查，不用共用常駐管理帳號。

此頁 PBKDF2 固定迭代數、RBAC 及單執行個體限流都是標準庫教學，不是上線組態。新建本機密碼儲存時依 OWASP Password Storage 與合規條件選 KDF，採獨立 salt、可版本化參數，量測登入容量，並設計驗證成功後升級雜湊；不要自行實作完整登入系統。

Input

輸入驗證要保護邊界與資源

API、CLI、檔案與外部 payload 都是不可信入口，必須有格式、長度、類型與錯誤回應策略。

先限制資源，再處理資料語意

  1. 入口根據內容類型／來源選擇解析器；先限制串流大小、解壓後總量、筆數、層數、逾時與並行數。不要等將整個 payload 載入記憶體才檢查大小。
  2. 用結構 schema 驗證長度、型別、允許值，再驗證日期次序、權限及資料間約束等業務規則。明定未知欄位政策。禁止不可信資料進入 pickle、動態程式執行或 shell；資料庫使用參數化查詢，輸出依 HTML、JSON 等上下文安全呈現。
  3. 檔案上傳改用伺服器產生的 ID，隔離儲存、不執行；存取權由資料庫紀錄決定。用路徑正規化輔助檢查，不把 resolve() 單獨當作隔離機制；可變 symlink 和檢查與使用之間的競態需由檔案系統或隔離權限處理。
  4. 網路外呼走受控目的地、通過出口限制；網址驗證不能只對照顯示字串，需考慮 DNS、重新導向及所有連線嘗試的網路政策。Webhook 先驗整體簽章與時窗、再驗一次性／重放政策，最後才解析與執行已授權業務。

對外錯誤只回傳穩定錯誤碼及追蹤 ID；不要回堆疊、SQL、舊密碼或實際規則。以合成資料測超限、無效編碼與未知欄位；測試應證明沒有寫入或副作用，而非只確認 HTTP 回了 4xx。

Secrets

Secrets 不應進入程式碼、log 或測試 fixture

密碼、token、private key 要有來源、遮罩、輪替與事故處理流程。

先限制誰可取得，再排輪替與撤銷

  1. 發行服務獨立身分，短效、窄範圍
  2. 使用秘密管理服務；不寫入產物
  3. 輪替驗證新憑證後切換；必要時限期並存
  4. 失效撤銷舊憑證，驗證拒絕並留證據

程式、映像層、CI artifacts、追蹤、錯誤頁與測試 fixture 都不要存真實秘密。環境變數可用作教學分離，不是保險箱：子程序、診斷與記憶體轉儲也可能暴露。生產優先以工作負載身分向秘密管理器取短效憑證，限制誰可讀、向何處送；日誌只允許約定欄位與安全識別碼，不收原始 Authorization、Cookie 或所有 request body。

外洩時先按事件程序撤銷或限制憑證，記錄使用時間、依賴與影響範圍，再輪替、重新授權並驗證舊憑證不可用。只刪除 Git 檔案或遮罩日誌，不會撤銷外洩的權限。可控的常態輪替與真實外洩時立即撤銷應分開演練。

Supply Chain

套件與建置流程要可追蹤、可重現

lock file、hash、SBOM、弱點掃描與版本標註是 Python 交付安全的基本證據。

把交付門檻綁到產物，而不是綁到「某次 CI 綠燈」

  1. 受保護原始碼分支保護、必要覆核、最小 CI 權限
  2. 隔離建置鎖版及來源、以短時身分存取私有資源
  3. 發布證據digest、SBOM、弱點報告、來源證明
  4. 部署前驗證身分、產物、政策版本與授權發布點
各類證據各自能回答什麼
證據驗證重點不能單獨證明
鎖檔與 hash鎖定應用的直接及間接依賴、版本、來源及檔案；私有套件倉庫避免未審核的索引回退套件本身沒有已知或未知風險
SBOM + SCA對實際發布產物產出成分清單，保存掃描日期、資料源與例外理由；高風險看公開利用、可達性、影響和修補所有業務邏輯或所有弱點均已測過
簽章、來源證明依部署策略驗證簽發者、建置器／來源和產物 digest，且與審核提交相符可重現建置或產物內容必然安全；SLSA 等級需逐條滿足適用要求
例外與到期範圍、補償控制、核准者、到期、重驗日期；不合政策預設阻擋永久放行，或把過期報告挪作本次證據

關卡判定與變更後重驗

  • Pull request：靜態分析（SAST）、秘密掃描、依賴分析及安全單元測試。失敗先定位到程式或依賴變更，再以人工覆核區辨誤報。除了情境測試，也要查身分與授權模型的變更是否涵蓋新背景工作或 API。
  • 候選發布：隔離測試環境以受控合成資料跑整合測試，確認跨組織不洩漏、重送不產生重複副作用、日誌不含秘密。針對實際工件掃描並產生對應的 SBOM，優先審查政策禁止、正在被利用、可到達或高影響的弱點；不能以單一評分代替判斷。
  • 部署：發布者與執行身分分離；完整驗證 digest、簽章及允許的建置身分。撤回版本或機密輪替後，重跑相同的必要測試與監控確認。安全工具未執行、資料不新鮮或證據綁錯版本，不應當作綠燈。

未受信任來源的 PR 只在隔離、無部署秘密的環境作檢查；發布流程與日常 PR 權限分離，第三方工作流程依組織政策固定到已審核版本。鎖檔更新與安全更新都要經複查和重新建置。部署以 digest 提升同一份產物到下一環境，不在部署點邊拉最新版邊建。SLSA v1.2 定義來源與建置供應鏈要求；pip 安全安裝 說明雜湊驗證模式。

Runtime

執行期要能限制濫用並留下審計線索

rate limit、secure error、audit log 與 incident playbook 讓安全控制能被驗證與維運。

發布後：先保留可追溯證據，再判斷要停止、隔離或回復

  1. 偵測與判斷Owner、告警門檻、影響範圍
  2. 保存與圍堵留證、停用受影響身分或功能
  3. 校驗與復原已知良好產物、相容性、再驗證
  4. 復盤與補測根因、期限、監控與證據回填
  • 觀測：記 UTC、追蹤 ID、非敏感主體代號、動作、資源、決策結果與政策版本。日誌寫入／讀取／保留分權，知道自己有多少事件漏失；按政策移除秘密與不必要個資。
  • 應對：先定查核與升級條件，建立清楚的值班與決策權。留存必要證據、記錄誰何時做哪項處置；不要為趕快還原而覆寫原始證據。若有持續損害，依事件指揮優先圍堵。
  • 回復：重啟或回滾不等於事件解除。復原前查漏洞是否也存在於舊版本、資料庫結構是否可回退、暴露憑證是否撤銷。先灰度部署已驗證版本，檢查政策、審計、資料一致性與錯誤率，再解除圍堵。
  • 演練：故障模擬只對合成環境；演練只用假憑證、離線或明確隔離資料。將偵測與復原時間、回復點、測試報告及修復議題回填需求 ID。

可用 NIST SP 800-61 Rev. 3 的事件回應框架作為組織分工參考；對工控設備，任何實體動作須依已核准的站點操作與安全程序，監控服務不能代替安全連鎖。

from __future__ import annotations

import pathlib
import os
import subprocess
import sys


ROOT = pathlib.Path(__file__).resolve().parents[1]
SRC = ROOT / "src"
TESTS = ROOT / "tests"
sys.path.insert(0, str(SRC))


def run(command: list[str]) -> None:
    env = {**os.environ, "PYTHONPATH": str(SRC)}
    subprocess.run(command, cwd=ROOT, env=env, check=True)


def main() -> int:
    files = [*SRC.glob("security_engineering/*.py"), *TESTS.glob("*.py"), pathlib.Path(__file__)]
    run([sys.executable, "-m", "py_compile", *map(str, files)])
    run([sys.executable, "-m", "unittest", "discover", "-s", str(TESTS), "-v"])
    run([sys.executable, "-m", "security_engineering.demo"])
    print("security smoke passed: auth + policy + audit + manifest")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

from __future__ import annotations

from dataclasses import dataclass, field
from typing import Any


SENSITIVE_KEYS = {"password", "token", "secret", "authorization"}


def redact(fields: dict[str, Any]) -> dict[str, Any]:
    return {key: ("***" if key.lower() in SENSITIVE_KEYS else value) for key, value in fields.items()}


@dataclass
class AuditLog:
    events: list[dict[str, Any]] = field(default_factory=list)

    def record(self, event: str, actor: str, trace_id: str, **fields: Any) -> dict[str, Any]:
        item = {"event": event, "actor": actor, "trace_id": trace_id, **redact(fields)}
        self.events.append(item)
        return item

from __future__ import annotations

import base64
import hashlib
import hmac
import os


class PasswordHasher:
    def __init__(self, iterations: int = 200_000) -> None:
        if iterations < 100_000:
            raise ValueError("iterations must be at least 100000")
        self.iterations = iterations

    def hash_password(self, password: str, *, salt: bytes | None = None) -> str:
        if len(password) < 12:
            raise ValueError("password must be at least 12 characters")
        salt = salt or os.urandom(16)
        digest = hashlib.pbkdf2_hmac("sha256", password.encode("utf-8"), salt, self.iterations)
        return ".".join(
            [
                "pbkdf2_sha256",
                str(self.iterations),
                base64.urlsafe_b64encode(salt).decode("ascii"),
                base64.urlsafe_b64encode(digest).decode("ascii"),
            ]
        )

    def verify(self, password: str, encoded_hash: str) -> bool:
        try:
            algorithm, iterations, salt_b64, digest_b64 = encoded_hash.split(".", 3)
            if algorithm != "pbkdf2_sha256":
                return False
            salt = base64.urlsafe_b64decode(salt_b64.encode("ascii"))
            expected = base64.urlsafe_b64decode(digest_b64.encode("ascii"))
            actual = hashlib.pbkdf2_hmac("sha256", password.encode("utf-8"), salt, int(iterations))
            return hmac.compare_digest(expected, actual)
        except (ValueError, TypeError):
            return False


def constant_time_token_match(expected: str, actual: str) -> bool:
    return hmac.compare_digest(expected.encode("utf-8"), actual.encode("utf-8"))

from __future__ import annotations

import json

from .audit import AuditLog
from .auth import PasswordHasher, constant_time_token_match
from .policy import RolePolicy
from .rate_limit import SlidingWindowRateLimiter
from .supply_chain import DependencyRecord, validate_manifest
from .validation import safe_error_response, validate_user_payload


def main() -> int:
    hasher = PasswordHasher(iterations=120_000)
    encoded = hasher.hash_password("correct-horse-battery")
    policy = RolePolicy()
    audit = AuditLog()
    limiter = SlidingWindowRateLimiter(limit=2, window_seconds=60)
    payload = validate_user_payload({"email": "operator@example.com", "role": "operator"})
    audit.record("login.success", payload.email, "trace-sec-1", token="demo-token")
    result = {
        "password_verified": hasher.verify("correct-horse-battery", encoded),
        "token_match": constant_time_token_match("expected-token", "expected-token"),
        "operator_can_write_order": policy.can(payload.role, "write", "order"),
        "operator_can_delete_order": policy.can(payload.role, "delete", "order"),
        "rate_limit": [limiter.allow(payload.email, 1), limiter.allow(payload.email, 2), limiter.allow(payload.email, 3)],
        "audit": audit.events,
        "safe_error": safe_error_response("invalid_request", "trace-sec-1"),
        "manifest": validate_manifest([DependencyRecord("fastapi", "0.120.0", "sha256:abc123")]),
    }
    print(json.dumps(result, ensure_ascii=False, indent=2, sort_keys=True))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

from __future__ import annotations

from dataclasses import dataclass, field


Permission = tuple[str, str]


@dataclass(frozen=True)
class RolePolicy:
    permissions: dict[str, set[Permission]] = field(
        default_factory=lambda: {
            "admin": {("read", "order"), ("write", "order"), ("delete", "order"), ("read", "audit")},
            "operator": {("read", "order"), ("write", "order")},
            "auditor": {("read", "order"), ("read", "audit")},
        }
    )

    def can(self, role: str, action: str, resource: str) -> bool:
        return (action, resource) in self.permissions.get(role, set())

from __future__ import annotations

from collections import defaultdict, deque
from dataclasses import dataclass, field


@dataclass
class SlidingWindowRateLimiter:
    limit: int
    window_seconds: float
    attempts: dict[str, deque[float]] = field(default_factory=lambda: defaultdict(deque))

    def allow(self, key: str, now: float) -> bool:
        bucket = self.attempts[key]
        while bucket and now - bucket[0] >= self.window_seconds:
            bucket.popleft()
        if len(bucket) >= self.limit:
            return False
        bucket.append(now)
        return True

    hash: str


def validate_manifest(records: list[DependencyRecord]) -> dict[str, object]:
    missing = [item.name for item in records if not item.version or not item.hash.startswith("sha256:")]
    return {
        "dependencies_total": len(records),
        "passed": not missing,
        "missing_or_invalid": missing,
    }

from __future__ import annotations

import re
from dataclasses import dataclass


class ValidationError(ValueError):
    pass


@dataclass(frozen=True)
class UserPayload:
    email: str
    role: str


def validate_user_payload(payload: dict[str, object]) -> UserPayload:
    email = payload.get("email")
    role = payload.get("role")
    if not isinstance(email, str) or not re.fullmatch(r"[^@\s]+@[^@\s]+\.[^@\s]+", email):
        raise ValidationError("invalid email")
    if len(email) > 120:
        raise ValidationError("email too long")
    if role not in {"admin", "operator", "auditor"}:
        raise ValidationError("invalid role")
    return UserPayload(email=email, role=str(role))


def safe_error_response(error_code: str, trace_id: str) -> dict[str, str]:
    return {"error": error_code, "trace_id": trace_id}

"""安全預設：參數化 SQL 防注入、路徑穿越防護、秘密不進日誌（標準函式庫）。"""
import logging
import re
import sqlite3
import sys
from pathlib import Path

db = sqlite3.connect(":memory:")
db.executescript("CREATE TABLE point(name TEXT, value REAL); "
                 "INSERT INTO point VALUES ('AHU1_SAT', 22.5), ('AHU2_SAT', 23.1), ('ADMIN_PW', 0);")

evil = "AHU1_SAT' OR '1'='1"
unsafe = db.execute(f"SELECT name FROM point WHERE name = '{evil}'").fetchall()
safe = db.execute("SELECT name FROM point WHERE name = ?", (evil,)).fetchall()
print(f"字串拼接查詢回傳 {len(unsafe)} 筆（注入成功）；參數化查詢回傳 {len(safe)} 筆")

BASE = Path("/srv/bms/reports").resolve()


def safe_path(user_input: str) -> Path:
    p = (BASE / user_input).resolve()
    if not p.is_relative_to(BASE):
        raise PermissionError(f"拒絕存取報表目錄以外的路徑：{user_input}")
    return p


for name in ("2026-11.csv", "../../../etc/passwd", "sub/../2026-10.csv"):
    try:
        print("允許：", safe_path(name))
    except PermissionError as e:
        print(e)


class Redact(logging.Filter):
    PATTERN = re.compile(r"(password|token|api_key)=([^\s&]+)", re.I)

    def filter(self, record):
        record.msg = self.PATTERN.sub(r"\1=***", str(record.msg))
        return True


log = logging.getLogger("gw")
h = logging.StreamHandler(sys.stdout)
h.setFormatter(logging.Formatter("%(levelname)s %(message)s"))
h.addFilter(Redact())
log.addHandler(h)
log.setLevel(logging.INFO)
log.info("connect host=10.0.0.5 user=bms password=Bms#2026! token=abc123")

工程現場案例：報表下載功能可以讀到 /etc/passwd

某 BAS 網頁提供報表下載，網址參數是檔名，後端直接 open(REPORT_DIR + name)。測試人員把 name 改成 ../../../etc/passwd 就下載到系統檔案。同一個系統的點位查詢還用字串拼接 SQL，輸入 ' OR '1'='1 就能列出所有點位，包括不該公開的項目。

範例顯示：參數化查詢讓惡意字串只被當成一個值，回傳 0 筆；路徑先正規化再檢查，穿越嘗試被拒絕，正常的子目錄路徑仍可使用；日誌中的密碼在寫出前就被遮蔽。

  1. 所有 SQL 一律使用參數化查詢或 ORM，不用 f-string 組 SQL。
  2. 處理使用者提供的路徑時先 resolve()，再檢查是否位於允許目錄內。
  3. 日誌加上遮蔽過濾器，並避免記錄完整的請求標頭或連線字串。
  4. 以 bandit 等工具在 CI 掃描常見的危險寫法。

練習題與自我檢查

  1. 為什麼字串拼接的查詢回傳 3 筆？

    看解答

    組出的 SQL 是 WHERE name = 'AHU1_SAT' OR '1'='1'，'1'='1' 永遠為真，所以所有列都符合，包括 ADMIN_PW。

  2. safe_path() 若只檢查 user_input 是否包含 '..'，有什麼漏洞？

    看解答

    攻擊者可以用絕對路徑（/etc/passwd，Path 會直接替換基底）、符號連結或編碼後的字元繞過。先 resolve 再檢查最終路徑才可靠。

  3. Redact 過濾器只處理 record.msg，若用 log.info('pw=%s', password) 這種寫法會怎樣？

    看解答

    密碼在 record.args 裡，格式化時才組進訊息，過濾器看到的 msg 只有 'pw=%s'，遮蔽失敗。應改成對 record.getMessage() 的結果遮蔽，或避免把秘密當成參數傳給日誌。

  4. 參數化查詢可以防止所有 SQL 相關的問題嗎？

    看解答

    不行。表名、欄位名與 ORDER BY 方向不能參數化，若要依使用者輸入決定，必須用白名單對應。權限控制（例如查詢帳號只能讀特定表）也是必要的另一層防護。
