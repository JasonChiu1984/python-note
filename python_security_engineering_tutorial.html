Threat Model

先定義資產、入口與失敗模式

安全設計要從資料、使用者、外部依賴與濫用路徑開始，不是等弱掃報告才補洞。

Identity

身分驗證與授權要明確分層

登入只回答你是誰，授權才回答你能不能執行某個動作。

Input

輸入驗證要保護邊界與資源

API、CLI、檔案與外部 payload 都是不可信入口，必須有格式、長度、類型與錯誤回應策略。

Secrets

Secrets 不應進入程式碼、log 或測試 fixture

密碼、token、private key 要有來源、遮罩、輪替與事故處理流程。

Supply Chain

套件與建置流程要可追蹤、可重現

lock file、hash、SBOM、弱點掃描與版本標註是 Python 交付安全的基本證據。

Runtime

執行期要能限制濫用並留下審計線索

rate limit、secure error、audit log 與 incident playbook 讓安全控制能被驗證與維運。
