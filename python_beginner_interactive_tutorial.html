學習地圖

先建立資料在記憶體裡的形狀，再理解語法如何搬動資料。專案不是語法堆疊，而是把責任切成可測試、可替換、可維護的模組。

1. Object數字、文字、容器、布林值，先看資料能裝什麼。
2. Syntax條件、迴圈、例外、檔案，讓程式能做決策。
3. Function把重複行為封裝，輸入、處理、輸出都清楚。
4. Module把檔案和 package 做成邊界，專案開始長骨架。
5. Project加上測試、設定、日誌、CLI/API，走向可交付。

大型專案應用

大型專案的重點不是檔案變多，而是邊界清楚。UI 或 CLI 只負責接收請求，service 負責規則，repository 負責資料來源，test 負責守住行為。

建議目錄

用 package 切出可測試邊界，讓 CLI/API 可以替換，service 與 domain 不被外部工具綁死。

Service 範例

service 只說規則，不直接知道資料存在 JSON、SQLite 或 API。

from dataclasses import dataclass

@dataclass
class Note:
    title: str
    body: str

class NoteService:
    def __init__(self, repo):
        self.repo = repo

    def create(self, title: str, body: str) -> Note:
        if not title.strip():
            raise ValueError("title is required")
        note = Note(title=title, body=body)
        self.repo.save(note)
        return note
