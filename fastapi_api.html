      四種打包與部署方案比較表

      方案 適用場景 相依鎖定機制 擴展方式 關鍵實戰要點
      Docker + uv 雲端微服務、K8s、Cloud Run pyproject.toml + uv.lock 單容器單 Worker + 平台水平副本 多階段建置、非 root、`exec` PID 1 接收 SIGTERM
      Wheel (uv build) 內部私有 PyPI、企業元件分發 pyproject.toml (PEP 621) 搭配目標主機 Uvicorn / Gunicorn 使用 `src/` 佈局與 `hatchling`，明確區分 `fastapi[standard]`
      PyInstaller 離線內網、本機桌面工具 API 打包整份 Python Runtime 單機單程序執行檔 必加 Uvicorn hidden-imports，並由程式碼呼叫 `uvicorn.run(app)`
      Systemd + Nginx 傳統 Linux VM、自架 VPS .venv + uv sync --locked `--workers N`（每核 1 Worker） Nginx 終結 TLS、綁定 `127.0.0.1`、開啟 `--proxy-headers`
