02 / HEAD CALCULATION

Q、流速、壓力差與總揚程

計算式子要件
連續方程式Q = A × v，A = πD²/4D 是管內徑；Q 換成 m³/s：m³/h ÷ 3,600。支路流量相加為總流量，不同管徑不會有同樣流速。
壓差轉揚程H_Δp = Δp/(ρg)Pa / (kg/m³ × m/s²) = m；kPa 先 ×1,000。取壓口高度或管徑不同，加 Δz 及 (v₂²−v₁²)/(2g) 才是泵總揚程。
管路、管件H_loss = (f·L/D + ΣK)·v²/(2g)f 為 Darcy 摩擦因子，不是 Fanning。實體多種管徑／流量，應各段分開算；閥位、粗糙度、雷諾數都能改變係數。
盤管、濾網、末端需求H_eq = ΣΔp_eq/(ρg)用設備資料及污堵工況定壓降。若給末端 DP 要求，先釐清其已含閥／盤管與否，避免雙計。
系統需求H_system = Δz + Δp_boundary/(ρg) + Δ(v²)/(2g) + ΣH_loss式子沿選定入口與出口，項目依實際邊界取捨；固定速度、固定閥位及近穩態才適合用常係數模型。

閉式循環：整個充滿水的回路走回同一點時，幾何高程上升及回降抵銷；泵仍需克服管路／設備損失與所需差壓。靜壓在高點、吸入口、膨脹及充水方面仍然重要。開式轉移：兩槽都通大氣且液面速度近零時，高差仍存在；有出口槽壓或異管徑邊界再加壓力與速度項。冷卻塔如果有開放排放點，要按真實液面和出流邊界，不套用閉式經驗。

03 / CURVES

泵 ∩ 系統，才是流量與揚程

合成清水 ρ=998 kg/m³、g=9.80665 m/s²。單一路徑：管內徑 150 mm、長 150 m、Darcy f=0.022、ΣK=14；盤管、濾網和其他設備在 120 m³/h 合計壓降 130 kPa，教學近似依 Q² 變化。合成泵在基準轉速：H_p(Q)=32−12·(Q/120)²，Q 取 m³/h。在指定範圍做二分法，沒有正交點就報錯，不外插。

看圖不要把泵的零流量揚程當設計流量揚程。系統曲線會隨閥位、濾網水阻或分支更動；並聯多泵在共同揚程下加流量，串聯在共同流量下加揚程，仍要再與系統曲線求交點。

04 / POWER & SPEED

輸入功率要分清液壓、軸、電三層

P_hyd = ρgQH / 1,000 [kW]（Q 以 m³/s）；P_shaft = P_hyd/η_pump；P_elec = P_shaft/(η_motor · η_VFD)。合成基準點以 η_pump=0.76、η_motor=0.92、η_VFD=0.97 估算，結果見圖表。效率在真實機組隨工況改變，馬達銘牌功率不是實際耗電。算能耗時以同口徑電 kW 對時間積分，勿用單點乘整年。

相似律在同轉子、相似工況近似 Q ∝ n、H ∝ n²、軸功率 ∝ n³；它是換算泵曲線，不保證系統點照比例移動。80% 轉速，合成純摩擦閉式回路才恰好有 80% 流量；有 8 m 靜揚程時比例不同，若關閉揚程低過靜揚程甚至無有效輸送。別直接宣稱降速 20% 一定節省 48.8% 電力；實際還要看控制點、負載、泵及驅動效率、最小流量、溫升與共振限制。

05 / SUCTION

NPSHa 是現場可用值；NPSHr／NPSH3 看廠牌

在泵吸入口指定參考面，若壓力表量的是靜壓，NPSHa = p_abs/(ρg) + v_s²/(2g) − p_vapor/(ρg)。表壓須加當地大氣壓才成絕對壓；蒸氣壓同用絕對壓並依液溫，在入口壓力低、高海拔、熱水與堵濾網工況都要核對。若從上游儲槽計算，應以液面絕對壓與液位高差扣吸入管損；別把吸入口量測已反映的管損再扣一次。

合成吸入口 135 kPa(a)、液體蒸氣壓假設 1.230 kPa(a)，速度由案例內徑求得：NPSHa 約 13.85 m。這只驗算可用值；沒有指定廠牌的泵浦 NPSHr 曲線、實際最低液位及溫度，就不能判定汽蝕裕量是否足夠。把 NPSHa 與同流量、轉速、工作液的廠商需求比較；NPSH3 通常指揚程降低 3% 的測試點，不是零汽蝕。實際裕量由用途、廠商與設計審查決定，本頁不提供通用倍數。

"""Synthetic single water pump; validates arithmetic, not equipment selection."""
import argparse
import json
import math
import unittest

G = 9.80665
RHO = 998.0


def checked(x, label, *, zero=False):
    if not math.isfinite(x) or x < 0 or (not zero and x == 0):
        raise ValueError(f"invalid {label}")
    return x


def area(diameter_m):
    return math.pi * checked(diameter_m, "inside diameter") ** 2 / 4


def velocity(flow_m3h, diameter_m):
    return checked(flow_m3h, "flow", zero=True) / 3600 / area(diameter_m)


def pressure_head(delta_pa, rho=RHO):
    return checked(delta_pa, "pressure drop", zero=True) / (checked(rho, "density") * G)


def system_head(q, static_m=0):
    # Representative closed loop: 150 m of pipe, ID 150 mm, Darcy f=.022,
    # sum K=14. Coil, filter and other equipment cost 130 kPa at 120 m3/h.
    v = velocity(q, 0.15)
    pipe = (0.022 * 150 / 0.15 + 14) * v * v / (2 * G)
    equipment = pressure_head(130_000) * (q / 120) ** 2
    return checked(static_m, "static head", zero=True) + pipe + equipment


def pump_head(q, speed=1):
    # Synthetic reference curve, not valid beyond its declared plot domain.
    checked(q, "flow", zero=True)
    if not 0.7 <= speed <= 1 or q > 180 * speed:
        raise ValueError("outside synthetic pump curve range")
    return speed ** 2 * (32 - 12 * (q / speed / 120) ** 2)


def operating_point(speed=1, static_m=0):
    lo, hi = 0.0, 180 * speed
    def residual(q):
        return pump_head(q, speed) - system_head(q, static_m)
    if not residual(lo) > 0 > residual(hi):
        raise ValueError("no positive intersection in curve range")
    for _ in range(65):
        mid = (lo + hi) / 2
        if residual(mid) > 0:
            lo = mid
        else:
            hi = mid
    q = (lo + hi) / 2
    return q, system_head(q, static_m)


def powers(q, head, pump_eta, motor_eta, drive_eta):
    if any(not 0 < eta <= 1 for eta in (pump_eta, motor_eta, drive_eta)):
        raise ValueError("efficiency must be >0 and <=1")
    hydraulic = RHO * G * (checked(q, "flow", zero=True) / 3600) * checked(head, "head", zero=True) / 1000
    shaft = hydraulic / pump_eta
    return hydraulic, shaft, shaft / motor_eta / drive_eta


def npsha(suction_abs_pa, vapor_abs_pa, suction_velocity_m_s):
    # Suction static pressure at the pump reference plane; same elevation datum.
    head = pressure_head(suction_abs_pa) - pressure_head(vapor_abs_pa)
    return head + checked(suction_velocity_m_s, "suction velocity", zero=True) ** 2 / (2 * G)


def model():
    q, h = operating_point()
    q8, h8 = operating_point(.8)
    p = powers(q, h, .76, .92, .97)
    v = velocity(q, .15)
    return {
        "point": {"flow_m3h": q, "head_m": h, "velocity_m_s": v,
                  "delta_kpa": h * RHO * G / 1000,
                  "hydraulic_kw": p[0], "shaft_kw": p[1], "electrical_kw": p[2],
                  "npsha_m": npsha(135_000, 1_230, v)},
        "speed_80": {"flow_m3h": q8, "head_m": h8},
        "open_8m_point": dict(zip(("flow_m3h","head_m"), operating_point(1,8))),
        "curve": [{"q": q, "pump_100": pump_head(q), "system": system_head(q),
                   "system_with_8m_static": system_head(q,8),
                   "pump_80": pump_head(q,.8) if q <= 144 else None}
                  for q in range(0,181,4)],
    }


class LabTests(unittest.TestCase):
    def test_continuity_and_pressure(self):
        self.assertAlmostEqual(velocity(120, .15) * area(.15) * 3600, 120)
        self.assertAlmostEqual(pressure_head(RHO * G * 10), 10)

    def test_point_residual(self):
        q, h = operating_point()
        self.assertAlmostEqual(h, pump_head(q))
        self.assertEqual(system_head(0), 0)
        self.assertEqual(system_head(0, 8), 8)
        self.assertLess(operating_point(static_m=8)[0], q)

    def test_affinity_closed_not_open(self):
        self.assertAlmostEqual(operating_point(.8)[0] / operating_point()[0], .8)
        self.assertNotAlmostEqual(
            operating_point(.8, 8)[0] / operating_point(1, 8)[0], .8)

    def test_power_and_suction(self):
        hydraulic, shaft, electrical = powers(120, 20, .76, .92, .97)
        self.assertTrue(hydraulic < shaft < electrical)
        self.assertLess(npsha(135_000, 10_000, 2), npsha(135_000, 1230, 2))

    def test_reject_invalid(self):
        for call in (lambda: velocity(-1,.15), lambda: velocity(5,0),
                     lambda: pressure_head(float("nan")), lambda: powers(2, 2, 0, .9, .9),
                     lambda: pump_head(150,.8), lambda: operating_point(1,40)):
            with self.assertRaises(ValueError):
                call()


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--self-test", action="store_true")
    args = parser.parse_args()
    if args.self_test:
        unittest.main(argv=["lab"], verbosity=2)
    else:
        print(json.dumps(model(), indent=2, allow_nan=False))


if __name__ == "__main__":
    main()

07 / VERIFICATION

用現場證據驗算，而不是拿合成值選泵

  1. 確認兩端點、高程、吸排壓位置、管內徑、流體、最高溫／最低液位、實際閥位與管件；沿最不利路徑重算。
  2. 以需求流量、負載／壓差範圍校核廠牌曲線和效率，含低負載與備援工況；檢查允許運轉區、最小流量、NPSH 需求及馬達負載。
  3. 依核可程序對照同時刻流量、泵進出壓、頻率、電功率與水溫；區分感測器校準、路徑損失與設備狀態。計算教材不能當作現場選型、壓力安全、控制設定或驗收簽證。

可實跑範例：泵曲線與系統曲線求解變頻運轉點

泵曲線以二次式表示並依相似定律隨轉速縮放，系統曲線為靜揚程加摩擦損失。程式以二分法找出達到目標流量所需的轉速，估算電力並與立方定律比較。效率簡化為定值，實務上效率會隨運轉點改變。二分法只在本算例的 20%～100% 轉速區間搜尋；先檢查可達流量範圍，無解就回報錯誤。

"""變頻泵浦：泵曲線 × 系統曲線求運轉點，並比較有／無靜揚程時的節能估算（標準函式庫）。

泵曲線（額定轉速）：H = 42 − 0.0012 Q²     （Q：m3/h，H：m）
系統曲線：H = H_static + k Q²
轉速比 n 時泵曲線依相似定律：H = 42 n² − 0.0012 Q²
"""
import math

A, B = 42.0, 0.0012           # 泵曲線係數
ETA = 0.72                    # 泵＋馬達＋變頻器總效率（簡化為定值）
RHO_G = 1000 * 9.81


def operating_point(n, h_static, k):
    """解 A n² − B Q² = h_static + k Q²。"""
    q2 = (A * n * n - h_static) / (B + k)
    if q2 <= 0:
        return 0.0, h_static          # 轉速太低，無法克服靜揚程
    q = math.sqrt(q2)
    return q, h_static + k * q2


def electric_kw(q_m3h, h_m):
    return RHO_G * (q_m3h / 3600) * h_m / ETA / 1000


def speed_for_flow(target_q, h_static, k):
    """求模型 20%～100% 轉速範圍內可達的正流量（m³/h）；不是 VFD 指令。"""
    if not all(math.isfinite(x) for x in (target_q, h_static, k)) or target_q <= 0 or h_static < 0 or k < 0:
        raise ValueError("本模型要求正目標流量及非負靜揚程與阻力係數")
    lo, hi = 0.2, 1.0
    q_lo, _ = operating_point(lo, h_static, k)
    q_hi, _ = operating_point(hi, h_static, k)
    if not q_lo <= target_q <= q_hi:
        raise ValueError(f"目標超出模型可達的流量範圍 {q_lo:.2f}～{q_hi:.2f} m³/h")
    for _ in range(60):               # 二分法
        mid = (lo + hi) / 2
        q, _ = operating_point(mid, h_static, k)
        lo, hi = (mid, hi) if q < target_q else (lo, mid)
    return hi


if __name__ == "__main__":
    for label, h_static in (("閉式冰水迴路（無靜揚程）", 0.0), ("冷卻水塔開式迴路（靜揚程 8 m）", 8.0)):
        k = (30.0 - h_static) / 150.0 ** 2          # 讓 150 m3/h 時系統需 30 m
        q100, h100 = operating_point(1.0, h_static, k)
        p100 = electric_kw(q100, h100)
        print(f"== {label}")
        print(f"  額定轉速運轉點：Q={q100:.1f} m3/h，H={h100:.1f} m，電力 {p100:.1f} kW")
        for frac in (0.8, 0.6):
            target = q100 * frac
            n = speed_for_flow(target, h_static, k)
            q, h = operating_point(n, h_static, k)
            p = electric_kw(q, h)
            print(f"  流量 {frac:.0%}：轉速 {n:.1%}，H={h:.1f} m，電力 {p:.1f} kW"
                  f"（立方定律估 {p100 * frac ** 3:.1f} kW）")

工程現場案例：冷卻水泵改變頻，節電只有預估的一半

某工廠把冷卻水塔的泵浦改成變頻，廠商用立方定律估流量 60% 時功率只剩 22%。實際量測卻接近 35%。原因是冷卻水塔是開式迴路，有約 8 m 的靜揚程（水要被打到塔頂），轉速降低時揚程不能跟著平方下降。

範例中 60% 流量時，閉式迴路轉速 60%、電力 2.3 kW，與立方定律一致；開式迴路則需要 69.4% 轉速、電力 3.8 kW，比立方定律估的 2.4 kW 高出約 60%。轉速再往下降，泵浦甚至無法克服靜揚程、流量直接歸零。

  1. 確認迴路型式：閉式冰水迴路靜揚程接近 0，冷卻水塔與揚水系統則有明顯靜揚程。
  2. 量測至少兩個運轉點的流量與差壓，擬合系統曲線的靜揚程與 k 值。
  3. 用泵浦廠商曲線（含效率）求運轉點，不要只用立方定律。
  4. 設定變頻器最低頻率，確保最低轉速時仍能克服靜揚程，並維持冷卻水塔噴頭的最低流量。

練習題與自我檢查

  1. 為什麼閉式迴路的計算結果剛好等於立方定律？

    看解答

    靜揚程為 0 時系統曲線通過原點（H = kQ²），與相似定律的等效率曲線重合，流量、揚程、功率分別與轉速的一次、二次、三次方成正比，所以完全符合立方定律（在效率不變的假設下）。

  2. 開式迴路 8 m 靜揚程時，模型的零流量臨界轉速是多少？這等於現場最低運轉轉速嗎？

    看解答

    零流量臨界是 √(8 ÷ 42) ≈ 43.6%；轉速必須超過臨界才有正流量。這不是最低允許轉速；實際需另查泵浦允許範圍與冷卻水塔所需的最低流量。

  3. 在開式迴路的 60% 流量運轉點（約 69.4% 轉速），如果泵浦、馬達與變頻器的總效率從 72% 降到 62%，估算電力是多少？

    看解答

    保持流量與揚程不變，電力與總效率成反比：以原模型約 3.8 kW 乘上 0.72 ÷ 0.62，約 4.4 kW。60% 是流量比例，並非轉速設定。

  4. 修改 operating_point()，讓它在轉速不足時丟出例外而不是回傳 (0, h_static)，有什麼好處？

    看解答

    呼叫端無法忽略這個狀況。回傳 0 流量可能被當成正常的停機值進入節能計算；丟出例外能迫使使用者檢查設定的最低轉速是否合理。

  5. 目標流量在模型範圍之外時，為什麼不能直接採用搜尋端點？

    看解答

    搜尋端點仍可能達不到目標。20%～100% 是本算例搜尋範圍，不是現場允許轉速；零流量由停機或控制策略另行判斷。

  6. 若冷卻水塔較高，靜揚程改為 12 m（系統在 150 m³/h 時仍需 30 m），流量 60% 時轉速、電力各是多少？零流量臨界轉速呢？

    看解答

    k = (30 − 12) ÷ 150²。額定轉速運轉點 Q = 122.5 m³/h、H = 24.0 m、11.1 kW。流量 60% 時轉速 73.7%、H = 16.3 m、電力 4.5 kW，約為額定的 40.8%；立方定律估 2.4 kW，低估將近一半。零流量臨界轉速 √(12 ÷ 42) ≈ 53.5%，比 8 m 時的 43.6% 高；這仍不是現場允許的最低轉速。已用範例函式實際執行驗證。

    靜揚程越高，可調降的轉速範圍越窄、節能越少；改造前要量測實際靜揚程，不能沿用其他案場的比例。
