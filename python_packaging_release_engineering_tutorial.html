Packaging Release Engineering｜本機實驗

把 Python 專案交付成可驗證的 release artifact

不要交付「在開發機跑過的原始碼」。交付可安裝的成品，以及能回答「它來自哪個版本、如何驗證、出問題如何回退」的紀錄。以下用一個有 CLI 與套件資料檔的最小專案，走完從原始碼到乾淨環境的流程。

開始本機實驗看流程圖上線前檢驗回教材入口

架構圖：建置、驗收、發布三道邊界

實驗止於驗收；不需帳號，不會上傳。

  1. 建置區受控原始碼 + pyproject.toml → sdist → wheel
  2. 驗收區下載同一份候選成品 → 核對摘要 → 新 venv 安裝 → 跑 CLI
  3. 發布區只接收已驗證的同一位元組；正式流程另行授權

旁路證據：保留成品 SHA-256、原始碼 commit、建置工具版本、測試紀錄與核准／工作流程 ID。需要可信來源時再驗證簽署的 provenance，不拿一般 JSON 假冒簽章。

01 / 契約

先定義套件名稱與安裝入口

發行名稱用於安裝與中繼資料，import 名稱是 Python 模組識別字，不能假設同名。

  • release-note-lab 是發行名稱；匯入使用 release_note_lab。檔名可能將連字號正規化成底線。
  • [build-system] 設定建置後端與依賴；[project] 描述成品版本、Python 需求與執行期依賴。兩種類型的依賴分開管理。
  • [project.scripts] 讓安裝器建立 CLI。驗收時執行真正的 CLI 入口，而不是直接跑 repo 內的檔案。
  • 這個練習是純 Python、無執行期依賴，宣告 Python ≥3.10；宣告範圍不是測試結果，正式專案依支援範圍配置 CI。
pyproject.toml（完整檔案）
[build-system]
requires = ["setuptools==80.9.0"]
build-backend = "setuptools.build_meta"

[project]
name = "release-note-lab"
version = "0.1.0"
description = "Local-only release engineering exercise"
readme = "README.md"
requires-python = ">=3.10"
dependencies = []

[project.scripts]
release-note-lab = "release_note_lab:main"

[tool.setuptools.packages.find]
where = ["src"]

[tool.setuptools.package-data]
release_note_lab = ["message.txt"]

from importlib.resources import files


def message() -> str:
    return files(__package__).joinpath("message.txt").read_text(encoding="utf-8").strip()


def main() -> None:
    print(f"{version('release-note-lab')}: {message()}")

03 / 成品

先建 sdist，再從 sdist 建 wheel

讓 sdist 實際輪到建置；不要只從 checkout 建 wheel，否則漏掉的來源檔會被掩蓋。

sdist（.tar.gz）
來源發行包；安裝時通常需由工具與後端再建成 wheel。它不是 Git repo 備份，也不保證含有測試、審查紀錄或 CI 憑據。
wheel（.whl）
可直接安裝的套件；本例為 py3-none-any。有原生擴充時，應依 Python／ABI／平台標籤發布並逐個測試；不要用本例推論各環境可直接共用。
兩份包都需要驗證
PyPA build 的預設雙包流程會從 sdist 建 wheel；本章用它檢查來源包足以供建置，並對交付的 wheel 做完整安裝冒煙測試。
# 檢查檔案清單，不執行其中程式
python -m tarfile -l "$DIST/release_note_lab-0.1.0.tar.gz"
python -m zipfile -l "$DIST/release_note_lab-0.1.0-py3-none-any.whl"

預期 wheel 中含 release_note_lab/message.txt、METADATA、WHEEL、entry_points.txt 與 RECORD。RECORD 是安裝檔案清單及部分檔案摘要，不是整份 wheel 的簽章。

04 / 證據

完整性、來源、可重建性各自驗證

知道檔案沒壞，不等於知道誰建置；知道誰建置，也不等於證明沒有漏洞。

完整性：SHA-256
比對收到的檔案與已核准摘要；下載管道若能同時被改寫成品與摘要，裸摘要不能證明來源。範例以 UTF-8 相容 ASCII、固定檔名與換行格式產生 SHA256SUMS，在安裝前驗證。
來源：簽署的 attestation / provenance
按政策核對成品 digest、信任的簽署者／publisher、repo、ref 或工作流程。PyPI Publish Attestation 證明發布者與成品的聲明，不等於完整建置 provenance，也不代表已通過測試。一般 JSON 只算未簽署紀錄。
可重建性：用第二次建置驗證
鎖定 source commit、Python／OS／工具版本、相依圖、時間與 locale。SOURCE_DATE_EPOCH 只對會讀取它的工具生效；不同後端、歸檔格式、檔案順序與平台都可能改變位元組。重建失配先找差異，不要修改舊摘要來讓關卡通過。

最少附上：安裝包、來源包、SHA-256、建置條件、測試命令／環境／結果、已知限制、回退版本。SBOM 是依賴清單，不是漏洞不存在或已修補的證據。

05 / 流程

先驗成品，再讓同一成品過發布閘門

每一站要有可觀察結果。以成品雜湊當作建置、驗收與發布的共同識別。

  1. 01 固定來源核對 tag 與 commit
  2. 02 建置先 sdist，再 wheel
  3. 03 驗包檔案清單與 SHA-256
  4. 04 乾淨驗收新 venv、pip check、CLI、資源檔
  5. 05 核准同一成品、證據齊全才可發布

建置工作不持有發布憑證；驗收工作下載候選成品並重新驗證；發布工作不能重建另一份同名檔案。CI 如需透過 Trusted Publishing 授權，應限定核准的 repo／workflow／environment。練習僅留在本機，不包含上傳步驟。

Go / No-Go

程式上線前：檢驗流程與工具

從要上線的版本倒推：用同一個 commit 建置、用同一組成品摘要驗收。找不到報告、掃描器失敗或演練未完成時，標記為未通過，不以人工勾選代替證據。

  1. 固定候選版本commit、目標環境、wheel SHA-256
  2. 檢查程式品質單元／整合測試、Lint、型別
  3. 檢查相依與憑證掃描鎖檔與原始碼、產出 SBOM
  4. 驗收候選成品確認摘要，隔離安裝並執行入口
  5. 準備回退與核准在測試環境演練、留存 go/no-go 紀錄

輸入、工具、停點與證據

關卡輸入與工具何時停止應保留的證據
測試目標支援矩陣、固定測試資料；unittest 或 pytest。必要案例失敗、未執行或環境覆蓋不符。案例、執行結束狀態、Python／OS、commit。
Lint／型別原始碼與固定設定；Ruff、mypy。違反規則，或未經審查停用規則。規則設定雜湊、命令與工具版本、輸出。
相依風險該環境的實際相依清單；pip-audit 等。違反風險政策、掃描失敗或清單有漏；例外需核准人、原因、期限及緩解措施。鎖檔雜湊、掃描來源與時間、JSON 報告、例外。
密鑰掃描受授權的 Git 歷史或指定檔案範圍；Gitleaks。找到未處理密鑰、掃描歷史不完整或工具失敗。確認曝露時撤銷／輪替，不只刪檔。掃描範圍與遮罩後結果；不留原始密鑰。
SBOM針對目標環境鎖檔或已安裝的成品；CycloneDX。缺檔、生成失敗、與交付內容不符或缺關鍵元件。SBOM、格式版本、關聯成品 SHA-256。
成品驗收同一候選 wheel、受信任摘要、隔離 venv；check_release.py。雜湊、安裝、pip check、真實 CLI 或資料檔驗證任一失敗。摘要驗證、完整命令、目標環境、測試輸出。
回退演練前一穩定成品、設定與資料相容計畫、健康指標；隔離測試環境。無法在時限內恢復，或遷移後的資料不能安全回復。回退觸發門檻、執行結果、恢復時間、核准人。

展開證據 Gate 完整程式
"""Local manifest gate. Validates evidence metadata; does not run scans or deploy."""

import argparse
import hashlib
import json
from pathlib import Path

REQUIRED = (
    "tests", "lint_and_types", "dependency_audit", "secret_scan", "sbom",
    "artifact_smoke", "rollback_rehearsal",
)


def sha256(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as stream:
        while block := stream.read(1024 * 1024):
            digest.update(block)
    return digest.hexdigest()


def distinct_keys(pairs: list[tuple]) -> dict:
    out: dict = {}
    for key, value in pairs:
        if key in out:
            raise ValueError(f"duplicate key: {key}")
        out[key] = value
    return out


def run(candidate: Path, manifest: Path) -> list[str]:
    digest = sha256(candidate)
    payload = json.loads(manifest.read_text(encoding="utf-8"),
                         object_pairs_hook=distinct_keys)
    if not isinstance(payload, dict) or payload.get("candidate_sha256") != digest:
        return ["candidate digest mismatch"]
    gates = payload.get("gates")
    if not isinstance(gates, dict):
        return ["invalid gates"]
    errors = []
    for name in REQUIRED:
        item = gates.get(name)
        if (not isinstance(item, dict) or item.get("status") != "pass"
                or not isinstance(item.get("evidence"), str)
                or not item["evidence"].strip()):
            errors.append(f"missing passing evidence: {name}")
    return errors


def main() -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("candidate", type=Path)
    parser.add_argument("manifest", type=Path)
    args = parser.parse_args()
    try:
        errors = run(args.candidate, args.manifest)
    except (ValueError, OSError):
        print(json.dumps({"decision": "BLOCK", "reasons": ["unreadable artifact or manifest"]}))
        return 2
    print(json.dumps({"decision": "BLOCK" if errors else "PASS", "reasons": errors}))
    return 1 if errors else 0


if __name__ == "__main__":
    raise SystemExit(main())

06 / 維運

用失敗情境驗證發布設計

保留上一版已驗證成品，並將套件回退、設定回退、資料遷移回退分開評估。

  • 摘要錯誤：隔離候選成品、停止安裝，核對儲存與傳輸紀錄。
  • CLI 找不到：核對 entry point、是否裝到預期虛擬環境、實際啟動的執行檔路徑。
  • 原始碼單測通過、wheel 讀不到資料檔：確認 package-data 與實際包內容，從 sdist 重建後再測。
  • 有執行期依賴：改用經審核且完整的 wheelhouse 與雜湊鎖定，不要照抄此例的 --no-deps。
  • 已發布錯版：依索引規則用新版本修正發行，必要時依政策 yank；部署端明確鎖定已驗證版本，不能假設 yank 會讓所有客戶端自動撤回。

07 / 本機實作

從 pyproject.toml 走到驗證過的安裝成品

以下指令適用 macOS／Linux 的 POSIX shell。從 repository 根目錄進入新實驗目錄；不會發布到 PyPI 或 GitHub。首次取得建置工具需要網路或自備 wheelhouse。

pyproject.toml · 驗證腳本 · 既有進階實驗

A. 建置與原始碼單測

cd '範例程式碼/verified_release_lab'
TOOLS="$(mktemp -d)"
DIST="$(mktemp -d)"
python3 -m venv "$TOOLS/venv"
PY="$TOOLS/venv/bin/python"
"$PY" -m pip install 'build==1.2.2.post1' 'setuptools==80.9.0'
PYTHONPATH=src "$PY" -m unittest discover -s tests -v
export SOURCE_DATE_EPOCH=1700000000 TZ=UTC
"$PY" -m build --no-isolation --outdir "$DIST"

--no-isolation 不建立第二層建置環境；此處已有獨立、指定版本的建置環境。正式專案仍需鎖定間接依賴與環境映像；這兩個直接 pin 不構成完整的供應鏈鎖定。

B. 寫入摘要，然後在乾淨 venv 驗證

# 建置工作只寫一次。驗收工作只跑 verify/smoke，不重寫摘要。
"$PY" check_release.py "$DIST" write
"$PY" check_release.py "$DIST" smoke
# 預期 SHA-256 PASS / No broken requirements found.
# 0.1.0: Release artifact verified; wheel smoke PASS (...)

C. 重建比對與負向測試

本次 Linux／CPython 3.12.14、兩次同工具環境重建：wheel 位元組相同；sdist 不同，差異從 gzip 標頭時間欄開始。這不是跨機器或跨版本的可重現承諾。

SECOND="$(mktemp -d)"
"$PY" -m build --no-isolation --outdir "$SECOND"
cmp "$DIST/release_note_lab-0.1.0-py3-none-any.whl"     "$SECOND/release_note_lab-0.1.0-py3-none-any.whl"
# 不假設 sdist 也相同；分開比較並記錄。
cmp "$DIST/release_note_lab-0.1.0.tar.gz"     "$SECOND/release_note_lab-0.1.0.tar.gz"

# 僅竄改另一份暫存副本，原始候選成品不變。
BAD="$(mktemp -d)"

"""Verify the lab's exact package pair; then smoke-test the wheel in a clean venv."""

import argparse
import hashlib
import hmac
import os
from pathlib import Path
import subprocess
import sys
from tempfile import TemporaryDirectory
import venv

NAMES = ("release_note_lab-0.1.0-py3-none-any.whl", "release_note_lab-0.1.0.tar.gz")
MANIFEST = "SHA256SUMS"


def manifest_bytes(dist: Path) -> bytes:
    actual = {p.name for p in dist.iterdir() if p.name != MANIFEST}
    if actual != set(NAMES):
        raise SystemExit(f"Expected only the two lab artifacts; found {sorted(actual)}")
    lines = []
    for name in NAMES:
        with (dist / name).open("rb") as artifact:
            sha = hashlib.sha256()
            while block := artifact.read(1024 * 1024):
                sha.update(block)
        lines.append(f"{sha.hexdigest()}  {name}\n")
    return "".join(lines).encode("ascii")


def verify(dist: Path) -> None:
    if not hmac.compare_digest((dist / MANIFEST).read_bytes(), manifest_bytes(dist)):
        raise SystemExit("SHA-256 mismatch: do not install or promote these files")


def smoke(dist: Path) -> None:
    with TemporaryDirectory(prefix="release-smoke-") as temp:
        temp = Path(temp)
        envdir = temp / "venv"
        venv.EnvBuilder(with_pip=True).create(envdir)
        bindir = envdir / ("Scripts" if os.name == "nt" else "bin")
        py = bindir / ("python.exe" if os.name == "nt" else "python")
        exe = bindir / ("release-note-lab.exe" if os.name == "nt" else "release-note-lab")
        env = {k: v for k, v in os.environ.items() if not k.startswith(("PYTHON", "PIP_"))}
        subprocess.run(
            [py, "-I", "-m", "pip", "--isolated", "install", "--no-index",
             "--no-deps", dist / NAMES[0]],
            cwd=temp, env=env, check=True,
        )
        subprocess.run([py, "-I", "-m", "pip", "--isolated", "check"],
                       cwd=temp, env=env, check=True)
        actual = subprocess.check_output([exe], cwd=temp, env=env, text=True).strip()
        expected = "0.1.0: Release artifact verified"
        if actual != expected:
            raise SystemExit(f"CLI output mismatch: {actual!r}")
        print(f"{actual}; wheel smoke PASS ({sys.version.split()[0]})")


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("dist", type=Path)
    parser.add_argument("mode", choices=("write", "verify", "smoke"))
    args = parser.parse_args()
    dist = args.dist.resolve()
    if args.mode == "write":
        with (dist / MANIFEST).open("xb") as target:
            target.write(manifest_bytes(dist))
    else:
        verify(dist)
        print("SHA-256 PASS")
        if args.mode == "smoke":
            smoke(dist)


if __name__ == "__main__":
    main()

from __future__ import annotations

import argparse
from pathlib import Path

from .release import ReleaseGateError, run_release_gate, validate_release_metadata


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(description="Run packaging release gate checks.")
    parser.add_argument("command", choices=["verify", "build"], help="verify metadata or build release evidence")
    parser.add_argument("--project-root", default=".", help="project root path")
    parser.add_argument("--dist-dir", default=None, help="optional dist output directory")
    return parser


def main(argv: list[str] | None = None) -> int:
    parser = build_parser()
    args = parser.parse_args(argv)
    project_root = Path(args.project_root).resolve()
    dist_dir = Path(args.dist_dir).resolve() if args.dist_dir else None

    try:
        if args.command == "verify":
            metadata = validate_release_metadata(project_root)
            print(f"release metadata ok: {metadata.name} {metadata.version}")
            return 0
        archive_path, manifest_path = run_release_gate(project_root, dist_dir=dist_dir)
        print(f"release artifact: {archive_path}")
        print(f"release manifest: {manifest_path}")
        return 0
    except ReleaseGateError as exc:
        parser.exit(status=2, message=f"release gate failed: {exc}\n")


if __name__ == "__main__":
    raise SystemExit(main())

from __future__ import annotations

import hashlib
import json
import re
import tarfile
import tomllib
from dataclasses import dataclass
from datetime import datetime, timezone
from pathlib import Path
from typing import Iterable


class ReleaseGateError(RuntimeError):
    """Raised when release evidence is incomplete or inconsistent."""


@dataclass(frozen=True)
class ProjectMetadata:
    name: str
    version: str
    package: str
    changelog: Path
    dist_dir: Path

    @property
    def archive_name(self) -> str:
        return f"{self.name}-{self.version}.tar.gz"


def load_project_metadata(project_root: Path) -> ProjectMetadata:
    pyproject = project_root / "pyproject.toml"
    if not pyproject.exists():
        raise ReleaseGateError("Missing pyproject.toml")

    data = tomllib.loads(pyproject.read_text(encoding="utf-8"))
    project = data.get("project", {})
    tool = data.get("tool", {}).get("release_gate", {})
    name = project.get("name")
    version = project.get("version")
    package = tool.get("package") or str(name).replace("-", "_")
    changelog = project_root / tool.get("changelog", "CHANGELOG.md")
    dist_dir = project_root / tool.get("dist_dir", "dist")

    if not name or not version:
        raise ReleaseGateError("pyproject.toml must define project.name and project.version")
    return ProjectMetadata(name=name, version=version, package=package, changelog=changelog, dist_dir=dist_dir)


def read_package_version(project_root: Path, package: str) -> str:
    init_file = project_root / "src" / package / "__init__.py"
    if not init_file.exists():
        raise ReleaseGateError(f"Missing package init: {init_file}")
    match = re.search(r'^__version__\s*=\s*["\']([^"\']+)["\']', init_file.read_text(encoding="utf-8"), re.MULTILINE)
    if not match:
        raise ReleaseGateError(f"Missing __version__ in {init_file}")
    return match.group(1)


def validate_release_metadata(project_root: Path) -> ProjectMetadata:
    metadata = load_project_metadata(project_root)
    package_version = read_package_version(project_root, metadata.package)
    if package_version != metadata.version:
        raise ReleaseGateError(f"Version mismatch: pyproject={metadata.version}, package={package_version}")
    if not metadata.changelog.exists():
        raise ReleaseGateError(f"Missing changelog: {metadata.changelog}")
    changelog_text = metadata.changelog.read_text(encoding="utf-8")
    if f"## v{metadata.version}" not in changelog_text:
        raise ReleaseGateError(f"Missing changelog entry for v{metadata.version}")
    return metadata


def iter_release_files(project_root: Path) -> Iterable[Path]:
    include_roots = [project_root / "pyproject.toml", project_root / "README.md", project_root / "CHANGELOG.md", project_root / "src"]
    for root in include_roots:
        if root.is_file():
            yield root
        elif root.is_dir():
            for path in sorted(root.rglob("*")):
                if path.is_file() and "__pycache__" not in path.parts and path.suffix != ".pyc":
                    yield path


def build_source_archive(project_root: Path, dist_dir: Path | None = None) -> Path:
    metadata = validate_release_metadata(project_root)
    target_dir = dist_dir or metadata.dist_dir
    target_dir.mkdir(parents=True, exist_ok=True)
    archive_path = target_dir / metadata.archive_name
    prefix = f"{metadata.name}-{metadata.version}"

    with tarfile.open(archive_path, "w:gz") as archive:
        for path in iter_release_files(project_root):
            relative = path.relative_to(project_root)
            tar_info = archive.gettarinfo(str(path), arcname=str(Path(prefix) / relative))
            tar_info.uid = tar_info.gid = 0
            tar_info.uname = tar_info.gname = ""
            tar_info.mtime = 0
            with path.open("rb") as source:
                archive.addfile(tar_info, source)
    return archive_path


def sha256_file(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as source:
        for block in iter(lambda: source.read(1024 * 64), b""):
            digest.update(block)
    return digest.hexdigest()


def write_release_manifest(project_root: Path, archive_path: Path) -> Path:
    metadata = validate_release_metadata(project_root)
    manifest = {
        "name": metadata.name,
        "version": metadata.version,
        "package": metadata.package,
        "artifact": archive_path.name,
        "sha256": sha256_file(archive_path),
        "generated_at": datetime.now(timezone.utc).isoformat(),
        "files": [str(path.relative_to(project_root)) for path in iter_release_files(project_root)],
        "gates": ["metadata", "version", "changelog", "archive", "checksum"],
    }
    manifest_path = archive_path.with_name("release-manifest.json")
    manifest_path.write_text(json.dumps(manifest, indent=2, sort_keys=True) + "\n", encoding="utf-8")
    return manifest_path


def run_release_gate(project_root: Path, dist_dir: Path | None = None) -> tuple[Path, Path]:
    archive_path = build_source_archive(project_root, dist_dir=dist_dir)
    manifest_path = write_release_manifest(project_root, archive_path)
    return archive_path, manifest_path

"""Local manifest gate. Validates evidence metadata; does not run scans or deploy."""

import argparse
import hashlib
import json
from pathlib import Path

REQUIRED = (
    "tests", "lint_and_types", "dependency_audit", "secret_scan", "sbom",
    "artifact_smoke", "rollback_rehearsal",
)


def sha256(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as stream:
        while block := stream.read(1024 * 1024):
            digest.update(block)
    return digest.hexdigest()


def distinct_keys(pairs: list[tuple]) -> dict:
    out: dict = {}
    for key, value in pairs:
        if key in out:
            raise ValueError(f"duplicate key: {key}")
        out[key] = value
    return out


def run(candidate: Path, manifest: Path) -> list[str]:
    digest = sha256(candidate)
    payload = json.loads(manifest.read_text(encoding="utf-8"),
                         object_pairs_hook=distinct_keys)
    if not isinstance(payload, dict) or payload.get("candidate_sha256") != digest:
        return ["candidate digest mismatch"]
    gates = payload.get("gates")
    if not isinstance(gates, dict):
        return ["invalid gates"]
    errors = []
    for name in REQUIRED:
        item = gates.get(name)
        if (not isinstance(item, dict) or item.get("status") != "pass"
                or not isinstance(item.get("evidence"), str)
                or not item["evidence"].strip()):
            errors.append(f"missing passing evidence: {name}")
    return errors


def main() -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("candidate", type=Path)
    parser.add_argument("manifest", type=Path)
    args = parser.parse_args()
    try:
        errors = run(args.candidate, args.manifest)
    except (ValueError, OSError):
        print(json.dumps({"decision": "BLOCK", "reasons": ["unreadable artifact or manifest"]}))
        return 2
    print(json.dumps({"decision": "BLOCK" if errors else "PASS", "reasons": errors}))
    return 1 if errors else 0


if __name__ == "__main__":
    raise SystemExit(main())
