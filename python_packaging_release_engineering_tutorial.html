MetadataArtifactEvidencePipeline
Metadata

先把 package 身分變成契約

發布工程的第一步不是 build，而是確認名稱、版本、Python 版本與入口點都有明確來源。

Layout

src layout 讓 import 邊界更可靠

包裝結構會影響測試可信度、import 行為與使用者安裝後的錯誤面。

Artifact

artifact 要能重建、可比對、可追蹤

sdist、wheel、executable 的用途不同，但都需要 checksum 與 manifest 支撐交付。

Evidence

release note 要連到測試與風險證據

發布紀錄應回答改了什麼、怎麼驗、失敗如何回退。

Pipeline

CI gate 決定哪些 artifact 可以被推送

測試、metadata、build、smoke 與簽核要有清楚順序。

Operations

發布後仍要能診斷、回復與稽核

外部 PyPI/GitHub Release 權限、token、promotion 與 rollback 都要有邊界。
