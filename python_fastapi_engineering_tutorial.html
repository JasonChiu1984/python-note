FastAPI Intro

簡介與專案心智模型

先把 FastAPI 放在正確位置：它是 ASGI web framework，靠 Python type hints、Pydantic、Starlette 與 OpenAPI，把 API contract 變成可驗證、可測試、可部署的 service。

Commands

指令說明與參數表

開發、測試、啟動與部署都要知道每個參數在控制什麼，尤其是 `--reload`、`--workers`、host/port、環境變數與 release smoke test。

指令用途常用參數工程提醒
pip install "fastapi[standard]"安裝 FastAPI 與標準開發依賴搭配 venv / lock file部署環境要固定版本
fastapi dev app/main.py本機開發啟動--host、--port開發用，不當 production process manager
fastapi run app/main.py啟動 production-oriented server--host、--port仍需搭配部署平台、health check、logs
uvicorn app.main:app --reload開發 reload--reload、--factoryreload 不能進 production
uvicorn app.main:app --workers 4多 worker 啟動--workers、--host、--port每個 worker 有獨立 memory 與 DB pool
pytest -qAPI 測試-q、-k、--maxfail測 contract，不只測函式
python -m buildwheel / sdist 交付讀取 pyproject.toml安裝 wheel 後再跑 smoke test
Routing

路由、回應與 API contract

每個 path operation 都是對外契約：path/query/body/status/response model 錯了，前端、SDK、CI、監控都會一起痛。

Validation

驗證、依賴注入與安全邊界

Pydantic model、Depends、settings、security、middleware 是 FastAPI 能從 demo 變成專案的核心。這章刻意把 failure mode 放進每張卡。

Applications

專案級應用案例

把 API 寫進 service/repository/test boundary：notes API、DB session、upload、SSE/WebSocket、背景任務、OpenAPI versioning。

Packaging

打包、部署與 release smoke test

FastAPI 交付通常不是單一 exe，而是 wheel、container、process manager、workers、環境變數、health check、rollback script 的組合。

Checklist

專案驗收清單

完成此篇後，你應該能把一個 FastAPI service 從 contract、code、test、package 到 deployment smoke test 串起來。

Contract每個 endpoint 有 request/response model、status code 與錯誤格式。
TestingTestClient、dependency override、DB fake、contract regression。
SecurityCORS、auth、secrets、rate limit、permission boundary。
Deliverywheel/container、health check、workers、rollback、logs。
