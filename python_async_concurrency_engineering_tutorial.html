ModelTasksFlowFailureTesting
Model

先理解 event loop，不要只背 await

非同步的核心不是更快，而是在等待 I/O 時把控制權交回 event loop。

Tasks

Task lifecycle 要有 owner 與退出條件

每個 background task 都應知道誰建立、如何取消、錯誤去哪裡。

Flow Control

用 backpressure 保護記憶體與下游

沒有邊界的 queue 會把瞬間流量變成延遲、記憶體與事故。

Failure

Timeout、retry 與 cancellation 必須被設計

外部 I/O 沒有 timeout 就沒有可靠性；取消被吞掉會讓 shutdown 不可信。

Testing

並發測試要可重跑、可診斷

測試要鎖住順序、失敗注入與邊界，不要依賴碰巧的 timing。

Delivery

交付前要留下 worker 系統證據

release note 要包含 queue size、timeout、worker count、smoke result 與 rollback 限制。
