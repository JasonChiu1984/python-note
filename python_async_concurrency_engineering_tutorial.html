把任務從接受、執行做到可確認的結束

用 Python 3.11–3.15 標準函式庫做一條離線管線。目標不是永不失敗，而是有界、分得出失敗類型，並且不會在子任務早退後卡著等佇列。

架構與責任預算與重試關機流程測試與交付程式碼

架構圖：資料流和監督不是同一條路

先算等待預算，再決定佇列、並發與重試

「幾個 worker」限制同時進行的操作，並不保證下游只收到指定的每秒速率。若下游要求每秒 20 次，另加速率限制器；若多個 worker 共用一條半雙工 RS-485，則每條實體匯流排同時只執行一個交易。同步阻塞 I/O 可考慮 asyncio.to_thread()，但取消等待不會強制結束已跑起來的執行緒；CPU 密集工作另評估程序或其他平行模型。

預算範例控制點要驗收什麼
入列等待admission_timeout：等 Queue.put() 最久多久；若逾時或呼叫者在邊界取消，回應未確認時不能推定一定沒有入列；正式系統依 job ID 查詢接收狀態。滿載時上游也要限制同時等待的 producer 數量；有界 Queue 不限制 Queue 外面的待入列任務數。
單次 I/O現存參數 per_item_timeout 用於每次嘗試；單次期限是它與剩餘總期限中較小者。逾時與永久錯誤不是同一類；重試前確認副作用能否安全重送。
整筆工作job_timeout 以事件迴圈單調時鐘計，從提交起含入列、佇列等待、嘗試與退避；已排入但期限耗盡者不再呼叫 handler。比較排隊時間與 I/O 時間；量測整筆 P95／P99，分開記每次嘗試逾時與最終工作逾時。
關機排空停止並等 producer 收尾後，以 drain_timeout 約束排空階段；逾時即轉取消與清理，不宣稱已交付。測過期中的工作會清理、佇列不留下假成功；清理合作性不佳時須由程序級監督作後備。

容量算例（非基準測試）：若下游允許 4 個同時作業、每筆平均 200 ms，無重試且充分利用時，粗估處理能力為 4 ÷ 0.2＝20 筆/s。短暫進到 30 筆/s，等候區 20 格約 20 ÷ (30−20)＝2 秒填滿。平均值無法保證尾端延遲；現場用尖峰、下游變慢與重試的資料重新估算，並同時管控待入列的 producer 數量。

重試決策

  • 明確允許重送的暫時錯誤才進退避；範例採有上限的指數等待，正式部署可加隨機抖動，避免所有 worker 同一刻重試。
  • 驗證、權限及不相容的資料錯誤應立即回報。非預期程式錯誤不能塞回同一條佇列無限重跑。
  • 逾時不是「對方未執行」。重試會產生副作用時，必須有接收端去重、狀態查詢或人工對帳；範例的 idempotency_key 只是欄位，沒有提供去重保證。逾時後若無法安全查證，就不要用這個離線範例直接執行寫入。

關機圖：停止接受 → 排空，或取消並承認未完成

停止入口 → 等 producer 結束 → 監督排空。每次取出都在 finally 呼叫 task_done()。

  • 正常：佇列排空且 worker 健康本例發出每個 worker 一個停止標記，再等待全部退出。
  • 異常：排空逾時或 worker 早退取消剩餘 worker、等待清理並傳回失敗；記憶體中的未完成工作不保留。

Queue.join() 只表示未完成帳數歸零，不表示全部成功或已落盤。Python 3.13 起可以改用 asyncio.Queue.shutdown(immediate=False) 與 QueueShutDown 正常排空；immediate=True 會改變 join 的一般完成語意，不能當成交付確認。範例為同時支援 3.11–3.15，不分支使用新 API。不要吞掉 CancelledError；在 finally 釋放資源後讓取消傳回上層。

把故障測試與交付證據放在一起

  1. 正常路徑：核對接受筆數、完成筆數、輸出與入列上限。固定 worker 數不保證結果按輸入順序，消費端以 job ID 對應。
  2. 壓力與故障：用 Event 把 handler 卡在可預期位置，驗證滿載背壓、worker 在入列或排空等待時失敗、暫時／永久失敗、整筆期限與撤銷清理。測試本身也有等待上限。
  3. 上線指標：看佇列深度和最老工作等待時間、接受／拒絕率、處理時間 P95／P99、重試與最終失敗。交付紀錄應包含版本、工作負載、併發、逾時、測試輸出及撤回條件。
  4. 正式服務：本例的結果列表與佇列都在記憶體，適合有限批次；長時間服務改用有界結果出口，失敗須重播時用耐久工作儲存，並把接收端去重與確認邊界納入設計。

Model

先理解 event loop，不要只背 await

非同步的核心不是更快，而是在等待 I/O 時把控制權交回 event loop。

Tasks

Task lifecycle 要有 owner 與退出條件

每個 background task 都應知道誰建立、如何取消、錯誤去哪裡。

Flow Control

用 backpressure 保護記憶體與下游

沒有邊界的 queue 會把瞬間流量變成延遲、記憶體與事故。

Failure

Timeout、retry 與 cancellation 必須被設計

外部 I/O 沒有 timeout 就沒有可靠性；取消被吞掉會讓 shutdown 不可信。

Testing

並發測試要可重跑、可診斷

測試要鎖住順序、失敗注入與邊界，不要依賴碰巧的 timing。

Delivery

交付前要留下 worker 系統證據

release note 要包含 queue size、timeout、worker count、smoke result 與 rollback 限制。

#!/usr/bin/env python3
from __future__ import annotations

import asyncio
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT / "src"))

from async_concurrency_engineering import RetryableJobError, WorkItem, run_pipeline


async def handler(item: WorkItem) -> int:
    await asyncio.sleep(0.005)
    if item.payload == 7:
        raise RetryableJobError("retryable smoke failure")
    return item.payload * 3


async def main() -> None:
    attempts: dict[str, int] = {}

    async def smoke_handler(item: WorkItem) -> int:
        attempts[item.item_id] = attempts.get(item.item_id, 0) + 1
        if attempts[item.item_id] == 1 and item.payload == 7:
            raise RetryableJobError("dependency busy")
        return await handler(WorkItem(item.item_id, 8 if item.payload == 7 else item.payload, item.idempotency_key))

    items = [
        WorkItem("a", 2, "a"),
        WorkItem("b", 7, "b"),
        WorkItem("c", 5, "c"),
    ]
    results, metrics = await run_pipeline(items, smoke_handler, worker_count=2, max_attempts=2)
    if metrics.submitted != 3 or metrics.succeeded != 3 or metrics.retried != 1:
        raise SystemExit(f"unexpected metrics: {metrics}")
    if sorted(result.value for result in results) != [6, 15, 24]:
        raise SystemExit(f"unexpected results: {results}")
    print("async smoke passed: bounded workers + retry + metrics")


if __name__ == "__main__":
    asyncio.run(main())

"""Bounded, in-memory asyncio worker pipeline for Python 3.11+."""

from __future__ import annotations

import asyncio
import math
from collections.abc import Awaitable, Callable, Iterable
from dataclasses import dataclass
from typing import TypeVar


class RetryableJobError(Exception):
    """Retry only when the operation's contract permits it."""


class PermanentJobError(Exception):
    """Repetition would not fix this job."""


@dataclass(frozen=True)
class WorkItem:
    item_id: str
    payload: int
    idempotency_key: str


@dataclass(frozen=True)
class JobResult:
    item_id: str
    status: str
    attempts: int
    value: int | None = None
    error: str | None = None
    duration_ms: float = 0.0  # Includes queue wait, not merely handler runtime.


@dataclass
class AsyncPipelineMetrics:
    submitted: int = 0
    succeeded: int = 0
    failed: int = 0
    timed_out: int = 0  # Terminal timed-out jobs, a subset of failed.
    attempt_timeouts: int = 0
    retried: int = 0   # Additional attempts that actually started.
    cancelled: int = 0  # Started jobs cancelled during abort.


@dataclass(frozen=True)
class _Envelope:
    item: WorkItem
    started: float
    deadline: float


Handler = Callable[[WorkItem], Awaitable[int]]
T = TypeVar("T")


class AsyncWorkerPipeline:
    """Single-event-loop owner; stop and await producers before close() or abort()."""

    def __init__(
        self,
        handler: Handler,
        *,
        worker_count: int = 3,
        max_queue_size: int = 8,
        per_item_timeout: float = 0.25,
        max_attempts: int = 2,
        admission_timeout: float = 1.0,
        job_timeout: float = 2.0,
        retry_delay: float = 0.02,
        drain_timeout: float = 5.0,
    ) -> None:
        if min(worker_count, max_queue_size, max_attempts) < 1:
            raise ValueError("worker count, queue size and attempts must be positive")
        budgets = (per_item_timeout, admission_timeout, job_timeout, drain_timeout)
        if not all(math.isfinite(x) and x > 0 for x in budgets):
            raise ValueError("time budgets must be finite and positive")
        if not math.isfinite(retry_delay) or retry_delay < 0:
            raise ValueError("retry_delay must be finite and non-negative")
        self._handler = handler
        self._worker_count = worker_count
        self._queue: asyncio.Queue[_Envelope | None] = asyncio.Queue(maxsize=max_queue_size)
        self._per_item_timeout = per_item_timeout
        self._max_attempts = max_attempts
        self._admission_timeout = admission_timeout
        self._job_timeout = job_timeout
        self._retry_delay = retry_delay
        self._drain_timeout = drain_timeout
        self._workers: list[asyncio.Task[None]] = []
        self._accepting = True
        self._submitters = 0
        self._closed = False
        self._closing_lock = asyncio.Lock()
        self.metrics = AsyncPipelineMetrics()
        self.results: list[JobResult] = []  # Finite demo only: use a result sink for long-running services.

    async def start(self) -> None:
        if not self._accepting:
            raise RuntimeError("pipeline is closed")
        if not self._workers:
            self._workers = [
                asyncio.create_task(self._worker_loop(), name=f"async-worker-{index}")
                for index in range(self._worker_count)
            ]

    async def _supervise(self, operation: Awaitable[T]) -> T:
        """Watch worker failure while waiting on admission or drain."""
        waiting = asyncio.ensure_future(operation)
        try:
            await asyncio.wait([waiting, *self._workers], return_when=asyncio.FIRST_COMPLETED)
            for worker in self._workers:
                if worker.done():
                    worker.result()  # Re-raise the real failure.
                    raise RuntimeError("worker stopped before draining")
            return waiting.result()
        finally:
            if not waiting.done():
                waiting.cancel()
            await asyncio.gather(waiting, return_exceptions=True)

    async def submit(self, item: WorkItem) -> None:
        if not self._workers or not self._accepting:
            raise RuntimeError("pipeline is not accepting submissions")
        now = asyncio.get_running_loop().time()
        envelope = _Envelope(item, now, now + self._job_timeout)
        self._submitters += 1
        try:
            async with asyncio.timeout(min(self._admission_timeout, self._job_timeout)):
                await self._supervise(self._enqueue(envelope))
        finally:
            self._submitters -= 1

    async def _enqueue(self, envelope: _Envelope) -> None:
        await self._queue.put(envelope)
        self.metrics.submitted += 1  # Admission is counted at the actual queue boundary.

    async def close(self) -> None:
        async with self._closing_lock:
            if self._closed:
                return
            if self._submitters:
                raise RuntimeError("stop and await producers before closing")
            self._accepting = False
            try:
                async with asyncio.timeout(self._drain_timeout):
                    if self._workers:
                        await self._supervise(self._queue.join())
                        for _ in self._workers:
                            await self._queue.put(None)
                        await asyncio.gather(*self._workers)
                self._closed = True
            except BaseException:
                await self.abort()
                raise

    async def abort(self) -> None:
        """Cancel workers, await their cleanup, and discard in-memory backlog."""
        self._accepting = False
        for worker in self._workers:
            if not worker.done():
                worker.cancel()
        await asyncio.gather(*self._workers, return_exceptions=True)
        while not self._queue.empty():
            self._queue.get_nowait()
            self._queue.task_done()
        self._closed = True

    async def _worker_loop(self) -> None:
        while True:
            envelope = await self._queue.get()
            try:
                if envelope is None:
                    return
                self.results.append(await self._handle_with_retry(envelope))
            finally:
                self._queue.task_done()

    async def _handle_with_retry(self, envelope: _Envelope) -> JobResult:
        clock = asyncio.get_running_loop().time
        item = envelope.item
        attempts = 0
        last_status, last_error = "timed_out", "job deadline expired"
        try:
            while attempts < self._max_attempts:
                remaining = envelope.deadline - clock()
                if remaining <= 0:
                    last_status, last_error = "timed_out", "job deadline expired"
                    break
                attempts += 1
                if attempts > 1:
                    self.metrics.retried += 1
                try:
                    async with asyncio.timeout(min(remaining, self._per_item_timeout)):
                        value = await self._handler(item)
                    self.metrics.succeeded += 1
                    return JobResult(item.item_id, "succeeded", attempts, value=value,
                                     duration_ms=round((clock() - envelope.started) * 1000, 3))
                except TimeoutError:
                    self.metrics.attempt_timeouts += 1
                    last_status, last_error = "timed_out", "timeout"
                except RetryableJobError as exc:
                    last_status, last_error = "failed", str(exc)
                except PermanentJobError as exc:
                    last_status, last_error = "failed", str(exc)
                    break
                if attempts < self._max_attempts:
                    delay = min(self._retry_delay * 2 ** min(attempts - 1, 10), 1.0)
                    await asyncio.sleep(min(delay, max(0, envelope.deadline - clock())))
        except asyncio.CancelledError:
            self.metrics.cancelled += 1
            raise
        self.metrics.failed += 1
        if last_status == "timed_out":
            self.metrics.timed_out += 1
        return JobResult(item.item_id, last_status, attempts, error=last_error,
                         duration_ms=round((clock() - envelope.started) * 1000, 3))


async def run_pipeline(
    items: Iterable[WorkItem],
    handler: Handler,
    *,
    worker_count: int = 3,
    max_queue_size: int = 8,
    per_item_timeout: float = 0.25,
    max_attempts: int = 2,
    admission_timeout: float = 1.0,
    job_timeout: float = 2.0,
    retry_delay: float = 0.02,
    drain_timeout: float = 5.0,
) -> tuple[list[JobResult], AsyncPipelineMetrics]:
    pipeline = AsyncWorkerPipeline(
        handler, worker_count=worker_count, max_queue_size=max_queue_size,
        per_item_timeout=per_item_timeout, max_attempts=max_attempts,
        admission_timeout=admission_timeout, job_timeout=job_timeout,
        retry_delay=retry_delay, drain_timeout=drain_timeout,
    )
    await pipeline.start()
    try:
        for item in items:
            await pipeline.submit(item)
        await pipeline.close()
    except BaseException:
        await pipeline.abort()
        raise
    return pipeline.results, pipeline.metrics

from __future__ import annotations

import asyncio
import unittest

from async_concurrency_engineering import AsyncWorkerPipeline, PermanentJobError, RetryableJobError, WorkItem, run_pipeline


class AsyncWorkerPipelineTests(unittest.IsolatedAsyncioTestCase):
    async def test_processes_items_with_bounded_workers(self) -> None:
        async def handler(item: WorkItem) -> int:
            await asyncio.sleep(0)
            return item.payload * 10

        items = [WorkItem(f"job-{index}", index, f"key-{index}") for index in range(5)]
        results, metrics = await run_pipeline(items, handler, worker_count=2)

        self.assertEqual(metrics.submitted, 5)
        self.assertEqual(metrics.succeeded, 5)
        self.assertEqual(sorted(result.value for result in results), [0, 10, 20, 30, 40])

    async def test_retries_retryable_error(self) -> None:
        calls: dict[str, int] = {}

        async def handler(item: WorkItem) -> int:
            calls[item.item_id] = calls.get(item.item_id, 0) + 1
            if calls[item.item_id] == 1:
                raise RetryableJobError("temporary dependency failure")
            return item.payload + 1

        results, metrics = await run_pipeline([WorkItem("retry", 41, "retry-key")], handler, max_attempts=2)

        self.assertEqual(results[0].status, "succeeded")
        self.assertEqual(results[0].attempts, 2)
        self.assertEqual(results[0].value, 42)
        self.assertEqual(metrics.retried, 1)

    async def test_timeout_is_classified(self) -> None:
        async def slow_handler(item: WorkItem) -> int:
            await asyncio.sleep(0.05)
            return item.payload

        results, metrics = await run_pipeline(
            [WorkItem("slow", 1, "slow-key")],
            slow_handler,
            per_item_timeout=0.001,
            max_attempts=1,
        )

        self.assertEqual(results[0].status, "timed_out")
        self.assertEqual(metrics.timed_out, 1)
        self.assertEqual(metrics.failed, 1)

    async def test_queue_maxsize_creates_backpressure(self) -> None:
        release_worker = asyncio.Event()

        async def handler(item: WorkItem) -> int:
            await release_worker.wait()
            return item.payload

        pipeline = AsyncWorkerPipeline(handler, worker_count=1, max_queue_size=1)
        await pipeline.start()
        await pipeline.submit(WorkItem("first", 1, "first"))
        await asyncio.sleep(0)
        await pipeline.submit(WorkItem("second", 2, "second"))

        second_submit = asyncio.create_task(pipeline.submit(WorkItem("third", 3, "third")))
        await asyncio.sleep(0.01)

        self.assertFalse(second_submit.done())
        second_submit.cancel()
        with self.assertRaises(asyncio.CancelledError):
            await second_submit
        release_worker.set()
        await pipeline.close()

    async def test_close_drains_queue_and_stops_workers(self) -> None:
        async def handler(item: WorkItem) -> int:
            await asyncio.sleep(0)
            return item.payload

        pipeline = AsyncWorkerPipeline(handler, worker_count=2)
        await pipeline.start()
        await pipeline.submit(WorkItem("one", 1, "one"))
        await pipeline.submit(WorkItem("two", 2, "two"))
        await pipeline.close()

        self.assertEqual(len(pipeline.results), 2)
        self.assertTrue(all(worker.done() for worker in pipeline._workers))


    async def test_worker_failure_surfaces_while_admission_is_blocked(self) -> None:
        hit = asyncio.Event()
        release = asyncio.Event()

        async def handler(item: WorkItem) -> int:
            hit.set()
            await release.wait()
            raise LookupError("unexpected handler defect")

        p = AsyncWorkerPipeline(handler, worker_count=1, max_queue_size=1)
        await p.start()
        try:
            await p.submit(WorkItem("active", 1, "active"))
            await hit.wait()
            await p.submit(WorkItem("queued", 2, "queued"))
            blocked = asyncio.create_task(p.submit(WorkItem("blocked", 3, "blocked")))
            await asyncio.sleep(0)
            self.assertFalse(blocked.done())
            release.set()
            with self.assertRaisesRegex(LookupError, "unexpected handler defect"):
                await asyncio.wait_for(blocked, 1)
        finally:
            await p.abort()
        self.assertTrue(all(worker.done() for worker in p._workers))
        self.assertEqual(p.metrics.submitted, 2)

    async def test_worker_failure_surfaces_during_drain(self) -> None:

    async def test_permanent_error_never_retries(self) -> None:

        self.assertEqual((result[0].status, result[0].attempts, metrics.retried), ("failed", 1, 0))

    async def test_drain_timeout_cleans_worker_and_discards_backlog(self) -> None:
        active = asyncio.Event()
        cleaned = asyncio.Event()
        never = asyncio.Event()

        async def handler(item: WorkItem) -> int:
            active.set()
            try:
                await never.wait()
            finally:
                cleaned.set()
            return item.payload

        p = AsyncWorkerPipeline(handler, worker_count=1, max_queue_size=1,
                                drain_timeout=0.015, per_item_timeout=1)
        await p.start()
        await p.submit(WorkItem("active", 1, "active"))
        await active.wait()
        await p.submit(WorkItem("queued", 2, "queued"))
        with self.assertRaises(TimeoutError):
            await p.close()
        self.assertTrue(cleaned.is_set())
        self.assertTrue(p._queue.empty())
        self.assertEqual(p.metrics.cancelled, 1)
        await p.close()  # Idempotent after cleanup.

    async def test_total_job_budget_caps_retries(self) -> None:
        async def handler(item: WorkItem) -> int:
            raise RetryableJobError("busy")
        results, metrics = await run_pipeline(

            job_timeout=0.04, retry_delay=1.0,

        self.assertEqual((results[0].status, results[0].attempts), ("timed_out", 1))
        self.assertEqual((metrics.timed_out, metrics.retried), (1, 0))
