01｜先問要防的是讀取、竄改，還是冒用

目標／工具機密性完整性／來源工程用法及限制
SHA-256 雜湊不提供僅在摘要另有可信來源時可核對內容hashlib.sha256。不加密，不能用單次雜湊存密碼。Base64 只是編碼。
HMAC-SHA-256不提供共用密鑰持有人可算與驗，無法區分是哪一位持有人hmac.digest、hmac.compare_digest。可保護訊息完整性；須另外約定時效與重放控制。
Argon2id 密碼 KDF不是資料加密以成本較高的推導檢查密碼每個密碼用獨立隨機 salt，保存參數及雜湊；按環境量測調整成本，不用硬編廣泛通用的數值。
AES-GCM（AEAD）保護明文密文與 AAD 驗證是針對密鑰持有人用 AESGCM；同一密鑰不可重複 nonce。AAD 不保密；重放要由應用處理。
Ed25519 數位簽章不提供私鑰簽署、可信公鑰驗證交付檔案與更新聲明；公鑰要獨立建立信任，另驗版本與部署時間窗。
TLS 1.3保護傳輸連線驗證憑證與主機名；必要時加雙向 TLS沿用平台 TLS，不自製握手。終止於代理後，仍須檢查後段信任邊界與應用授權。

要防竄改但不需要保密，例如公開 release：優先簽章。要把跨信任邊界的資料變成只有持鑰服務能讀的密文：用 AEAD。兩者都不能替代使用者、角色或設備授權。

02｜架構圖：將資料與金鑰的責任分開

資料金鑰 DEK

加密資料的金鑰。解包後僅在獲准的程序邊界短暫使用；不寫進 log、網址、程式碼或共用設定檔。

金鑰加密金鑰 KEK

由 KMS／HSM 保管，授權的服務用它包裝或解包 DEK。把誰可解包、記錄與配額一起設計。

輪替與復原

新寫用新版本；舊版本僅作限期讀取。依威脅、保存期限和復原計畫重包裝或重加密；若 DEK 疑似外洩，單換 KEK 不會使既有密文重新安全。

03｜流程圖：從封裝到拒絕

  • Nonce：不是祕密，但同一把金鑰不可重複。96 位元是 GCM 推薦長度。隨機有碰撞機率；正式大量、多程序寫入需依規範設計用量上界、輪替與唯一值分配，並涵蓋重啟、備份還原及多實例，不能照抄教具的低用量策略。
  • AAD：可綁定版本、金鑰識別與記錄上下文。要由接收端依請求的可信上下文重建，不能單靠收到的記錄 ID 判定歸屬；序列化須固定。AAD 不會因此變祕密。
  • 標籤與重放：PyCA AESGCM 使用 16 位元組標籤並附在密文尾端。有效封包本身仍可能被重送；若是事件或控制資料，另核對事件序號／允許時間窗及重複處理規則。

04｜本機 Python 實作：AES-GCM round-trip

在你自己的虛擬環境安裝受信任版本的 cryptography，再下載 完整 Python 檔。教具不連線、不讀取個資、金鑰不寫入檔案；安裝套件的命令若未有本機套件快取則需網路。

python -m pip install cryptography

python python_cryptography_deep_dive_lab.py --test
from secrets import token_bytes
from cryptography.hazmat.primitives.ciphers.aead import AESGCM

key = AESGCM.generate_key(bit_length=256)
nonce = token_bytes(12)  # 低用量教具；正式系統須設計同鑰唯一。
aad = b'["record-v1","demo-kid","record-1"]'
sealed = AESGCM(key).encrypt(nonce, b"HVAC demo", aad)
assert AESGCM(key).decrypt(nonce, sealed, aad) == b"HVAC demo"
看「加密成功」與「拒絕」的差別

預設輸出 JSON 封包、明文 HVAC demo 以及錯誤 AAD 的拒絕訊息。每次執行都生成全新密鑰與 nonce，密文不固定。測試同時檢查合法明文、錯誤 AAD、竄改 tag、不支援版本／金鑰識別及大小限制；不對未驗證資料做解析或業務處理。

AES-GCM 不是密碼儲存方式，也不會讓執行程序看不到本身解出的明文。交付程式的簽發、封裝與信任鏈另見 Python 程式碼保護。

05｜上線驗收與常見失誤

輸入與失敗

測試破損、超大小、未知版本、換 record ID、缺金鑰、標籤一位元變動。對外用統一錯誤，不將底層例外、金鑰或明文寫進 log。

執行與重啟

測並行、重啟或備份回復時 nonce 不重用；驗證拒絕不導致明文下落、重送有自己的政策、權限撤銷後不可再解包。

輪替與災備

量測新舊金鑰的讀寫覆蓋，測新寫只走新版、舊讀限期且有稽核，確認備份和回復與金鑰保留期限一致。

觀測與責任

記版本、拒絕計數與輪替覆蓋；不得用單一密鑰橫跨租戶和用途。P99 量測包含 KMS 等待，分開評估吞吐與安全邊界。
