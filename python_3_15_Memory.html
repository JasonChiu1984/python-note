Tachyon 統計採樣剖析器

profiling.sampling · PEP 799

近零開銷

基於 PEP 768 安全外部介面，支援對線上行程零重啟 attach 採樣。內建 --mode wall/cpu/gil/exception、--async-aware 與 --opcodes，可直接輸出 Flame Graph、逐行 Heatmap 與 Live TUI；傳統 cProfile 則整併至 profiling.tracing。

$ python3.15 -m profiling.sampling attach 48210 --mode gil --flamegraph
⏳

顯式延遲匯入 (Explicit Lazy Import)

lazy import · 冷啟動與 RSS 減重

啟動加速

以顯式語法延後重型套件（如 torch、pandas、scipy）的實際載入與初始化，直到程式碼首次存取該名稱才觸發匯入。大幅縮短 CLI、Serverless 與微服務冷啟動延遲，並顯著壓低閒置 Worker 的基準 RSS 記憶體佔用。

lazy import torch, pandas # 僅在實際推論路徑才載入
🧊

經典分代 GC 回歸與 frozendict

Generational GC · gc.freeze() · frozendict

CoW 共享

Python 3.15 回歸穩定可預測的經典分代 GC（Generational GC），消除尾延遲不可預期波動。在 Gunicorn/Uvicorn 等 Fork 模型下搭配 gc.freeze() 凍結常駐物件，避免 GC 寫入標頭破壞 Copy-on-Write (CoW) 共享頁；並內建不可變且可雜湊的 frozendict 提升快取鍵與只讀設定的記憶體安全與效能。

gc.freeze() # Fork 前凍結； cfg = frozendict(timeout=30)
🔬

預設啟用 Frame Pointers

perf · eBPF · Native C/Rust Unwinding

全堆疊視野

官方建置預設保留 Frame Pointers（-fno-omit-frame-pointer），讓 Linux perf 與 eBPF 剖析工具能無縫展開原生堆疊，打通 Python 函式與底層 C 擴充套件（NumPy、PyO3/Rust、OpenSSL、SQLite）之間的效能黑盒。

$ perf record -F 999 -g --call-graph fp -- python3.15 app.py
