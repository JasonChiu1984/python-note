Python 神乎其技

從可讀的語法走到可驗證的資料處理。五個獨立範例均只用標準函式庫，支援 Python 3.11 及以上。

惰性資料流用上下文保證收尾不可變資料快照結構式分派結構化非同步

一眼選對工具

  • 大資料、不必全部保留 → 惰性迭代
  • 開關檔案、資源一定要釋放 → 上下文管理器
  • 資料需要穩定快照 → frozen dataclass
  • 依訊息形狀分派 → 結構式比對
  • 同批 I/O 需要一致的生命週期 → TaskGroup

這是原創工程教材，不是同名書籍的逐章摘要。操作方式：複製程式、另存為 UTF-8 的 example.py，執行 python3 example.py。

技巧 01

惰性資料流

itertools.islice + 產生器

先決定「需要幾筆」再取值，避免為了少量結果把整份輸入載入記憶體。適合日誌、感測快照或大型 CSV 的第一階段篩選。

  1. 逐筆讀取
  2. 篩選
  3. 變換
  4. 只拿前 N 筆

避坑：產生器只能走一次，不能當快照共享；若不用切片或限時，無限來源可能永遠跑不完。

from itertools import islice

def high_readings(readings, threshold=28.0):
    for point, value in readings:
        if value >= threshold:
            yield point, round(value, 1)

def sensor_stream():
    yield "T01", 26.2
    yield "T02", 29.4
    yield "T03", 31.5
    raise AssertionError("已取足兩筆，不應繼續讀取")

first_two = list(islice(high_readings(sensor_stream()), 2))
assert first_two == [("T02", 29.4), ("T03", 31.5)]
print(first_two)

預期輸出： [('T02', 29.4), ('T03', 31.5)]

技巧 02

用上下文保證收尾

contextmanager

把建立與釋放資源放在同一個抽象層。呼叫方保留業務動作，程序正常或丟出例外都會走到清理步驟。

  1. 進入
  2. 取得資源
  3. 執行工作
  4. finally 一定收尾

避坑：不要在 finally 吞掉原始例外；清理本身也可能失敗。真實故障時應保留原始錯誤並紀錄清理狀況。

from contextlib import contextmanager
from io import StringIO

@contextmanager
def managed_buffer():
    stream = StringIO()
    try:
        yield stream
    finally:
        stream.close()

try:
    with managed_buffer() as buffer:
        buffer.write("sample")
        raise ValueError("simulate failure")
except ValueError as exc:
    assert str(exc) == "simulate failure"
    assert buffer.closed
else:
    raise AssertionError("原始例外不應被吞掉")

print("例外後確認資源已釋放")

預期輸出： 例外後確認資源已釋放

技巧 03

不可變資料快照

dataclass(frozen=True, slots=True)

用命名欄位賦予資料契約；不就地修改現有快照，需要更新時產出新物件。slots 省掉常見的每實例屬性字典，但資源收益要用實際物件量測。

  1. 來源資料
  2. 建立快照
  3. 刊登新值
  4. 讀取端使用同一筆快照

避坑：frozen 只管欄位重新賦值。內含 list 或 dict 仍可能被修改；以 tuple 和其他不可變成員組成快照。這不代表更新共享參照的複合邏輯自動安全。

from dataclasses import dataclass, replace

@dataclass(frozen=True, slots=True)
class Snapshot:
    sensor: str
    samples: tuple[float, ...]

original = Snapshot("T01", (26.2, 26.5))
updated = replace(original, samples=original.samples + (27.0,))
assert original.samples == (26.2, 26.5)
assert updated.samples[-1] == 27.0
assert not hasattr(updated, "__dict__")
print(updated)

預期輸出： Snapshot(sensor='T01', samples=(26.2, 26.5, 27.0))

技巧 04

結構式分派

match / case

比起一串索引與 if，直接寫出可讀的訊息形狀，用 guard 補充業務條件。適合固定命令格式或分版本處理事件。

  1. 訊息
  2. 對照結構
  3. 驗證細節
  4. 執行或拒絕

避坑：映射模式預設允許額外鍵；未知欄位必須明確決定接受或拒絕。bool 是 int 的子類別，若協定只允許整數，要特別排除。

def dispatch(message):
    match message:
        case {"op": "poll", "interval": int(sec), **extra} \
                if type(sec) is int and 1 <= sec <= 300 and not extra:
            return ("poll", sec)
        case {"op": "stop", **extra} if not extra:
            return ("stop", None)
        case _:
            return ("invalid", None)

assert dispatch({"op": "poll", "interval": 5}) == ("poll", 5)
assert dispatch({"op": "stop"}) == ("stop", None)
for bad in (True, 0, 301, "5"):
    assert dispatch({"op": "poll", "interval": bad})[0] == "invalid"
assert dispatch({"op": "poll", "interval": 5, "unused": 1})[0] == "invalid"
print("有效命令與錯誤命令皆已驗證")

預期輸出： 有效命令與錯誤命令皆已驗證

技巧 05

結構化非同步

asyncio.TaskGroup + timeout

同一批任務跟隨同一個生命週期；一項 I/O 失敗會取消其他仍執行的同組任務。下面用 Event 確保示範的同組工作已啟動，不以猜測的排程時間測取消。

  1. 啟動同批 I/O
  2. 等待結果
  3. 任務失敗即取消同組
  4. 交接

避坑：asyncio 是協作式 I/O 並發，不等於 CPU 多核平行；避免在事件迴圈直接做重度純 Python 運算。逾時會提出取消，不是程序硬殺，且不代表外部系統已回滾。

import asyncio

async def main():
    ready = asyncio.Event()
    cleaned = asyncio.Event()

    async def sibling():
        ready.set()
        try:
            await asyncio.Event().wait()
        finally:
            cleaned.set()

    async def failing_read():
        await ready.wait()
        raise OSError("模擬通訊失敗")

    async with asyncio.timeout(2):
        try:
            async with asyncio.TaskGroup() as group:
                group.create_task(sibling())
                group.create_task(failing_read())
        except* OSError as group_error:
            assert str(group_error.exceptions[0]) == "模擬通訊失敗"
            assert cleaned.is_set()
        else:
            raise AssertionError("預期讀取失敗")
    print("同組取消與資源收尾已驗證")

asyncio.run(main())

預期輸出： 同組取消與資源收尾已驗證
