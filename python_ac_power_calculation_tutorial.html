交流電力與電力角

從電壓、電流、相角算有功、無功與視在功率；以一致的方向和時間窗彙整負載，區分功率因數角與發電機功角。

資料架構計算流程三角形與算例兩種角度諧波與限制電力品質分析Python

01｜量測邊界和資料流

  1. 電力支路合成的電壓、電流 RMS 與相角
  2. 統一口徑量測邊界、方向、相數、品質與時間
  3. 邊界計算先計 P／Q，再求 S、PF、φ
  4. 報表核對比較支路和總表；電費另看電能與需量定義

本課約定吸收有功為正、感性（電流落後）Q 為正、容性（電流超前）Q 為負。不同電表可能以進／出電或不同象限命名；接資料時先讀設備文件，不能從單一 PF 符號猜測超前或落後。本頁只以合成資料說明，不含帶電量測、調整或補償選型。

02｜從 RMS 到 P、Q、S 和 PF

  1. 選相數單相或平衡三相
  2. 先求視在功率單相 VI；三相 √3 × 線電壓 × 線電流
  3. 分解有功與無功依 φ 的 cos 與 sin 得到 P、Q
  4. 彙整同窗負載各自加總 P 與帶正負號的 Q，再重算 S／PF
量理想正弦、吸收有功負載單位及解讀
S 視在功率單相 VRMSIRMS ÷ 1000；平衡三相 √3 VLLIL ÷ 1000kVA；三相 VLL 是線對線電壓，IL 為線電流
P 有功功率S cos φkW；平均能量轉換率，不是 kWh
Q 無功功率S sin φkvar；按方向保留正負號
PF 與 φPF = P/S；φ = atan2(Q,P)PF 無因次；atan2 回傳弧度，顯示時轉角度。S=0 不報角度與 PF。

三相式的 φ 是相電壓與對應相電流的角；以平衡總量使用線電壓、線電流時，不是直接取任意線對線電壓角和線電流角相減。PF 單獨無法判斷 Q 正負，宜同時顯示 kvar 或超前／落後。時間累積用各段 kW × 小時求 kWh；不要從 kVA 直接當成 kWh 或套入帳單。

04｜「電力角」可能指不同量

  • 功率因數角 φ：在正弦負載是對應相電壓與相電流的相位差，帶方向的功率三角形用 atan2(Q,P) 表達。
  • 同步機功角 δ：描述同步機內電勢與端／參考匯流排電壓的相位差，取決於選用等效模型與參考。它不是電流相角，也不能只靠 kW、kvar、PF 或 φ 推回。匯流排間相角也需說明是哪兩個電壓相量。本頁不拿理想機組模型做發電機操作或穩定度整定。

05｜諧波、不平衡與電表讀值

單相總真實 PF＝同窗平均有功（v(t)×i(t) 的平均）÷（總電壓 RMS × 總電流 RMS）。位移 PF＝基波相差的 cos φ1。畸變電流可能讓真實 PF 低於位移 PF；有諧波或不平衡時，不把所有非有功成分都算成同一個 Q，也不直接套 S²=P²+Q²、單一 φ 或平衡三相公式。

查明電表對三相 S、PF、無功與需量的演算法、方向及時間窗；比對帳單時另查費率與計費口徑。可接續閱讀 台灣電費計算教材。

06｜電力品質分析與計算

先分辨「配電點長期畸變」、「馬達端三相不平衡」和「設備重啟前的短時間電壓事件」。三者可能同時出現，但分母、量測位置與時間窗不同，不能以一個功率因數或一張十分鐘平均圖判定。以下只使用合成資料或既有匯出檔進行離線分析。

資料架構圖

指標、公式與分母

真實 PF 與位移 DPF
單相 PF = 平均(v×i) ÷ (VrmsIrms)，時域樣本須同步；DPF = cos(基波電壓相角 − 基波電流相角)。只有電壓為純基波、電流無直流且完整涵蓋基波週期、諧波正交時，才可用 PF = DPF ÷ √(1 + (THDI/100)²)。不平衡三相勿拿三個單相 PF 的算術平均代替儀表定義。
THD 與 TDD
THDV、THDI = √ΣXh² ÷ X1 × 100%；TDD 用相同指定整數階諧波電流的平方和開根號，但除以 PCC 的基波最大需量負載電流 IL。報表應標註階數範圍及群組法；IL 依場所資料與標準方法取得，不用瞬時 I1、斷路器額定或任意尖峰代替。THD 上升可能只是負載下降、分母變小。
IEC 型 VUF 與 NEMA 型偏差
ABC 相序、a = ej120°；V1 = (Va + aVb + a²Vc) / 3，V2 = (Va + a²Vb + aVc) / 3；VUF = |V2| / |V1| × 100%。NEMA 型算法用三條線電壓 RMS 對其平均值的最大絕對偏差 / 平均值 × 100%，不是只用三相相電壓大小代替，也不等於序分量。此例沒有電壓諧波，因此基波線電壓即為全 RMS。
暫降、暫升與中斷
暫降用最小殘餘電壓 ÷ 參考電壓（pu）、暫升用最大電壓 ÷ 參考電壓；兩者的事件時間 = 結束 − 開始。選定固定或滑動參考、起訖門檻、遲滯及多相合併規則；中斷另依採用規範的門檻與時間歸類。瞬態尖峰用波形分析，不以半週更新 RMS 代替。閃爍 Pst（10 分鐘）、Plt（通常 2 小時）由合規閃爍量測取得，不能用 RMS 標準差冒充。

判讀流程圖

逐項複算：合成的變頻器負載

  1. 230 V 正弦單相電壓，電流基波 40 A 落後 30°，5／7 次電流為 12／9 A RMS，其餘為 0。諧波合成為 √(12²+9²) = 15 A，總電流 √(40²+15²) = 42.720 A；有功 230×40×cos30° = 7.967 kW；PF 0.8109、DPF 0.8660。
  2. THDI = 15/40 = 37.50%；假定 PCC 的 IL 為 60 A，TDD = 15/60 = 25.00%；純正弦電壓的 THDV = 0%。本例數值不代表合格門檻。
  3. 另取一組同步三相基波相量：230∠0°、218∠−120°、236∠120° V。用相量相減再取大小得到線電壓約 388.03、393.28、403.58 V；VUF ≈ 2.321%，NEMA 型 ≈ 2.182%。
  4. 單相事件窗 RMS = [230, 180, 179, 193, 212] V，每半週更新一次（60 Hz 為 8.333 ms），參考 230 V，教學進入 <0.90 pu、退出 ≥0.92 pu。第 2 筆進入，第 5 筆退出；殘餘 179/230 = 0.7783 pu，下降深度 22.17%，時間 3 × 8.333 ms = 25.0 ms。這個範例只接受第一筆達退出門檻（≥0.92 pu）的連續取樣。若第一筆低於進入門檻，可能已在事件中；若落在遲滯區（0.90 ≤ pu < 0.92），也無法從單筆判定先前狀態。這兩種起始狀態都拒算。若缺少第 5 筆恢復樣本，則無法確認事件結束。空資料也拒算，不能解讀成「沒有事件」。截取紀錄時，以事件前已達退出門檻的樣本為起點，保留其後的連續樣本，直到事件後第一筆達退出門檻的恢復值。

"""理想正弦、供電側正向合成算例；不接電表、不操作電力設備。"""
from dataclasses import dataclass
import math
import unittest


@dataclass(frozen=True)
class Power:
    p_kw: float
    q_kvar: float

    @property
    def s_kva(self):
        return math.hypot(self.p_kw, self.q_kvar)

    @property
    def pf(self):
        return self.p_kw / self.s_kva if self.s_kva else None

    @property
    def phi_deg(self):
        return math.degrees(math.atan2(self.q_kvar, self.p_kw)) if self.s_kva else None


def sinusoidal(volts_rms, amps_rms, phi_deg, *, balanced_3ph=False):
    values = (volts_rms, amps_rms, phi_deg)
    if not all(math.isfinite(x) for x in values):
        raise ValueError("只能接受有限數值")
    if min(volts_rms, amps_rms) < 0 or not -90 <= phi_deg <= 90:
        raise ValueError("RMS 不可為負；本例僅涵蓋吸收有功的負載")
    # 三相的 volts 是線對線、amps 是線電流；phi 是相電壓/相電流角。
    s = (math.sqrt(3) if balanced_3ph else 1) * volts_rms * amps_rms / 1000
    phi = math.radians(phi_deg)
    # 消除 cos(±90°) 的微小浮點殘留。
    return Power(0.0 if abs(phi_deg) == 90 else s * math.cos(phi),
                 s * math.sin(phi))


def aggregate(loads):
    """同一時間窗與邊界；此例限可用單一複功率表示的正弦系統。"""
    loads = tuple(loads)
    if any(not (math.isfinite(x.p_kw) and math.isfinite(x.q_kvar))
           for x in loads):
        raise ValueError("P、Q 必須為有限值")
    return Power(math.fsum(x.p_kw for x in loads), math.fsum(x.q_kvar for x in loads))


def true_pf_1ph(p_kw, volts_rms, amps_rms):
    """P 已由同窗平均 v(t)*i(t) 取得；V、I 為總 RMS。"""
    if not all(math.isfinite(x) for x in (p_kw, volts_rms, amps_rms)):
        raise ValueError("只能接受有限數值")
    if min(volts_rms, amps_rms) < 0:
        raise ValueError("RMS 不可為負")
    s = volts_rms * amps_rms / 1000
    if abs(p_kw) > s and not math.isclose(abs(p_kw), s, rel_tol=1e-12):
        raise ValueError("|P| 不可大於 S，請核對時間窗和量測定義")
    return max(-1, min(1, p_kw / s)) if s else None


def example():
    a = sinusoidal(400, 100, math.degrees(math.acos(.8)), balanced_3ph=True)
    b = sinusoidal(400, 60, -30, balanced_3ph=True)
    return a, b, aggregate((a, b))


class Tests(unittest.TestCase):
    def test_balanced_and_sum(self):
        a, b, total = example()
        self.assertAlmostEqual(a.s_kva, 69.2820323028)
        self.assertAlmostEqual(a.pf, .8)
        self.assertGreater(a.q_kvar, 0)
        self.assertLess(b.phi_deg, 0)
        self.assertAlmostEqual(total.q_kvar, 20.7846096908)
        self.assertLess(total.s_kva, a.s_kva + b.s_kva)

    def test_single_phase_and_bad_input(self):
        self.assertAlmostEqual(sinusoidal(230, 10, 0).p_kw, 2.3)
        self.assertIsNone(sinusoidal(230, 0, 0).phi_deg)
        for v, i, phi in ((-1, 10, 10), (230, 10, 110), (math.nan, 10, 0)):
            with self.assertRaises(ValueError):
                sinusoidal(v, i, phi)

    def test_harmonic_pf_and_limit(self):
        self.assertAlmostEqual(true_pf_1ph(1.84, 230, 10), .8)
        self.assertIsNone(true_pf_1ph(0, 230, 0))
        with self.assertRaises(ValueError):
            true_pf_1ph(2.31, 230, 10)


if __name__ == "__main__":
    import sys
    if "--test" in sys.argv:
        unittest.main(argv=["lab"])

可實跑範例：三相功率加總、不平衡率與電容量估算

以 cmath 計算各相基波複功率 S₁ = V₁·I₁·e^{jφ}。向量功率比 ΣP₁ ÷ |ΣS₁| 不等同含諧波或不平衡時電表的總功率因數。電容補償以 max(0, Q₁ − P₁·tan(acos(目標落後位移功因))) 估算；Q₁ 感性落後為正、容性超前為負。不可把 PF 幅值或含諧波的總 PF 當作基波 kvar。

"""三相電壓不平衡率、各相功率加總與功率因數改善電容量估算（標準函式庫 cmath）。"""
import cmath
import math

# 某配電盤三相量測（相電壓、相電流有效值，電流落後電壓的角度）
PHASES = {
    "R": dict(v=228.0, i=182.0, lag_deg=36.0),
    "S": dict(v=224.5, i=176.0, lag_deg=38.5),
    "T": dict(v=231.2, i=169.0, lag_deg=34.0),
}
LINE_V = {"RS": 392.4, "ST": 394.1, "TR": 398.9}


def unbalance_pct(values):
    """NEMA MG-1 定義：最大偏差 ÷ 平均 × 100%。"""
    avg = sum(values) / len(values)
    return max(abs(v - avg) for v in values) / avg * 100


def phase_power(v, i, lag_deg):
    s = v * i * cmath.exp(1j * math.radians(lag_deg)) / 1000     # 複功率 kVA，落後為正 Q
    return s


def capacitor_kvar(p1_kw, q1_kvar, target_dpf):
    """新增電容的基波估算：p1 > 0，q1 帶號（感性正、容性負）。"""
    if not math.isfinite(p1_kw) or p1_kw <= 0 or not math.isfinite(q1_kvar):
        raise ValueError("基波 kW 須為正值，且 kW、kvar 須為有限數")
    if not 0 < target_dpf <= 1:
        raise ValueError("目標落後位移功率因數須在 (0, 1] 內")
    q1_target = p1_kw * math.tan(math.acos(target_dpf))
    return max(0.0, q1_kvar - q1_target)  # 已超前或已達標：不得再加入電容


if __name__ == "__main__":
    total = 0j
    for name, ph in PHASES.items():
        s = phase_power(**ph)
        total += s
        print(f"{name} 相：P={s.real:6.2f} kW  Q={s.imag:6.2f} kvar  S={abs(s):6.2f} kVA  PF={s.real / abs(s):.3f}")
    print(f"合計：P={total.real:.2f} kW  Q={total.imag:.2f} kvar  S={abs(total):.2f} kVA")
    pf = total.real / abs(total)
    naive_s = sum(abs(phase_power(**ph)) for ph in PHASES.values())
    print(f"本基波模型的向量功率比 = ΣP₁ ÷ |ΣS₁| = {pf:.3f}（若把各相 kVA 直接相加得 {naive_s:.2f} kVA）")
    vu = unbalance_pct(list(LINE_V.values()))
    iu = unbalance_pct([ph["i"] for ph in PHASES.values()])
    print(f"線電壓不平衡 {vu:.2f}%，電流不平衡 {iu:.2f}%")
    for target in (0.90, 0.95, 0.98):
        kvar = capacitor_kvar(total.real, total.imag, target)
        print(f"落後基波目標 {target:.2f}：模擬估算 {kvar:.1f} kvar（非電容組選型）")

工程現場案例：冰水泵馬達溫度偏高，功率因數只有 0.8

某機房的冰水泵配電盤，三相電流分別是 182、176、169 A，電流不平衡 3.8%，功率因數 0.807。馬達溫度偏高，維修人員先懷疑軸承。範例顯示線電壓不平衡只有 0.95%，但電流不平衡放大到 3.8%；感應馬達的負序電流會造成額外發熱，電壓不平衡 1% 就可能讓溫升明顯增加。

先查三相負載分配與接點，再判斷是否需要功率因數補償。本例 39.0 kvar 是合成資料在感性落後、目標 0.95 時的連續理論量，不是現場選型或投切指令。變頻器等非線性負載應另由合格人員評估電表定義、基波 kvar、諧波、諧振、最低負載與補償級距。

  1. 依電力分析儀手冊確認帶方向的基波 kvar 與位移功率因數；分開記錄總 PF、諧波與負載區間。
  2. 以範例的 unbalance_pct() 計算線電壓與電流不平衡率，電壓不平衡超過 1% 時先查上游。
  3. 補償只針對感性基波 Q；已超前或已達目標時，範例回傳 0。若已過度補償，0 只代表不應加碼，不表示現況達標。
  4. 電容組有變頻器負載時，先評估諧波與諧振風險，再決定是否加電抗器。

  • 諧波限制可參考 IEEE 519-2022（電力系統諧波控制建議作法與要求），它取代 2014 版，限制值以公共耦合點（PCC）為準。台電依平均功率因數以 80% 為基準調整電費、超過 95% 的部分不再扣減；增減比例以台電最新電價表為準，不同整理資料寫法不一，計算前請直接查電價表。 來源：IEEE 519-2022 來源：Fluke 430 Series II 使用手冊：附錄 A，位移功率因數

練習題與自我檢查

  1. 為什麼範例中的向量功率比不能用各相 PF 的算術平均？

    看解答

    各相負載不同，比例不能直接平均。本模型先加總基波 P₁、Q₁，再除以複功率總和的絕對值。它不保證等於各款電表以有效視在功率或其他方法計得的總 PF。

  2. 把 T 相電流改成 150 A，電流不平衡率是多少？

    看解答

    平均 (182 + 176 + 150) ÷ 3 = 169.33 A，最大偏差 |150 − 169.33| = 19.33 A，不平衡率 11.4%。可改 PHASES 重新執行驗證。

  3. 同為 30 kW、位移功因幅值 0.85，感性落後與容性超前的結果相同嗎？

    看解答

    不相同。帶正負號的基波 Q₁ 約為 +18.59 或 −18.59 kvar。目標落後 0.95 時，感性案例理論上需新增約 8.73 kvar，超前案例不應新增電容，故回傳 0。演算並未驗證任何現場投切。

  4. capacitor_kvar() 算的是三相總量還是每相？

    看解答

    輸入與結果均是本算例的三相合計，39.0 kvar 是估算而非設備選型。電容組的額定總容量、電壓及安裝條件須另行核對。
