讀 CSV 前先定義字典：點號、缺值和零不能互換

001 是點位代碼，不是可以加總的整數；NA 也可能是業務代碼，不一定是缺值。Pandas 的預設缺值表包含空白與 NA 等字串。若同時存在代碼欄與讀值欄，要分欄指定欄位型態和缺值規則，而不是全表 fillna(0)。

延伸學習：實作、現場案例與自我檢查

本節把前面的讀檔契約延伸到 BAS 趨勢資料最常做的三件事：只用品質良好的資料、重取樣成 15 分鐘平均，以及轉成一個點位一欄的寬表，並同時保留每個區間的有效筆數。

可實跑範例：BAS 趨勢資料：dtype、品質篩選與 15 分鐘寬表

範例需要 pandas 3.x（本頁輸出以 pandas 3.1.1 產生）。point_id 明確指定為 string 並關閉預設缺值，保住 001 與 NA 兩個點位代碼；只有 value 欄的空白視為缺值。重取樣同時輸出 mean 與 count，讓讀報表的人知道每格平均是幾筆資料算出來的。

下載範例 example.py

"""用 pandas 整理 BAS 趨勢資料：明確 dtype、缺值規則、15 分鐘重取樣、寬表轉換（需 pandas 3.x）。"""
from io import StringIO

import pandas as pd

RAW = """ts,point_id,value,quality
2026-11-20 08:00:05,001,22.4,good
2026-11-20 08:04:58,001,22.6,good
2026-11-20 08:09:40,001,,comm_fail
2026-11-20 08:15:02,001,23.1,good
2026-11-20 08:00:10,NA,12.8,good
2026-11-20 08:05:12,NA,12.9,good
2026-11-20 08:15:30,NA,13.4,good
2026-11-20 08:20:00,NA,13.3,good
"""

if __name__ == "__main__":
    print("pandas", pd.__version__.split(".")[0] + ".x")
    df = pd.read_csv(StringIO(RAW), dtype={"point_id": "string", "value": "Float64", "quality": "category"},
                     keep_default_na=False, na_values={"value": [""]}, parse_dates=["ts"])
    print(df.dtypes.to_string())
    print(f"點位代碼：{df['point_id'].unique().tolist()}（001 保留前導零，NA 是代碼不是缺值）")

    names = {"001": "AHU1_SAT", "NA": "CHW_SUPPLY"}
    df["point"] = df["point_id"].map(names)
    good = df[df["quality"] == "good"]
    wide = (good.set_index("ts").groupby("point")["value"]
            .resample("15min").agg(["mean", "count"]).unstack(level=0))
    wide.columns = [f"{p}_{stat}" for stat, p in wide.columns]
    print(wide.round(2).to_string())

    coverage = good.groupby("point").size() / df.groupby("point").size()
    print("有效資料比例：", coverage.round(2).to_dict())
    print("comm_fail 筆數：", int((df["quality"] == "comm_fail").sum()))

執行方式：python example.py，需先 pip install pandas

工程現場案例：點位代碼 NA 被讀成缺值，冰水溫度整欄消失

某專案的點位代碼採三碼縮寫，其中冰水供水溫度的代碼剛好是 NA。用 pd.read_csv() 預設參數讀檔時，pandas 把 NA 當成缺值，這個點位的所有資料都變成空值，groupby 時直接被排除，報表少了一個關鍵點位卻沒有任何錯誤訊息。

另一個點位 001 被推斷成整數 1，與另一棟大樓的點位 1 混在一起。範例以 dtype 與 keep_default_na=False 明確定義欄位契約，並把 comm_fail 的資料排除在平均之外，同時輸出有效資料比例，讓資料品質問題浮上檯面。

  1. 為每個匯出檔建立欄位契約：哪些欄位是代碼（string）、哪些是量測值（Float64）、缺值字串是什麼。
  2. 讀檔後立即檢查 dtypes 與代碼清單，與點位表比對。
  3. 依 quality 欄篩選後再計算，並保留 count 或有效比例。
  4. 把契約寫成函式與測試，換新版本 pandas 時先跑一次歷史樣本。

練習題與自我檢查

  1. 把 read_csv() 的 keep_default_na=False 拿掉，point_id 欄會發生什麼事？

    看解答

    NA 會被當成缺值，CHW_SUPPLY 的 4 筆資料 point_id 變成 <NA>，map() 後 point 也是缺值，groupby 會排除它們，寬表只剩 AHU1_SAT。

  2. 08:00 區間的 AHU1_SAT 平均為什麼是 22.5，而不是把 3 筆都算進去？

    看解答

    08:09:40 那筆 quality 為 comm_fail 且 value 為空，已在 good 篩選時排除，所以只有 22.4 與 22.6 兩筆，平均 22.5，count 為 2。

  3. 如果要把 15 分鐘平均改成「區間內有效筆數少於 2 筆就顯示缺值」，要怎麼改？

    看解答

    先算出 mean 與 count，再用 wide[mean_col] = wide[mean_col].where(wide[count_col] >= 2)。範例中 08:15 的 AHU1_SAT 只有 1 筆，會變成缺值。

  4. 為什麼 value 用 Float64（大寫 F）而不是 float64？

    看解答

    Float64 是 pandas 的可空擴充型別，缺值以 <NA> 表示，和整數、布林的可空型別行為一致；float64 只能用 NaN。在需要區分「缺值」與運算結果 NaN 的報表中，可空型別比較清楚。
