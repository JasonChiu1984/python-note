選一條專題路線

共同基礎 → 選修專題 → 專案交付。下面是建議順序，不是硬性先修要求。

專題路線 · 01

資料分析與自動報表

讀一份 CSV，清理後用固定格式輸出可核對的報表。

  1. Pandas 入門實驗先練 CSV 預覽、分組與圖表
  2. NumPy 向量化看懂 ndarray、維度與數值測試
  3. Pandas 工程教材建立可重跑的 ETL
  4. Excel 與迴歸輸出工作簿；需要預測時再學迴歸
  5. 迴歸分析實戰驗證切分、誤差與外推限制
專題路線 · 02

API、前端與外部整合

做一個有輸入驗證的 API，並驗收更新失敗與重連行為。

  1. FastAPI路由、依賴注入、OpenAPI
  2. 前端資料流比較 Fetch、SSE、WebSocket 等方式
  3. WebSocket 架構確認事件、連線與重連邊界
  4. 前端自動刷新選擇輪詢、推播或快取策略
  5. API 整合韌性設逾時，分辨可重試與不可重試
  6. BeautifulSoup × re練 HTML 選擇器與文字解析
專題路線 · 03

工程品質、效能與發布

留下測試結果、效能基線與可驗證安裝成品。

  1. 依賴與環境治理固定依賴與執行版本
  2. 測試品質迴路把需求轉成可失敗的驗收條件
  3. 並發效能實測比較執行緒、程序與子直譯器
  4. 日誌與持久化驗證失敗能在日誌與持久化資料追查
  5. CI/CD 品質閘門阻擋未完成測試與驗證的發布
  6. 發布成品驗證隔離環境安裝並驗證成品
專題路線 · 04

工業通訊與能源監測

用離線樣本做到資料品質檢查、通訊診斷與能源對帳。

  1. 工業協定選型依現場更新頻率與安全需求選型
  2. 工業資料閘道明確標記逾時、過期值與讀寫邊界
  3. Wireshark 封包解析用可重現的離線封包查通訊
  4. 工業通訊塞車先定位在哪一層排隊
  5. 機房 CDU 能效分開核對冷卻量與實測用電
  6. ISO 50001 報表核對基線、量測邊界及報表
