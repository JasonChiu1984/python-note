從 Excel 到可檢驗的迴歸模型

用外氣溫度解釋每日冷房耗電，從資料整理、擬合到保留測試。示範資料為合成資料，不是實機、節能或節費證據。

流程圖模型與指標圖解結果Excel 對照可執行範例工程應用工程驗證補充

01　流程圖：先分時序，再擬合

  1. 1　整理資料同一時區與取樣週期，補缺／標缺，統一單位。
  2. 2　依時間分割舊資料訓練，較新資料測試；測試期不回頭挑模型。
  3. 3　建立基準先來一條訓練平均數，再比單變量迴歸。
  4. 4　檢查殘差查條件偏差、漂移與超出訓練範圍的點。
  5. 5　再決定用途能否用於預估、異常篩選或只可作描述。

每列為同日、同一冷房用電邊界。outdoor_c 是日均室外溫度 °C；cooling_kwh 是每日冷房用電 kWh。若要預估未來一天，應用當時可取得的天氣預報，不能拿事後實測外氣當「即時預報」。

02　模型、單位與分數

ŷ = ȳ + b(x − x̄)；b = Σ[(x − x̄)(y − ȳ)] / Σ[(x − x̄)²]。最小平方法使訓練資料誤差平方和較小。係數 b 單位是 kWh／日／°C，表示模型關聯斜率，不是因果效應。中心值採訓練平均外氣，而不是把 0°C 當有意義的截距。

指標如何解讀
MAE平均絕對誤差；與每日用電同單位，不會讓正負誤差互相抵銷。
平均有號殘差實際 − 預測；正值偏低估，負值偏高估。平均接近零不表示誤差小。
R²1 − SSE / SST；測試 R² 的 SST 以測試實際值平均計算，可能為負。實際耗電全部相同時本例回傳 null，不硬給數字。這個 R² 的數學比較基準不同於以訓練平均產生的可部署預測基準。

04　Excel 公式與資料交接

假設 A 欄日期、B 欄外氣、C 欄耗電；依日期排好序，資料共 28 日。第 2–21 列為訓練，第 22–29 列為測試。

儲存格公式／作用
D22=FORECAST.LINEAR(B22,$C$2:$C$21,$B$2:$B$21)（向下填到 D29）
E22=C22-D22（有號殘差，填到 E29）
F22=ABS(E22)（絕對誤差，填到 F29）
MAE=AVERAGE(F22:F29)
測試 R²=IF(DEVSQ(C22:C29)=0,NA(),1-SUMSQ(E22:E29)/DEVSQ(C22:C29))。不要用預測與實際值的相關係數平方冒充這項測試分數。

另存 UTF-8 CSV，欄名用 date,outdoor_c,cooling_kwh，日期格式 2026-07-01。原始檔留存、清理規則另存；若資料是累積電表讀值，先處理差分、歸零和缺漏，再建日耗電目標。

"""以合成 HVAC 日電量示範一元線性迴歸，僅用 Python 標準函式庫。"""
from dataclasses import dataclass
from datetime import date, timedelta
from math import isfinite, isclose
from statistics import mean
import argparse
import csv
import json
import unittest


@dataclass(frozen=True)
class Row:
    day: date
    outdoor_c: float
    cooling_kwh: float


def fixture():
    temperatures = [26, 27, 26.5, 29, 28, 27.5, 30, 31, 29.5, 30.5,
                    28.5, 27, 26.5, 32, 31, 30, 29, 28, 27.5, 30,
                    29.5, 31, 32, 29, 27.5, 30, 31.5, 33]
    noise = [-21, 6, -12, 18, 2, -14, 11, 23, -7, 14, -6, -3,
             4, 17, -12, 8, -13, 5, -7, 6, -5, 17, 9, -14, -2, 14, -6, 23]
    start = date(2026, 7, 1)
    return [Row(start + timedelta(days=i), x, 610 + 54 * (x - 26) + noise[i])
            for i, x in enumerate(temperatures)]


def load_csv(path):
    rows = []
    with open(path, encoding="utf-8-sig", newline="") as file:
        reader = csv.DictReader(file)
        required = {"date", "outdoor_c", "cooling_kwh"}
        if not required.issubset(reader.fieldnames or ()):
            raise ValueError("CSV 缺少 date、outdoor_c 或 cooling_kwh")
        for n, row in enumerate(reader, start=2):
            try:
                parsed = Row(date.fromisoformat(row["date"]),
                             float(row["outdoor_c"]), float(row["cooling_kwh"]))
                if not all(isfinite(v) for v in (parsed.outdoor_c, parsed.cooling_kwh)):
                    raise ValueError("不可為 NaN 或無窮大")
                if parsed.cooling_kwh < 0:
                    raise ValueError("每日耗電量不可為負")
            except (TypeError, ValueError) as exc:
                raise ValueError(f"第 {n} 列格式有誤：{exc}") from exc
            rows.append(parsed)
    return rows


@dataclass(frozen=True)
class Model:
    x0: float
    y0: float
    slope: float
    xmin: float
    xmax: float

    def predict(self, x):
        return self.y0 + self.slope * (x - self.x0)

    def outside_training(self, x):
        return not self.xmin <= x <= self.xmax


def fit(rows):
    if len(rows) < 2:
        raise ValueError("至少需要兩筆訓練資料")
    xs = [r.outdoor_c for r in rows]
    ys = [r.cooling_kwh for r in rows]
    x0, y0 = mean(xs), mean(ys)
    sxx = sum((x - x0) ** 2 for x in xs)
    if not sxx:
        raise ValueError("訓練溫度無變異，無法估計斜率")
    slope = sum((x - x0) * (y - y0) for x, y in zip(xs, ys)) / sxx
    return Model(x0, y0, slope, min(xs), max(xs))


def time_split(rows, test_size):
    ranked = sorted(rows, key=lambda r: r.day)
    if len({r.day for r in ranked}) != len(ranked):
        raise ValueError("每日資料須唯一；請先處理重複日期")
    if not 2 <= test_size <= len(ranked) - 2:
        raise ValueError("訓練與測試區間各至少需要兩筆")
    return ranked[:-test_size], ranked[-test_size:]


def score(observed, estimated):
    if not observed or len(observed) != len(estimated):
        raise ValueError("兩組資料須非空且同長度")
    residuals = [actual - pred for actual, pred in zip(observed, estimated)]
    center = mean(observed)
    sst = sum((y - center) ** 2 for y in observed)
    return {"mae_kwh_per_day": mean(abs(e) for e in residuals),
            "bias_actual_minus_prediction": mean(residuals),
            "r2": None if not sst else 1 - sum(e * e for e in residuals) / sst}


def evaluate(rows, test_size=8):
    train, test = time_split(rows, test_size)
    m = fit(train)
    actual = [r.cooling_kwh for r in test]
    predicted = [m.predict(r.outdoor_c) for r in test]
    return train, test, m, score(actual, predicted), score(actual, [m.y0] * len(test))


class Checks(unittest.TestCase):
    def test_fit_exact_line(self):
        d = date(2026, 1, 1)
        m = fit([Row(d, x, 100 + 12 * x) for x in (1, 2, 3)])
        self.assertTrue(isclose(m.slope, 12.0))
        self.assertTrue(isclose(m.predict(4), 148.0))
        self.assertTrue(m.outside_training(4))

    def test_constant_x_rejected(self):
        d = date(2026, 1, 1)
        with self.assertRaises(ValueError):
            fit([Row(d, 30, 10), Row(d, 30, 20)])

    def test_constant_target_r2_undefined(self):
        self.assertIsNone(score([2.0, 2.0], [2.0, 2.0])["r2"])

    def test_r2_can_be_negative(self):
        self.assertLess(score([2.0, 3.0], [1.0, 1.0])["r2"], 0)

    def test_holdout_and_baseline(self):
        train, test, m, result, baseline = evaluate(list(reversed(fixture())))
        self.assertLess(train[-1].day, test[0].day)
        self.assertEqual((len(train), len(test)), (20, 8))
        self.assertEqual(sum(m.outside_training(r.outdoor_c) for r in test), 1)
        self.assertLess(result["mae_kwh_per_day"], baseline["mae_kwh_per_day"])

    def test_duplicate_date_rejected(self):
        rows = fixture()
        with self.assertRaises(ValueError):
            time_split(rows + [rows[0]], 8)


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--csv", help="自有 CSV：date,outdoor_c,cooling_kwh")
    parser.add_argument("--test-size", type=int, default=8)
    parser.add_argument("--self-test", action="store_true")
    args = parser.parse_args()
    if args.self_test:
        result = unittest.TextTestRunner(verbosity=2).run(
            unittest.defaultTestLoader.loadTestsFromTestCase(Checks))
        return int(not result.wasSuccessful())
    try:
        train, test, m, metrics, baseline = evaluate(
            load_csv(args.csv) if args.csv else fixture(), args.test_size)
    except (OSError, ValueError) as exc:
        parser.error(str(exc))
    print(json.dumps({
        "source": "CSV" if args.csv else "合成資料，非場域實測",
        "train": [str(train[0].day), str(train[-1].day), len(train)],
        "test": [str(test[0].day), str(test[-1].day), len(test)],
        "x0_c": m.x0, "y0_kwh_per_day": m.y0, "slope_kwh_per_c_per_day": m.slope,
        "training_range_c": [m.xmin, m.xmax],
        "outside_training": [str(r.day) for r in test if m.outside_training(r.outdoor_c)],
        "metrics": metrics, "baseline": baseline,
    }, ensure_ascii=False, indent=2))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

06　工程應用：能用、不能用，與如何校正

  • 日預估與異常提示：以設備和天氣的實際可用資料估計耗電，再用殘差挑值得調查的日期。估計值不是控制指令。
  • 分段與多變量：低溫區可能沒有冷房需求，高溫區設備或流量達上限，考慮分段斜率或加入濕度、營運時數、負載、樓層使用與控制模式。先作時間滾動驗證，不以測試期重挑特徵或轉換。
  • 校正與漂移：比較季節、尖峰時段與低負載的殘差，不另挑好看的分數。查溫度感測器校正、電表倍率、變更時點與班表，確認結構漂移後才重估。要給區間，應用足夠的獨立保留資料驗證涵蓋率。
  • 冷量和電量不同：水側瞬時冷量為 Q̇ ≈ ρ·cₚ·V̇·ΔT（依一致的 SI 單位得 kW），不能只用 ΔT 推算，也不是冷凍機的電力。計算期間電能需對電功率積分；量能效率或節能驗收還需固定量測邊界、可靠基準與干擾因子。

判讀：相關性不是因果、R² 高不代表部署可用，超出訓練範圍要標記並限制使用。合成例刻意接近線性，不能直接把分數當成實場期望值。

可實跑範例：時序切分、基準比較與殘差漂移偵測

用 statistics.linear_regression 擬合外氣溫度與冰水系統日用電。測試期後半段模擬冰機結垢、效率下降，殘差持續超過門檻。門檻取訓練期殘差 RMS 的 3 倍，是常見的起點，需依實際誤報率調整。

"""時序切分、與「沿用昨天」基準比較、殘差漂移偵測（標準函式庫 statistics）。"""
from statistics import fmean, linear_regression

# 每日外氣平均溫度（°C）與冰水系統用電（MWh），前 20 天訓練、後 10 天測試；第 26 天起冰機結垢效率變差
TEMP = [24.1, 25.3, 26.0, 27.2, 26.8, 28.1, 29.0, 28.4, 27.5, 26.9,
        27.8, 29.3, 30.1, 30.8, 29.9, 28.7, 29.5, 30.6, 31.2, 30.4,
        29.8, 30.9, 31.5, 32.0, 31.1, 30.7, 31.8, 32.4, 31.9, 32.6]
KWH = [18.2, 19.5, 20.1, 21.6, 21.0, 22.8, 23.9, 23.1, 22.0, 21.3,
       22.4, 24.3, 25.2, 26.1, 25.0, 23.6, 24.6, 25.8, 26.6, 25.7,
       25.0, 26.4, 27.1, 27.8, 26.7, 27.3, 28.9, 29.8, 29.4, 30.4]
SPLIT = 20


def mae(a, b):
    return fmean(abs(x - y) for x, y in zip(a, b))


if __name__ == "__main__":
    slope, intercept = linear_regression(TEMP[:SPLIT], KWH[:SPLIT])
    print(f"訓練期模型：MWh = {intercept:.2f} + {slope:.3f} × 溫度")
    pred = [intercept + slope * t for t in TEMP[SPLIT:]]
    naive = KWH[SPLIT - 1:-1]                                # 沿用前一天的值
    actual = KWH[SPLIT:]
    print(f"測試期 MAE：迴歸 {mae(pred, actual):.2f}、沿用昨天 {mae(naive, actual):.2f} MWh")
    train_res = [y - (intercept + slope * x) for x, y in zip(TEMP[:SPLIT], KWH[:SPLIT])]
    limit = 3 * (fmean(r * r for r in train_res) ** 0.5)
    print(f"殘差告警門檻 ±{limit:.2f} MWh（訓練期殘差 RMS 的 3 倍）")
    for day, (p, a) in enumerate(zip(pred, actual), start=SPLIT + 1):
        r = a - p
        flag = "  ← 超出門檻，檢查設備" if abs(r) > limit else ""
        print(f"  第 {day} 天 預測 {p:5.2f} 實際 {a:5.2f} 殘差 {r:+.2f}{flag}")

工程現場案例：模型輸給「沿用昨天」，原因不是模型太差

範例中迴歸模型的測試期 MAE 是 0.99 MWh，反而比沿用昨天的 0.91 MWh 差。單看這個數字，會以為迴歸沒用；但逐日殘差顯示，前 5 天殘差都在 0.3 MWh 以內，第 26 天起突然跳到 1.3 MWh 以上且持續增加，這是設備狀態改變，不是模型失準。

「沿用昨天」會自動吸收這種漂移，所以誤差較小，但它也因此看不出設備變差。迴歸模型的價值在於提供一條「正常狀態」的基準線：殘差持續偏離時，就是去檢查冰機冷凝器結垢、冷卻水塔或感測器的訊號。

  1. 資料依時間切分，不要隨機抽樣；測試期一定在訓練期之後。
  2. 任何模型都要和沿用昨天、同期平均等簡單基準比較。
  3. 以訓練期殘差設定告警門檻，連續數天超出才告警，降低誤報。
  4. 設備維修或改善後重新訓練基準模型，並記錄版本。

    看解答

    迴歸的殘差在 0.14–0.26 之間，MAE 約 0.21；沿用昨天在溫度變動的日子誤差較大。漂移發生前，迴歸明顯較好。可修改 actual、pred、naive 的切片範圍驗證。

  2. 為什麼不能把 30 天資料隨機打散後切成訓練與測試？

    看解答

    時序資料前後相關，隨機切分會讓模型「看過」測試期前後的資料，評估結果過度樂觀，也無法反映部署後只能用過去預測未來的情況。

  3. 殘差門檻為什麼用訓練期殘差 RMS 的 3 倍？

    看解答

    若殘差大致呈常態分布，超過 3 倍標準差的機率很低（約 0.3%），可以把誤報控制在少數。但實際殘差常有偏態或自相關，需依歷史資料檢視誤報率再調整。

  4. 第 26 天起殘差都是正的，代表用電比預期高還是低？可能的設備原因有哪些？

    看解答

    殘差 = 實際 − 預測 > 0，代表用電比溫度預期的高。可能原因包括冷凝器結垢、冷卻水塔散熱不良、冷媒不足、冰水出水溫度設定被調低，或電表、溫度感測器異常。
