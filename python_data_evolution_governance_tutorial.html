Overview

先定義資料版本契約，再做 migration

資料演進治理的第一步不是寫 script，而是先說清楚版本、相容與回退條件。

案例：把整數攝氏度移成固定精度，不破壞已存資料

V1：readings(id, c) 記錄整數攝氏度。舊資料 22°C 是整數 22。V2：保留 c，增設可為 NULL 的 deci_c；回填後同一筆記錄變成 c=22、deci_c=220。V3：移除 c，只保存 deci_c，才開始接受 22.1°C（221）。

這是欄位表示法與資料契約的變更，不是浮點數四捨五入練習。相容期間維持舊格式可表示範圍。若 V2 就允許 221，你無法無損還原成舊版整數攝氏度；這樣即使保留舊欄位，也不代表具備可回退性。

版本命名區分三件事：schema 版本（結構）、應用版本（程式行為）與回填進度（資料準備狀態）。「schema 已是 V2」不代表所有資料都已回填，也不代表允許移除舊欄位。

Architecture

把相容讀寫、回填與回退拆成明確層次

compat read/write、backfill、preflight 與 rollback evidence 應各自可驗證。

讀相容與寫相容是兩份契約

單檔實驗故意沒有用 trigger 互補，也沒有版本路由服務。部署者必須先停掉 V1 寫入者，包括排程任務、離線同步與直接 SQL，才讓 V2 相容寫入者接手。舊讀者可繼續使用明列欄位的查詢，舊寫者不能直接回線。若舊寫必須並存，請先設計經驗證的資料庫同步機制與雙向映射，而不是假設雙欄位自動一致。

Configuration

用 manifest 寫出升版規則與風險邊界

沒有 manifest 的資料升版，多半只是在賭運氣。

先把會讓你按下停止的條件寫進發布單

migration: c_to_deci_c
schema: 1 → 2 → 3
transform: deci_c = c * 10
phase_2: keep v1 readers; drain all v1 writers
batch: ordered positive ids, start after last_id
cutover_gate: no NULL, no unequal c * 10, restore drill passed
contract_gate: old readers/writers retired, replication/replay plan approved
stop_if: schema drift, unexplained missing rows, lock budget exceeded

這是發布單範例，並非程式會讀取的 YAML。實驗使用 PRAGMA user_version 做單一資料庫的版本標籤，並核對 V1 欄位結構。正式系統要再核對 migration 檔校驗值、約束、索引、視圖、觸發器與外鍵，不要只看版本號或欄位名。

交易流程圖：一批資料怎麼安全抵達下一階段

  1. 預檢 → 擴展

    在交易內確認 V1 欄位符合預期，新增可為 NULL 的新欄位、CHECK 與 migration_state，提交 V2。已有 V2 時不重複執行 DDL。

  2. 相容部署 → 分批取數

    切換 V2 寫入後，worker 用 BEGIN IMMEDIATE，依正整數主鍵排序，從 last_id 後取下一批。

  3. 填值 → 先驗證失敗情境

    只更新 deci_c 為 NULL 的記錄；即使 V2 已填入也不覆寫。若在寫入後、更新 checkpoint 前失敗，兩個狀態都應回到上一批已提交的位置。

  4. checkpoint → COMMIT → 下一批

    同一筆交易把 last_id 移到批次尾端。重開 worker 會從已提交的位置繼續；選不到列時結束，重新執行會得到 0。

  5. 全表驗收 → 切讀 → 觀察

    驗收必須獨立掃描整表確認 NULL 與差異為零，不能把「沒有下一批」當作完整證據。過渡期若有問題，暫停收斂並切回舊讀。

  6. 還原演練 → 收斂

    驗證快照備份可復原並確認舊讀者退役。示範交易內重建 readings 表，複製資料並核對列數、換表後才標記 V3。

程式碼與設計決策

  • expand()：DDL 與版本標籤同交易。CHECK 允許尚未回填的 NULL，但若有值，需等於 c × 10。
  • compat_write()：新增或更新同時帶兩欄，包含 id 小於等於 checkpoint 的記錄；新資料不指望 worker 再補。參數綁定只用於 SQL 值。
  • backfill_batch()：範例固定主鍵不重排，更新資料和指標用同一連線。若場景允許多來源倒灌舊資料，必須有同步寫入、補漏掃描或其他驗證策略。
  • contract()：在同一個寫入交易再做驗收，避免驗收後和換表前發生變更。示範表沒有外部依賴；真實重建須處理索引、觸發器、視圖、foreign key 與外部應用引用，不能照抄 DROP TABLE。
  • backup_to_new_file()：使用 SQLite 備份 API 另建快照並檢查 integrity_check，不以檔案複製取代正在寫入的 SQLite 備份，也不覆蓋既有檔。

"""Disposable SQLite migration lab. Run with Python 3.10+: python3 sqlite_data_evolution_lab.py"""
import sqlite3
import tempfile
import unittest
from contextlib import contextmanager
from pathlib import Path

V1 = "CREATE TABLE readings(id INTEGER PRIMARY KEY CHECK(id > 0), c INTEGER NOT NULL CHECK(typeof(c)='integer' AND c BETWEEN -40 AND 100))"
V3 = "CREATE TABLE readings_next(id INTEGER PRIMARY KEY CHECK(id > 0), deci_c INTEGER NOT NULL CHECK(typeof(deci_c)='integer' AND deci_c BETWEEN -400 AND 1000))"


@contextmanager
def connect(path):
    db = sqlite3.connect(path, timeout=3, isolation_level=None)
    try:
        yield db
    finally:
        db.close()


@contextmanager
def write_transaction(db):
    db.execute('BEGIN IMMEDIATE')
    try:
        yield
        db.execute('COMMIT')
    except BaseException:
        if db.in_transaction:
            db.execute('ROLLBACK')
        raise


def version(db):
    return db.execute('PRAGMA user_version').fetchone()[0]


def initialize(db):
    with write_transaction(db):
        db.execute(V1)
        db.executemany('INSERT INTO readings(c) VALUES (?)', [(18,), (22,), (27,)])
        db.execute('PRAGMA user_version = 1')


def expand(db):
    with write_transaction(db):
        if version(db) == 2:
            return
        if version(db) != 1 or db.execute(
            "PRAGMA table_info(readings)"
        ).fetchall() != [(0, 'id', 'INTEGER', 0, None, 1),
                         (1, 'c', 'INTEGER', 1, None, 0)]:
            raise RuntimeError('unexpected schema; stop')
        db.execute("""ALTER TABLE readings ADD COLUMN deci_c INTEGER
            CHECK(deci_c IS NULL OR (typeof(deci_c)='integer'
            AND deci_c BETWEEN -400 AND 1000 AND deci_c = c * 10))""")
        db.execute('CREATE TABLE migration_state(name TEXT PRIMARY KEY, last_id INTEGER NOT NULL)')
        db.execute("INSERT INTO migration_state VALUES ('c_to_deci_c', 0)")
        # Deployment precondition: drain all legacy writers.
        db.execute('PRAGMA user_version = 2')


def compat_write(db, row_id, c):
    """Only V2 writes are allowed by the deployment gate during the lab window."""
    with write_transaction(db):
        if version(db) != 2:
            raise RuntimeError('compat write requires expand phase')
        db.execute("""INSERT INTO readings(id,c,deci_c) VALUES (?,?,?)
            ON CONFLICT(id) DO UPDATE SET c=excluded.c,deci_c=excluded.deci_c""",
                   (row_id, c, c * 10))


def checkpoint(db):
    value = db.execute("SELECT last_id FROM migration_state WHERE name = ?", ('c_to_deci_c',)).fetchone()
    if value is None:
        raise RuntimeError('checkpoint missing; stop')
    return value[0]


def backfill_batch(db, size=2, *, simulate_interrupt=False):
    if not 1 <= size <= 1000:
        raise ValueError('size must be within 1..1000')
    with write_transaction(db):
        if version(db) != 2:
            raise RuntimeError('backfill requires expand phase')
        rows = db.execute('SELECT id FROM readings WHERE id > ? ORDER BY id LIMIT ?',
                          (checkpoint(db), size)).fetchall()
        if not rows:
            return 0
        db.executemany('UPDATE readings SET deci_c=c*10 WHERE id=? AND deci_c IS NULL', rows)
        if simulate_interrupt:
            raise RuntimeError('simulated abort before checkpoint')
        db.execute('UPDATE migration_state SET last_id=? WHERE name=?',
                   (rows[-1][0], 'c_to_deci_c'))
        return len(rows)


def validate(db):
    nulls, mismatches = db.execute("""SELECT COUNT(CASE WHEN deci_c IS NULL THEN 1 END),
          COUNT(CASE WHEN deci_c != c*10 THEN 1 END) FROM readings""").fetchone()
    if nulls or mismatches:
        raise RuntimeError(f'validation blocked: nulls={nulls}, mismatch={mismatches}')


def read_deci_c(db):
    if version(db) == 1:
        return db.execute('SELECT id,c*10 FROM readings ORDER BY id').fetchall()
    if version(db) == 3:
        return db.execute('SELECT id,deci_c FROM readings ORDER BY id').fetchall()
    return db.execute('SELECT id,COALESCE(deci_c,c*10) FROM readings ORDER BY id').fetchall()


def rollback_reader(db):
    if version(db) == 3:
        raise RuntimeError('v1 schema no longer available after contract')
    return db.execute('SELECT id,c FROM readings ORDER BY id').fetchall()


def contract(db):
    with write_transaction(db):
        if version(db) != 2:
            raise RuntimeError('contract requires expand phase')
        validate(db)
        db.execute(V3)
        db.execute('INSERT INTO readings_next SELECT id,deci_c FROM readings')
        old_count = db.execute('SELECT COUNT(*) FROM readings').fetchone()[0]
        new_count = db.execute('SELECT COUNT(*) FROM readings_next').fetchone()[0]
        if old_count != new_count:
            raise RuntimeError('row count mismatch')
        db.execute('DROP TABLE readings')
        db.execute('ALTER TABLE readings_next RENAME TO readings')
        db.execute('DROP TABLE migration_state')
        db.execute('PRAGMA user_version = 3')


def backup_to_new_file(src, target):
    """Exclusive destination, never overwrite a file. Only for the lab."""
    target = Path(target)
    with target.open('xb'):
        pass
    try:
        with connect(target) as dst:
            src.backup(dst)
            if dst.execute('PRAGMA integrity_check').fetchone() != ('ok',):
                raise RuntimeError('snapshot integrity check failed')
    except BaseException:
        target.unlink()
        raise


class Lab(unittest.TestCase):
    def setUp(self):
        tmp = tempfile.TemporaryDirectory()
        self.addCleanup(tmp.cleanup)
        self.root = Path(tmp.name)
        cm = connect(self.root / 'lab.db')
        self.db = cm.__enter__()
        self.addCleanup(cm.__exit__, None, None, None)
        initialize(self.db)

    def test_drift_blocks_expand(self):
        self.db.execute('ALTER TABLE readings ADD COLUMN unexpected TEXT')
        with self.assertRaisesRegex(RuntimeError, 'schema'):
            expand(self.db)
        self.assertEqual(version(self.db), 1)

    def test_expand_is_idempotent_and_compatible(self):
        expand(self.db)
        expand(self.db)
        self.assertEqual(rollback_reader(self.db), [(1,18), (2,22), (3,27)])
        self.assertEqual(read_deci_c(self.db), [(1,180), (2,220), (3,270)])

    def test_batch_abort_then_resume_and_rerun(self):
        expand(self.db)
        self.assertEqual(backfill_batch(self.db, 1), 1)
        with self.assertRaisesRegex(RuntimeError, 'simulated'):
            backfill_batch(self.db, 1, simulate_interrupt=True)
        self.assertEqual(checkpoint(self.db), 1)
        self.assertEqual(self.db.execute('SELECT deci_c FROM readings WHERE id=2').fetchone(), (None,))
        self.assertEqual(backfill_batch(self.db), 2)
        self.assertEqual(backfill_batch(self.db), 0)
        validate(self.db)

    def test_compat_write_updates_behind_checkpoint(self):
        expand(self.db)
        backfill_batch(self.db)
        compat_write(self.db, 1, 19)
        self.assertEqual(read_deci_c(self.db)[0], (1,190))
        self.assertEqual(rollback_reader(self.db)[0], (1,19))

    def test_contract_gates_and_constraints(self):
        expand(self.db)
        with self.assertRaisesRegex(RuntimeError, 'nulls'):
            contract(self.db)
        while backfill_batch(self.db):
            pass
        contract(self.db)
        self.assertEqual(read_deci_c(self.db), [(1,180), (2,220), (3,270)])
        with self.assertRaisesRegex(RuntimeError, 'no longer'):
            rollback_reader(self.db)
        with self.assertRaises(sqlite3.IntegrityError):
            self.db.execute('INSERT INTO readings(deci_c) VALUES (?)', (None,))
        with self.assertRaises(sqlite3.IntegrityError):
            self.db.execute('INSERT INTO readings(deci_c) VALUES (?)', (1001,))

    def test_backup_and_restore_drill(self):
        expand(self.db)
        while backfill_batch(self.db):
            pass
        snapshot = self.root / 'snapshot.db'
        backup_to_new_file(self.db, snapshot)
        contract(self.db)
        self.db.execute('UPDATE readings SET deci_c=181 WHERE id=1')
        restored = self.root / 'restore-drill.db'
        with connect(snapshot) as source:
            backup_to_new_file(source, restored)
        with connect(restored) as recovery:
            self.assertEqual(version(recovery), 2)
            self.assertEqual(rollback_reader(recovery)[0], (1,18))
        self.assertEqual(read_deci_c(self.db)[0], (1,181))  # No in-place overwrite.
        with self.assertRaises(FileExistsError):
            backup_to_new_file(self.db, restored)


if __name__ == '__main__':
    unittest.main(verbosity=2)

from __future__ import annotations

import tempfile
from pathlib import Path

from data_evolution_governance.migration import Checkpoint, backfill_records, preflight_check
from data_evolution_governance.report import write_migration_report
from data_evolution_governance.testing import sample_manifest, sample_records


def main() -> None:
    records = sample_records()
    issues = preflight_check(records)
    if issues:
        raise SystemExit(f"unexpected preflight issues: {issues}")
    checkpoint = Checkpoint()
    first_pass, partial = backfill_records(records, checkpoint=checkpoint, stop_after=2)
    resumed, summary = backfill_records(first_pass + records[2:], checkpoint=checkpoint)
    if partial.last_processed_id != 2:
        raise SystemExit("checkpoint did not advance to expected id")
    if summary.last_processed_id < 2 or not summary.rollback_validated:
        raise SystemExit("rollback validation failed")
    with tempfile.TemporaryDirectory() as tmpdir:
        report_path = Path(tmpdir) / "migration_report.json"
        write_migration_report(report_path, manifest=sample_manifest(), summary=summary, preflight_issues=issues)
        if not report_path.exists():
            raise SystemExit("migration report not written")
    if not any(int(item.get("schema_version", 1)) == 2 for item in resumed):
        raise SystemExit("records were not upgraded")
    print("data evolution smoke passed: compat + checkpoint + rollback + evidence")


if __name__ == "__main__":
    main()

from __future__ import annotations

from dataclasses import dataclass

from .models import DataEvolutionError, LegacyReader, read_record


@dataclass(frozen=True)
class MigrationManifest:
    from_version: int
    to_version: int
    expand_steps: tuple[str, ...]
    contract_condition: str


@dataclass
class Checkpoint:
    last_processed_id: int = 0


@dataclass(frozen=True)
class MigrationSummary:
    upgraded: int
    skipped: int
    drifted: int
    last_processed_id: int
    rollback_validated: bool


def preflight_check(records: list[dict[str, object]]) -> list[str]:
    issues: list[str] = []
    required = {"record_id", "device_id", "timestamp", "value"}
    for payload in records:
        missing = sorted(required - payload.keys())
        if missing:
            issues.append(f"record {payload.get('record_id', 'unknown')}: missing {','.join(missing)}")
    return issues


def apply_expand(payload: dict[str, object]) -> dict[str, object]:
    record = read_record(payload)
    expanded = record.to_payload()
    expanded["schema_version"] = 2
    expanded["severity"] = record.severity
    expanded["device_group"] = record.device_group
    return expanded


def backfill_records(
    records: list[dict[str, object]],
    *,
    checkpoint: Checkpoint | None = None,
    stop_after: int | None = None,
) -> tuple[list[dict[str, object]], MigrationSummary]:
    active_checkpoint = checkpoint or Checkpoint()
    upgraded = 0
    skipped = 0
    drifted = 0
    output: list[dict[str, object]] = []
    processed_in_run = 0
    for payload in records:
        record_id = int(payload.get("record_id", 0))
        if record_id <= active_checkpoint.last_processed_id:
            output.append(payload)
            skipped += 1
            continue
        try:
            expanded = apply_expand(payload)
        except (KeyError, TypeError, ValueError, DataEvolutionError):
            drifted += 1
            output.append(payload)
            continue
        output.append(expanded)
        upgraded += 1
        active_checkpoint.last_processed_id = record_id
        processed_in_run += 1
        if stop_after is not None and processed_in_run >= stop_after:
            break
    rollback_validated = all("level" in LegacyReader().read(item) for item in output if int(item.get("schema_version", 1)) == 2)
    return output, MigrationSummary(
        upgraded=upgraded,
        skipped=skipped,
        drifted=drifted,
        last_processed_id=active_checkpoint.last_processed_id,
        rollback_validated=rollback_validated,
    )

from __future__ import annotations

from dataclasses import asdict, dataclass


class DataEvolutionError(ValueError):
    pass


@dataclass(frozen=True)
class TelemetryRecord:
    record_id: int
    device_id: str
    timestamp: str
    value: float
    severity: str
    device_group: str
    schema_version: int = 2
    level: str | None = None

    def to_payload(self) -> dict[str, object]:
        return asdict(self)


def read_record(payload: dict[str, object]) -> TelemetryRecord:
    version = int(payload.get("schema_version", 1))
    if version == 1:
        severity = str(payload.get("level", "info"))
        device_group = str(payload.get("device_group", "ungrouped"))
    elif version == 2:
        severity = str(payload["severity"])
        device_group = str(payload.get("device_group", "ungrouped"))
    else:
        raise DataEvolutionError(f"unsupported schema version: {version}")
    return TelemetryRecord(
        record_id=int(payload["record_id"]),
        device_id=str(payload["device_id"]),
        timestamp=str(payload["timestamp"]),
        value=float(payload["value"]),
        severity=severity,
        device_group=device_group,
        schema_version=2,
        level=str(payload["level"]) if "level" in payload else None,
    )


class LegacyReader:
    def read(self, payload: dict[str, object]) -> dict[str, object]:
        severity = str(payload.get("severity") or payload.get("level", "info"))
        return {
            "record_id": int(payload["record_id"]),
            "device_id": str(payload["device_id"]),
            "timestamp": str(payload["timestamp"]),
            "value": float(payload["value"]),
            "level": severity,
            "schema_version": 1,
        }

from __future__ import annotations

import json
from pathlib import Path

from .migration import MigrationManifest, MigrationSummary


def write_migration_report(
    path: Path,
    *,
    manifest: MigrationManifest,
    summary: MigrationSummary,
    preflight_issues: list[str],
) -> None:
    payload = {
        "manifest": {
            "from_version": manifest.from_version,
            "to_version": manifest.to_version,
            "expand_steps": list(manifest.expand_steps),
            "contract_condition": manifest.contract_condition,
        },
        "summary": {
            "upgraded": summary.upgraded,
            "skipped": summary.skipped,
            "drifted": summary.drifted,
            "last_processed_id": summary.last_processed_id,
            "rollback_validated": summary.rollback_validated,
        },
        "preflight_issues": preflight_issues,
    }
    path.write_text(json.dumps(payload, ensure_ascii=False, indent=2), encoding="utf-8")

Verification

驗收要同時覆蓋升版、續跑與回退

資料演進不是 migration 跑完就算完成，還要證明能重跑、能停止、能回讀。

六項實驗證據

  1. 陌生欄位使預檢停止，不偷偷修正 schema。
  2. 可重複 expand，新舊讀路徑資料一致。
  3. 故意在 checkpoint 前中斷，驗證資料和指標都未推進，再續跑並重跑。
  4. 更新 checkpoint 之前的主鍵，兩欄仍一致。
  5. 未回填完成不得收斂，收斂後舊讀不可用且約束生效。
  6. 用備份另開復原檔、實際讀舊格式，確認來源未覆蓋；快照之後的新寫入不在備份裡。

上線驗收還要補哪些？

用實際資料量與備份容量估算工期，量測每批耗時、寫入延遲 P95、忙碌錯誤、尚未填值列數與 journal/WAL 成長。測試不代表已經驗證多程序壓力、跨庫事件同步、斷電或資料損毀。

發布紀錄至少保存 schema 版本、migration 檔版本、每批範圍、截止時間、來源／目的資料量、NULL 與差異數、備份時間點，以及實際演練耗時與簽核。

Troubleshooting

先比對資料版本與報告，再看應用程式

大多數資料升版事故，本質上都是版本契約或回填證據不足。

三種「回退」請先分清，否則可能丟新資料

  1. 交易回滾：單一未提交批次失敗時撤回這批更新與 checkpoint，之前已提交的批次不會消失。
  2. 應用切回舊讀：收斂前 c 仍存在，切回舊讀後保留 V2 寫入以維持雙欄一致；不必還原快照，也不會因切讀丟資料。此流程不承諾退回完整 V1 寫入程式。
  3. 資料恢復：收斂後不直接開舊程式。先停寫，評估是否能 forward fix 或在保留所有新值的前提下做逆向轉換；若不可，將備份還原到隔離檔，驗證可用，再盤點快照後的資料，經核准後才決定切換與重播。

22.1°C 無法無損回到 V1，因此已出現新精度時不能用除以 10 後四捨五入冒充回復。備份只還原到某個時間點：RPO 是可承受的資料遺失範圍；RTO 是可承受的復原時間。先量測、記錄並讓負責人核准。

先停止擴大影響，再診斷

  • busy / locked：暫停 worker，縮小批次；查長交易和寫入稽核，再以有上限的退避重試。不可在鎖內等網路或人工確認。
  • checkpoint 已到尾但仍有 NULL：找出相容層漏寫或資料倒灌的來源，修復後對照缺漏列；不能直接改進度來通過收斂。
  • 語意不符：核對單位、精度與有效範圍，區分原始值、已換算值及無效資料；不要默默把異常變成零。
Best Practices

讓資料升版變成可交付、可回退資產

版本發布時，schema 狀態、backfill 進度與 rollback 可行性都應被記錄。

發布前可照做的清單

  1. 確認應用與 schema 相容矩陣，盤點所有舊讀與寫入者。
  2. 將 expand、回填、切讀與 contract 分成不同發布關卡。
  3. 實測備份、資料驗收、觀察窗與異常回退。正式收斂另安排維護窗口。
  4. 工控場景優先在離線、去識別化遙測副本演練；控制命令、設備設定與現場連鎖不可用這個測試腳本操作。

延伸學習：實作、現場案例與自我檢查

本頁說明資料演進治理。本節示範一種不需要改寫舊資料的做法：每筆紀錄帶 schema 版本，讀取時依序套用升級函式到最新結構；遇到比程式更新的版本則明確拒絕。

可實跑範例：版本化紀錄與逐版升級

v1 → v2 補上單位；v2 → v3 欄位改名、單位代碼標準化、新增品質欄位（舊資料標記 unknown）。每個升級函式只處理相鄰兩版，新增版本時只需加一個函式。

下載範例 example.py

"""資料結構演進：每筆紀錄帶 schema 版本，讀取時逐版升級到最新結構；舊資料不改寫也能讀（標準函式庫）。"""
import json

RECORDS = [
    '{"v": 1, "point": "AHU1_SAT", "value": 22.5}',
    '{"v": 2, "point": "AHU1_SAT", "value": 22.6, "unit": "C"}',
    '{"v": 3, "point_id": "AHU1_SAT", "value": 22.7, "unit": "degC", "quality": "good"}',
    '{"v": 4, "point_id": "AHU1_SAT", "value": 22.8}',
]


def v1_to_v2(r):
    return {**r, "v": 2, "unit": "C"}                     # v1 沒有單位欄位，當時一律是攝氏


def v2_to_v3(r):
    r = dict(r)
    r["point_id"] = r.pop("point")                       # 欄位改名
    r["unit"] = {"C": "degC", "F": "degF"}[r["unit"]]    # 單位改用 UCUM 風格代碼
    r["quality"] = "unknown"                             # 新欄位：舊資料沒有品質資訊
    r["v"] = 3
    return r


UPGRADES = {1: v1_to_v2, 2: v2_to_v3}
LATEST = 3


def load(line):
    r = json.loads(line)
    if r["v"] > LATEST:
        raise ValueError(f"版本 {r['v']} 比程式支援的 {LATEST} 新，請先升級讀取程式")
    while r["v"] < LATEST:
        r = UPGRADES[r["v"]](r)
    return r


if __name__ == "__main__":
    for line in RECORDS:
        try:
            print(load(line))
        except ValueError as e:
            print("拒絕：", e)

拒絕： 版本 4 比程式支援的 3 新，請先升級讀取程式

工程現場案例：三年的歷史資料有三種格式，報表程式滿是 if

某平台三年來改了兩次資料格式：先加上單位欄位，後來把 point 改名為 point_id 並加入品質。報表程式裡到處是 if 'point' in r 之類的判斷，每次新功能都要記得處理三種格式，錯誤不斷。

逐版升級把格式差異集中在一處：讀取時一律轉成最新版，其他程式只需處理一種結構。舊資料不需要一次性改寫（改寫數億筆資料本身就有風險）。遇到 v4 這種比程式還新的資料直接拒絕，避免舊程式誤讀新格式。

  1. 每筆紀錄或每個檔案都帶 schema 版本，第一版就要有。
  2. 每次格式變更寫一個升級函式與測試，處理相鄰兩版。
  3. 新增欄位時明確定義舊資料的預設值或「未知」，不要猜。
  4. 寫入端先升級，讀取端要能讀新版後才開始寫新版（或同時部署）。

版本與法規更新（核對日期 2026-11-28）

  • 單位代碼可參考 UCUM（Unified Code for Units of Measure）；溫度以 Cel 表示攝氏、[degF] 表示華氏。範例的 degC 是常見的簡化寫法，跨系統交換時建議採用正式代碼並寫進資料字典。 來源：UCUM

練習題與自我檢查

  1. 若 v2 的資料中出現 unit 為 "K"（克耳文），v2_to_v3 會怎樣？

    看解答

    對照表沒有 K，會丟出 KeyError。這是好事：未知單位應該被發現而不是被猜測。可以把例外轉成更清楚的訊息，並在對照表中補上 K。

  2. 為什麼 v1_to_v2 可以直接補 unit 為 C？

    看解答

    依範例的假設，v1 時期所有資料都是攝氏。這種假設必須有依據並寫在註解或文件中；若不確定，應該標記為 unknown 而不是猜。

  3. 讀取程式只支援到 v3，但寫入端已經開始寫 v4，會發生什麼？部署順序應該怎麼安排？

    看解答

    舊讀取程式遇到 v4 會拒絕，報表中斷。應先部署能讀 v4 的讀取程式，確認全部更新後，再讓寫入端開始寫 v4。

  4. 升級函式為什麼要回傳新的 dict，而不是直接修改傳入的 r？

    看解答

    避免副作用：呼叫端若還持有原始物件，原地修改會讓它意外改變，也讓測試難以比對前後差異。
