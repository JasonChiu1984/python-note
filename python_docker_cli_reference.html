指令清單與預期輸出

執行前：命令列示例採 POSIX shell，先在 Docker × Python 教材的範例資料夾操作。例中 default 不是安全保證；先以 context inspect 確認實際端點。所有按鈕只改網頁或複製文字，不會執行任何命令。唯讀指令的輸出也可能有敏感資訊。舊版 Engine localhost 發布有額外網路限制，請查官方埠發布警告，不要把埠發布當成完整防火牆。

共 29 條。唯讀＝不要求變更 Engine 狀態；觀察仍可能啟動短命程序。

docker context show

確認目標唯讀
docker context show
預期證據
列出目前 context 名稱。
注意事項
名稱不是實際端點；還要看 context inspect。
官方參數

docker context inspect

確認目標唯讀
docker context inspect default --format '{{.Endpoints.docker.Host}}'
預期證據
顯示指定 context 的 Docker 端點。
注意事項
若為 SSH/TCP、或不確定是本機，就先不要執行變更指令。
官方參數

docker version

確認目標唯讀
docker --context default version
預期證據
分別列出 Client 和 Server 版本及 API。
注意事項
只有 Client 或出現連線錯誤，先查 daemon、端點和權限。
官方參數

docker info

確認目標唯讀
docker --context default info --format '{{.OSType}} {{.Architecture}} cgroup={{.CgroupVersion}}'
預期證據
確認的是 Engine 的核心平台與 cgroup 版本。
注意事項
Docker Desktop 的 Engine 結果不是 macOS 或 Windows 主機核心。
官方參數

docker buildx build

建立映像變更
docker --context default buildx build --load -t docker-cli-study:local .
預期證據
建置並將單平台實驗映像載入本機映像庫；執行目錄須有 Dockerfile。
注意事項
有 build cache 不代表基底已更新；此例 tag 可變，發佈時另記 digest。
官方參數

docker image inspect

建立映像唯讀
docker --context default image inspect docker-cli-study:local --format '{{.Id}} {{.Os}}/{{.Architecture}}'
預期證據
驗本機映像 ID 和平台。
注意事項
本機 image ID 不是 registry manifest 或 index digest。
官方參數

docker buildx imagetools inspect

建立映像向外查詢
docker --context default buildx imagetools inspect docker.io/library/python:3.14-slim
預期證據
查 Registry 的 manifest／index 與可用平台；會對 Registry 發請求。
注意事項
查到 digest 只能識別內容，不能替代簽章或來源驗證。
官方參數

docker image pull

建立映像變更
docker --context default image pull docker.io/library/python:3.14-slim
預期證據
下載映像到 Engine；需可存取 Registry。
注意事項
變動的是本機映像快取／標籤，已啟動的容器不會自動換版。
官方參數

docker container run

操作容器變更
docker --context default container run -d --pull=never --name docker-cli-study -p 127.0.0.1:18082:8080 docker-cli-study:local
預期證據
建立且啟動新容器；以主機 18082 轉到容器 8080。
注意事項
名稱和埠若被使用先停下確認；不要直接清理其他容器。
官方參數

docker container ls

操作容器唯讀
docker --context default container ls -a --filter name=docker-cli-study
預期證據
查看同名篩選的容器，含已停止。
注意事項
名稱篩選可能匹配部分名稱；對照 ID，再對精確名稱操作。
官方參數

docker container inspect

診斷取證唯讀
docker --context default container inspect docker-cli-study --format '{{json .State}}'
預期證據
查看 running、exit code、OOMKilled 和可用的 health 狀態。
注意事項
用 OOM 事件及日誌佐證；137 不能單獨定案。
官方參數

docker container exec

操作容器觀察
docker --context default container exec docker-cli-study python /app/app.py sample
預期證據
在已運行的合成遙測容器另啟程序，輸出固定樣本。
注意事項
exec 可執行任意程式，即使這個範例不寫檔；不證明 HTTP 服務正常。
官方參數

docker container stop

操作容器變更
docker --context default container stop --timeout 5 docker-cli-study
預期證據
要求指定容器停止，逾時可強制結束。
注意事項
先查該服務退出契約及結清標記；不能只看命令成功。
官方參數

docker container logs

診斷取證唯讀
docker --context default container logs --timestamps --tail 100 docker-cli-study
預期證據
讀取最近的容器 stdout/stderr 與時間戳。
注意事項
自訂日誌驅動或只寫容器檔案時，可能無法看到預期內容。
官方參數

docker container stats

診斷取證唯讀
docker --context default container stats --no-stream docker-cli-study
預期證據
取得一次資源取樣，交叉比對 CPU、記憶體、I/O 和 PID。
注意事項
單點值無法判斷限流；讀 cgroup 前後差值並關聯請求證據。
官方參數

docker events

診斷取證唯讀
docker --context default events --since 15m --until 0s --filter container=docker-cli-study
預期證據
回看有限時間窗內的 Engine 事件；until 0s 是現在。
注意事項
事件資料有限，daemon 重啟、短時爆量或未留存都會造成缺口。
官方參數

docker container top

診斷取證唯讀
docker --context default container top docker-cli-study
預期證據
列出容器程序，核對主程序與背景工作是否存在。
注意事項
能看到進程不代表程式能接受請求，也不能證明資料新鮮。
官方參數

docker container port

診斷取證唯讀
docker --context default container port docker-cli-study 8080/tcp
預期證據
看容器 8080/TCP 的發布對應。
注意事項
只有埠對應不代表應用已 listen；另測本機 HTTP 與資料契約。
官方參數

docker network ls

核對資料唯讀
docker --context default network ls
預期證據
列出 Engine 網路的 ID、驅動與範圍。
注意事項
列出名稱後才 inspect 具體網路，不要把 bridge 直接當成 PLC 所在 VLAN。
官方參數

docker network inspect

核對資料唯讀
docker --context default network inspect bridge --format '{{json .IPAM.Config}}'
預期證據
在有內建 bridge 的 Linux Engine 查看設定子網。
注意事項
若不存在先用 network ls 確認；不代表容器連線或原廠廣播可用。
官方參數

docker volume ls

核對資料唯讀
docker --context default volume ls
預期證據
列出 Engine 管理的 volumes。
注意事項
不顯示 bind mount；用容器 .Mounts 交叉核對。
官方參數

docker container inspect

核對資料唯讀
docker --context default container inspect docker-cli-study --format '{{json .Mounts}}'
預期證據
核對當前容器掛載種類、去向及讀寫狀態。
注意事項
空清單不是資料已備份；路徑是 Engine 所在環境的視角。
官方參數

docker system df

核對資料唯讀
docker --context default system df
預期證據
區分映像、容器、volume 和 build cache 的 Engine 估計用量。
注意事項
reclaimable 是估計，可回收不等於可刪；未備份的 volume 不做清理示範。
官方參數

docker compose version

管理專案唯讀
docker compose version
預期證據
確認 Compose 外掛指令可執行。
注意事項
這和 Engine Server 版本不同；先核對版本再用可選旗標。
官方參數

docker compose config

管理專案唯讀
docker --context default compose -p python-interop-lab config --quiet
預期證據
驗證合併、插值後的 Compose 設定；成功時通常無輸出。
注意事項
一般 config 可能顯示插值資料，分享前需遮蔽；靜態通過不是 Engine 或業務驗收。
官方參數

docker compose up

管理專案變更
docker --context default compose -p python-interop-lab up -d --build --wait --wait-timeout 45 telemetry
預期證據
建置及啟動範例服務，再等 running／healthy；支援旗標視 Compose 版本。
注意事項
無 healthcheck 時 running 不等於就緒；先在實驗資料夾確認 compose.yaml。
官方參數

docker compose ps

管理專案唯讀
docker --context default compose -p python-interop-lab ps --all
預期證據
按專案列出 running 及停止的服務容器。
注意事項
使用和 up 相同的目錄與專案名；找不到可能是定位錯誤。
官方參數

docker compose logs

管理專案唯讀
docker --context default compose -p python-interop-lab logs --tail 50 telemetry
預期證據
依服務取日誌，重建後核對容器與時間。
注意事項
若上一次容器已移除，不能假設 Compose 可取回舊日誌。
官方參數

docker compose down

管理專案變更
docker --context default compose -p python-interop-lab down
預期證據
停止並移除這個實驗專案的容器和非外部網路。
注意事項
不加 -v 預設不移除 volumes，但容器可寫層會消失；匿名卷不保證下次 up 自動掛回。
