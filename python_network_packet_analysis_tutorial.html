Python 網路封包解析

從一筆 Ethernet II 位元組紀錄，沿著 IPv4 標頭找到 TCP／UDP 區段。用標準函式庫拆欄位、驗證長度並輸出 JSON。本章只讀兩筆內建合成樣本，不需網路、管理權限或外部套件。

01 / 資料分層

架構圖：從框架到應用資料

  1. L2｜Ethernet II前 14 bytes：目的 MAC、來源 MAC、EtherType。0x0800 代表 IPv4。
  2. L3｜IPv4依 IHL 決定標頭後的起點；Total Length 限定 IPv4 終點。Protocol 6＝TCP，17＝UDP。
  3. L4｜傳輸層TCP：Data Offset 決定標頭末端；UDP：固定 8 bytes 標頭，Length 含標頭。
  4. 應用資料｜單筆示例只輸出 payload 範圍的十六進位。不假設目的埠等於應用協定，也不解讀加密內容。

先辨識來源鏈路型別。本練習直接餵 Ethernet II 位元組；一般 PCAP／PCAPNG 還有外層容器、鏈路型別、時間戳、捕獲長度與原始長度。不能把整個捕獲檔直接當一個 frame，也不能假設所有紀錄都是 Ethernet。

「frame」、「IPv4 datagram」、「TCP segment／UDP datagram」不是同一個位元組範圍。TCP 是位元組串流，單筆 payload 不代表一則完整應用訊息；需要多筆重組、順序／重傳處理與應用層 framing。UDP 保留 datagram 邊界，但不提供 TCP 式的可靠送達。

02 / 解析器資料流

流程圖：先驗邊界，再讀欄位

  1. 讀固定標頭最少 14 bytes 才能讀 EtherType；只接受未標記的 IPv4。
  2. 建立 IPv4 視窗確認版本、IHL×4、Total Length；擷取不足拒絕；忽略 IPv4 邊界外資料。
  3. 分片／協定分流MF=1 或 fragment offset 非 0 拒絕；DF 單獨出現不代表是分片。
  4. 建立 L4 視窗UDP 驗至少 8 且 Length 等於 IPv4 payload；TCP 驗至少 20、Data Offset 不越界。
  5. 輸出結果成功輸出 JSON；格式、支援範圍或長度有誤時回 ParseError。

每次處理 offset 都先檢查 start + length ≤ len(view)。Python slice 越界會悄悄縮短，所以不能只用切片當成驗證。struct.unpack_from() 也應讀已確認足夠的範圍。

例：UDP 的 Length=12 → 8 bytes 標頭 + 4 bytes 資料。TCP 沒有同義的 UDP Length 欄位；正常的非分片 IPv4 datagram 中，此例 TCP payload = 51 − 24 − 24 = 3 bytes。外層尾端不會被當作 payload；一般來源可能另含 FCS 或無 padding，本程式不嘗試辨識尾端種類。

04 / 常見工具

API 怎麼選：欄位拆解、離線檔案與資料匯出

API／工具常見用法與適用場景拿到資料後仍要核對
bytes.fromhexbytes.fromhex("0800")：將固定範例轉成兩個 bytes。不是文字編碼轉換；不從外界載入樣本。
memoryviewmemoryview(frame)[14:]：取得子視圖，不複製所切資料。生命週期跟著來源；轉為 bytes 或 hex 表示時會配置輸出。
structstruct.unpack_from("!H", view, 12)：從 offset 12 讀 big-endian 無號 16 位整數。! 是網路位元組序，calcsize("!H")==2。先驗邊界。
ipaddressstr(ipaddress.IPv4Address(b"\xc0\x00\x02\x01"))：將四個位元組轉成 IPv4 字串。數值和字串輸入的語意與錯誤處理要區分。
Scapy（選用）scapy.utils.PcapReader 可逐筆讀已授權、脫敏樣本；rdpcap() 適合小檔讀入記憶體。核對封裝、截斷與資源用量；不在本次環境執行。
TShark（選用）讀檔模式 -r；-T fields 配 -e 選欄位，適合離線交叉比對。核對欄位定義、空值、加密和 dissector 推斷；本章不擷取即時流量。

socket 的 TCP／UDP 端點介面通常拿到應用層資料，不等於 Ethernet frame。接收長度、封裝格式與權限需求應先由輸入資料契約決定。

完整程式：packet_lab.py
"""Decode only the two built-in documentation fixtures. No file or network input."""

import argparse
import ipaddress
import json
import struct

FIXTURES = {
    "udp": bytes.fromhex(
        "0200000000020200000000010800 "
        "450000200001000040118e95c0000201c6336402 "
        "30391f90000c0000 4c414221 "
        "0000000000000000000000000000"  # Ethernet padding, not part of IPv4
    ),
    "tcp": bytes.fromhex(
        "0200000000020200000000010800 "
        "460000330002400040064c8bc0000201c6336402 01010000 "
        "303901bb000000010000000260184000b2540000 01010000 "
        "4c4142"
    ),
}


class ParseError(ValueError):
    """Record is incomplete, inconsistent, or intentionally unsupported."""


def bounded(view: memoryview, start: int, length: int, name: str) -> memoryview:
    if start < 0 or length < 0 or start + length > len(view):
        raise ParseError(f"{name}: truncated")
    return view[start:start + length]


def mac(view: memoryview) -> str:
    return view.hex(":")


def parse_frame(frame: bytes) -> dict:
    captured = memoryview(frame)
    eth = bounded(captured, 0, 14, "Ethernet II")
    ether_type, = struct.unpack_from("!H", eth, 12)
    if ether_type != 0x0800:
        raise ParseError("EtherType: only untagged IPv4 (0x0800) is supported")

    fixed_ip = bounded(captured, 14, 20, "IPv4 minimum header")
    version, ihl = fixed_ip[0] >> 4, (fixed_ip[0] & 0xF) * 4
    if version != 4 or ihl < 20:
        raise ParseError("IPv4: invalid version or IHL")
    total, identification, frag = struct.unpack_from("!HHH", fixed_ip, 2)
    if total < ihl:
        raise ParseError("IPv4: Total Length is smaller than header")
    ip = bounded(captured, 14, total, "IPv4 Total Length")
    if frag & 0x8000:
        raise ParseError("IPv4: reserved fragmentation flag is set")
    if frag & 0x3FFF:  # MF (0x2000) or non-zero offset, not DF (0x4000)
        raise ParseError("IPv4: fragmented datagrams are unsupported")

    protocol = fixed_ip[9]
    segment = ip[ihl:]
    if protocol == 17:
        header = bounded(segment, 0, 8, "UDP minimum header")
        src_port, dst_port, length, checksum = struct.unpack_from("!HHHH", header)
        if length < 8 or length != len(segment):
            raise ParseError("UDP: length differs from IPv4 payload")
        payload = segment[8:length]
        info = {"kind": "UDP", "header_bytes": 8, "length": length,
                "checksum_field": checksum}
    elif protocol == 6:
        header = bounded(segment, 0, 20, "TCP minimum header")
        src_port, dst_port, seq, ack = struct.unpack_from("!HHII", header)
        offset = (header[12] >> 4) * 4
        if offset < 20:
            raise ParseError("TCP: invalid Data Offset")
        bounded(segment, 0, offset, "TCP header including options")
        payload = segment[offset:]
        checksum, = struct.unpack_from("!H", header, 16)
        info = {"kind": "TCP", "header_bytes": offset, "sequence": seq,
                "acknowledgment": ack, "flags_low8_hex": f"{header[13]:02x}",
                "checksum_field": checksum}
    else:
        raise ParseError("IPv4 Protocol: only TCP (6) and UDP (17) are supported")

    return {
        "captured_bytes": len(captured),
        "ethernet": {"source": mac(eth[6:12]), "destination": mac(eth[:6]),
                     "ethertype_hex": f"{ether_type:04x}"},
        "ipv4": {"source": str(ipaddress.IPv4Address(bytes(fixed_ip[12:16]))),
                 "destination": str(ipaddress.IPv4Address(bytes(fixed_ip[16:20]))),
                 "header_bytes": ihl, "total_length": total, "ttl": fixed_ip[8],
                 "identification": identification, "protocol": protocol,
                 "dont_fragment": bool(frag & 0x4000)},
        "transport": {**info, "source_port": src_port, "destination_port": dst_port},
        "payload_length": len(payload), "payload_hex": payload.hex(),
        "unparsed_ethernet_tail_bytes": len(captured) - 14 - total,
    }


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("fixture", choices=FIXTURES)
    args = parser.parse_args()
    try:
        result = parse_frame(FIXTURES[args.fixture])
    except ParseError as exc:
        parser.exit(1, f"parse error: {exc}\n")
    print(json.dumps(result, indent=2))


if __name__ == "__main__":
    main()
完整程式：test_packet_lab.py
import unittest

from packet_lab import FIXTURES, ParseError, parse_frame


class PacketLabTest(unittest.TestCase):
    def test_udp_payload_excludes_ethernet_padding(self):
        p = parse_frame(FIXTURES["udp"])
        self.assertEqual(p["captured_bytes"], 60)
        self.assertEqual(p["ipv4"]["source"], "192.0.2.1")
        self.assertEqual(p["ipv4"]["destination"], "198.51.100.2")
        self.assertEqual(p["transport"]["length"], 12)
        self.assertEqual(p["transport"]["destination_port"], 8080)
        self.assertEqual(p["payload_hex"], "4c414221")
        self.assertEqual(p["unparsed_ethernet_tail_bytes"], 14)

    def test_tcp_ip_ihl_and_data_offset_use_words(self):
        p = parse_frame(FIXTURES["tcp"])
        self.assertEqual(p["captured_bytes"], 65)
        self.assertEqual(p["ipv4"]["header_bytes"], 24)
        self.assertEqual(p["transport"]["header_bytes"], 24)
        self.assertEqual(p["transport"]["destination_port"], 443)
        self.assertEqual(p["transport"]["sequence"], 1)
        self.assertEqual(p["transport"]["flags_low8_hex"], "18")
        self.assertEqual(p["payload_hex"], "4c4142")
        self.assertTrue(p["ipv4"]["dont_fragment"])

    def test_truncated_ethernet_header(self):
        with self.assertRaisesRegex(ParseError, "Ethernet II: truncated"):
            parse_frame(FIXTURES["udp"][:13])

    def test_truncated_ipv4_total_length(self):
        with self.assertRaisesRegex(ParseError, "IPv4 Total Length: truncated"):
            parse_frame(FIXTURES["udp"][:45])

    def test_unsupported_ethertype(self):
        frame = bytearray(FIXTURES["udp"])
        frame[12:14] = bytes.fromhex("86dd")
        with self.assertRaisesRegex(ParseError, "EtherType"):
            parse_frame(bytes(frame))

    def test_fragmentation_is_out_of_scope(self):
        frame = bytearray(FIXTURES["udp"])
        frame[20:22] = bytes.fromhex("2000")
        with self.assertRaisesRegex(ParseError, "fragmented datagrams"):
            parse_frame(bytes(frame))

    def test_bad_udp_length(self):
        frame = bytearray(FIXTURES["udp"])
        frame[38:40] = bytes.fromhex("000d")
        with self.assertRaisesRegex(ParseError, "UDP: length"):
            parse_frame(bytes(frame))

    def test_bad_tcp_offset(self):
        frame = bytearray(FIXTURES["tcp"])
        frame[50] = 0xF0
        with self.assertRaisesRegex(ParseError, "TCP header including options: truncated"):
            parse_frame(bytes(frame))


if __name__ == "__main__":
    unittest.main()
06 / 能證明與不能證明的事

驗收：把解析正確性限縮到可觀察條件

  • 確認 UDP 只輸出 4 bytes payload、尾端 14 bytes 不混入；TCP 兩層選項區各 4 bytes，最後只輸出 3 bytes payload。
  • 先看錯誤落在哪一道檢查：測試包含 Ethernet 截斷、IPv4 Truncation、非 IPv4、IPv4 分片、UDP 長度不符及 TCP Data Offset 越界。
  • 欄位 checksum_field 只是讀值；本程式不驗 IP 或傳輸層校驗和。IPv4 UDP checksum 0 代表未提供；TCP checksum 的行為不同。校驗和不是來源身分驗證。
  • 本實驗不支援 VLAN、IPv6、分片重組、TCP 串流重組、解密、FCS 驗證或任意 PCAP。受控流程分析真實檔案時，先取得使用許可、確認資料留存／遮罩政策，並使用成熟的離線工具處理不同 link type。

練習題

  1. 手算 TCP 範例的應用資料範圍，再與 JSON 的 3 bytes 相互核對。
