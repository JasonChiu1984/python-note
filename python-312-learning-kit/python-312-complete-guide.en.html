C01｜Blocks and names

Colons introduce blocks; indentation decides branch membership. An if block has no separate lexical scope, but a name assigned only in an untaken branch is unavailable. Both branches assign a value; 28 yields high.

Runnable example
def c01():
    value = 28
    if value >= 28:
        state = "high"
    else:
        state = "normal"
    return state == "high"

assert c01() is True
print("C01 OK")

C02｜Numbers, strings, f-strings, and bytes

Float uses approximations; display precision does not change the value. str is text and bytes are octets. Encode explicitly at an I/O boundary; the UTF-8 round trip reconstructs 溫度=27.5.

Runnable example
def c02():
    sensor = "溫度"
    value = 27.5
    wire = f"{sensor}={value:.1f}".encode("utf-8")
    return isinstance(wire, bytes) and wire.decode("utf-8") == "溫度=27.5"

assert c02() is True
print("C02 OK")

C03｜Binding, mutability, and copies

Assignment is not copying. list.copy() keeps nested objects shared. After appending AHU-02, the shallow copy sees it while the deep copy does not. Do not use deepcopy as a substitute for managing live resources.

Runnable example
from copy import deepcopy

def c03():
    original = [["AHU-01"]]
    alias = original
    shallow = original.copy()
    deep = deepcopy(original)
    alias[0].append("AHU-02")
    return shallow[0] == ["AHU-01", "AHU-02"] and deep[0] == ["AHU-01"]

assert c03() is True
print("C03 OK")

C04｜Operators and precedence

Multiplication precedes addition. Floor division rounds down, not toward zero. 0 < x <= 4 evaluates the middle expression once. The results are 11, 3, 1 and True; use parentheses for mixed boolean logic.

Runnable example
def c04():
    return (5 + 2 * 3, 7 // 2, 7 % 2, 0 < 4 <= 4) == (11, 3, 1, True)

assert c04() is True
print("C04 OK")

C05｜Containers, slices, unpacking, and comprehensions

Lists retain order, sets remove duplicates, and dictionaries map keys to values. Do not assume sets are sorted. The slice stop is exclusive, and the starred target gathers the remainder. The result has first=24, last=28, with [28] selected.

Runnable example
def c05():
    head, *rest = [24, 26, 24, 28]
    unique = set(rest)
    row = {"first": head, "last": rest[-1]}
    return (row, len(unique), [n for n in rest[1:] if n >= 25]) == (
        {"first": 24, "last": 28}, 3, [28]
    )

assert c05() is True
print("C05 OK")

C06｜if, match, loops, and loop else

match checks structure, not just equality; a bare name captures rather than compares. Finding a high reading uses break, so loop else does not run. Normal exhaustion triggers else.

Runnable example
def c06():
    events = []
    for reading in [("offline", 0), ("ok", 28)]:
        match reading:
            case ("ok", value) if value >= 28:
                events.append("high")
                break
            case _:
                continue
    else:
        events.append("no alarm")
    return events == ["high"]

assert c06() is True
print("C06 OK")

C07｜Function parameters and variadic arguments

Parameters before / are positional-only, *offsets collects extra positional values, factor is keyword-only, and **tags captures extra keywords. The result is (23, 'PLC'). Avoid mutable list defaults shared across calls.

Runnable example
def c07():
    def scale(value, /, *offsets, factor=1, **tags):
        return value * factor + sum(offsets), tags["source"]
    return scale(10, 1, 2, factor=2, source="PLC") == (23, "PLC")

assert c07() is True
print("C07 OK")

C08｜LEGB, closures, and decorators

Lookup proceeds through local, enclosing, global, and builtins. nonlocal rebinds the enclosing counter. Decoration replaces the function at definition time; wraps preserves its name. Calls return (1, 28) and (2, 28); this simple counter is not a thread synchronization mechanism.

Runnable example
from functools import wraps

def c08():
    def counter():
        calls = 0
        def decorate(fn):
            @wraps(fn)
            def wrapped(*args, **kwargs):
                nonlocal calls
                calls += 1
                return calls, fn(*args, **kwargs)
            return wrapped
        return decorate
    @counter()
    def read():
        return 28
    return read() == (1, 28) and read() == (2, 28) and read.__name__ == "read"

assert c08() is True
print("C08 OK")

C09｜Classes, dataclasses, and object protocols

dataclass can generate initialization and equality. __str__ supplies the display, yielding AHU-01=27.0. frozen prevents ordinary field assignment; it does not deeply freeze nested mutable values.

Runnable example
from dataclasses import dataclass

def c09():
    @dataclass(frozen=True)
    class Sample:
        point: str
        value: float
        def __str__(self):
            return f"{self.point}={self.value:.1f}"
    return str(Sample("AHU-01", 27)) == "AHU-01=27.0"

assert c09() is True
print("C09 OK")

C10｜Iterators, yield, and yield from

next consumes one item; yield suspends the function and yield from delegates. The successive results are 25, [26, 27], and []. Create a new iterator instead of reusing an exhausted generator.

Runnable example
def c10():
    def samples():
        yield 25
        yield from (26, 27)
    iterator = samples()
    return next(iterator) == 25 and list(iterator) == [26, 27] and list(iterator) == []

assert c10() is True
print("C10 OK")

C11｜Exceptions, cause chains, and ExceptionGroup

raise … from exc preserves the original fault. except* handles matching subgroups; the example handles input and timeout, while unmatched errors propagate. Do not make infrastructure faults look like valid readings.

Runnable example
def c11():
    try:
        try:
            float("offline")
        except ValueError as exc:
            raise RuntimeError("bad sensor data") from exc
    except RuntimeError as exc:
        chained = isinstance(exc.__cause__, ValueError)
    labels = []
    try:
        raise ExceptionGroup("polling", [ValueError("bad input"), TimeoutError("late")])
    except* ValueError:
        labels.append("input")
    except* TimeoutError:
        labels.append("timeout")
    return chained and labels == ["input", "timeout"]

assert c11() is True
print("C11 OK")

C12｜with and contextmanager

with structures acquisition and cleanup. A contextmanager acquires before yield and cleans up in finally. Expect open, 27.5, close even though exceptional exits also run cleanup. Do not infer transaction commit semantics without checking the context manager.

Runnable example
from contextlib import contextmanager

def c12():
    events = []
    @contextmanager
    def stream():
        events.append("open")
        try:
            yield 27.5
        finally:
            events.append("close")
    with stream() as value:
        events.append(value)
    return events == ["open", 27.5, "close"]

assert c12() is True
print("C12 OK")

C13｜Typing as a data contract

TypedDict gives static key-and-value checks; the example reads celsius=27.5. It does not reject malformed inbound data at runtime, so validate schema, range, and units separately.

Runnable example
from typing import TypedDict

def c13():
    class Reading(TypedDict):
        point: str
        celsius: float
    row: Reading = {"point": "AHU-01", "celsius": 27.5}
    return row["celsius"] == 27.5

assert c13() is True
print("C13 OK")

C14｜Modules, imports, entry points, and environments

Import loads a module and normally executes its top level once. Guard the script entry point with __name__ so imports do not start polling. The example loads 27 through json; sys.executable helps identify the active environment.

Runnable example
import importlib
import sys

def c14():
    library = importlib.import_module("json")
    return library.loads("27") == 27 and bool(sys.executable)

assert c14() is True
print("C14 OK")

C15｜Files, JSON, and the standard library

Path uses explicit UTF-8 here. JSON is a data format, not Python code. Reading back gives the dictionary with 設備. Never use eval to parse JSON; production code also needs input-size and write-failure checks.

Runnable example
import json
from pathlib import Path
from tempfile import TemporaryDirectory

def c15():
    with TemporaryDirectory() as temp:
        path = Path(temp) / "report.json"
        path.write_text(json.dumps({"設備": "AHU-01"}, ensure_ascii=False), encoding="utf-8")
        return json.loads(path.read_text(encoding="utf-8")) == {"設備": "AHU-01"}

assert c15() is True
print("C15 OK")

C16｜Async syntax and TaskGroup

Calling async code creates a coroutine; await suspends until its awaitable finishes. TaskGroup waits on exit, and a non-cancellation failure cancels siblings and is grouped. The two tasks return 25 and 26; the example checks both results. Move blocking I/O off the event loop.

Runnable example
import asyncio

async def c16():
    async def read(value):
        await asyncio.sleep(0)
        return value
    async with asyncio.TaskGroup() as group:
        a = group.create_task(read(25))
        b = group.create_task(read(26))
    return (a.result(), b.result()) == (25, 26)

assert asyncio.run(c16()) is True
print("C16 OK")

Ten additional boundary checks

Run each example independently. The assertions are the expected outcomes; exceptions are intentional. Download ten checks。

C01 / C03 | Names and identity

Names reference objects. A mutable default persists across calls; use a None default and create a fresh container when required.

def add(value, items=None):
    if items is None:
        items = []
    items.append(value)
    return items
assert add(2) == [2] and add(3) == [3]
C02 | Character count and byte count

Protocol and file sizes are often in bytes; a Chinese character is not one UTF-8 byte. Choose encoding at the input boundary.

text = '冰水'
wire = text.encode('utf-8')
assert (len(text), len(wire), wire.decode('utf-8')) == (2, 6, text)
C04 | Short circuit and meaningful zero

Do not use or to mean missing. A zero flow reading is valid and must not be replaced by a default.

def configured(value, fallback):
    return fallback if value is None else value
assert configured(0, 100) == 0
assert configured(None, 100) == 100
C05 | Slices and nested aliases

A list slice copies the outer list, not nested referents. Decide explicitly which levels a retained snapshot will copy.

points = [['T01', 24], ['T02', 26]]
copy = points[:]
copy[0][1] = 25
assert copy is not points and points[0][1] == 25
C06 | for…else and search exhaustion

A loop else belongs to the loop, not its last if. It runs on normal exhaustion but not after break.

def find_alarm(points):
    for name, value in points:
        if value >= 30:
            break
    else:
        return None
    return name
assert find_alarm([('T01', 20)]) is None
assert find_alarm([('T02', 31)]) == 'T02'
C07 / C13 | Annotation is not validation

Validate JSON/API data at runtime even with annotations. bool subclasses int; exclude booleans from strict sensor fields.

def samples(n: int) -> int:
    if type(n) is not int or n < 0:
        raise ValueError('invalid sample count')
    return n
assert samples(0) == 0
try:
    samples(True)
except ValueError:
    pass
else:
    raise AssertionError('accepted boolean')
C08 | Late binding in closures

A lambda looks up free variables later. Capture the current value through a default argument or a factory to avoid every callback reading the final item.

broken = [lambda: n for n in range(3)]
fixed = [lambda n=n: n for n in range(3)]
assert [f() for f in broken] == [2, 2, 2]
assert [f() for f in fixed] == [0, 1, 2]
C09 | Dataclass default factory

Mutable fields need a per-instance factory. frozen limits field reassignment; it is not deep immutability.

from dataclasses import dataclass, field
@dataclass
class Batch:
    values: list[int] = field(default_factory=list)
a, b = Batch(), Batch()
a.values.append(2)
assert b.values == []
C10 | Consuming an iterator twice

After sum exhausts an iterator, list will see nothing. Rebuild the source or materialize it if the size is acceptable.

rows = iter([10, 20])
assert sum(rows) == 30
assert list(rows) == []
C11 / C12 | Cleanup on failure

Put cleanup in finally, and propagate the error. Suppressing it can make callers report success.

from contextlib import contextmanager
state = []
@contextmanager
def resource():
    try:
        yield
    finally:
        state.append('closed')
try:
    with resource():
        raise OSError('simulated')
except OSError:
    assert state == ['closed']

2. Python 3.12 changes and upgrades

PEP 695: Generics and aliases

A type alias can be evaluated lazily; it is not a class. first[T] preserves static element types, not runtime validation. Use TypeVar / TypeAlias for 3.11 because a version check cannot hide syntax from its parser.

type Reading = tuple[str, float]

def first[T](items: list[T]) -> T:
    return items[0]

assert first([("AHU-01", 25.2)])[0] == "AHU-01"

PEP 701: f-string grammar

Replacement fields can reuse outer quotes and contain backslashes where normal Python expressions permit them. The example prints AHU-01: 25.2; use temporary variables for a 3.11-compatible path.

row = {"name": "AHU-01", "value": 25.25}
print(f"{row["name"]}: {row["value"]:.1f}")

PEP 709: Comprehension inlining

List, set, and dict comprehensions no longer need an extra frame. Iteration variables still do not leak, but locals() can now see outer names and traces can differ. Generator expressions are excluded. The example prints True.

def has_outer():
    outer = 42
    return ["outer" in locals() for item in (0,)][0]

print(has_outer())

Tooling and standard-library APIs

typing.override requires a static checker for signature checking. Path.walk does not follow symlinks by default. sys.monitoring is an event API, not a performance guarantee. The example checks the walk root.

from pathlib import Path

root, directories, filenames = next(Path(".").walk())
assert root == Path(".")

Removals and deprecations

distutils is removed from the standard library, and clean venvs no longer preinstall setuptools. Check your pyproject.toml backend. Invalid backslash escapes now emit SyntaxWarning; use raw strings for regexes. A globally installed setuptools is not evidence that fresh builds work.

import re
assert re.fullmatch(r"AHU-\d{2}", "AHU-01")

3. Async, parallelism, and runtimes

The GIL is not an application lock, and async does not imply parallelism. Measure correctness, latency, throughput, and cancellation. Do not treat a toy timing as a hardware conclusion.

ModeUse and boundary
asyncioConcurrent I/O waits; replace or offload blocking APIs.
threadsBlocking I/O or extensions that release the GIL; protect shared state with queues or locks.
processesMultiprocess execution can help Python CPU work; account for serialization and startup.
subinterpretersPEP 684’s per-interpreter GIL is a C API change. 3.12 does not expose the Python-level interpreter interface described by the 3.15 guide.
"""Compare task modes on CPython 3.12. Correctness demonstration, not a benchmark."""
import asyncio
from concurrent.futures import ThreadPoolExecutor, ProcessPoolExecutor
import sys


def squares(n):
    return sum(i * i for i in range(n))


async def two_reads():
    async def read(v):
        await asyncio.sleep(0.002)
        return v
    async with asyncio.TaskGroup() as tasks:
        a, b = (tasks.create_task(read(n)) for n in (25, 26))
    return [a.result(), b.result()]


def main():
    expected = [30, 55]
    inp = [5, 6]
    assert [squares(n) for n in inp] == expected
    assert asyncio.run(two_reads()) == [25, 26]
    with ThreadPoolExecutor(2) as pool:
        assert list(pool.map(squares, inp)) == expected
    with ProcessPoolExecutor(2) as pool:
        assert list(pool.map(squares, inp)) == expected
    print(f"CPython {sys.version.split()[0]}: serial, asyncio, thread, process OK")


if __name__ == "__main__":
    main()

4. Engineering practice, evolution, and exercises

Eight-point collector: TaskGroup owns task lifetime, each point has its own timeout, invalid/time-out rows are not turned into zeros, and output preserves point order. Expect eight rows, six valid readings, mean 26.65 °C, and alarms on AHU-02 and AHU-06.

Boundary checks cover missing fields, None, NaN, infinity, bool, strings and out-of-range values. bool is a subclass of int, but True is not 1 °C. The simulated 20 ms timeout is not a production SLA.

def normalize(row):
    if "celsius" not in row:
        return "missing", None
    value = row["celsius"]
    if type(value) not in (int, float) or not -40 <= value <= 90 or not math.isfinite(value):
        return "invalid", None
    return "valid", value

async def sample(point, value, delay):
    try:
        async with asyncio.timeout(0.020):
            await asyncio.sleep(delay)
    except TimeoutError:
        return {"point": point, "quality": "timeout", "celsius": None}
    quality, reading = normalize({"celsius": value})
    return {"point": point, "quality": quality, "celsius": reading}

Version evolution and safe upgrade order

3.10 already has match. 3.11 already has TaskGroup, ExceptionGroup, and tomllib. 3.12 adds generic syntax, the new f-string grammar and comprehension inlining. Establish a baseline, switch to a clean 3.12 environment, then adopt features incrementally so dependency and language changes can be rolled back separately.

Exercises and self-check

  1. Remove all valid readings; the mean should be null, not a division by zero.
  2. Set the threshold to 29 °C. Only AHU-06 should alarm; quality must be unchanged.
  3. Write to the same path twice. The second write must fail without overwriting the first report.
  4. Add a hex bytes field. Report the source and field when decoding fails.

5. Engineering diagrams: CLI and service delivery

A CLI output-path conflict must stop rather than report success. Service delivery additionally needs health, timeouts, recovery, retention, and pinning checks. No service is deployed by this guide.
