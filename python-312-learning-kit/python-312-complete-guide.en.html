Python 3.12 Learning Guide

Last updated：2026-11-25

Use an AHU temperature example to learn the language changes, then check porting issues in a clean environment. The lab needs neither third-party packages nor network access.

Python 3.12.0 shipped on 2023-10-02. PEP 693 schedules source-only security releases as needed until about October 2028. The lab was tested on CPython 3.12.14; that is the test version, not a claim that it is the newest patch. Check the official schedule before deployment.

1. Moving from 3.11 to 3.12

Start with three changes: new generic syntax needs a 3.12 parser, f-string quoting rules are less restrictive, and CPython inlines list, set, and dictionary comprehensions. Check for hidden dependencies on distutils and packaging tools before deployment.

2. Type parameters and aliases | PEP 695

def first[T] declares the parameter on the function that uses it. A static checker can preserve the input list’s element type in the return value. type Reading declares a type alias; it neither validates telemetry nor supplies a class for isinstance(). For 3.11 compatibility use TypeVar and TypeAlias. Hiding the new syntax in a version check cannot avoid a parse error.

type Reading = tuple[str, float]

def first[T](items: list[T]) -> T:
    return items[0]

assert first([("AHU-01", 25.2)])[0] == "AHU-01"

3. f-strings | PEP 701

Replacement fields can reuse the outer quote style and contain backslashes where normal expressions permit them, such as a newline string passed to join. Format specifications such as :.1f work as before. If a tool still parses 3.11 grammar, assign dictionary fields to temporary variables before formatting.

record = {"zone": "AHU-01", "temperature": 25.25}
print(f"{record["zone"]}: {record["temperature"]:.1f} °C")

4. Comprehensions | PEP 709

CPython inlines list, dict, and set comprehensions into the surrounding function rather than using a separate comprehension frame. Iteration variables still do not leak; locals() inside a comprehension can see outer locals, and tracing and traceback structure can differ. Generator expressions are not inlined by this change. Benchmark your own workload.

outer = 99
assert [outer * 2 for outer in range(3)] == [0, 2, 4]
assert outer == 99  # no variable leakage

5. Standard-library exercises

typing.override helps a static checker detect a misspelled override; it does not enforce overrides at runtime. Path.walk() walks a local log tree and does not follow symbolic links by default. sys.monitoring offers a low-impact event API for tooling, not a guarantee of application speedups.

from pathlib import Path

for directory, folders, names in Path(".").walk():
    print(directory, len(names))

6. Porting and validation

Python 3.12 removes distutils from the standard library. Use pyproject.toml and a maintained build backend. New venv environments no longer preinstall setuptools; declare it explicitly when legacy tooling needs it. Invalid backslash escapes now emit SyntaxWarning; use raw strings for regex patterns. For native extensions, check wheel availability for your OS, CPU, and ABI, then retest in a clean environment.

python3.12 -m venv .venv
python3.12 -W error::SyntaxWarning python-312-lab.py --test
python3.12 python-312-lab.py
