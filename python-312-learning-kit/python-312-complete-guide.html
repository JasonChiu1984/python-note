1. 從 3.11 升到 3.12

這一版最先看三件事：新泛型語法只在 3.12 起可解析；f-string 的引號規則放寬；列表、集合和字典推導式在 CPython 3.12 改為內嵌。部署時另查 distutils 和建置工具是否被暗中依賴。

2. 型別參數與別名｜PEP 695

def first[T] 把型別參數放在使用它的函式上；型別檢查器據此保留輸入清單的元素型別。type Reading 建立型別別名，不會驗證 PLC 資料，也不是可傳入 isinstance() 的類別。需要支援 3.11 時，改用 TypeVar 與 TypeAlias；用 if sys.version_info 包住新語法也無法解決解析錯誤。

type Reading = tuple[str, float]

def first[T](items: list[T]) -> T:
    return items[0]

assert first([("AHU-01", 25.2)])[0] == "AHU-01"

3. f-string｜PEP 701

現在可在替換欄位內重複使用外層引號，也可放在一般運算式中合法使用的反斜線，例如 join 的換行字串。格式規格 :.1f 不變；若工具鏈仍解析 3.11，先把字典取值拆出，再格式化。

record = {"zone": "AHU-01", "temperature": 25.25}
print(f"{record["zone"]}: {record["temperature"]:.1f} °C")

4. 推導式｜PEP 709

CPython 將列表、字典和集合推導式內嵌到外層函式，不再需要獨立的推導式程式框。迭代變數依舊不會洩漏到外層；但推導式內的 locals() 能看到外層區域變數，追蹤器及 traceback 也可能不同。產生器運算式不在此次內嵌範圍；速度以實際資料驗證。

outer = 99
assert [outer * 2 for outer in range(3)] == [0, 2, 4]
assert outer == 99  # no variable leakage

5. 標準函式庫可以直接練什麼

typing.override 讓靜態檢查器找出拼錯的覆寫方法，不提供執行期保證。Path.walk() 適合巡覽本機紀錄檔；預設不追蹤符號連結。sys.monitoring 是提供給工具的低影響事件 API，並非行程效能必然改善。

from pathlib import Path

for directory, folders, names in Path(".").walk():
    print(directory, len(names))

6. 移植與驗收

Python 3.12 標準函式庫移除了 distutils；建置流程改用 pyproject.toml 與維護中的建置後端。新建 venv 不再預先裝入 setuptools；舊工具若仍需要，明確列為建置或執行依賴。無效反斜線跳脫改發 SyntaxWarning；regex 改用 raw 字串。若含原生擴充，核對作業系統、CPU 架構及 ABI 的 wheel，再從乾淨環境重跑測試。

python3.12 -m venv .venv
python3.12 -W error::SyntaxWarning python-312-lab.py --test
python3.12 python-312-lab.py
