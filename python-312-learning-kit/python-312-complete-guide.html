C01｜程式區塊與名稱

冒號開始區塊，縮排決定哪些敘述在同一分支。if 不另建詞法作用域；但如果只在未執行分支賦值，使用名稱會失敗。兩分支均賦值後，28 對應 high。

可執行範例
def c01():
    value = 28
    if value >= 28:
        state = "high"
    else:
        state = "normal"
    return state == "high"

assert c01() is True
print("C01 OK")

C02｜數值、字串、f-string 與 bytes

float 的十進位表示可能有近似誤差，格式的位數不會改寫原數值。str 是文字，bytes 是八位元資料；只在通訊／儲存邊界用明確編碼轉換。UTF-8 往返應還原 溫度=27.5。

可執行範例
def c02():
    sensor = "溫度"
    value = 27.5
    wire = f"{sensor}={value:.1f}".encode("utf-8")
    return isinstance(wire, bytes) and wire.decode("utf-8") == "溫度=27.5"

assert c02() is True
print("C02 OK")

C03｜名稱繫結、可變性與複製

指定不是複製；外層 list.copy() 仍共用內層。新增 AHU-02 後淺拷貝也看得到，deepcopy 的獨立巢狀資料不變。不要用 deepcopy 取代連線或其他資源的生命週期設計。

可執行範例
from copy import deepcopy

def c03():
    original = [["AHU-01"]]
    alias = original
    shallow = original.copy()
    deep = deepcopy(original)
    alias[0].append("AHU-02")
    return shallow[0] == ["AHU-01", "AHU-02"] and deep[0] == ["AHU-01"]

assert c03() is True
print("C03 OK")

C04｜運算子與優先序

乘法先於加法；// 是向下取整，不是向零截斷。比較鏈 0 < x <= 4 會只求值一次中間運算式。案例得到 11、3、1、True；遇混合布林最好加括號。

可執行範例
def c04():
    return (5 + 2 * 3, 7 // 2, 7 % 2, 0 < 4 <= 4) == (11, 3, 1, True)

print("C04 OK")

C05｜容器、切片、解包與推導式

list 有順序、set 去重、dict 是鍵值表；不能把 set 當有排序的輸出。切片右界不含，星號接住剩餘元素。範例輸出 first=24、last=28，篩選剩 [28]。

可執行範例
def c05():
    head, *rest = [24, 26, 24, 28]
    unique = set(rest)
    row = {"first": head, "last": rest[-1]}
    return (row, len(unique), [n for n in rest[1:] if n >= 25]) == (
        {"first": 24, "last": 28}, 3, [28]
    )

assert c05() is True
print("C05 OK")

C06｜if、match、迴圈與迴圈 else

match 是結構比對，不是等號串列；裸名稱圖樣會捕捉，不等於比較常數。搜尋找到 high 就 break，因此 for 的 else 不執行；正常耗盡才執行。

可執行範例
def c06():
    events = []
    for reading in [("offline", 0), ("ok", 28)]:
        match reading:
            case ("ok", value) if value >= 28:
                events.append("high")
                break
            case _:
                continue
    else:
        events.append("no alarm")
    return events == ["high"]

assert c06() is True
print("C06 OK")

C07｜函式參數：位置、關鍵字、可變引數

/ 左側為僅限位置，*offsets 收集多餘位置值，factor 只能用關鍵字，**tags 收集多餘命名值。結果是 (23, 'PLC')。避免以可變 list 當預設值造成跨呼叫共用。

可執行範例
def c07():
    def scale(value, /, *offsets, factor=1, **tags):
        return value * factor + sum(offsets), tags["source"]
    return scale(10, 1, 2, factor=2, source="PLC") == (23, "PLC")

assert c07() is True
print("C07 OK")

C08｜LEGB、閉包與裝飾器

名稱查找由 local、enclosing、global 到 builtins；nonlocal 可重新繫結外層 calls。裝飾時就替換函式，wraps 保留名稱。兩次呼叫回傳 (1, 28)、(2, 28)；這個簡單計數不是執行緒同步實作。

可執行範例
from functools import wraps

def c08():
    def counter():
        calls = 0
        def decorate(fn):
            @wraps(fn)
            def wrapped(*args, **kwargs):
                nonlocal calls
                calls += 1
                return calls, fn(*args, **kwargs)
            return wrapped
        return decorate
    @counter()
    def read():
        return 28
    return read() == (1, 28) and read() == (2, 28) and read.__name__ == "read"

assert c08() is True
print("C08 OK")

C09｜class、dataclass 與物件協定

dataclass 可代建初始化與比較；__str__ 控制 str() 顯示，輸出 AHU-01=27.0。frozen 阻止正常欄位指定，不會把巢狀可變物件深度凍結。

可執行範例
from dataclasses import dataclass

def c09():
    @dataclass(frozen=True)
    class Sample:
        point: str
        value: float
        def __str__(self):
            return f"{self.point}={self.value:.1f}"
    return str(Sample("AHU-01", 27)) == "AHU-01=27.0"

assert c09() is True
print("C09 OK")

C10｜迭代器、yield 與 yield from

next 消耗下一筆；yield 暫停函式，yield from 委派序列。依序取到 25、[26, 27]、[]；需要重跑就建立新 iterator，而不是重用已耗盡的生成器。

可執行範例
def c10():
    def samples():
        yield 25
        yield from (26, 27)
    iterator = samples()
    return next(iterator) == 25 and list(iterator) == [26, 27] and list(iterator) == []

assert c10() is True
print("C10 OK")

C11｜例外、原因鏈與 ExceptionGroup

raise … from exc 保存原始失敗，便於定位資料格式。except* 各自處理群組中的相符子樹，例題處理 input 與 timeout；未相符項會繼續傳播。不要用無區別 except 把系統錯誤變成正常讀值。

可執行範例
def c11():
    try:
        try:
            float("offline")
        except ValueError as exc:
            raise RuntimeError("bad sensor data") from exc
    except RuntimeError as exc:
        chained = isinstance(exc.__cause__, ValueError)
    labels = []
    try:
        raise ExceptionGroup("polling", [ValueError("bad input"), TimeoutError("late")])
    except* ValueError:
        labels.append("input")
    except* TimeoutError:
        labels.append("timeout")
    return chained and labels == ["input", "timeout"]

assert c11() is True
print("C11 OK")

C12｜with 與 contextmanager

with 管理取得與清理；contextmanager 在 yield 前取得資源，finally 在離開時清理。預期順序 open、27.5、close，正常與例外都走清理。不能假設 with 都會提交交易，仍要看 context manager 的契約。

可執行範例
from contextlib import contextmanager

def c12():
    events = []
    @contextmanager
    def stream():
        events.append("open")
        try:
            yield 27.5
        finally:
            events.append("close")
    with stream() as value:
        events.append(value)
    return events == ["open", 27.5, "close"]

assert c12() is True
print("C12 OK")

C13｜typing：資料契約

TypedDict 補上鍵和值的靜態契約；範例查到 celsius=27.5。它不會在執行期拒絕外部錯誤資料，仍需驗證 schema、範圍與單位。

可執行範例
from typing import TypedDict

def c13():
    class Reading(TypedDict):
        point: str
        celsius: float
    row: Reading = {"point": "AHU-01", "celsius": 27.5}
    return row["celsius"] == 27.5

assert c13() is True
print("C13 OK")

C14｜模組、import、入口與環境

import 載入模組且通常只執行一次模組頂層程式。用 __name__ 判斷腳本入口，避免 import 時啟動採集。範例從 json 載入 27；sys.executable 可確認啟動的是哪個環境。

可執行範例
import importlib
import sys

def c14():
    library = importlib.import_module("json")
    return library.loads("27") == 27 and bool(sys.executable)

assert c14() is True
print("C14 OK")

C15｜檔案、JSON 與標準庫

Path 以明確 UTF-8 編碼讀寫；JSON 是資料格式，不是 Python 程式。讀回應是含「設備」的字典。不要用 eval 解讀 JSON，生產版也要考慮檔案大小與寫入失敗。

可執行範例
import json
from pathlib import Path
from tempfile import TemporaryDirectory

def c15():
    with TemporaryDirectory() as temp:
        path = Path(temp) / "report.json"
        path.write_text(json.dumps({"設備": "AHU-01"}, ensure_ascii=False), encoding="utf-8")
        return json.loads(path.read_text(encoding="utf-8")) == {"設備": "AHU-01"}

assert c15() is True
print("C15 OK")

C16｜async 語法與 TaskGroup

呼叫 async 函式會產生 coroutine，不會自行執行；await 讓出控制直到 awaitable 完成。TaskGroup 在離開時等待子任務，非取消錯誤會取消同組其他任務並彙總。範例取得 25、26；勿在事件迴圈內直接執行阻塞 I/O。

可執行範例
import asyncio

async def c16():
    async def read(value):
        await asyncio.sleep(0)
        return value
    async with asyncio.TaskGroup() as group:
        a = group.create_task(read(25))
        b = group.create_task(read(26))
    return (a.result(), b.result()) == (25, 26)

assert asyncio.run(c16()) is True
print("C16 OK")

十個容易誤判的語法邊界

每段可獨立執行；assert 寫出預期結果，例外皆為刻意測試。 下載十項邊界實驗。

C01 / C03｜名稱與同一物件

名稱指向物件；用可變預設引數會跨呼叫累積。若每次都應該是新資料，使用 None 佔位再建容器。

def add(value, items=None):
    if items is None:
        items = []
    items.append(value)
    return items
assert add(2) == [2] and add(3) == [3]
C02｜字元與位元組長度

網路長度與儲存格式往往以 bytes 計；中文不是每字一 byte。錯誤編碼應在輸入邊界被發現。

text = '冰水'
wire = text.encode('utf-8')
assert (len(text), len(wire), wire.decode('utf-8')) == (2, 6, text)
C04｜短路與有意義的 0

不能以 or 代替『缺值』判斷。零流量是有效量測，不應被預設流量覆蓋。

def configured(value, fallback):
    return fallback if value is None else value
assert configured(0, 100) == 0
assert configured(None, 100) == 100
C05｜切片與深層別名

列表切片建立新外層但保留內層參考。若要保存可稽核快照，明確決定是否複製內層。

points = [['T01', 24], ['T02', 26]]
copy = points[:]
copy[0][1] = 25
assert copy is not points and points[0][1] == 25
C06｜for…else 尋找失敗

迴圈的 else 不是最後一次 if 的 else。正常走完才執行，遇到 break 則跳過。

def find_alarm(points):
    for name, value in points:
        if value >= 30:
            break
    else:
        return None
    return name
assert find_alarm([('T01', 20)]) is None
assert find_alarm([('T02', 31)]) == 'T02'
C07 / C13｜驗證不是型別註記

從 JSON/API 進來的資料仍要做 runtime 驗證。Python 的 bool 是 int 子類，嚴格點表欄位應把它排除。

def samples(n: int) -> int:
    if type(n) is not int or n < 0:
        raise ValueError('invalid sample count')
    return n
assert samples(0) == 0
try:
    samples(True)
except ValueError:
    pass
else:
    raise AssertionError('accepted boolean')
C08｜閉包的晚期查找

lambda 讀取的是之後查到的名稱。讓目前值成為預設引數，或寫工廠函式，以免每筆回呼都指向最後一項。

broken = [lambda: n for n in range(3)]
fixed = [lambda n=n: n for n in range(3)]
assert [f() for f in broken] == [2, 2, 2]
assert [f() for f in fixed] == [0, 1, 2]
C09｜dataclass 預設工廠

可變的欄位要由每個實例各自建立。frozen 限制欄位重新指派，不是深層不可變。

from dataclasses import dataclass, field
@dataclass
class Batch:
    values: list[int] = field(default_factory=list)
a, b = Batch(), Batch()
a.values.append(2)
assert b.values == []
C10｜迭代器重複消費

先做 sum 再轉 list，第二次會是空。若需要重讀，重新建立來源或在資料量可接受時物化。

rows = iter([10, 20])
assert sum(rows) == 30
assert list(rows) == []
C11 / C12｜失敗也要釋放資源

釋放設在 finally，例外仍應上傳給呼叫端。若吞下例外，後續服務會誤判成功。

from contextlib import contextmanager
state = []
@contextmanager
def resource():
    try:
        yield
    finally:
        state.append('closed')
try:
    with resource():
        raise OSError('simulated')
except OSError:
    assert state == ['closed']

2. Python 3.12 新增與升級變更

PEP 695：泛型與 type 別名

type 宣告可以延後求值；它不是 class。first[T] 讓型別檢查保留元素型別，不會驗證內容。3.11 必須改用 TypeVar / TypeAlias，版本條件無法保護舊解析器。

type Reading = tuple[str, float]

def first[T](items: list[T]) -> T:
    return items[0]

assert first([("AHU-01", 25.2)])[0] == "AHU-01"

PEP 701：f-string 文法

替換欄能重複外層引號，也能含一般運算式允許的反斜線。以下印出 AHU-01: 25.2；3.11 路徑改用暫存變數。

row = {"name": "AHU-01", "value": 25.25}
print(f"{row["name"]}: {row["value"]:.1f}")

PEP 709：推導式內嵌

list、set、dict 推導式移除額外 frame；不影響外層 iter 變數，但 locals() 可看到外層名稱，追蹤結果也可能變。產生器運算式不包含在這次變更。範例顯示 True。

def has_outer():
    outer = 42
    return ["outer" in locals() for item in (0,)][0]

print(has_outer())

工具與標準庫 API

typing.override 不會自動檢查方法簽名；需配合靜態工具。Path.walk 預設不跟隨 symlink。sys.monitoring 是低開銷監測介面，不是效能保證。以下對同一路徑走訪並核對根目錄。

from pathlib import Path

root, directories, filenames = next(Path(".").walk())
assert root == Path(".")

移除與棄用

distutils 移出標準庫，乾淨 venv 不再預裝 setuptools；檢查 pyproject.toml 的建置後端。無效反斜線跳脫從 DeprecationWarning 提升為 SyntaxWarning；regex 使用 raw 字串。不要以系統碰巧裝了 setuptools 判定所有主機都能建置。

import re
assert re.fullmatch(r"AHU-\d{2}", "AHU-01")

3.15 → 3.12 對照與退路

3.153.12 的實作決策
lazy import普通 import／在函式內延遲 import；別把相同副作用或時機當保證。
推導式解包 / comprehension unpacking雙層 for 逐層展開；3.12 的內嵌最佳化不是此語法。
frozendict / sentinelMappingProxyType 是唯讀檢視而非不可變快照；私有 object() 要用 is 比對。
UTF-8 預設 / default encoding對檔案明寫 encoding='utf-8'；不要假定 3.12 的 locale 編碼。
Closed TypedDict / TypeFormTypedDict 提供靜態契約；需要強制拒絕額外欄位就另外驗證。
Tachyon / startup config用 cProfile、明確入口與測試；不把 3.15 的監測與啟動 API 移植到 3.12。
free-threading / iterator synchronization普通 CPython 3.12 有 GIL；以 Queue、Lock 或程序隔離保護共享狀態，不使用 3.15 專用同步 API。
新標準庫與 C 擴充 / libraries and C extensions在 3.12 環境確認 wheel/ABI、標準庫 API 與套件依賴；不假定新方法存在。

3. 非同步、平行與執行環境

GIL 不是業務鎖，async 也不代表平行。可觀察的是正確性、延遲、吞吐和取消，不要把固定範例或秒數當硬體結論。

方式適用與邊界
asyncioI/O 多路等待；阻塞 API 要改成非阻塞或卸載。
threads阻塞 I/O 或會釋出 GIL 的擴充；用 queue/lock 保護共享狀態。
processes純 Python CPU 密集工作可用多程序；要算序列化與啟動成本。
subinterpretersPEP 684 的每直譯器 GIL 是 C API 成果；3.12 不提供 3.15 教材的 Python 直譯器介面。
"""Compare task modes on CPython 3.12. Correctness demonstration, not a benchmark."""
import asyncio
from concurrent.futures import ThreadPoolExecutor, ProcessPoolExecutor
import sys


def squares(n):
    return sum(i * i for i in range(n))


async def two_reads():
    async def read(v):
        await asyncio.sleep(0.002)
        return v
    async with asyncio.TaskGroup() as tasks:
        a, b = (tasks.create_task(read(n)) for n in (25, 26))
    return [a.result(), b.result()]


def main():
    expected = [30, 55]
    inp = [5, 6]
    assert [squares(n) for n in inp] == expected
    assert asyncio.run(two_reads()) == [25, 26]
    with ThreadPoolExecutor(2) as pool:
        assert list(pool.map(squares, inp)) == expected
    with ProcessPoolExecutor(2) as pool:
        assert list(pool.map(squares, inp)) == expected
    print(f"CPython {sys.version.split()[0]}: serial, asyncio, thread, process OK")


if __name__ == "__main__":
    main()

4. 工程實務、版本沿革與學習練習

八點採集：TaskGroup 保留結構化生命週期；每點獨立 timeout；缺值與逾時不編成 0、不列進平均；結果依輸入點序。範例應產出 8 列、6 有效、平均 26.65 °C，AHU-02 與 AHU-06 告警。

def normalize(row):
    if "celsius" not in row:
        return "missing", None
    value = row["celsius"]
    if type(value) not in (int, float) or not -40 <= value <= 90 or not math.isfinite(value):
        return "invalid", None
    return "valid", value

延伸學習：實作、現場案例與自我檢查

3.12 讓泛型與型別別名的寫法大幅簡化（PEP 695），也新增了 itertools.batched 並放寬 f-string 的語法限制（PEP 701）。本節用讀取 Modbus 暫存器的分批計畫與帶型別的讀值物件示範。

可實跑範例：PEP 695 泛型、batched 與 f-string

Reading[T] 不需要 TypeVar 與 Generic；latest[T] 是泛型函式；type Address = int 建立延遲求值的型別別名，實際型別存在 __value__。batched(addrs, 125) 依 Modbus 單次最多讀 125 個暫存器的限制切分。

下載範例 extension-example.py

"""Python 3.12：PEP 695 泛型語法與 type 別名、itertools.batched 分批讀取、更彈性的 f-string（需 Python 3.12+）。"""
from dataclasses import dataclass
from itertools import batched

type Address = int                       # type 陳述式：清楚的型別別名


@dataclass(frozen=True)
class Reading[T]:                        # 不必再寫 TypeVar 與 Generic[T]
    point: str
    value: T


def latest[T](items: list[Reading[T]]) -> Reading[T]:
    return items[-1]


if __name__ == "__main__":
    addrs: list[Address] = list(range(0, 250))
    plans = [(b[0], len(b)) for b in batched(addrs, 125)]     # Modbus 單次最多讀 125 個暫存器
    print("分批讀取計畫（起始位址, 數量）：", plans)
    temps = [Reading("SAT", 22.4), Reading("SAT", 22.6)]
    modes = [Reading("MODE", "cooling")]
    print("最新溫度：", latest(temps), "；最新模式：", latest(modes))
    point = {"name": "SAT", "unit": "°C"}
    print(f"{point["name"]} 的單位是 {point["unit"]}")    # 3.12 起 f-string 內可重用相同引號
    print("Address 的實際型別：", Address.__value__)

工程現場案例：一次讀 250 個暫存器，設備回傳例外碼 03

Modbus 規定 Read Holding Registers 單次最多 125 個暫存器（許多設備更少）。某程式一次要求 250 個，設備回傳 Illegal Data Value。以 batched() 依上限切分，就不必自己寫索引計算。

型別參數讓同一個 Reading 類別同時表示數值點與文字狀態點，型別檢查工具也能分辨 latest(temps) 回傳的是 Reading[float]。

  1. 查設備手冊確認單次讀取的暫存器上限，寫進設定。
  2. 用 batched() 產生讀取計畫，並合併連續位址以減少請求數。
  3. 資料類別使用 PEP 695 語法標註型別參數。
  4. 以 mypy 或 pyright 檢查，確認泛型推論正確。

練習題與自我檢查

  1. 若暫存器有 260 個，batched(addrs, 125) 會產生哪些批次？

    看解答

    (0, 125)、(125, 125)、(250, 10)。最後一批不足 125 個也會產生；若要求每批都滿，3.13 起可用 strict=True。

  2. type Address = int 與 Address = int 有什麼不同？

    看解答

    前者建立 TypeAliasType 物件，右側延遲求值，可以前向參考尚未定義的型別，型別工具也明確知道它是別名。後者只是普通變數賦值，Address 就是 int 本身。

  3. 範例中的 f"{point["name"]}" 在 3.11 執行會怎樣？

    看解答

    SyntaxError。3.12 之前 f-string 內不能重複使用外層的引號，必須改成 point['name']。

  4. Reading[T] 在執行時會檢查 value 的型別嗎？

    看解答

    不會。型別參數只供靜態檢查工具使用，執行時 Reading("SAT", "abc") 也能建立。需要執行時檢查時，使用 pydantic 等驗證工具或在 __post_init__ 中自行檢查。
