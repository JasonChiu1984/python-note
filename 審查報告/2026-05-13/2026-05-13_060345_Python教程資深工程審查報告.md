## 四、本輪修正方向

本輪不新增路線，而是把高階案例第四批語意校閱落地：

| 主題 | v1.4.0 校閱案例 | 補強重點 |
|---|---|---|
| Architecture | Command Bus | handler registry、transaction wrapper、trace context、audit log |
| Data | Schema Migration Gate | expand/contract、schema diff、backfill checkpoint、rollback note |
| Concurrency | Rate Limited HTTP Client | token bucket、retry-after、quota exhausted、provider metric |
| Reliability | Poison Message | retry_count、DLQ、error reason、operator replay |
| Performance | File Lock | lock timeout、stale lock cleanup、crash recovery、corruption runbook |
| Security | Secret Rotation | active/previous key、kid lookup、rotation window、redacted report |
| Testing | Migration Rollback Plan | backup checksum、reverse migration、partial failure、rollback evidence |
| Observability | Error Budget | SLI/SLO、burn rate、release freeze、incident annotation |
| Packaging | Sandboxed Subprocess | list args、timeout、stderr capture、allowed command policy |
| Platform | GDPR Delete Workflow | dry-run、async deletion、external failure、tombstone audit |
