本頁互動實驗室示範了 frozendict 與 sentinel 的行為。本節把它們組合成一個實際可用的點位設定類別：不可變、可當字典鍵、建立時驗證，並能從 CSV 匯入。

可實跑範例：不可變點位設定類別與 CSV 匯入

dataclass(frozen=True, slots=True) 讓實例不可修改且省記憶體；tags 欄位用 frozendict 讓整個物件可雜湊；with_changes() 以 sentinel 區分「不改」與「設為 None」。匯入時位址超出範圍的列會被拒絕。

下載範例 example.py

"""不可變設備設定：dataclass(frozen, slots) ＋ frozendict 欄位 ＋ sentinel 預設值，並以 CSV 往返驗證。需 Python 3.15。"""
import csv
import io
from dataclasses import dataclass, field, replace

UNSET = sentinel("UNSET")


@dataclass(frozen=True, slots=True)
class Point:
    name: str
    addr: int
    scale: float = 1.0
    tags: frozendict = field(default_factory=frozendict)
    alarm_high: float | None = None

    def __post_init__(self):
        if not 0 <= self.addr <= 65535:
            raise ValueError(f"{self.name}: 位址 {self.addr} 超出 0–65535")


def with_changes(p: Point, *, scale=UNSET, alarm_high=UNSET) -> Point:
    """只改有傳入的欄位；None 代表「清除告警上限」，UNSET 代表「不變」。"""
    changes = {k: v for k, v in (("scale", scale), ("alarm_high", alarm_high)) if v is not UNSET}
    return replace(p, **changes)


if __name__ == "__main__":
    sat = Point("SAT", 0, 0.1, frozendict(unit="degC", ahu="AHU-01"), alarm_high=30.0)
    print(sat)
    print("改倍率：", with_changes(sat, scale=0.01).scale, "；清除告警：", with_changes(sat, alarm_high=None).alarm_high,
          "；不傳：", with_changes(sat).alarm_high)
    try:
        sat.scale = 1.0
    except AttributeError as e:
        print("直接修改：", type(e).__name__)
    print("可當字典鍵：", {sat: "已部署"}[Point("SAT", 0, 0.1, frozendict(ahu="AHU-01", unit="degC"), 30.0)])

    buf = io.StringIO()
    w = csv.writer(buf)
    w.writerow(["name", "addr", "scale", "unit", "alarm_high"])
    w.writerow([sat.name, sat.addr, sat.scale, sat.tags["unit"], "" if sat.alarm_high is None else sat.alarm_high])
    w.writerow(["RAT", 70000, 0.1, "degC", ""])
    buf.seek(0)
    for row in csv.DictReader(buf):
        try:
            p = Point(row["name"], int(row["addr"]), float(row["scale"]), frozendict(unit=row["unit"]),
                      float(row["alarm_high"]) if row["alarm_high"] else None)
            print("匯入成功：", p.name, p.addr, p.alarm_high)
        except ValueError as e:
            print("匯入失敗：", e)

工程現場案例：點位設定在執行中被改掉，沒有人知道是誰

某閘道器把點位設定讀成普通 dict，多個模組共用同一份物件。其中一個除錯模組為了測試把倍率改成 1.0，忘了改回，其他模組也跟著讀到錯誤倍率。因為 dict 可以在任何地方被修改，事後很難追到修改點。

改成 frozen dataclass 後，任何直接修改都會立即丟出 FrozenInstanceError；需要不同設定時用 replace() 產生新物件，舊物件不受影響。CSV 匯入時在 __post_init__ 驗證位址範圍，錯誤在載入階段就被擋下，不會等到通訊時才發現。

  1. 把點位設定定義成 frozen dataclass，欄位型別與驗證寫在類別裡。
  2. 巢狀的對應資料（標籤、單位）用 frozendict，讓整個物件可雜湊。
  3. 匯入 CSV 時逐列建立物件，失敗的列收集起來一次回報，不要只回報第一個錯誤。
  4. 變更設定一律透過 replace() 或 with_changes()，並記錄新舊版本。

版本與法規更新（核對日期 2026-11-28）

  • dataclass 的 slots=True 自 Python 3.10 起提供；frozendict 與 sentinel 為 Python 3.15 新增。若要在 3.14 以前使用，tags 可改用 types.MappingProxyType（唯讀但不可雜湊）或 tuple 形式的鍵值對。 來源：Python 文件：dataclasses

練習題與自我檢查

  1. 把 tags 欄位的型別改成一般 dict，範例中哪一行會失敗？為什麼？

    看解答

    把 sat 當字典鍵的那一行會丟出 TypeError。frozen dataclass 的 __hash__ 會對所有欄位取雜湊，dict 不可雜湊。

  2. with_changes(sat, alarm_high=None) 和 with_changes(sat) 的差別是什麼？

    看解答

    前者明確把告警上限清除為 None；後者沒有傳 alarm_high，參數值是 UNSET，該欄位不被列入 changes，保持原值 30.0。

  3. CSV 中 alarm_high 欄位是空字串時，程式怎麼處理？

    看解答

    空字串轉成 None，表示沒有告警上限。不能直接 float('')，會丟出 ValueError。

  4. 為什麼位址驗證放在 __post_init__，而不是在讀 CSV 的迴圈裡？

    看解答

    放在類別裡，不論物件從 CSV、JSON 或程式碼建立，都會經過同一個驗證；放在迴圈裡，其他建立路徑就可能繞過驗證。
