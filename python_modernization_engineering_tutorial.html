Python 3.14 Features

新特性要先變成工程規則

template strings、deferred annotations、standard zstd 都有價值，但要教成可維護規則，而不是只示範語法。

Runtime Decisions

free-threaded、subinterpreters 與 GC 需要風險分級

runtime 改動會牽動 C extension、資料科學套件、web worker model 與記憶體行為，必須用獨立測試線驗證。

Upgrade Matrix

把版本升級做成 CI 與 dependency matrix

正式升級不是本機跑過一次，而是多版本、多依賴、多入口的可重複驗收。

Gate最低要求失敗時處置交付證據
Runtime matrix3.12 / 3.13 / 3.14 / 3.15-dev3.15-dev 可 allow-failure，3.14 不可CI run URL、版本列表
Static gatesruff、mypy 或既有型別工具修正 annotation / import / typing regressionlog artifact
Runtime gatespytest、coverage、integration smoke補 regression test，不降門檻coverage report
Dependency gateswheel availability、C extension import smokepin 舊版或延後 runtime 切換lock file diff
Release gatescanary、rollback、artifact metadata回退 runtime image 或 packagerelease note
Delivery Governance

把版本決策寫入 release 與 rollback

版本升級要能被審查、被回退、被追溯。每個 adoption 都要連到測試、風險與產物。
