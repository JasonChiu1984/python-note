02 / dimensions

已知管內流速：用真實內徑求截面積

D（m）＝內徑（mm）÷ 1000；A＝πD² ÷ 4；Q＝v̄ × A

適用前提：圓管滿水、已知該截面的平均軸向速度 v̄。如果只量到單點速度、量到的是外徑，或管路沒有充滿，不能直接套用。DN／NPS 是公稱值，應查同規格、壁厚和襯裡扣除後的實際內徑。若現場型錄只提供公稱尺寸，不填推估值當實測。

合成例：內徑 250 mm、截面平均流速 1.2 m/s → A＝0.049087 m² → Q＝0.058905 m³/s＝212.0575 m³/h＝3534.29 L/min。直徑進入平方項，同速下誤把內徑填大 10%，Q 會高估 21%。

m³/hL/min× 1000 ÷ 6072 → 1200

L/minm³/s÷ 60,0001200 → 0.02

m³ 是體積、m³/h 是體積流率；要算噸／小時還需液體密度（kg/m³）。不同溫度與乙二醇比例下，不能固定用 1 m³＝1 公噸。

03 / signal decision

先辨識輸出，再選公式

脈衝 K-factor

若廠商定義 K 為 pulse/L，計數窗 Δt 秒讀到 ΔN 個脈衝，則 V＝ΔN/K（L），Q＝60ΔN/(KΔt)（L/min）。K＝200 pulse/L、30 s 累增 1500 pulses → 7.5 L、15 L/min。

這是合成 K，不是任一型號的設定值。若型錄給的是 L/pulse 就用乘法；若為 pulse/m³，先輸出 m³ 再換算。核對原始感測脈衝或變送器重設的每脈衝體積、計數沿、倍率與回捲。未確認回捲或重設時，把負增量標成無效。

已線性化流量 vs. 原始差壓

若 4–20 mA 已線性代表 Q：令 f＝(I−4)/16，Q＝Qmin＋f(Qmax−Qmin)。原始差壓 ΔP 近似與 Q² 成正比；固定密度、零起點與已知差壓設計量程的教材條件，Q＝QFS√(ΔP/ΔPFS)。

若 mA 線性代表 0–100 kPa ΔP，先用 f × 100 求 ΔP，再在一處開平方根。若變送器已設平方根、或數位暫存器提供工程流量，PLC／Python 不再開根。完整工程模型還需孔板或一次元件、密度、流態、量程與廠商算法。

本範例嚴格標記 <4 mA 為 under_range、>20 mA 為 over_range，不鉗成 0 或 100%。真機的超量程、飽和和警報電流區間依型號與設定（含 NAMUR 選項）。原始負 ΔP 不用 abs()；先確認方向、取壓管、零偏、量程和變送器品質。低流量切除有自己的旗標，不等同量測到零；真機可能另有切入切出回差。

05 / totalization

從瞬時流量累積有效區間體積

梯形近似：Vi＝(Qi＋Qi+1)/2 × Δts/3600 （Q：m³/h；V：m³）

梯形法適合把兩點之間流量視為線性；若來源明定前一筆值在整段內保持不變，才改用左矩形。若資料是累積脈衝或設備已算好的總量，改用確認回捲／重設後的相鄰差值，不要把總量再次積分。

漏點未送來，和送來一筆缺值，結果不同

假設每 30 s 應有一筆，0 s 與 60 s 都是 60 m³/h，最大允許間隔為 60 s：

  • 30 s 整筆沒收到：程式只看到 0 s、60 s，間隔未超限，算出 1.000 m³；有效時間覆蓋率是 60/60＝100%，但排程只收到 2/3 筆。
  • 30 s 明確標為缺值：輸入包含 TimedFlow(30, None, "missing")，前後兩段都跳過，沒有可積分的有效體積（None，不是 0 m³）；有效時間覆蓋率是 0/60＝0%。

這裡的覆蓋率分母是第一筆到最後一筆輸入的時間，不是報表時間窗，也不是排程到齊率。若不允許跨漏點估算，先用採集週期（含容許抖動）或序號對齊排程，把缺少的時槽明確標成缺值，再積分；報表另外列出排程到齊率。

現場將時間存成帶時區的事件時間，確認來源時鐘、重新連線/重送、重複與亂序策略；本程式用同基準秒數並拒絕不遞增的樣本。允許正反向時應分開說明淨值、正向與反向總量；腳本雙向選項只給帶正負號的淨值。

06 / difference investigation

兩支表相差 40%：先定義分母，再找證據

先查什麼辨識線索要保存的證據
同一標的同時刻、同方向、同流路、同統計窗；中間無旁通、補水、分流、儲存量變化。P&ID、設備及支路點位、同步趨勢、泵閥狀態
換算設定量程 0–100 和 0–140 同接 20 mA 恰可造出 40%；也可能是 K-factor、直徑、單位、反向或差壓平方根位置。兩台表設定匯出、原始 mA／脈衝／暫存器、量程與倍率版本
實體安裝依型號核對滿管、流向、氣泡、沉積、管徑與襯裡、直管段與流態。超音波表依手冊核對聲路與耦合；電磁表核對導電度與接地。安裝照片、型號與手冊、材質壁厚、介質溫度及濃度
有參考才談誤差無可追溯基準只知道彼此差異；多工況比對並評估重複性與不確定度，不能先判定哪支表正確。校正證書、量測範圍、基準不確定度、重複性與原始記錄

相同流速與滿管模型若要單靠直徑造成 +40%，B 的設定內徑約為 A 的 √1.4＝1.1832 倍。這和量程配置都是排查用假說，不是對任何現場流量計的診斷，也不是直接更改設定的理由。

延伸學習：實作、現場案例與自我檢查

本節補上三個現場最常踩的雷：4–20 mA 斷線與飽和怎麼判斷、差壓式流量計為什麼要設小流量切除，以及 16 位元脈衝累計器溢位時怎麼算增量。

可實跑範例：mA 訊號判讀、開方切除與脈衝溢位

check_ma() 依 NAMUR NE43 把電流分成正常、超出量測範圍與故障三類；ma_to_flow_dp() 示範差壓訊號開方後零點附近被放大的現象；pulse_delta() 處理 65535 → 0 的計數器回捲。

下載範例 example.py

"""流量計訊號換算：4–20 mA（線性與差壓開方）、小流量切除、脈衝累計器溢位處理（標準函式庫）。"""
import math


def check_ma(ma):
    """NAMUR NE43：3.8–20.5 mA 為量測範圍；≤3.6 或 ≥21 mA 為故障訊號；其間為超出量測範圍。"""
    if ma <= 3.6 or ma >= 21.0:
        raise ValueError(f"{ma} mA 為故障訊號（斷線、短路或變送器自診斷告警）")
    if ma < 3.8 or ma > 20.5:
        raise ValueError(f"{ma} mA 超出量測範圍（飽和），數值不可信")


def ma_to_flow_linear(ma, span):
    check_ma(ma)
    pct = max(0.0, (ma - 4) / 16)
    return pct * span


def ma_to_flow_dp(ma, span, cutoff_pct=0.05):
    """差壓式未線性化：流量 ∝ √差壓。低於切除點直接歸零，避免零點雜訊被開方放大。"""
    check_ma(ma)
    dp_pct = max(0.0, (ma - 4) / 16)
    flow_pct = math.sqrt(dp_pct)
    return 0.0 if flow_pct < cutoff_pct else flow_pct * span


def pulse_delta(prev, curr, rollover=65_536):
    """16 位元脈衝計數器（例如 Modbus 單一暫存器）跨越 65535 → 0 時的增量。"""
    if curr >= prev:
        return curr - prev
    return curr + rollover - prev


if __name__ == "__main__":
    span = 100.0                                   # m3/h
    print(" mA    線性 m3/h   差壓開方 m3/h")
    for ma in (4.0, 4.04, 4.16, 8.0, 12.0, 20.0):
        print(f"{ma:5.2f} {ma_to_flow_linear(ma, span):9.2f} {ma_to_flow_dp(ma, span):12.2f}")
    for bad in (2.1, 20.8):
        try:
            ma_to_flow_linear(bad, span)
        except ValueError as e:
            print(f"{bad} mA：", e)

    k_factor = 10.0                                # 脈衝／m3
    readings = [65_210, 65_480, 65_530, 120, 410]  # 每 5 分鐘讀一次，第 4 筆溢位
    total = 0
    for a, b in zip(readings, readings[1:]):
        d = pulse_delta(a, b)
        total += d
        print(f"{a:>6} → {b:>6}：+{d:>4} 脈衝 = {d / k_factor:5.1f} m3")
    print(f"20 分鐘累計 {total} 脈衝 = {total / k_factor:.1f} m3，平均 {total / k_factor * 3:.1f} m3/h")

工程現場案例：夜間無流量，冰水流量卻顯示 5 m³/h

某冰水系統使用差壓式流量計，DDC 端自行開方換算。夜間泵浦停止後，變送器零點輸出 4.04 mA（只有 0.25% 的差壓），開方後變成 5% 流量，也就是 5 m³/h。以每晚停機 12 小時計，一個月累計多出約 1,800 m³ 的虛假冰水量，冷凍噸計算也跟著失真。

對照範例輸出：4.04 mA 線性換算只有 0.25 m³/h，開方後是 5.00 m³/h。解法是設定小流量切除（本例 5%），並確認開方只在一個地方做：變送器已開方就不要在 DDC 再開一次，否則 8 mA 會從 50 m³/h 變成 70.7 m³/h。

  1. 查變送器設定與銘牌，確認輸出是線性流量還是原始差壓，記錄在點位表的備註欄。
  2. DDC 或閘道器只在一處做開方，並設定小流量切除與 NAMUR 故障判斷。
  3. 脈衝累計器確認位元數（16 或 32 位元）與倍率，程式用 pulse_delta() 的方式處理回捲。
  4. 以泵浦停機時段驗證零點：流量應為 0，累計值不應增加。

練習題與自我檢查

  1. 8 mA 對應的流量，線性與差壓開方分別是多少？為什麼差這麼多？

    看解答

    線性 25 m³/h、差壓開方 50 m³/h。8 mA 代表 25% 的差壓，而流量與差壓的平方根成正比，√0.25 = 0.5，所以是 50%。

  2. 若累計器是 32 位元，pulse_delta() 的 rollover 要改成多少？

    看解答

    2³² = 4,294,967,296。32 位元計數器通常放在兩個 Modbus 暫存器，還要確認高低字組順序。

  3. 兩次讀值間隔 5 分鐘，如果其中一次讀取失敗、下一次才成功，pulse_delta() 還能算出正確的累計量嗎？

    看解答

    可以，只要間隔內計數器回捲不超過一次。累計器保存的是總數，跳過一次讀取只是把兩段增量合併。但若間隔太長、可能回捲兩次以上，就無法判斷，要縮短輪詢週期或改用 32 位元計數器。

  4. 為什麼 20.8 mA 不應該直接當成 100% 流量顯示？

    看解答

    超過 20.5 mA 代表變送器已飽和，實際流量可能遠超量程，只顯示 100% 會低估。應標示為超量程並告警，必要時重新選定量程。
