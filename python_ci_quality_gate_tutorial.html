先定義品質閘門要阻擋什麼風險

CI/CD 不是把指令塞進 YAML，而是把專案可以交付的條件寫清楚。

Local Gate

本機 gate 要和 CI 使用同一組命令

開發者在提交前執行的檢查，應盡量等同 CI 的阻擋條件。

Matrix

版本矩陣要分清 blocking 與 preview

stable runtime 應阻擋 release；beta preview 適合作為升級預警。

Coverage

Coverage 是風險訊號，不是唯一品質指標

coverage gate 要搭配 error path、contract test 與 smoke evidence。

Workflow

Workflow 要包含 trigger、matrix 與 artifact policy

PR、main、tag 與 manual dispatch 的行為要在教學中說清楚。

Release

發布決策要留下 gate evidence

release note 應能說明版本、commit、命令、結果、例外與 rollback 邊界。
