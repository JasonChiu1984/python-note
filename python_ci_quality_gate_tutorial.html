把檢查變成交付規則：從 PR 到實際部署

每一道閘門都要說清楚「何時執行、擋哪個風險、什麼算通過、留下哪份證據」。同一個成品先驗證，再往預備與正式環境推進，不要每個環境各重建一次。

下載可編輯的兩張架構與流程圖

Gate 矩陣：用風險決定關卡放在哪裡

關卡必過條件證據失敗處置
PR：快速格式／靜態檢查、單元測試、必要錯誤路徑。coverage 是補充訊號。commit、Python 版、各項退出碼與必要測試數。阻擋合併；零個測試、取消或必要步驟沒跑不算通過。
主線：完整支援版本及 OS／架構的矩陣、整合契約、遷移與復原演練。未承諾的平台另列探索，不將它混入發版條件。每格矩陣、服務版本、測試報告、初始資料版本。不貼可發版標籤；找出是程式、測試或基礎環境問題。
候選：交付裝 wheel 後在來源目錄外做 smoke；驗證成品 digest、來源及授權。依政策檢查弱點與授權條款。成品名稱、SHA-256、來源 commit、建置環境與政策結果。缺檔、換檔、雜湊不符或來源未核實時擋住，不能用 tag 名稱代替 digest。
部署：營運拉取已驗證成品；監控健康、延遲、錯誤與資料訂正狀態；明訂停止擴大的條件。部署環境、成品 digest、核准、監測時窗與回復紀錄。暫停流量切換。能回退才回退；不相容的資料遷移採 forward fix 或驗證過的還原。

直接重跑：通過、測試失敗、成品被改動

本機離線 Python 3.11+ 範例只建立合成資料，不安裝套件也不部署。先下載 Python 品質閘門實驗。

python python_ci_quality_gate_deep_lab.py --test
python python_ci_quality_gate_deep_lab.py
python python_ci_quality_gate_deep_lab.py --inject tests
python python_ci_quality_gate_deep_lab.py --inject artifact
  • subprocess.run([...], shell=False, timeout=..., check=False) 以參數陣列執行子程序；明確辨識退出碼與逾時。不要把來自輸入的字串丟進 shell。
  • unittest 用不變條件測正例、測試失敗後短路、雜湊不符與逾時；實際專案可用 python -m unittest discover -s tests，並另確認發現的測試數符合預期。
  • hashlib.file_digest(stream, "sha256") 計算檔案內容；期望值要來自受信任的清單或驗證過的來源證明。實驗用程式內固定合成原件計算，不能證明現場的成品來源。
  • json.dumps() 把結果輸出到標準輸出；錯誤說明走標準錯誤。實務報告不應包含憑證、個資或環境變數全文。
GitHub Actions 範例：矩陣快檢和證據保存

放在教材實驗所在的儲存庫根目錄時可跑；這是教學 CI，不是自動部署設定。版本矩陣應依實際支援承諾。設定儲存庫 rulesets／required checks 才會阻擋合併。required workflow 不應因不相符的 path filter 而一直無結果；若有合併佇列，加入 merge_group。

name: Quality gate
on: [pull_request, push, merge_group]
permissions:
  contents: read
jobs:
  verify:
    name: Gate (Python ${{ matrix.python }})
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        python: ["3.11", "3.12"]
    steps:
      - uses: actions/checkout@11bd71901bbe5b1630ceea73d27597364c9af683
        with:
          persist-credentials: false
      - uses: actions/setup-python@a26af69be951a213d495a4c3e4e4022e16d87065
        with:
          python-version: ${{ matrix.python }}
      - name: Run gate
        run: |
          python python_ci_quality_gate_deep_lab.py --test
          python python_ci_quality_gate_deep_lab.py > gate.json
      - uses: actions/upload-artifact@ea165f8d65b6e75b540449e92b4886f43607fa02
        if: ${{ always() }}
        with:
          name: gate-python-${{ matrix.python }}
          path: gate.json
          if-no-files-found: ignore

固定完整 Action commit SHA 並查其屬於官方儲存庫；它不是永不更新的信任設定。記錄執行環境及已解析的 Python 版；需要可重現時固定 base image digest、直譯器、依賴和 runner 的相關輸入。always() 只保留已有報告，不將失敗改為成功。

成品驗收與回退：把證據用在真正的部署決策

候選建置完成後，從受信任位置取得預期 digest，與待部署檔案比對。若建置流程已發佈 GitHub attestation，可在有存取授權的環境執行 gh attestation verify path/to/artifact --repo OWNER/REPOSITORY，再按組織政策核對簽署工作流程與來源。驗證來源證明不是程式安全保證。

允許例外時記錄唯一編號、失敗範圍、責任人、到期日、補償控制與再驗證時點。到期自動失效；不可把所有失敗改成 continue-on-error。回退須指定前一個已驗證 digest、資料相容性與停止條件。文件先要求復原演練，不假設換回舊程式就會回復資料。

官方文件：GitHub Actions 安全操作、儲存庫規則、成品來源證明、Python 子程序、Python 單元測試、SHA-256 檔案 API。

Contract

先定義品質閘門要阻擋什麼風險

CI/CD 不是把指令塞進 YAML，而是把專案可以交付的條件寫清楚。

Local Gate

本機 gate 要和 CI 使用同一組命令

開發者在提交前執行的檢查，應盡量等同 CI 的阻擋條件。

Matrix

版本矩陣依支援承諾設定

承諾支援的版本須通過發版檢查。可另設正在評估的版本做升級預警。

Coverage

Coverage 是風險訊號，不是唯一品質指標

coverage gate 要搭配 error path、contract test 與 smoke evidence。

Workflow

Workflow 要包含 trigger、matrix 與 artifact policy

PR、main、tag 與 manual dispatch 的行為要在教學中說清楚。

Release

發布決策要留下 gate evidence

release note 應能說明版本、commit、命令、結果、例外與 rollback 邊界。

from __future__ import annotations

from pathlib import Path
import sys

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT / "src"))

from ci_quality_gate import build_release_evidence, evaluate_gate  # noqa: E402


def main() -> int:
    report = evaluate_gate(ROOT, version="0.1.0", commit="local")
    evidence = build_release_evidence(report)
    evidence_path = ROOT / "ci_gate_evidence.json"
    evidence_path.write_text(evidence + "\n", encoding="utf-8")
    if report.passed:
        print("ci quality gate passed: compile + tests + coverage + matrix + workflow")
        return 0
    print(evidence)
    return 1


if __name__ == "__main__":
    raise SystemExit(main())

from __future__ import annotations

from dataclasses import dataclass, field
from pathlib import Path
import json
import os
import py_compile
import subprocess
import sys
from typing import Iterable


@dataclass(frozen=True)
class CheckResult:
    name: str
    passed: bool
    detail: str
    blocking: bool = True


@dataclass(frozen=True)
class GateReport:
    version: str
    commit: str
    results: tuple[CheckResult, ...] = field(default_factory=tuple)

    @property
    def passed(self) -> bool:
        return all(result.passed or not result.blocking for result in self.results)

    def to_dict(self) -> dict[str, object]:
        return {
            "version": self.version,
            "commit": self.commit,
            "passed": self.passed,
            "results": [
                {
                    "name": result.name,
                    "passed": result.passed,
                    "detail": result.detail,
                    "blocking": result.blocking,
                }
                for result in self.results
            ],
        }


def run_py_compile(paths: Iterable[Path]) -> CheckResult:
    checked = 0
    for path in paths:
        py_compile.compile(str(path), doraise=True)
        checked += 1
    return CheckResult("py_compile", True, f"compiled {checked} python files")


def run_unittest(project_root: Path) -> CheckResult:
    command = [sys.executable, "-m", "unittest", "discover", "-s", "tests", "-v"]
    completed = subprocess.run(
        command,
        cwd=project_root,
        env={**os.environ, "PYTHONPATH": "src"},
        text=True,
        capture_output=True,
        check=False,
    )
    if completed.returncode == 0:
        return CheckResult("unittest", True, "unittest discover passed")
    detail = (completed.stdout + completed.stderr).strip().splitlines()[-1:]
    return CheckResult("unittest", False, detail[0] if detail else "unittest failed")


def check_coverage_policy(covered_items: int, total_items: int, floor: int = 80) -> CheckResult:
    if total_items <= 0:
        return CheckResult("coverage_policy", False, "total_items must be positive")
    percent = round((covered_items / total_items) * 100)
    passed = percent >= floor
    return CheckResult("coverage_policy", passed, f"coverage model {percent}% >= {floor}%")


def check_runtime_matrix(stable: str, beta: str) -> tuple[CheckResult, CheckResult]:
    stable_ok = stable.startswith("3.14")
    beta_ok = beta.startswith("3.15")
    return (
        CheckResult("stable_runtime", stable_ok, f"stable runtime lane {stable}", blocking=True),
        CheckResult("beta_runtime", beta_ok, f"beta preview lane {beta}", blocking=False),
    )


def check_workflow_contract(path: Path) -> CheckResult:
    text = path.read_text(encoding="utf-8")
    required = ["pull_request", "push", "workflow_dispatch", "3.14", "3.15-dev", "compile", "test"]
    missing = [item for item in required if item not in text]
    if missing:
        return CheckResult("workflow_contract", False, f"missing workflow tokens: {', '.join(missing)}")
    return CheckResult("workflow_contract", True, "workflow has trigger, matrix, compile, and test")


def build_release_evidence(report: GateReport) -> str:
    return json.dumps(report.to_dict(), ensure_ascii=False, indent=2, sort_keys=True)


def evaluate_gate(project_root: Path, version: str, commit: str) -> GateReport:
    source_files = sorted((project_root / "src").glob("ci_quality_gate/*.py"))
    script_files = sorted((project_root / "scripts").glob("*.py"))
    results: list[CheckResult] = [
        run_py_compile([*source_files, *script_files]),
        run_unittest(project_root),
        check_coverage_policy(covered_items=9, total_items=10, floor=80),
        check_workflow_contract(project_root / ".github" / "workflows" / "python-ci.yml"),
    ]
    results.extend(check_runtime_matrix(stable="3.14", beta="3.15-dev"))
    return GateReport(version=version, commit=commit, results=tuple(results))

from __future__ import annotations

from dataclasses import dataclass
from typing import Callable, Iterable

from .checks import CheckResult


@dataclass(frozen=True)
class CIJob:
    name: str
    run: Callable[[], CheckResult]
    blocking: bool = True


class Pipeline:
    def __init__(self, jobs: Iterable[CIJob]) -> None:
        self._jobs = tuple(jobs)

    def run(self) -> tuple[CheckResult, ...]:
        results: list[CheckResult] = []
        for job in self._jobs:
            result = job.run()
            if result.blocking != job.blocking:
                result = CheckResult(result.name, result.passed, result.detail, job.blocking)
            results.append(result)
            if job.blocking and not result.passed:
                break
        return tuple(results)

from __future__ import annotations

from pathlib import Path
import tempfile
import unittest

from ci_quality_gate.checks import (
    CheckResult,
    GateReport,
    build_release_evidence,
    check_coverage_policy,
    check_runtime_matrix,
    check_workflow_contract,
)
from ci_quality_gate.pipeline import CIJob, Pipeline


class QualityGateTests(unittest.TestCase):
    def test_coverage_policy_blocks_low_coverage(self) -> None:
        result = check_coverage_policy(covered_items=7, total_items=10, floor=80)
        self.assertFalse(result.passed)
        self.assertTrue(result.blocking)

    def test_runtime_matrix_marks_beta_non_blocking(self) -> None:
        stable, beta = check_runtime_matrix("3.14", "3.15-dev")
        self.assertTrue(stable.passed)
        self.assertTrue(beta.passed)
        self.assertFalse(beta.blocking)

    def test_gate_report_allows_non_blocking_failure(self) -> None:
        report = GateReport(
            version="0.1.0",
            commit="abc123",
            results=(
                CheckResult("unit", True, "ok"),
                CheckResult("beta", False, "preview failed", blocking=False),
            ),
        )
        self.assertTrue(report.passed)

    def test_release_evidence_is_json(self) -> None:
        report = GateReport(version="0.1.0", commit="abc123", results=(CheckResult("unit", True, "ok"),))
        evidence = build_release_evidence(report)
        self.assertIn('"passed": true', evidence)
        self.assertIn('"commit": "abc123"', evidence)

    def test_workflow_contract_detects_required_tokens(self) -> None:
        with tempfile.TemporaryDirectory() as tmp:
            path = Path(tmp) / "python-ci.yml"
            path.write_text("pull_request\npush\nworkflow_dispatch\n3.14\n3.15-dev\ncompile\ntest\n", encoding="utf-8")
            self.assertTrue(check_workflow_contract(path).passed)

    def test_pipeline_stops_on_blocking_failure(self) -> None:
        jobs = [
            CIJob("compile", lambda: CheckResult("compile", False, "syntax error"), blocking=True),
            CIJob("test", lambda: CheckResult("test", True, "should not run"), blocking=True),
        ]
        results = Pipeline(jobs).run()
        self.assertEqual(len(results), 1)
        self.assertEqual(results[0].name, "compile")


if __name__ == "__main__":
    unittest.main()

深入解析與評估邊界

矩陣上綠不等於交付可用：Job A 建置、Job B 檢查，若 Job C 重新 build 再發布，已不是確定測過的 bytes。建置一次並用 digest 取成品，保留 policy 版本與環境；不同平台 wheel 各自建立證據，不假設所有平台有相同 digest。

允許手段要能被稽核：本例要求 unit、install、smoke 皆唯一且通過，沒有人工豁免。若實務允許例外，應有明確範圍、原因、逾期、擁有人與簽核證據；不同報告重複不能取最後綠燈來掩蓋。

digest 本身不是信任：JSON 若能由不可信人員重寫，攻擊者仍可換掉成品與所有摘要。正式應確認報告或 attestations 的簽章、可驗證身分、受信任 CI 工作流程，以及 attestation 主體是實際部署的成品。此實驗故意不對接真實憑證或上傳。

區分測試種類：此合成資料讓每項報告指向同一 digest；實務原始碼 unit test 可只對 revision，另設產物 install/smoke 對 digest，不能把只測原始碼的 unit 改名為已執行該 wheel。
