01 / METRICS

各指標要回答不同問題

指標公式及單位解讀與界線
PUE全機房耗能 ÷ IT 耗能；無量綱同時窗及相同機房範圍；納入已界定的電力損失、冷卻、輔助設施。PUE 不等於完成工作量效率、碳或總能耗。
iPUE指定非連續 12 個月期間的設施耗能 ÷ IT 耗能；無量綱短期間監控用。ISO/IEC 30134-2:2026 的正式 PUE 是連續 12 個月；一小時算例是短窗示範，不是正式年度 PUE。
pPUE子邊界總耗能 ÷ 同邊界 IT 耗能；無量綱例如單機廳、機櫃群；清楚列出不在子邊界的 UPS、共享冰機或其他設備。僅冷卻能耗 ÷ IT 不是 pPUE，也不可與全站 PUE 混列排名。
WUE所採方法範圍內的用水量 ÷ IT 用電；L/kWh 或 m³/MWh，數值等同揭露站內用水、取水／消耗定義、是否含上游能源用水，及飲用／再生來源。冷卻塔補水、排放、蒸發是不同量，不雙計。
CUE方法邊界內的營運排放 ÷ IT 用電；kgCO₂e/kWh係數與排放來源分開治理；揭露係數年份、電網區、地點／市場方法與適用直接排放。只計電力時標明不是完整 CUE 盤查，不含硬體製造。
REF / ERF可再生能源／總耗能；合格再利用能源／總耗能揭露來源、權利歸屬、自發自用、外部用熱交付及計量；可再生比例與熱回收是兩項指標，不能從 PUE 分子直接扣掉或重複算。

參考 ISO/IEC 30134-2:2026 PUE、The Green Grid pPUE §7、ISO/IEC 30134-8 CUE、ISO/IEC 30134-6 ERF 與 EU 2024/1364 Annex II–III（PUE/WUE/ERF/REF）。EU 文件用作明確可讀的計量方法參考，不代表專案適用歐盟申報。短時窗監控不可冒充年度揭露或認證。

02 / METERING

計量架構：先畫電力單線圖，再選分子分母

共享冰機與電池：混用建物以獨立分表為優先；若需分攤共享冰機、泵塔或配電，保存分攤方法、版本、熱量占比與不確定性，不以整棟電力作機房 PUE。釐清場內發電、自用、外送及 UPS 電池充放電；短窗跨越切換或能量跨期時加註，不強行修成看起來合理。

03 / WORKFLOW

同窗對齊、品質優先，才加總計算

若兩表皆為累計 kWh，取相鄰同窗的差值，負差先區別計數器重置、翻轉、反向電量與資料錯序，不能直接取絕對值。使用功率表時，分清平均 kW 或瞬時 kW；用實際秒數換成小時，對資料空洞不盲目插值。資料庫存 UTC，顯示時才轉台灣時間。

窗口不完整 ≠ 零耗電。精確揭露缺窗／覆蓋率；先保留原始資料與缺口，不補零或把缺少 IT 的時段當成無窮大。有效分母為零時報無定義。全站對齊後 PUE 小於 1 時先複核邊界、時間及 CT/PT 倍率；儲能、估配及測點混用也可能讓短窗不適合直接解讀。

04 / SYNTHETIC TREND

實際比較的是時窗總和，不是比率平均

資料全部為教學合成，不能用來推估任何真實機房。比較完整期間時，PUE = Σ 設施 kWh ÷ Σ IT kWh；等價於按各窗 IT 能源加權的比率，而不是直接平均 15 分鐘 PUE。

05 / COOLING PLANT

冰水 ΔT、RT 和 kW/RT 先分清熱功與電功

ΔT = T_return − T_supply [K]；Q̇ = ρ × V̇ × cₚ × ΔT [kW 熱]。使用 ρ [kg/m³]、V̇ [m³/s]、cₚ [kJ/(kg·K)]。例如清水、近似 ρ = 1000、cₚ = 4.186、流量 60 L/s（216 m³/h）、供回水 7/13 °C，則 ΔT = 6 K、Q̇ = 1,506.96 kW 熱。

冷噸 RT = Q̇ [kW 熱] ÷ 3.516853 ≈ 428.50 RT。若同一熱量邊界的量測耗電為 270 kW，對應效率約 0.630 kW/RT。若 270 kW 是冰機分表結果，就只能稱冰機效率；全廠要再納入該邊界的冰水泵、冷卻水泵及塔等。這是獨立算例，不是上方 PUE 資料的子表。冷噸是制冷能力，不是重量。

整段廠效率用 電 kWh ÷ 冷噸小時 (RT·h)，再換算同等 kW/RT；勿平均瞬時 kW/RT。流量與溫差量測應對同一支路、同一時刻；若混合水或乙二醇，換用相應密度與比熱。低流量／接近零 ΔT 時，量測誤差會放大；未達計量可靠範圍時將 kW/RT 標為無效而非判定變差。

趨勢先查什麼避免誤判
同冷量下 ΔT 掉、流量升感測器差、旁通混水、閥位、盤管／流量平衡及最低流量要求定負載時流量可能被迫補高、泵耗增加；但不能只靠 ΔT 下結論。
冰機 kW/RT 降、全廠升泵塔過度運轉、濕球、冰機切換或周邊設備控制冰機 KPI 不代表整廠優化；同負載與氣候才可比較。
PUE 升、IT 和總負載降固定冷卻／配電、低負載、量測邊界或 UPS 電池跨窗不要看到 PUE 升就推論總用電或總排放升。

展開教學用指標函式：先檢查窗口，再算總和
from math import fsum

def pue(valid_windows):
    """輸入已去重、同邊界、同時窗並通過品質檢查的 (facility, it) kWh。"""
    observations = list(valid_windows)
    facility = fsum(row[0] for row in observations)
    it = fsum(row[1] for row in observations)
    if it <= 0:
        raise ValueError("IT energy denominator must be positive")
    return facility / it

assert pue([(20, 10), (45, 30)]) == 65 / 40
assert pue([(20, 10), (45, 30)]) != (2.0 + 1.5) / 2

07 / ACCEPTANCE

驗收：先交付可追溯證據，再談改善目標

  1. 檢查電力單線、冷卻及水路邊界。記錄電表序號、CT/PT 倍率、方向、表位與資料品質映射。
  2. 取一段正常與一段切換時窗，對照總表、IT 分表與冷卻電表，查重複與未計量項；另用重置、缺值、零分母等測例檢查拒絕路徑。
  3. 留存時間窗、時區、覆蓋率、有效窗數、分攤方法、量綱、版號與可追溯原始值。補資料後能重算，不能悄悄覆蓋歷史。
  4. 營運比較除 PUE 同時看設施與 IT 的 kWh、冷卻 kW/RT、負載、環境及可服務的 IT 工作；冷卻策略須另驗設備廠規格、最低流量、冷卻塔濕球條件、備援和現場連鎖。
