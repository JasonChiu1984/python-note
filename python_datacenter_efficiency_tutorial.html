01 / METRICS

各指標要回答不同問題

指標公式及單位解讀與界線
PUE全機房耗能 ÷ IT 耗能；無量綱同時窗及相同機房範圍；納入已界定的電力損失、冷卻、輔助設施。PUE 不等於完成工作量效率、碳或總能耗。
iPUE指定非連續 12 個月期間的設施耗能 ÷ IT 耗能；無量綱短期間監控用。ISO/IEC 30134-2:2026 的正式 PUE 是連續 12 個月；一小時算例是短窗示範，不是正式年度 PUE。
pPUE子邊界總耗能 ÷ 同邊界 IT 耗能；無量綱例如單機廳、機櫃群；清楚列出不在子邊界的 UPS、共享冰機或其他設備。僅冷卻能耗 ÷ IT 不是 pPUE，也不可與全站 PUE 混列排名。
WUE所採方法範圍內的用水量 ÷ IT 用電；L/kWh 或 m³/MWh，數值等同揭露站內用水、取水／消耗定義、是否含上游能源用水，及飲用／再生來源。冷卻塔補水、排放、蒸發是不同量，不雙計。
CUE方法邊界內的營運排放 ÷ IT 用電；kgCO₂e/kWh係數與排放來源分開治理；揭露係數年份、電網區、地點／市場方法與適用直接排放。只計電力時標明不是完整 CUE 盤查，不含硬體製造。
REF / ERF可再生能源／總耗能；合格再利用能源／總耗能揭露來源、權利歸屬、自發自用、外部用熱交付及計量；可再生比例與熱回收是兩項指標，不能從 PUE 分子直接扣掉或重複算。

參考 ISO/IEC 30134-2:2026 PUE、The Green Grid pPUE §7、ISO/IEC 30134-8 CUE、ISO/IEC 30134-6 ERF 與 EU 2024/1364 Annex II–III（PUE/WUE/ERF/REF）。EU 文件用作明確可讀的計量方法參考，不代表專案適用歐盟申報。短時窗監控不可冒充年度揭露或認證。

05 / COOLING PLANT

冰水 ΔT、RT 和 kW/RT 先分清熱功與電功

ΔT = T_return − T_supply [K]；Q̇ = ρ × V̇ × cₚ × ΔT [kW 熱]。使用 ρ [kg/m³]、V̇ [m³/s]、cₚ [kJ/(kg·K)]。例如清水、近似 ρ = 1000、cₚ = 4.186、流量 60 L/s（216 m³/h）、供回水 7/13 °C，則 ΔT = 6 K、Q̇ = 1,506.96 kW 熱。

冷噸 RT = Q̇ [kW 熱] ÷ 3.516853 ≈ 428.50 RT。若同一熱量邊界的量測耗電為 270 kW，對應效率約 0.630 kW/RT。若 270 kW 是冰機分表結果，就只能稱冰機效率；全廠要再納入該邊界的冰水泵、冷卻水泵及塔等。這是獨立算例，不是上方 PUE 資料的子表。冷噸是制冷能力，不是重量。

整段廠效率用 電 kWh ÷ 冷噸小時 (RT·h)，再換算同等 kW/RT；勿平均瞬時 kW/RT。流量與溫差量測應對同一支路、同一時刻；若混合水或乙二醇，換用相應密度與比熱。低流量／接近零 ΔT 時，量測誤差會放大；未達計量可靠範圍時將 kW/RT 標為無效而非判定變差。

趨勢先查什麼避免誤判

冰機 kW/RT 降、全廠升泵塔過度運轉、濕球、冰機切換或周邊設備控制冰機 KPI 不代表整廠優化；同負載與氣候才可比較。

這裡以液對液 CDU（冷卻液分配單元）為例。設施水側 FWS 接收熱量，IT 技術冷卻側 TCS 把熱從液冷設備帶回；兩側經熱交換器隔離。預設 CDU 電力邊界只涵蓋該設備的輸入電表（內建泵、控制器與電源損失；再列是否含內建輔機）。上游設施泵、冰機、冷卻塔等另計。若系統為液對氣、內含冷凍循環，或泵在外側機櫃，需重新定義邊界。

最近端溫差與熱平衡：用於診斷，不能直接換算節電

  • 冷端逼近溫差。取同一時刻 TCS 冷供液 − FWS 冷進水；A 窗若 FWS 進水為 26 °C，則 30−26＝4 K。此處定義的是冷端量；若比較設備資料，先核對廠商 ATD 是否同樣取點。FWS 暖出水若為 34.8 °C，另一端是 38−34.8＝3.2 K，不能用冷端 4 K 當所有端點或當對數平均溫差。流量、入水條件、換熱器髒污及瞬態都會影響它；運轉容量須回到機型曲線、許用流量／壓降與冷卻液性質核對。
  • 雙側比對。A 窗 FWS 若為 55 m³/h、26→34.8 °C，則傳熱估計約 562.78 kW；以 TCS 為參考，e = (Q̇_FWS − Q̇_TCS) ÷ Q̇_TCS，示例 +0.83%，絕對偏差 0.83%。熱差也可能來自泵的熱量落點、環境散熱、旁通或閥位切換、儲熱、儀表偏差或對時問題，不要把熱差當成節能量。若泵在被量測的供回水段內，該讀數可能含泵注入的熱，應寫明位置與口徑。
  • 配對與不確定度。每側各自配對兩支溫度探頭，佈點避開混水或死角、檢查校正、流量計口徑及時間戳。若 A 窗兩探頭各有 0.10 K 標準不確定度且獨立、流量相對標準不確定度 2%，忽略冷卻液性質誤差時，單側合成約 √[(0.02)²＋(√2×0.10÷8)²]≈2.7%；0.83% 熱差僅憑此不能判成損失。仍需評估另一側及相關性，ΔT 很小時留白或標成低可信，不直接排名。

與既有 KPI 怎麼並列？CDU 比值只評估移熱所需的設備電力，不能當冰機 COP 或機房 PUE。一份 PUE 能量帳應按其採用的計量分類將 CDU 電量計入合適位置，不因設備接在 IT 配電後就重複加總，也不拿 CDU 熱能作 PUE 的分母。TCS 熱量僅代表液路承接的熱，不代表 IT 的所有發熱（另可能有風冷或其他散熱路徑）。

一併記錄機型、泵/備援模式、兩側流量壓差與溫度、流體性質、電表位置與覆蓋率。沒有通用節能閾值；同機型、同負載與邊界，再用有校正的趨勢比較。

指標計算怎麼解讀與驗收
LC-01 水側溫差、移熱功率、累積熱量ΔT = T回 − T供（K）；Q̇ = ρ × cp × V̇ × ΔT（kW）；Eth = Σ(Q̇i × Δti)（kWhth）。質量流率可直接用 kg/s；體積流量用 m³/s，若為 m³/h 先除 3,600。ρ 用 kg/m³；cp 用 kJ/(kg·K)。水乙二醇／丙二醇混合液依濃度和溫度取物性。逐筆配對流量與溫差後積分，不能用平均流量 × 平均溫差替代。保持正負號，逆流／逆傳熱先調查。
LC-02 液冷捕熱率、殘餘氣冷熱Rliq = EIT→液 / EIT × 100%；EIT→air ≈ EIT − EIT→液。同一批 IT、同一時間且熱蓄積可忽略時才可相減。若拿 CDU 的 TCS 熱表做代理，先排除泵熱、其他機櫃、自身散熱等跨邊界熱源，或揭露誤差。比率大於 100% 不截成 100%；差值是待查，不是負的氣冷需求。殘餘風量見 機房氣流計算。
LC-03 兩端逼近溫差、LMTD、UA逆流冷端 Ac = TCS供 − FWS供；熱端 Ah = TCS回 − FWS回；ΔTlm = (Ah − Ac) / ln(Ah/Ac)；UA ≈ Q̇HX / ΔTlm（kW/K）。兩端皆正且近穩態才用此逆流式；相等時 LMTD 等於共同溫差。兩端配對應來自實際換熱器出入口，不拿遠端混水溫度替代。比較換熱能力時鎖定兩側流量、物性及負載；逼近溫差增大不必然是污堵。
LC-04 熱量對帳與不確定度ΔE = EFWS − ETCS；相對差 = ΔE / ETCS；控制體積近穩態時 ΔE ≈ 邊界內加入液體之熱 − 對外散熱，瞬態另考慮蓄熱。正差不是「熱損率」。泵熱、未量測旁路、感測誤差與時間偏移都可能造成差異。若物性與各量測近似獨立，移熱相對標準不確定度可由流量、ρ、cp、ΔT 的相對不確定度平方和開根號估算；低 ΔT 時宜報絕對不確定度，並考慮兩支溫度計的共變異。

LC-06 CDU 電耗強度、泵電耗強度、輔機負載比ECDU / Eth（kWhe/kWhth）；1,000 × Epump / Eth（kWhe/MWhth）；ECDU / EIT。移熱分母固定 TCS 或 FWS 一側，報表註明。泵分表若已包含在 CDU 整機電表，不可再加一遍。比值越低不等於流量裕度足夠；與供液達標、最低支路流量一起看。詳見 CDU 能耗獨立算例。
LC-07 最小支路風險、流量不平衡、露點餘量取各支路 V̇實/V̇目標 的最小值；偏差 = (V̇實 − V̇目標)/V̇目標；露點餘量 = 局部最低暴露表面溫度 − 局部最高露點。支路目標依設備負載與原廠下限，不用等流量平均掩蓋不同需求。例：55/60 L/min = 91.7%；表面 19°C、露點 17°C，餘量 2 K，仍要考慮感測不確定度及失效狀態。不得把示例當全站設定值。

  • LC-09 需求流量與容量利用率：V̇需 = 3,600 × Q̇ / (ρ cp ΔT)，結果是 m³/h。以純水、300 kW、ΔT＝8 K 算，約 32.25 m³/h；應再查機櫃與 CDU 的最低流量、允許壓差和額定工況。若同一工況可用冷量為 350 kW，容量利用率為 300/350＝85.7%；不能以名牌容量直接宣告 N+1。
  • LC-10 逆流換熱器效能：C = ṁ cp（kW/K），ε = Q̇HX / [min(CTCS, CFWS) × (TCS回 − FWS供)]。例 A 用 TCS 側估 Q̇，代入 ε≈0.727，UA≈32.09 kW/K。兩側讀值有差時應標示所用側別及不確定度，不能將效能與整機 COP 混用。
  • LC-11 流量對帳：同一供水歧管，若總表 200 L/min，互不重疊的支路合計 190 L/min，待對帳 10 L/min（總表的 5%）。它不是已確認的漏液量；先查合法旁通、感測器量程、時間同步和未計量支路。

設施及全站：別把熱 kWh 跟電 kWh 混帳

指標公式與同窗示例邊界規則
LC-12 排熱量／冷卻系統耗電強度只加互不重疊的末端分路熱量；Ecooling / EIT（kWhe/kWhIT）或 Ecooling / Ehandled（kWhe/kWhth）。FWS 與 TCS 是同一熱流從兩面觀察；也不能將乾冷器、水塔或外部熱交換器移走的熱再與上游 CDU 熱量相加。分母要寫出哪個物理控制面。熱回用／儲能／環境散熱等互斥去向以一張能量帳對帳。
LC-13 冰機 COP／冷卻廠 kW/RTCOPchiller = Q̇蒸發器/P冰機；冷卻廠 kW/RT = 3.516853 × E廠用電/E蒸發器熱。合成 36 kWhe／180 kWhth → 0.703 kW/RT。只在明定分母為冰水產冷且同窗時，把冰機、納入的泵與排熱設備列進廠用電。乾冷／自然冷卻模式可按可比負載分開報；無蒸發器產冷時不可硬套此比值。
LC-14 PUE／區域 pPUE全站總能耗 ÷ IT 能耗：300/250 = 1.2000（期間示例）；區域邊界分子含區內 IT 與指定支援能耗：170/150 = 1.1333（pPUE 算例）。分子分母同窗且無重複。共享冷卻要揭露分攤方式及公用損失，不因 CDU 插在 IT PDU 就直接歸入 IT。區域指標不可冒稱全站；短期數字不冒稱年度正式 PUE。報告時核對量測類別、能源來源及適用版本。
LC-15 WUE／水塔水量帳示例站內消耗：180 L / 250 kWhIT = 0.72 L/kWhIT；水塔在水位穩定時補水 ≈ 蒸發＋排放＋飛散＋漏水。取水、實際消耗、排放或回補各自量測。不要把循環流量算作耗水，也不可用較低 PUE 推論 WUE 一定降低。若揭露含上游發電用水的口徑，另列方法及資料來源。
LC-16 CUE／電力碳強度分項用所選方法納入的營運能源排放 ÷ IT 能耗。只算外購電：300 × 0.45 ÷ 250 = 0.54 kgCO₂e/kWhIT（合成係數）。只算外購電不等於完整 CUE。區分直接燃料與外購能源，揭露地點／市場法、係數來源及所用 CO₂ 或 CO₂e；另行盤查冷媒逸散、建置與設備製造時，不能悄悄混入同一數字。
LC-17 ERF（能源再利用因子）合資格的再利用能源 Ereuse / 全站總能耗；40 kWhth 合資格外部交付／300 kWhe 全站能耗 = 13.33%（合成）。量外部實際交付且有用途的熱，不以冷卻迴路取熱或設計容量代替。揭露熱泵、加壓、管路與共用能源邊界；若交付熱含熱泵新增能量，不能把全部當成機房再利用。熱回用不直接從 PUE 分子相減。

from math import fsum

def pue(valid_windows):
    """輸入已去重、同邊界、同時窗並通過品質檢查的 (facility, it) kWh。"""
    observations = list(valid_windows)
    facility = fsum(row[0] for row in observations)
    it = fsum(row[1] for row in observations)
    if it <= 0:
        raise ValueError("IT energy denominator must be positive")
    return facility / it

可實跑範例：年度 PUE、partial PUE 與 WUE

PUE 以年度能量加總計算（總設施能量 ÷ IT 能量）；partial PUE 只看冷卻子系統；WUE 以每 kWh IT 能量的用水公升數表示。資料為合成值。

"""機房能效：PUE、partial PUE、WUE 與年度累計，並示範用瞬時值與能量值計算 PUE 的差異（標準函式庫）。"""

# 每月能量（MWh）與用水（m3）：IT、冷卻、配電損失、照明與其他
MONTHS = [
    # (IT, 冷卻, 配電損失, 其他, 用水)
    (720, 180, 43, 12, 2100), (650, 150, 39, 11, 1800), (720, 185, 43, 12, 2300),
    (700, 215, 42, 12, 2900), (730, 265, 44, 12, 3800), (710, 300, 43, 12, 4600),
    (735, 330, 44, 12, 5200), (735, 335, 44, 12, 5300), (710, 290, 43, 12, 4400),
    (725, 240, 43, 12, 3300), (705, 195, 42, 12, 2500), (725, 180, 43, 12, 2200),
]


if __name__ == "__main__":
    it = sum(m[0] for m in MONTHS)
    total = sum(sum(m[:4]) for m in MONTHS)
    cooling = sum(m[1] for m in MONTHS)
    water = sum(m[4] for m in MONTHS)
    print(f"年度 PUE = {total:,} ÷ {it:,} = {total / it:.3f}")
    print(f"冷卻 partial PUE = ({it:,} + {cooling:,}) ÷ {it:,} = {(it + cooling) / it:.3f}")
    print(f"WUE = {water:,} m3 ÷ {it:,} MWh = {water * 1000 / (it * 1000):.2f} L/kWh")
    monthly = [sum(m[:4]) / m[0] for m in MONTHS]
    print("各月 PUE：", [round(p, 2) for p in monthly])
    print(f"各月 PUE 算術平均 {sum(monthly) / 12:.4f}，年度 PUE {total / it:.4f}：此例 IT 負載穩定所以接近；IT 負載季節變化大時兩者會明顯不同，年度值應以能量加總計算")
    peak_it_kw, peak_total_kw = 1050, 1680                   # 夏季某時刻的瞬時功率
    print(f"夏季尖峰瞬時 PUE = {peak_total_kw / peak_it_kw:.2f}，不能代表年度值")

  2. 冷卻、配電、照明等子系統分別計算 partial PUE，找出改善重點。
  3. 用水量與 IT 能量同期間計算 WUE，標示是否包含冷卻水塔補水。
  4. 對外比較時確認對方使用相同的定義與量測等級。

練習題與自我檢查

  1. 若 7 月的 IT 能量從 735 降到 500 MWh（其他不變），7 月的 PUE 會變成多少？

    看解答

    (500 + 330 + 44 + 12) ÷ 500 = 1.772。IT 負載下降時冷卻與損失不會等比例下降，PUE 會變差，這是低負載機房 PUE 偏高的常見原因。

  2. 為什麼年度 PUE 不能用 12 個月 PUE 的算術平均？

    看解答

    PUE 是比值，各月的 IT 能量不同，直接平均等於給每個月相同權重。正確做法是先加總能量再相除，相當於以 IT 能量為權重的平均。

  3. WUE 的計算中，m³ 換成公升、MWh 換成 kWh，為什麼程式裡兩個 1000 會互相抵消？

    看解答

    1 m³ = 1,000 L，1 MWh = 1,000 kWh，分子分母都乘以 1,000，比值不變。程式寫出兩個 1000 是為了讓單位換算清楚可見。

  4. partial PUE 1.335 代表什麼？

    看解答

    冷卻用電約為 IT 用電的 33.5%。若改善冷卻讓 partial PUE 降到 1.25，以年度 IT 能量 8,565 MWh 計，約可省下 (0.335 − 0.25) × 8,565 ≈ 728 MWh。
