Overview

先定命令契約，再談自動化

如果參數、輸出與錯誤碼不穩，CLI 只是另一種不可維護腳本。

先約定操作者能信任什麼

CLI 不只是把腳本包一層參數。每個命令必須說清楚讀取哪些輸入、何時修改檔案、哪些情況可重跑，以及如何用退出碼與報表做交接。

本頁以「清單 → 預檢 → 建立結果檔 → 查驗」為例。預演不寫檔，實作需明確授權；正式環境還需另外設計並行工作鎖、回滾、通知與持久化證據。

Architecture

plan、apply、report 要明確分層

預檢、實作與證據輸出分離，才不會把風險與結果混在一起。

架構圖：入口、規則、操作與證據分層

  1. 01　命令入口argparse 解析命令和選項，將結果交給命令處理器。
  2. 02　驗證與規則檢查清單欄位、內容長度和預期輸出，不寫入檔案。
  3. 03　執行介面只有明確要求時才建立結果；以獨占方式拒絕覆蓋。
  4. 04　證據介面透過 JSON 與退出碼交接，獨立比對現有結果。

依賴方向：操作者／CI → 命令入口 → 應用規則 → 檔案介面。stdout 只輸出機器可讀 JSON；執行環境之外的告警與通知由呼叫端決定。

import argparse
import json
import sys
from pathlib import Path

def load_manifest(path):
    # 至多讀 4 KiB，避免直接解析不受限的大檔。
    with path.open("rb") as stream:
        raw = stream.read(4097)
    if len(raw) > 4096:
        raise ValueError("manifest 不可超過 4 KiB")
    data = json.loads(raw.decode("utf-8"))
    if not isinstance(data, dict) or set(data) != {"message"}:
        raise ValueError("manifest 必須只包含 message")
    message = data["message"]
    if not isinstance(message, str) or not message.strip() or len(message) > 200:
        raise ValueError("message 必須為 1–200 字元的非空白文字")
    return message + "\n"

def emit(command, status, code, **details):
    print(json.dumps(
        {"command": command, "status": status, "exit_code": code, **details},
        ensure_ascii=False,
    ))
    return code

def main():
    parser = argparse.ArgumentParser(description="可預演的 CLI 教學範例")
    commands = parser.add_subparsers(dest="command", required=True)
    for command in ("plan", "apply", "report"):
        sub = commands.add_parser(command)
        sub.add_argument("manifest", type=Path)
        sub.add_argument("output", type=Path)
        if command == "apply":
            sub.add_argument("--execute", action="store_true")
    args = parser.parse_args()
    try:
        expected = load_manifest(args.manifest).encode("utf-8")
    except (OSError, ValueError) as exc:
        return emit(args.command, "validation_error", 3, error=str(exc))

    try:
        if args.command == "plan":
            return emit("plan", "planned", 0, target=str(args.output))
        if args.command == "apply":
            if not args.execute:
                return emit("apply", "dry_run", 0, target=str(args.output))
            # xb 保證不覆蓋現有同名檔；非交易式提交。
            with args.output.open("xb") as stream:
                stream.write(expected)
            return emit("apply", "written", 0, target=str(args.output))

        with args.output.open("rb") as stream:
            matches = stream.read(len(expected) + 1) == expected
        return emit("report", "verified" if matches else "mismatch",
                    0 if matches else 2, target=str(args.output))
    except OSError as exc:
        return emit(args.command, "operation_error", 2, error=str(exc))

if __name__ == "__main__":
    sys.exit(main())
  1. load_manifest() 驗證清單，拒絕不符合格式或大小的輸入。
  2. plan 與未帶 --execute 的 apply 不寫檔。
  3. apply --execute 以 xb 拒絕覆蓋。寫入途中失敗可能留有部份結果；正式工具需選用交易式或原子發佈策略。
  4. report 比對位元組，不執行修復。退出碼 2 表示操作失敗或不符；在參數解析階段，argparse 本身也使用 2。

from __future__ import annotations

import json
import tempfile
from pathlib import Path

from cli_automation_engineering.cli import run


def main() -> None:
    with tempfile.TemporaryDirectory() as tmp_dir:
        root = Path(tmp_dir)
        manifest = root / "manifest.json"
        dry_run_report = root / "dry-run-report.json"
        apply_report = root / "apply-report.json"
        manifest.write_text(
            json.dumps(
                {
                    "items": [
                        {"id": "job-1", "action": "sync", "target": "gateway-a", "owner": "ops"},
                        {"id": "job-2", "action": "sync", "target": "gateway-b", "owner": "ops", "enabled": False},
                        {"id": "job-3", "action": "sync", "target": "gateway-c", "owner": "ops"},
                    ]
                },
                ensure_ascii=False,
                indent=2,
            ),
            encoding="utf-8",
        )

        dry_run_code = run(["apply", "--manifest", str(manifest), "--output", str(dry_run_report), "--dry-run"])
        if dry_run_code != 2:
            raise SystemExit(f"unexpected dry-run exit code: {dry_run_code}")

        apply_code = run(["apply", "--manifest", str(manifest), "--output", str(apply_report)])
        if apply_code != 2:
            raise SystemExit(f"unexpected apply exit code: {apply_code}")

        payload = json.loads(apply_report.read_text(encoding="utf-8"))
        if payload["executed"] != 2 or payload["blocked"] != 1:
            raise SystemExit("unexpected apply report counts")

    print("cli automation smoke passed: plan/apply/report + dry-run + exit-code + evidence")


if __name__ == "__main__":
    main()

from __future__ import annotations

import argparse
import json
from pathlib import Path
from typing import Sequence

from .engine import (
    EXIT_PARTIAL,
    EXIT_SUCCESS,
    EXIT_VALIDATION,
    apply_manifest,
    build_summary_line,
    load_manifest,
    plan_manifest,
    write_report,
)


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(description="CLI automation engineering sample")
    subparsers = parser.add_subparsers(dest="command", required=True)

    plan = subparsers.add_parser("plan", help="validate manifest and preview changes")
    plan.add_argument("--manifest", required=True)
    plan.add_argument("--output", required=True)

    apply_cmd = subparsers.add_parser("apply", help="execute manifest")
    apply_cmd.add_argument("--manifest", required=True)
    apply_cmd.add_argument("--output", required=True)
    apply_cmd.add_argument("--dry-run", action="store_true")

    report = subparsers.add_parser("report", help="print existing report summary")
    report.add_argument("--input", required=True)

    return parser


def run(argv: Sequence[str] | None = None) -> int:
    parser = build_parser()
    args = parser.parse_args(argv)
    try:
        if args.command == "report":
            payload = json.loads(Path(args.input).read_text(encoding="utf-8"))
            print(
                "mode={mode} dry_run={dry_run} validated={validated} blocked={blocked} executed={executed} status={status}".format(
                    **payload
                )
            )
            return EXIT_SUCCESS

        items = load_manifest(Path(args.manifest))
        if args.command == "plan":
            report = plan_manifest(items)
        else:
            report = apply_manifest(items, dry_run=bool(getattr(args, "dry_run", False)))
        write_report(report, Path(args.output))
        print(build_summary_line(report))
        return EXIT_SUCCESS if report.status == "success" else EXIT_PARTIAL
    except ValueError as exc:
        print(f"validation_error: {exc}")
        return EXIT_VALIDATION


if __name__ == "__main__":
    raise SystemExit(run())

from __future__ import annotations

import json
from dataclasses import asdict, dataclass
from pathlib import Path


EXIT_SUCCESS = 0
EXIT_PARTIAL = 2
EXIT_VALIDATION = 3
REQUIRED_FIELDS = ("id", "action", "target", "owner")


@dataclass
class ManifestItem:
    id: str
    action: str
    target: str
    owner: str
    enabled: bool = True


@dataclass
class ExecutionReport:
    mode: str
    dry_run: bool
    validated: int
    blocked: int
    executed: int
    status: str
    items: list[dict[str, object]]


def load_manifest(path: Path) -> list[ManifestItem]:
    payload = json.loads(path.read_text(encoding="utf-8"))
    items = payload.get("items")
    if not isinstance(items, list):
        raise ValueError("manifest items must be a list")
    manifest: list[ManifestItem] = []
    for raw in items:
        if not isinstance(raw, dict):
            raise ValueError("manifest item must be an object")
        missing = [field for field in REQUIRED_FIELDS if not raw.get(field)]
        if missing:
            raise ValueError(f"manifest item missing fields: {', '.join(missing)}")
        manifest.append(
            ManifestItem(
                id=str(raw["id"]),
                action=str(raw["action"]),
                target=str(raw["target"]),
                owner=str(raw["owner"]),
                enabled=bool(raw.get("enabled", True)),
            )
        )
    return manifest


def plan_manifest(items: list[ManifestItem]) -> ExecutionReport:
    report_items = []
    validated = 0
    blocked = 0
    for item in items:
        entry = asdict(item)
        if item.enabled:
            entry["decision"] = "ready"
            validated += 1
        else:
            entry["decision"] = "blocked"
            blocked += 1
        report_items.append(entry)
    status = "success" if blocked == 0 else "partial"
    return ExecutionReport("plan", True, validated, blocked, 0, status, report_items)


def apply_manifest(items: list[ManifestItem], dry_run: bool) -> ExecutionReport:
    report_items = []
    validated = 0
    blocked = 0
    executed = 0
    for item in items:
        entry = asdict(item)
        if not item.enabled:
            entry["result"] = "blocked"
            blocked += 1
        elif dry_run:
            entry["result"] = "dry-run"
            validated += 1
        else:
            entry["result"] = "executed"
            validated += 1
            executed += 1
        report_items.append(entry)
    status = "success" if blocked == 0 else "partial"
    return ExecutionReport("apply", dry_run, validated, blocked, executed, status, report_items)


def write_report(report: ExecutionReport, output_path: Path) -> Path:
    output_path.parent.mkdir(parents=True, exist_ok=True)
    output_path.write_text(json.dumps(asdict(report), ensure_ascii=False, indent=2), encoding="utf-8")
    return output_path


def build_summary_line(report: ExecutionReport) -> str:
    return (
        f"mode={report.mode} dry_run={str(report.dry_run).lower()} "
        f"validated={report.validated} blocked={report.blocked} executed={report.executed} status={report.status}"
    )

from __future__ import annotations

import json
import tempfile
import unittest
from pathlib import Path

from cli_automation_engineering.cli import run
from cli_automation_engineering.engine import EXIT_PARTIAL, EXIT_SUCCESS, EXIT_VALIDATION


class CliAutomationEngineeringTest(unittest.TestCase):
    def setUp(self) -> None:
        self.temp_dir = tempfile.TemporaryDirectory()
        self.root = Path(self.temp_dir.name)
        self.manifest = self.root / "manifest.json"
        self.report = self.root / "report.json"

    def tearDown(self) -> None:
        self.temp_dir.cleanup()

    def write_manifest(self, items: list[dict[str, object]]) -> None:
        self.manifest.write_text(json.dumps({"items": items}, ensure_ascii=False, indent=2), encoding="utf-8")

    def test_plan_returns_partial_when_disabled_item_exists(self) -> None:
        self.write_manifest(
            [
                {"id": "job-1", "action": "sync", "target": "gateway-a", "owner": "ops"},
                {"id": "job-2", "action": "sync", "target": "gateway-b", "owner": "ops", "enabled": False},
            ]
        )
        code = run(["plan", "--manifest", str(self.manifest), "--output", str(self.report)])
        self.assertEqual(code, EXIT_PARTIAL)
        payload = json.loads(self.report.read_text(encoding="utf-8"))
        self.assertEqual(payload["validated"], 1)
        self.assertEqual(payload["blocked"], 1)

    def test_apply_dry_run_does_not_execute_items(self) -> None:
        self.write_manifest([{"id": "job-1", "action": "deploy", "target": "edge-1", "owner": "release"}])
        code = run(["apply", "--manifest", str(self.manifest), "--output", str(self.report), "--dry-run"])
        self.assertEqual(code, EXIT_SUCCESS)
        payload = json.loads(self.report.read_text(encoding="utf-8"))
        self.assertTrue(payload["dry_run"])
        self.assertEqual(payload["executed"], 0)
        self.assertEqual(payload["items"][0]["result"], "dry-run")

    def test_invalid_manifest_returns_validation_exit_code(self) -> None:
        self.write_manifest([{"id": "job-1", "action": "deploy", "target": "edge-1"}])
        code = run(["plan", "--manifest", str(self.manifest), "--output", str(self.report)])
        self.assertEqual(code, EXIT_VALIDATION)
        self.assertFalse(self.report.exists())

    def test_report_command_reads_existing_report(self) -> None:
        self.report.write_text(
            json.dumps(
                {
                    "mode": "apply",
                    "dry_run": False,
                    "validated": 2,
                    "blocked": 0,
                    "executed": 2,
                    "status": "success",
                },
                ensure_ascii=False,
            ),
            encoding="utf-8",
        )
        code = run(["report", "--input", str(self.report)])
        self.assertEqual(code, EXIT_SUCCESS)


if __name__ == "__main__":
    unittest.main()
Verification

同時驗 CLI 行為、輸出格式與成功訊號

不只要命令可執行，還要能穩定被測試、被 release note 引用。

驗收表：不要只測成功路徑

  1. 合法清單的 plan 回傳 planned，預演回傳 dry_run，兩者退出碼均為 0，且結果檔不存在。
  2. 首次正式寫入回傳 written；原樣驗證為 verified；重複正式寫入須回傳 2 且不改原檔。
  3. 將清單改成 {}，預期退出碼 3；故意改結果檔，預期 mismatch 與退出碼 2。
  4. 在 CI 應分別檢查退出碼、stdout JSON、結果檔是否存在，以及失敗時是否維持原檔。

Best Practices

只要命令會進排程、進 CI、交給其他工程師或現場人員，就應有正式工程品質。

回教材入口回頁首

CLI 交付研究｜預設不寫、同目錄切換與失敗證據

CLI 先在記憶體完成驗證，再組出可重跑成品。預設預覽不寫入，只有明確給 --apply 及 --output 才允許在本機現有目錄替換檔案。實驗採單一寫入者與合成資料；正式多進程搶寫應由交易或鎖實作，不靠 os.replace() 充作併發控制。

概念／步驟驗收與限制
退出碼 0預覽完成或套用成功；用 written 欄位區分。
退出碼 1／2I/O 失敗是 1；argparse 參數錯誤是 2。stderr 診斷不混入 JSON。
斷電與競爭原子更換防半成品可見，不等於完全耐斷電；需要時另驗證檔案系統與目錄同步。

核心程式與復算

下方摘錄與可下載檔案同步。完整檔自帶合成資料，不連接裝置或外部服務。

def publish_snapshot(path: Path, artifact: bytes) -> None:
    """Same-directory replace; one writer, existing authorized output directory."""
    temporary = None
    try:
        with NamedTemporaryFile(dir=path.parent, prefix=".snapshot-", delete=False) as handle:
            temporary = Path(handle.name)
            handle.write(artifact)
            handle.flush()
            os.fsync(handle.fileno())
        os.replace(temporary, path)
    finally:
        if temporary is not None:
            temporary.unlink(missing_ok=True)

Internal Design

從 argv 到可驗收的退出結果

用一個標準庫案例看清命令列介面、規則、寫入與證據四層，而不是把所有工作塞進 main()。

架構圖｜把可變動的介面和副作用留在外層

  1. 命令入口argv → argparse → 子命令
  2. 設定與驗證合併來源，驗型別與範圍
  3. 應用層plan / apply / report 分流
  4. 輸出轉接層JSON、檔案、stderr 和退出碼

解析器只負責命令形狀，設定層負責業務範圍，寫入函式不應直接讀取環境變數。這使測試可以用固定設定餵給規則，用測試資料夾取代正式寫入路徑。

流程圖｜寫入路徑與錯誤分支

  1. 解析並驗證無效輸入 → stderr，退出 2
  2. 決定模式plan / dry-run：不寫檔
  3. 執行或讀回apply：同目錄暫存後換檔；report：唯讀
  4. 結束成功只輸出一筆 JSON；I/O 錯誤退出 3

下載兩張可編輯 Draw.io 圖

比較圖表｜同一份設定，不同命令的責任

plan
不寫檔。驗證輸入並在 stdout 顯示預期設定與來源。
apply --dry-run
不寫檔。走同一設定驗證分支，標示 dry-run；不保證路徑可寫。
apply
在既有、可信目錄寫一份報告；已存在的報告會以新版本取代。不是跨多個檔案的交易。
report
唯讀。檢查 schema 與欄位，僅顯示白名單內容。

設定優先順序與退出碼

內建預設 → JSON 檔 → CLI_DEMO_* 環境變數 → 命令列。每個欄位獨立決定來源。本例的 argparse 不給 --limit 預設，讓未傳值保留為 None；環境值先轉型，最終限制為 1–500。CI 請檢查退出碼，不要匹配翻譯過的錯誤文案。

  • 0：成功；stdout 為一筆 JSON。--help 是例外，印用法後退出 0。
  • 2：語法或資料輸入錯誤，診斷送 stderr，沒有成功 JSON。
  • 3：作業系統 I/O 錯誤，只回報錯誤類別，不將含有路徑或憑證的例外原文直接送進紀錄。

可下載實作｜預檢、寫入、查詢、拒絕

下載 標準庫範例程式，在新建的練習目錄中和 settings.json 放在一起執行。以下為 Bash／zsh 範例。

printf '%s\n' '{"site":"lab01","limit":20}' > settings.json
CLI_DEMO_LIMIT=30 python3 python_cli_engineering_deep_dive_lab.py plan --config settings.json --limit 40
python3 python_cli_engineering_deep_dive_lab.py apply --config settings.json --out report.json --dry-run
test ! -e report.json  # 只在全新練習目錄預期通過
python3 python_cli_engineering_deep_dive_lab.py apply --config settings.json --out report.json
python3 python_cli_engineering_deep_dive_lab.py report report.json
python3 python_cli_engineering_deep_dive_lab.py plan --limit 0
echo $?  # 2

第一個 plan 的 site 來自檔案，limit 是 40、由 CLI 勝出。把 --out 指向不存在的目錄，真寫入會退出 3；dry-run 不建立目錄，也不聲稱已測得寫入權限。

關鍵程式與失敗驗收

temp.flush()
os.fsync(temp.fileno())
# 先關閉暫存檔，再於同一目錄／檔案系統替換
os.replace(staging, target)

這個順序防止讀到只寫一半的 JSON；但不等於斷電持久性保證，也不提供鎖定或多寫入者序列化。需要斷電耐受時要按部署平台與檔案系統評估目錄同步、備份及恢復測試。寫入只用可信目錄，不把這個案例當作對不可信共享路徑的安全邊界。

可重複驗收：用 subprocess.run([...], capture_output=True, text=True) 驗退出碼、stdout 是否可由 json.loads 解析、stderr 是否為空，以及失敗時舊報告是否保持原樣。不要將敏感值放在 CLI 參數，參數可能被 shell 歷史或程序清單記錄；正式程式請另外設計秘密注入與去識別紀錄。
