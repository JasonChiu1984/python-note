## 7. Troubleshooting

| 狀況 | 補強方向 |
|---|---|
| benchmark 浮動太大 | 增加資料量、重複測量、使用 median |
| 優化後結果錯誤 | 先用同一 dataset 比對 slow/optimized output |
| profile 太雜 | 固定 workload 並只保留 top N cumulative time |
| memory peak 不穩定 | 固定測量區間，記錄 before/after snapshot |
| CI performance gate 偶發失敗 | threshold 不要貼近本機數值，CI 只擋明顯回退 |

## 8. Best Practices

- 沒有 baseline 不做效能結論。
- 沒有正確性 regression test 不做效能優化。
- CPU hotspot、allocation hotspot、I/O latency 要分開測。
- 效能報告要能被 release note 與 rollback decision 引用。
- 工業資料閘道要把輪詢間隔、timeout、批次大小、memory peak 與 fail-safe 一起驗收。
