## 4. Configuration

首頁需固定補強以下一致性檢查：

| 項目 | 建議內容 |
|---|---|
| 路由存在性 | 首頁每個 `href` 都要對應實際檔案 |
| 計數一致性 | 路線總數需與卡片與實際教材數一致 |
| SVG 一致性 | 視覺地圖節點不得保留已下架專題 |
| progress key | 不保留無實體教材的完成度 key |
| 版本敘述 | 首頁版本摘要需反映本輪實際修正 |

## 7. Troubleshooting

| 狀況 | 補強方向 |
|---|---|
| 首頁仍能搜到舊路徑 | 重新檢查卡片、SVG、腳本與版本摘要 |
| 版本升級但使用者仍點到失效頁 | 視為入口修正未完成 |
| 首頁腳本報錯 | 檢查已刪除的 progress target 與 key 是否還殘留 |

## 8. Best Practices

- 下架專題時，入口、圖示、腳本、版本敘述要一次同步。
- 教學 repo 的首頁應視為 release artifact 的一部分。
- 先修交付一致性，再決定是否補新主題。
