## 5. Troubleshooting

| 狀況 | 補強方向 |
|---|---|
| MCP 搜尋結果含示範條目 | 清理 `index.json` 與對應 demo 檔 |
| 教學資料與驗證資料混放 | 將示範匯出視為暫存或教學附件，不納入正式發布 |
| 維護版內容少但仍需發布 | 用 patch version 記錄品質修正，不硬加新主題 |

## 6. Best Practices

- 正式知識庫應像正式資料表，只留可持續使用的內容。
- 教學型範例資料應可重建，不應成為 release payload 的一部分。
- 維護版發行仍需保留 dated 審查、修正清單與更新紀錄。
