## 4. 教材內容範圍

- Runtime architecture、container boundary、process model
- Dockerfile：base image、layer order、non-root user、workdir、copy boundary、healthcheck
- `.dockerignore`：排除 cache、venv、dist、secrets、coverage
- Compose：service、network、ports、environment、restart、resource hints、dependency
- Env config：required variable、default、secret boundary、validation error
- Health/readiness：`/healthz`、`/readyz`、dependency degraded、startup gate
- Signal handling：SIGTERM、grace period、shutdown timeout
- Logging：stdout JSON log、request id、redaction、container log rotation
- Deployment gate：image tag、digest、smoke、rollback、release evidence
- Edge/site deployment：offline mode、site config、maintenance handover
