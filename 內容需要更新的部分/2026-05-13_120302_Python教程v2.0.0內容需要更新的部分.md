## 3. 必須補強的測試主題

| 主題 | 需補內容 |
|---|---|
| Strategy | testing pyramid、risk-based tests、definition of done |
| Fixtures | deterministic data、factory、clock injection、tmp path |
| Unit | business rule、error path、idempotency、boundary |
| Integration | repository boundary、file/database I/O、contract sample |
| Quality | coverage thinking、mutation thinking、flaky test triage |
| CI Gate | compile、test command、exit code、release smoke |
| Sample | 可執行 order service、fake repository、unittest、gate script |

## 4. 驗收條件

- 入口頁顯示十條路線，且包含「測試工程」卡片。
- 測試教材頁顯示 `v2.0.0` 與 30 張互動卡。
- `python-testing-completed` 進度在入口頁可顯示。
- `範例程式碼/testing_quality_gate/scripts/run_quality_gate.py` 可執行。
- `python3 -m py_compile` 通過新範例所有 Python 檔案。
- `PYTHONPATH=範例程式碼/testing_quality_gate/src python3 -m unittest discover -s 範例程式碼/testing_quality_gate/tests -v` 通過。

## 5. 風險備註

- 本輪用標準庫建立最低可驗證 baseline；pytest、coverage、ruff、mypy 可作為後續版本深化，不應阻擋本輪交付。
- 測試工程路線應聚焦可維護的品質迴路，不應變成單純測試語法速查表。
