## 7. Troubleshooting

| 狀況 | 補強方向 |
|---|---|
| 分不清四協定分工 | 補角色分工圖 |
| BACnet 被誤當成純 register 協定 | 補 object/routing/BBMD 說明 |
| OPC UA 被誤當成普通 polling API | 補 subscription/NodeId 心智 |
| MQTT 看起來像只是換個 port | 補 topic/payload/QoS/retain 治理說明 |

## 8. Best Practices

- 比較協定時，先看責任邊界，不先看 library。
- 沒有比較表，就很難把 register、NodeId、object、topic 放在同一張工程地圖裡。
- 工業教材若只講單一協定，不講橫向對照，使用者會缺少選型與整合心智。
- Python 在這類題目最有價值的是跨協定資料對齊，而不是只示範某一個 client 能連上。
