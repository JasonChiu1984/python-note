## 7. Troubleshooting

| 狀況 | 補強方向 |
|---|---|
| 非法狀態被直接寫入 | 補 transition table 與 guard |
| 流程逾時後無人接手 | 補 expiry / manual review 路徑 |
| 執行失敗但無法還原 | 補 compensation / rollback |
| 更新紀錄無法交代流程脈絡 | 補 audit trail / operator note |

## 8. Best Practices

- 工作流規則要集中，不要分散在多個 service 的條件判斷。
- compensation 與 timeout 是正式流程，不是例外補丁。
- audit trail 要可重播，不要只留最後狀態。
- 工作流更新紀錄要能讓下一位工程師直接接手。
