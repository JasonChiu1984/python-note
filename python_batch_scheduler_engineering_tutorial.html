Operational Design · Schedule to Evidence

可重跑、可交接：定義時間、寫入與復原邊界

以每天彙總感測資料為例：排程器只提出「哪一段資料要處理」，worker 決定如何處理，run ledger 用來查「結果是否已提交」。補跑重用原邏輯區間，不靠系統目前日期，也不假設排程只觸發一次。

下載可編輯的架構圖與流程圖

時間與鍵：同一天不一定是 24 小時

  • 邏輯日 ≠ 實際開跑時間：2025-03-09 的報表可以次日或多日後補跑，仍以該日的輸入界線為準。以 [start, end) 查詢避免相鄰批次重複讀取；儲存 UTC 界線，另保留 IANA 時區、原邏輯日與時區資料版本／來源。
  • 夏令時間：New York 行政日 2025-03-09 為 23 小時，2025-11-02 為 25 小時。按下一個本地邊界計算，不能將 UTC 起點一律加 24 小時。重複的本地時間要明訂 fold，不存在的時間則需明訂拒絕、跳過或調整政策；本例以 UTC 終點必須晚於起點作為入帳前檢查，不是所有 IANA 轉換規則的通用驗證器。
  • 曆日被跳過：Pacific/Apia 的 2011-12-30 在時區調整時被跳過；該日兩個午夜界線依此範例都轉成 2011-12-30T10:00:00Z，區間長度為 0。這不是「當天沒有資料」，而是該行政日不存在。範例在寫入執行紀錄或任何彙總前拒絕該區間，CLI 回傳 2。參考 IANA tzdb：Pacific/Apia、PEP 495：不存在的本地時間。
  • 鍵區分三層：用 job、租戶、固定 UTC 區間和處理修訂識別同一次邏輯處理；每次重試另有 attempt ID。重試不得改 run key；更正資料而需產生新版本時，先明確定義覆蓋或另外保存結果及核准規則。

情境工程規則交接證據
重複觸發唯一 run key；已成功勿重寫。不同分片須明定唯一鍵或事務邊界。區間、revision、attempt ID、已提交筆數與去重原因。
可重試失敗分辨暫時性與永久性；設總時限、有限次數、退避與 jitter。錯誤欄位或缺輸入資料先人工修正，不無限重試。錯誤分類、剩餘重試數、下一次時間、告警與負責人。
worker 消失跨程序 lease 到期可重新領取；只靠 TTL 不足，舊 worker 可能恢復。提交時校驗遞增 fencing token，或由目標系統拒絕舊令牌。持有者、到期、觸發接管時間、最新令牌。此實驗只示範短 SQLite 交易，未實作分散式 lease。
提交結果未知先以同一鍵查 ledger 或下游；本庫結果與完成標記可同交易。跨服務可使用 outbox 加接收端去重；若下游不能查收，不能宣稱 exactly-once。提交確認、下游冪等鍵、傳輸紀錄與對帳結果。
批次補跑用 dry run 列出 UTC 視窗和預估量，做分段與併發限額，避開線上尖峰。只在已知輸出與 checkpoint 的一致性下續跑。區間列表、版本／輸入快照、上限、核准、停止條件。

實際用法：同一區間先失敗、再提交、後去重

下載 Python 離線實驗，僅使用標準庫與記憶體 SQLite。實際執行需要 Python 3.11+；DST 步驟須有 IANA 時區資料。

python python_batch_scheduler_deep_lab.py --test
python python_batch_scheduler_deep_lab.py --date 2025-03-09 --zone UTC
python python_batch_scheduler_deep_lab.py --date 2025-03-09 --zone America/New_York

標準輸出 JSON 應依序出現 retryable → committed → duplicate_skipped，且只存入一列結果。此命令刻意注入預期故障並恢復，所以成功完成整組實驗回傳 0；正式 runner 應對不可恢復錯誤回傳非 0，並用結構化欄位區分重試、故障與正常去重。

反例：以下命令應在標準錯誤輸出「未形成正長度的行政日區間」，不會輸出彙總 JSON。

python python_batch_scheduler_deep_lab.py --date 2011-12-30 --zone Pacific/Apia
  • date.fromisoformat() 解析邏輯日；ZoneInfo() 按 IANA 名稱載入時區，astimezone() 轉換 UTC。
  • sqlite3.connect(..., isolation_level=None) 搭配明確 BEGIN IMMEDIATE，commit()／rollback() 決定同庫原子性；contextlib.closing() 保證關閉連線，交易回滾和資源關閉不是同一件事。
  • execute(sql, (run_key,)) 使用參數綁定，避免將資料插進 SQL 字串；json.dumps() 輸出可自動查核的報告。
交接手冊：現場第一輪如何處理
  1. 比對預計與實際區間，排除「正常延遲、沒有應到資料」與錯時區。
  2. 用 run key 找最後一次狀態與下游收件證明；若不確定是否已提交，不先重送。
  3. 確認影響範圍與輸入快照，開啟限量補跑；觀察 backlog、處理延遲、成功率和對帳差異。
  4. 確認業務結果再結案。手冊需寫明平日與假日值班、連線憑證轉移、告警目的地與停機條件。
排程器選型：比較約束，不比較品牌吞吐量
  • cron／systemd timer：適合單機、少量獨立工作；工作狀態、補跑及跨主機鎖要自己做。
  • Kubernetes CronJob：適合容器化工作；.spec.timeZone 與 concurrencyPolicy 是排程政策，不等同跨工作去重。短期可能漏建或重建 Job，工作本身仍須冪等。
  • Airflow 類工作流：有依賴圖、data interval、補跑及任務歷史；仍要控制外部副作用、權限、依賴資料與工作版本。

from __future__ import annotations

import json

from batch_scheduler_engineering.runner import BatchJobRunner, JobConfig, SchedulerExecutionError


def main() -> None:
    runner = BatchJobRunner()
    job = JobConfig(
        name="nightly-reconciliation",
        owner="team-ops",
        schedule="0 2 * * *",
        checkpoint_key="reconcile:last-item",
        max_attempts=3,
    )
    failures: dict[int, int] = {2: 1, 5: 3}

    def handler(item: int) -> None:
        remaining = failures.get(item, 0)
        if remaining:
            failures[item] = remaining - 1
            raise SchedulerExecutionError(f"transient failure on item {item}")

    first = runner.run_job(job, [0, 1, 2, 3], "worker-a", handler)
    second = runner.run_job(job, [0, 1, 2, 3, 4, 5], "worker-a", handler)
    backfill = runner.run_job(job, [1, 2, 3], "worker-b", lambda item: None, backfill_from=1)
    print(json.dumps({"first": first, "second": second, "backfill": backfill}, ensure_ascii=False, indent=2))
    if second["dead_letter_count"] != 1 or backfill["backfill_mode"] is not True:
        raise SystemExit("batch scheduler smoke failed")
    print("batch scheduler smoke passed: lease + checkpoint + retry + dead-letter + backfill")


if __name__ == "__main__":
    main()

from __future__ import annotations

from dataclasses import asdict, dataclass


class SchedulerExecutionError(RuntimeError):
    """Raised when a single batch item fails."""


class LeaseConflictError(RuntimeError):
    """Raised when another worker already owns the job lease."""


@dataclass(frozen=True)
class JobConfig:
    name: str
    owner: str
    schedule: str
    checkpoint_key: str
    max_attempts: int = 3


@dataclass
class SchedulerReport:
    job_name: str
    owner: str
    schedule: str
    worker_id: str
    processed: int = 0
    retries: int = 0
    dead_letter_count: int = 0
    last_checkpoint: int = -1
    backfill_mode: bool = False
    last_replayed_item: int | None = None


class BatchJobRunner:
    def __init__(self) -> None:
        self._leases: dict[str, str] = {}
        self._checkpoints: dict[str, int] = {}
        self._dead_letters: list[dict[str, object]] = []

    def acquire_lease(self, job: JobConfig, worker_id: str) -> None:
        current = self._leases.get(job.name)
        if current and current != worker_id:
            raise LeaseConflictError(f"job {job.name} is already leased by {current}")
        self._leases[job.name] = worker_id

    def release_lease(self, job: JobConfig, worker_id: str) -> None:
        if self._leases.get(job.name) == worker_id:
            self._leases.pop(job.name, None)

    def get_checkpoint(self, job: JobConfig) -> int:
        return self._checkpoints.get(job.checkpoint_key, -1)

    def dead_letters(self) -> list[dict[str, object]]:
        return list(self._dead_letters)

    def run_job(
        self,
        job: JobConfig,
        items: list[int],
        worker_id: str,
        handler,
        *,
        backfill_from: int | None = None,
    ) -> dict[str, object]:
        self.acquire_lease(job, worker_id)
        report = SchedulerReport(
            job_name=job.name,
            owner=job.owner,
            schedule=job.schedule,
            worker_id=worker_id,
            last_checkpoint=self.get_checkpoint(job),
            backfill_mode=backfill_from is not None,
        )
        start_from = backfill_from if backfill_from is not None else self.get_checkpoint(job) + 1
        try:
            for item in items:
                if item < start_from:
                    continue
                self._handle_item(job, item, handler, report)
        finally:
            self.release_lease(job, worker_id)
        result = asdict(report)
        result["dead_letters"] = self.dead_letters()
        return result

    def _handle_item(self, job: JobConfig, item: int, handler, report: SchedulerReport) -> None:
        attempts = 0
        while attempts < job.max_attempts:
            attempts += 1
            try:
                handler(item)
                report.processed += 1
                if report.backfill_mode:
                    report.last_replayed_item = item
                else:
                    report.last_checkpoint = item
                    self._checkpoints[job.checkpoint_key] = item
                return
            except SchedulerExecutionError as exc:
                if attempts < job.max_attempts:
                    report.retries += 1
                    continue
                self._dead_letters.append(
                    {
                        "job_name": job.name,
                        "item": item,
                        "attempts": attempts,
                        "reason": str(exc),
                    }
                )
                report.dead_letter_count = len(self._dead_letters)
                return

from __future__ import annotations

import unittest

from batch_scheduler_engineering.runner import BatchJobRunner, JobConfig, LeaseConflictError, SchedulerExecutionError


class BatchSchedulerEngineeringTests(unittest.TestCase):
    def setUp(self) -> None:
        self.runner = BatchJobRunner()
        self.job = JobConfig(
            name="nightly-reconciliation",
            owner="team-ops",
            schedule="0 2 * * *",
            checkpoint_key="reconcile:last-item",
            max_attempts=3,
        )

    def test_checkpoint_resume_skips_completed_items(self) -> None:
        seen: list[int] = []
        self.runner.run_job(self.job, [0, 1, 2], "worker-a", lambda item: seen.append(item))
        self.runner.run_job(self.job, [0, 1, 2, 3, 4], "worker-a", lambda item: seen.append(item))
        self.assertEqual(seen, [0, 1, 2, 3, 4])

    def test_lease_conflict_is_rejected(self) -> None:
        self.runner.acquire_lease(self.job, "worker-a")
        with self.assertRaises(LeaseConflictError):
            self.runner.acquire_lease(self.job, "worker-b")

    def test_retry_then_success_updates_checkpoint(self) -> None:
        attempts = {2: 1}

        def flaky(item: int) -> None:
            remaining = attempts.get(item, 0)
            if remaining:
                attempts[item] = remaining - 1
                raise SchedulerExecutionError("retryable")

        report = self.runner.run_job(self.job, [0, 1, 2], "worker-a", flaky)
        self.assertEqual(report["processed"], 3)
        self.assertEqual(report["retries"], 1)
        self.assertEqual(report["last_checkpoint"], 2)

    def test_dead_letter_after_retry_budget(self) -> None:
        def broken(_: int) -> None:
            raise SchedulerExecutionError("broken item")

        report = self.runner.run_job(self.job, [5], "worker-a", broken)
        self.assertEqual(report["dead_letter_count"], 1)
        self.assertEqual(report["dead_letters"][0]["item"], 5)

    def test_backfill_mode_reprocesses_window(self) -> None:
        seen: list[int] = []
        self.runner.run_job(self.job, [0, 1, 2], "worker-a", lambda item: seen.append(item))
        report = self.runner.run_job(self.job, [1, 2], "worker-b", lambda item: seen.append(item), backfill_from=1)
        self.assertTrue(report["backfill_mode"])
        self.assertEqual(seen, [0, 1, 2, 1, 2])

    def test_historical_backfill_does_not_move_normal_checkpoint(self) -> None:
        self.runner.run_job(self.job, [0, 1, 2, 3, 4], "normal", lambda _: None)
        replayed: list[int] = []
        report = self.runner.run_job(self.job, [1, 2], "review", replayed.append, backfill_from=1)
        self.assertEqual(replayed, [1, 2])
        self.assertEqual(report["last_replayed_item"], 2)
        self.assertEqual(report["last_checkpoint"], 4)
        self.assertEqual(self.runner.get_checkpoint(self.job), 4)
        seen: list[int] = []
        report = self.runner.run_job(self.job, [0, 1, 2, 3, 4, 5], "normal", seen.append)
        self.assertEqual(seen, [5])
        self.assertEqual(report["last_checkpoint"], 5)
        self.assertIsNone(report["last_replayed_item"])

    def test_backfill_beyond_checkpoint_does_not_skip_normal_work(self) -> None:
        self.runner.run_job(self.job, [0, 1, 2, 3, 4], "normal", lambda _: None)
        replayed: list[int] = []
        report = self.runner.run_job(self.job, [6], "review", replayed.append, backfill_from=6)
        self.assertEqual(replayed, [6])
        self.assertEqual(report["last_replayed_item"], 6)
        self.assertEqual(report["last_checkpoint"], 4)
        self.assertEqual(self.runner.get_checkpoint(self.job), 4)
        seen: list[int] = []
        self.runner.run_job(self.job, [0, 1, 2, 3, 4, 5, 6], "normal", seen.append)
        self.assertEqual(seen, [5, 6])
Verification

驗證要同時涵蓋邏輯、恢復與教材頁面

不只跑過一次成功路徑，還要驗 lease conflict 與失敗隔離。

回補用自己的輸入範圍，不更新例行作業的 last_checkpoint。報告另列 last_replayed_item（無成功項目時為 None）；例行作業依原游標續跑。若回補範圍跨過例行進度，兩次作業可能處理同一筆，寫入端仍須具備冪等性。

Troubleshooting

批次失敗時先看契約，再看人

大多數混亂來自缺 lease、checkpoint 或 backfill 邊界。

Best Practices

讓批次執行證據進 release note

operator 能從更新紀錄知道誰跑了什麼、失敗在哪裡、如何回補。
