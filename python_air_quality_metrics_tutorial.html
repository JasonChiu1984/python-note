1. 室內要看哪些指標？

指標與單位能幫你判斷什麼容易判斷錯的情況
CO₂ · ppm在以人員排放為主時，配合占用、室外背景及時間趨勢，作為通風線索。冷凍機房或低占用資料中心的低 CO₂ 不代表空氣中沒有粒子、氣體或其他污染。通風量不能只從單點濃度反推。
PM2.5／PM10 · μg/m³描述不同粒徑分級的顆粒質量濃度。看室內外同期趨勢、過濾器和局部來源。PM2.5 屬 PM10 涵蓋範圍，不應相加成「總顆粒」。低成本光學量測受粒徑、顆粒性質、濕度與儀器間差異影響。
溫度 · °C；相對濕度 · %RH監測熱環境、解讀 PM 與結露情境。這兩項是環境條件，不是污染物，也不代入官方 AQI。比較不同位置的 RH 時要看各點溫度。
壓差 · Pa輔助推斷氣流方向與門、濾網或房間邊界的狀態。先寫清楚 P(高壓端) − P(低壓端) 的符號與兩端位置。壓差不等於風量；門開、風機轉速和測點位置都會影響讀值。
外氣風門命令／回饋 · %解釋外氣與室內讀值變化的設備狀態，與風量、風機、時間戳一起看。風門開度不是外氣流量。命令不等於實際開度，更不能只因某個指標升降就自動調整。

感測位置與校驗

按用途選點：占用區點位用於了解典型人員活動，避開直接對著出風口、局部污染源或人員呼氣；室外比較點另設並標記防護與距離；回風點應標成混合訊號，不能冒充單一區域。查閱設備安裝要求與校正紀錄。同時記錄通訊位址、更新週期及單位轉換，例如工程值已換算就不能再乘一次比例。

CO₂ 與 PM 要交叉判讀

若室內 CO₂ 隨占用上升、室內 PM 尚穩定，先查占用、室外背景、通風量與感測位置。若室內 PM 與官方室外測站同時上升，也只是線索：先看站距、風向、時間延遲、外氣濾網與室內活動。不要從兩條同步曲線直接推論因果。

等間距與不規則資料，要分開算

本課示例是一格五分鐘，每格由一筆樣本代表，窗口共六格。有效平均 = 有效槽值總和 ÷ 有效槽數；涵蓋率 = 有效槽數 ÷ 六個預期槽。涵蓋率是本課的格點代理，不是從原始資料證明氣體在整格時間維持不變。

不規則事件：若已規定「每筆維持到下一筆」，可用 Σ(有效值 × 有效秒數) ÷ Σ(有效秒數)。每段裁進觀察窗、限制最大持有時間、遇故障或斷線截斷，超出的時間標為未知；涵蓋率另算有效秒數 ÷ 全窗秒數。

同一槽多筆需定義選樣或先做槽內平均；重送去重、亂序到達與時鐘飄移要保留記錄。最新畫面過期判斷可用「現在 − 最新有效量測時間」，與本課 CSV 的 stale 品質旗標是兩件事：舊資料重送成功不能變成新量測。

下方是可直接執行的最小核心。它示範一個合成區域，不另處理 CSV 格式；完整程式負責把時間與欄位讀入後再做檢查。

from math import isfinite
from statistics import mean

def summarize_slots(slots, minimum_coverage=0.6):
    # slots 事先按點位、時間窗和固定採樣間隔對齊。
    ok = [value for value, quality in slots
          if quality == "ok" and value is not None and isfinite(value)]
    ratio = len(ok) / len(slots) if slots else 0.0
    metric = mean(ok) if ok and ratio >= minimum_coverage else None
    return metric, len(ok), len(slots)

co2 = [(650, "ok"), (800, "ok"), (None, "missing"),
       (1200, "stale"), (1000, "ok"), (900, "ok")]
pm25 = [(6, "ok"), (12, "ok"), (None, "missing"),
        (30, "stale"), (25, "ok"), (None, "ok")]

assert summarize_slots(co2) == (837.5, 4, 6)
assert summarize_slots(pm25) == (None, 3, 6)
assert round(summarize_slots(pm25, 0.5)[0], 2) == 14.33

記錄輸出不能只有平均值：應帶參數版本、時間窗、預期格數、有效格數、最近有效時間、單位及採樣方法。若平均值不足，輸出 null 和明確原因，不用 0 代替。對不同指標的有效範圍要各自設定；開發時先用合成資料測漏格、重複、負值、NaN、次序錯亂及時間邊界。

6. 臺灣官方 AQI：外部觀測資料，不是室內自製分數

官方指標怎麼來？

環境部依測站的 O₃、PM2.5、PM10、CO、SO₂、NO₂ 等污染物濃度及各自時間基準換算副指標，取規則下最大的副指標。日值與即時發布值的統計時間和有效筆數規則不同，不能互換。

官方依據自 2025-01-01（民國 114 年 1 月 1 日）調整相關濃度門檻，本頁不抄寫門檻，也不產生官方 AQI。要解讀分類和時間規則，請查 環境部現行 AQI 說明。

怎麼放進儀表板？

從 官方空氣品質指標資料集（AQX_P_432） 讀取已發布的 AQI、測站、指標污染物、狀態及發布時間；日值另用 官方日 AQI（AQX_P_434）。保留原始資料時間與抓取時間，避免快取舊值卻仍標成即時。

站點需標「室外官方測站」；站在幾公里外也未必代表建物進氣口。找不到與時間對齊的官方資料就顯示未取得、過期或不適用。官方 AQI 不接受 CO₂、溫度、RH 或單筆室內 PM 作替代輸入。

7. 上線驗收：先組證據，再判斷設備狀態

  1. 量測驗收：核對點位、位置、單位、比例、校驗紀錄與更新間隔；確認壓差接管及符號、風門命令與實際回饋分開。
  2. 資料驗收：模擬不回報、空值、舊時間重送、品質故障與 UTC 窗口邊界；確認涵蓋率降低，告警帶資料年齡而不是把故障算成平均。
  3. 判讀驗收：把 CO₂、PM、溫濕度、占用、風量、壓差、外氣與設備維護資料沿同軸比較；保留各自單位，不把多個欄位合成不明分數。
  4. 變更邊界：此頁只做觀測、教學與人工核對。若需修改外氣控制，另評估通風要求、消防排煙、濕度與防結露、壓差、濾網及設備限制；經現場核准與獨立測試後再部署。

官方延伸：室內空氣品質標準 · 公告場所室內空氣品質檢驗測定管理辦法 · 環境部：室內通風與空調 · 環境部空氣品質監測網。本頁為資料工程教材，不是法規符合性判定或健康建議。

延伸學習：實作、現場案例與自我檢查

前面各節強調先確認資料品質再計算。本節把這個原則套到最常見的室內指標 CO2：八小時移動平均、涵蓋率判定，以及由 CO2 反推外氣量。

可實跑範例：CO2 八小時平均與外氣量估算

合成一天的會議室 CO2 資料（含 40 分鐘通訊中斷），計算截至不同時間點的八小時平均與涵蓋率，再用穩態質量平衡估算要維持 1,000 ppm 需要多少外氣。CO2 產生率 0.005 L/s/人是常用近似值，活動量不同時要調整。

下載範例 example.py

"""CO2 八小時移動平均、資料涵蓋率與外氣量估算（教學模型）。

- 室內空氣品質標準：CO2 八小時值 1,000 ppm、PM2.5 二十四小時值 35 μg/m3。
- 本例規定一個八小時窗至少要有 75% 的分鐘資料才計算平均，這是設計選擇，不是法規。
- 單一感測器的移動平均只與監測參考值比較，不能代替公告場所的法定採樣與符合性判定。
- 外氣量以穩態質量平衡估算：Q = N × G ÷ (Cin − Cout)，G 取成人坐姿約 0.005 L/s/人的近似值。
"""
from datetime import datetime, timedelta
from statistics import fmean

LIMIT_CO2_8H = 1000
MIN_COVERAGE = 0.75
CO2_GEN_LPS = 0.005          # L/s/人，近似值


def synthetic_day(start):
    """08:00–18:00 的會議室，每分鐘一筆；12:00–12:40 通訊中斷造成缺值。"""
    rows = []
    co2 = 450.0
    for m in range(600):
        t = start + timedelta(minutes=m)
        people = 0 if t.hour < 9 or t.hour >= 17 else (12 if 13 <= t.hour < 16 else 6)
        target = 430 + people * 75                      # 簡化的穩態濃度
        co2 += (target - co2) * 0.05                    # 一階逼近
        if not (t.hour == 12 and t.minute < 40):
            rows.append((t, round(co2)))
    return rows


def rolling_8h(rows, end):
    window_start = end - timedelta(hours=8)
    values = [v for t, v in rows if window_start < t <= end]
    coverage = len(values) / 480
    if coverage < MIN_COVERAGE:
        return None, coverage
    return fmean(values), coverage


def outdoor_air_lps(people, c_in, c_out=420):
    """穩態估算所需外氣量 L/s；c_in 必須高於 c_out。"""
    if c_in <= c_out:
        raise ValueError("室內濃度需高於室外，才能用 CO2 估算外氣量")
    return people * CO2_GEN_LPS / ((c_in - c_out) * 1e-6)


if __name__ == "__main__":
    rows = synthetic_day(datetime(2026, 11, 20, 8, 0))
    print(f"取樣筆數：{len(rows)}（應有 600 筆，缺 {600 - len(rows)} 筆）")
    peak_t, peak_v = max(rows, key=lambda r: r[1])
    print(f"單筆最高：{peak_v} ppm @ {peak_t:%H:%M}")
    for hh in (16, 17, 18):
        end = datetime(2026, 11, 20, hh, 0) - timedelta(minutes=1) if hh == 18 else datetime(2026, 11, 20, hh, 0)
        avg, cov = rolling_8h(rows, end)
        if avg is None:
            verdict = "資料不足"
        else:
            relation = "高於" if avg > LIMIT_CO2_8H else "未高於"
            verdict = f"{relation} {LIMIT_CO2_8H:,} ppm 監測參考值"
        shown = "—" if avg is None else f"{avg:.0f} ppm"
        print(f"截至 {end:%H:%M} 的八小時平均：{shown}，涵蓋率 {cov:.0%}，{verdict}")
    for people in (6, 12):
        q = outdoor_air_lps(people, c_in=1000)
        print(f"{people} 人、維持室內 1,000 ppm 所需外氣量：約 {q:.0f} L/s（{q * 3.6:.0f} m3/h）")

工程現場案例：會議室下午 CO2 高於監測參考值，空調箱外氣風門卻顯示全開

範例中單筆最高 1,330 ppm 出現在 15:12，但法規看的是八小時值：截至 16:00 的平均仍在 967 ppm，到 17:00 才超過 1,000 ppm。只看單筆最高值會過早告警，只看日平均又會漏掉下午的問題。

現場常見的原因是外氣風門開度與實際外氣量不一致：風門連桿鬆脫、外氣濾網堵塞，或 DDC 的最小外氣設定在下午被節能排程覆寫。CO2 推估的外氣量（12 人約 103 L/s）可以和空調箱外氣風量計或風門開度對照，找出差異。

  1. 確認 CO2 感測器裝在呼吸帶高度（約 1.1 m）、遠離出風口與門口，並記錄最近一次校正日期。
  2. 從 BAS 匯出 CO2、外氣風門開度、空調箱運轉狀態與室內人數（或門禁、會議預約）資料，時間對齊到分鐘。
  3. 用範例的 rolling_8h() 計算八小時值；涵蓋率不足的窗口標示為資料不足，不要用內插補成合格。
  4. 比對 CO2 推估外氣量與風量量測值，差異超過 20% 時檢查風門、濾網與 DDC 排程。

練習題與自我檢查

  1. 把 MIN_COVERAGE 改成 0.95 後重新執行，三個時間點的結果會怎麼變？這樣的設定合理嗎？

    看解答

    三個窗口的涵蓋率都是 92%，全部變成「資料不足」。門檻太高會讓一次短暫斷線就失去整天的判定；太低又會讓平均值失去代表性。實務上要依量測計畫或稽核要求決定，並在報表上寫明門檻。

  2. 同一間會議室若要把 CO2 控制在 800 ppm 以下，12 人需要多少外氣？

    看解答

    Q = 12 × 0.005 ÷ ((800 − 420) × 10⁻⁶) ≈ 158 L/s，約 568 m³/h，比 1,000 ppm 時多 50% 以上。可以用 outdoor_air_lps(12, c_in=800) 驗證。目標值越接近室外濃度，需要的外氣量增加得越快。

  3. 為什麼 outdoor_air_lps() 在室內濃度低於或等於室外時要直接報錯，而不是回傳很大的數字？

    看解答

    公式的分母變成零或負數，結果沒有物理意義。這通常代表感測器偏移、室外值取錯測站，或空間根本沒人。直接報錯能逼使用者先檢查資料，而不是把錯誤數字送進控制邏輯。

  4. PM2.5 的標準是二十四小時值。要把 rolling_8h() 改成 PM2.5 用的函式，需要改哪些地方？

    看解答

    窗口改成 24 小時（timedelta(hours=24)），分母改成 1,440 分鐘（或依實際取樣間隔計算應有筆數），門檻改成 35 μg/m³。若感測器是 5 分鐘一筆，分母要用 288，不能沿用分鐘數。
